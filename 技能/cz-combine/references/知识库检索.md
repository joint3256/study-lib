# 初中全科 · 知识库检索地图

> 做题前按下方步骤定位并检查素材。`LIB`、`TEXTBOOK_ROOT` 均取自本次检查结果，不沿用其他设备的绝对路径。
> 覆盖 6 科：数学、物理、化学、历史、道德与法治（道法）、语文。英语不在本技能范围。

## 定位与检查（Windows / Linux 共用）

本技能文件夹需完整复制，包含 `scripts/check_library.py`；检查只用 Python 3.8+ 标准库，仅列目录及读取文件首字节，不改写、创建、下载、搬迁或上传资料，不代表内容检索已经完成。

### 根目录规则

- 知识库：命令行 `--lib-root` 优先，其次环境变量 `CZ_COMBINE_LIB_ROOT`；两者均未设置时，检查技能实际目录（解析目录联接/符号链接）与当前工作目录及各级祖先，并检查各处的 `学习资料库`、`study-lib` 子目录。只检查这些位置，不递归扫描磁盘。
- 每个候选必须有可读且非空的 `知识清单/_编写规范与模板.md`，以及可列出的 `知识清单/初中/`、`方法套路/`。唯一候选才可选用；无候选列出所有尝试位置，多候选列出冲突位置并要求配置。根目录叫什么名字不限。
- 显式根目录必须是当前操作系统的绝对路径（可用 `~`）；空值、相对路径、其他系统的路径或不可读位置均报错，**不得退回其他副本掩盖错误**。命令行配置仅本次有效；环境变量需在运行技能的进程中可见。
- 教材库独立使用 `--textbook-root` / `CZ_COMBINE_TEXTBOOK_ROOT`；未配置时只尝试知识库的同级 `教材库/`，兼容原 Linux 布局。不能把知识库内仅存说明的 `教材/` 当成全本。
- 未配置且同级教材库缺失时报告完整位置与警告，仍可检索已验证的知识清单；显式教材库无效或 `--textbook` 指定的文件缺失时检查失败。教材缺失不影响用户附件的优先级，但附件也须实际读取后才能引用。

### 运行示例

以下示例先进入实际安装的 `cz-combine` 文件夹。示例路径需换成本机位置；整库原位使用可省略配置，直接让脚本发现。无需修改技能正文；已有 Linux 资料和教材目录也无需移动。

Windows PowerShell（包含空格/中文路径）：
```powershell
$env:CZ_COMBINE_LIB_ROOT = 'D:\学习资料\study-lib'
# 教材库不在知识库同级时，单独设置；没有全本则不要设置
# $env:CZ_COMBINE_TEXTBOOK_ROOT = 'E:\本地教材\教材库'
$json = python scripts/check_library.py --subject 数学 --require '知识清单/初中/数学/八年级下册.md'
if ($LASTEXITCODE -ne 0) { throw ($json -join "`n") }
$check = ($json -join "`n") | ConvertFrom-Json
$check.warnings | ForEach-Object { Write-Warning $_ }
$LIB = $check.lib_root
$TEXTBOOK_ROOT = $check.textbook_root
Select-String -LiteralPath (Join-Path $LIB '知识清单/初中/数学/八年级下册.md') -Pattern '勾股定理' -Encoding UTF8
```

Linux Bash：
```bash
export CZ_COMBINE_LIB_ROOT='/srv/教学资料/学习资料库'
# export CZ_COMBINE_TEXTBOOK_ROOT='/srv/教学资料/教材库'
if ! CHECK_JSON="$(python3 scripts/check_library.py --subject 数学 --require '知识清单/初中/数学/八年级下册.md')"; then
  printf '%s\n' "$CHECK_JSON" >&2
  exit 1
fi
printf '%s\n' "$CHECK_JSON"  # 保留警告与实际检查位置
LIB="$(printf '%s' "$CHECK_JSON" | python3 -c 'import json,sys; print(json.load(sys.stdin)["lib_root"])')"
TEXTBOOK_ROOT="$(printf '%s' "$CHECK_JSON" | python3 -c 'import json,sys; print(json.load(sys.stdin)["textbook_root"] or "")')"
grep -n '勾股定理' "$LIB/知识清单/初中/数学/八年级下册.md"
```

也可用 `--lib-root "本机绝对路径"` 临时覆盖环境变量；复制技能到独立的自定义技能目录且工作目录不在资料库附近时，必须显式配置。

### 检查结果与引用规则

- 标准输出是 JSON；退出码 `0` 表示本次所选检查通过，`1` 表示路径/资源检查失败（参数错误为 `2`）。Windows JSON 使用 ASCII 转义保留中文，避免旧版 PowerShell 编码损坏，解析后路径不变。`warnings` 必须展示，不能只看退出码。
- 默认检查六科；`--subject 数学` 可重复指定学科，检查该科所有册文件、方法目录内现有编号 `.md` 文件和讲法文件的非空/可读性。这不是资源完整盘点，不证明方法目录没有漏文件。
- 本题实际要使用的每个文件用 `--require '相对知识库的文件路径'` 精确检查；教材原文用 `--textbook '初中数学/人教版/人教版数学七年级上册.docx'`。参数可重复；必须在根目录内，不接受绝对路径或越界路径。通过后还须读取并定位相关内容；文件若随后丢失或读取/解析失败，也要报告实际路径，不能继续声称已引用。
- 检查失败、缺少 Python 或无本地文件访问能力：明确列出已知配置/尝试位置、缺失项和未完成检索的原因；请用户修正配置或提供附件。可继续模型讲解，但标注「知识库未完成检索，以下为模型总结」。
- 区分三种结果：**知识库不可用**（检查/读取失败）、**检索完成但无相关内容**、**教材全本不可用但知识清单可用**。只有实际读取了对应片段，才能标注该文件/章节为来源；知识清单不得冒充课本原文。
- 六科专精中的既有“命中证据”是编写时的例子，不是当前设备已检索的证明。所有 `$LIB/...` / `$TEXTBOOK_ROOT/...` 都表示相对已验证根目录的路径；Bash 可直接用此记法，PowerShell 使用 `Join-Path`，Python 使用 `pathlib.Path`。

## 三、分科检索顺序
1. 判科、定册：由题目考点确定学科与年级册次、单元/章关键词。
2. 取知识：grep 对应册 `知识清单/初中/<学科>/*.md`，取概念/公式/史实/观点/语文知识、考点、易错原文。
3. 取方法：按题型 grep `方法套路/...` 对应文件，取模型步骤、快解或答题模板。
4. 取讲法：需要大白话/口诀/比喻时查对应讲法话术文件。
5. 取课本原文：实际读取用户附件 docx 或检查后的本地教材文件；都没有则明确报告不可用位置，用已读到的知识清单并标注文件/章节来源，不声称引用课本原文。

Bash 检索示例（先完成上述检查并设置 `LIB`；Windows 对应使用 `Select-String -LiteralPath (Join-Path $LIB '相对路径') -Pattern '关键词'`）：
```bash
grep -n "商鞅变法"        "$LIB/知识清单/初中/历史/七年级上册.md"
grep -n "材料"            "$LIB/方法套路/历史/初中/07_历史材料题通用答题模板.md"
grep -n "社会主义核心价值观" "$LIB/知识清单/初中/道法/九年级上册.md"
grep -n "说明方法"        "$LIB/方法套路/语文/初中/04_现代文_说明文阅读.md"
grep -n "欧姆定律"        "$LIB/方法套路/物理/初中/10_电学_欧姆定律与串并联.md"
```

## 四、读取教材 docx（python-docx）
```python
from docx import Document
doc = Document(path)          # 用户附件或教材库中的 .docx
paras = [p.text for p in doc.paragraphs if p.text.strip()]
for t in doc.tables:          # 表格
    for row in t.rows:
        [c.text for c in row.cells]
```
按单元/章标题定位片段，只引用与本题相关的段落；读不到全文时如实说明，不编造原文。
