# 语法填空：有提示词/无提示词套路

---

## 方法：语法填空"分类解题法"

### ① 方法名
语法填空两大类解题法（有提示词/无提示词）

### ② 适用题型
高考英语语法填空（15分，10题）

### ③ 原理（语法 form 与意义 use）

**题型本质：** 语法填空 = 一篇短文里挖10个空，要么给提示词，要么不给。

**两大类：**

**一、有提示词（约6-7题）：**
给一个词，让你变形。考的是：
- 动词：时态/语态/非谓语
- 名词：单复数/所有格
- 形容词/副词：词性转换/比较级最高级
- 代词：格的变化

**二、无提示词（约3-4题）：**
不给词，让你填一个虚词。考的是：
- 冠词（a/an/the）
- 介词（in/on/at/of/to/for...）
- 连词/从句引导词（that/which/who/when/where/if/because/although...）
- 代词（it/they/them/...）

### ④ 操作步骤

**有提示词的题：**
1. **第一步：判断给的词是什么词性**
2. **动词 → 考什么？**
   - 句中有没有其他谓语动词？→ 有 → 非谓语；没有 → 谓语
   - 谓语 → 看时态（时间标志词）+ 主谓一致 + 主被动
   - 非谓语 → 看逻辑主语和动词的主被动关系 + 时间先后
3. **名词 → 看要不要变复数**（前面有数字/many/a few...）
4. **形容词/副词 → 看词性转换**（修饰名词用形容词，修饰动词/形容词用副词）
5. **代词 → 看格的变化**

**无提示词的题：**
1. **第一步：判断空格前后的关系**
2. **空格后是名词，前面没有冠词/物主代词 → 填冠词**（a/an/the）
3. **空格后是名词/动名词，前面没有动词 → 填介词**
4. **空格前后是两个完整句子 → 填连词/从句引导词**
5. **空格在主语/宾语位置，没有提示词 → 填代词**

### ⑤ 例题完整演示

**题干片段：**
Last year, I ______ (visit) my grandparents in the countryside. The farm was very beautiful. There ______ (be) many flowers and trees. I enjoyed ______ (I) there.

**分析：**
1. 第一空：Last year → 一般过去时 → visited
2. 第二空：many flowers and trees → 复数 → were（过去时）
3. 第三空：enjoy oneself → 我自己 → myself

**答案：visited; were; myself**

**无提示词例题：**
It is ______ interesting book. I read it twice.
→ 空格后 interesting book，单数可数名词，interesting 元音开头 → an

**答案：an**

### ⑥ ❌ 易错提醒
- **动词题先判断是谓语还是非谓语**——一个句子只能有一个谓语动词（并列谓语除外）
- **非谓语题：先找逻辑主语，再判断主被动**
- **无提示词题：两个完整句子之间必须有连词**——没有连词就填连词
- **冠词题：泛指用 a/an，特指用 the**
- **介词题：固定搭配要积累**——look forward to, be interested in, be good at...
