## 🎯 使用建议

1. **基础薄弱生**：先从初中语法类开始，一个方法练熟再练下一个。每个方法配5-10道题巩固。
2. **刷题时**：先判断这道题考哪个方法，再调用对应步骤，不要凭语感蒙。
3. **错题本**：把错题按"方法名"分类整理，同一个方法错了多次，说明这个方法没掌握。
4. **讲题时**：按六块结构讲——先讲方法名，再讲为什么（原理），再一步步演示，最后提醒易错点。
