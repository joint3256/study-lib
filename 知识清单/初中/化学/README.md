# 初中化学 · 知识清单（人教版，按 2022 课标修订 2024 新版）

> 用途：天津线上家教给**基础薄弱学生**讲题、查缺补漏、快速定位知识点。
> 版本：初中化学为**九年级**开设，共两册（九年级上册、九年级下册）。
> 编写依据：《义务教育化学课程标准（2022 年版）》+ 人教版 2024 新版教材目录。**章号以教材目录为准**，本清单按主题组织。

合计 **12 个单元（章）**，每个单元下固定六要素：
一、本章知识结构；二、核心概念（通俗→严谨）；三、定理、公式与结论；四、公式推导要点与常用模型；五、考点与典型题型·方法；六、易错易混。

## 各册单元速查

### 九年级上册
1. 第一单元 走进化学世界（物理/化学变化与性质、基本实验操作）
2. 第二单元 我们周围的空气（空气成分、氧气性质与制取）
3. 第三单元 物质构成的奥秘（分子原子、原子结构、元素）
4. 第四单元 自然界的水（水资源与净化、水的组成、化学式与化合价）
5. 第五单元 化学反应的定量关系（质量守恒定律、化学方程式及计算）
6. 第六单元 碳和碳的氧化物（碳单质、二氧化碳制取与性质、一氧化碳）
7. 第七单元 能源的合理利用与开发（燃烧与灭火、化石燃料、新能源）

### 九年级下册
1. 第八单元 金属和金属材料（金属材料、金属化学性质与活动性顺序、金属资源利用保护）
2. 第九单元 溶液（溶液形成、溶解度与溶解度曲线、溶质质量分数）
3. 第十单元 酸和碱（常见酸碱、酸碱通性、中和反应、pH）
4. 第十一单元 盐 化肥（常见盐、复分解反应、化学肥料、粗盐提纯）
5. 第十二单元 化学与社会（六大营养素与健康、材料分类、环境保护）

## 检索提示（给家教）
- **查缺补漏**：先按"册 → 单元 → 六要素"定位；概念不清看"二、核心概念"，记结论看"三"，套方法看"四/五"，防错看"六、易错易混"。
- **方程式**：全部集中在"三、定理、公式与结论"，已配平并注明条件与 ↑↓。
- **计算题范例**：高锰酸钾制氧计算（九上第五单元）、含杂质炼铁（九下第八单元）、溶质质量分数与稀释（九下第九单元）均可直接照步骤讲。
- **超纲说明**：未引入电离平衡、摩尔等高中内容；"拓展/选学"处已避免。
