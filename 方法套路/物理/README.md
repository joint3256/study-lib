## 覆盖范围

光的反射折射与凸透镜成像、受力分析与二力平衡、惯性、固体压强、液体压强与大气压、浮力（阿基米德/浮沉/称重法测密度）、功功率与机械效率、杠杆与滑轮、比热容与热量、欧姆定律与串并联、电功电功率与电热、电路故障与动态分析。
