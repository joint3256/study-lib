# 最严格核对清单（交付前强制 · 逐字逐图 · 不靠印象）

> 这是 tiqu-extractor 的**强制交付门**。目标是成品与原始照片"题目和配图完全一样、
> 不多加也不减少"。每一次提取都必须走完本清单，不允许"看着差不多就发"。

## 〇、铁律
1. **原始照片是唯一权威**；extract.json、Word、PDF、页面 PNG 全部是被检查对象。
2. **不靠印象、不凭"应该"、不凭记忆**：每一项都要把"原照片"和"成品"同时摆在
   眼前逐一对；对的是"每个字符、每根线"，不是"读个大概意思"。
3. **逐项打勾并记录实际结果**；看不清就裁块、放大；仍拿不准的标"待用户确认"，
   不猜、不臆造。
4. **改任何一处，都必须重跑"生成 Word → 转 PDF/页 → 重新核对"全流程**，并回看
   受影响位置的前后页；禁止"只改一处、其余默认没问题"。
5. 机检 0 错误 + 逐字、逐图、逐页三关全部通过，才允许交付；否则继续改。

## 一、机检先行（两道脚本，先把能确定的错误清零）
1. `python3 scripts/verify_extract.py extract.json`
   - **ERR 必须清零**（文件缺失、JSON 非法、题号重复等）；
   - **CHECK 逐条调出原照片确认并记录**（题号断档、疑似多加空格、括号内文字、填空缺空位等）。
2. `python scripts/verify_docx.py extract.json <成品.docx>` → 退出码 0，且 JSON 报告 `ok: true`。检查文字、选项及嵌入图片与提取数据一致；本脚本随技能携带，不需另找 `audit.py`。
3. 记录并与原卷逐项对数：题目总数、选择/填空/解答各几题、配图数、各配图宽高比。

## 二、逐字核对（每一道题，从左到右看"字符"）
- [ ] 题号连续、无漏题无重号；大题标题文字与原卷一致（含"共 X 分"）。
- [ ] 题干一字不多、一字不少；**原卷没有的说明句不得自行补入**（如"解答应写出…"）。
- [ ] 全部选项都在、顺序对、文字一致；选项数量与原卷相同。
- [ ] 每一**小问、分值**（如（6分））齐全。
- [ ] **空格（高频错）**：原卷中文与符号/数字紧贴时，不得加半角空格。典型对照：
      "在△ABC中""线段AD""15cm""BC=12""12小题""18米"。运算符两侧、数字与
      单位之间，一律以原卷为准。
- [ ] **标点（高频错）**：句末句号/问号/分号的有无与原卷一致；特别注意选择括号
      之后是否带句号，如"（　）。"。
- [ ] 运算符与符号看清：=、全等 ≅、相似 ∽、平行 ∥、垂直 ⊥、不等 ≠、比号 ∶、
      度 °、上下标；易混字符 0/O、1/l、6/b、5/S。
- [ ] **空位**：选择括号内必须为空；填空下划线的数量、长度与原卷一致，未填答案。

## 三、逐图核对（每一张配图，按"点 → 线 → 关系"逐项对）
> 把原照片里该图裁出放大，与重画配图并排；不要看"整体像不像"，要逐个元素对。
- [ ] 每个点的左右、上下相对位置与原卷一致；点字母齐全，且标在与原图**相同的
      方位**（字母在点的哪一侧也要对）。
- [ ] **线段连接关系**：哪两点相连、每条线止于哪个点、端点有无出头，逐一对。
- [ ] **交点**：落在哪条边/线的什么位置；两线到底交叉还是不交叉；交点字母位置。
- [ ] 实线/虚线分清（辅助线、延长线、立体不可见边）；直角符号、角弧、等长刻度、
      箭头的有无与位置正确。
- [ ] 角度观感、边长比例、平行/垂直关系正确（重画画布必须等比例）。
- [ ] 阴影/填充/网格的区域与边界一致；并列多图（如"下面四个图"）每个子图形态、
      编号 A/B/C/D 都对。
- [ ] 函数图：坐标轴、箭头、刻度标签、关键点（截距/顶点/交点）、曲线趋势准确。

> 实测曾抓到、以后**必查**的典型错误：① 漏画一条竖直实线、把斜虚线误画成水平；
> ② 把本来**不相交**的两条线画成相交、且线段在端点后多出一截；③ 交点字母方位
> 放反（左上误标右上）。遇到这类图必须先把题的真实几何弄清再重画。

## 四、逐页核对（把 PDF 每页渲染出来看）
- [ ] 每页题数、题号、配图与原卷对应，无错版。
- [ ] 全卷**无任何手写**：答案、勾叉、分数、草稿演算、手绘线条与小图。
- [ ] 无**多加**（空格、说明句、多余线条）也无**减少**（漏字、漏图、漏选项）。
- [ ] 跨页处题干与配图内容完整、未被裁切；若用户要求图文同页则调整排版。
- [ ] 页面 PNG 干净、清晰、无黑边、无水印或二维码残留。

## 五、必须向用户说明的边界（不得承诺"像素完全一样"）
- 干净版是"理解后重画、重排"：**逐字逐图一致是核对目标，不能仅凭机检通过就宣称已达到**；字体
  渲染、字距、换行位置、分页、填充纹理（如斜线网格 vs 纯色）、线宽等**排版像素
  无法与照片完全相同**。
- 要像素级一致只能用原照片（含手写）；要"干净无手写"就必然是重绘。
- 手写压在印刷线上、或模糊无法判定的地方，明确标出请用户确认，不猜、不补。

## 六、交付记录（每次填写，随结果一起给出）
- 原照片页数 / 成品页数：
- 题目数（选择 / 填空 / 解答）：
- 配图数；本次重画并修正了哪几张、各改了什么：
- verify_extract 的 ERR/CHECK 结果；verify_docx 结果：
- 仍待用户确认的项目：
