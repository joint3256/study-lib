## 每章结构（六要素，标题固定）

每章 `## 第N章 章名` 下依次为：
1. `### 一、本章知识结构`（树形图＋节次）
2. `### 二、核心概念（通俗→严谨）`（物理量写符号/单位/标矢量）
3. `### 三、定理、公式与结论`（LaTeX，注方向、单位、条件、常数）
4. `### 四、公式推导要点与常用模型`
5. `### 五、考点与典型题型·方法`（题型→步骤→范例，可算出）
6. `### 六、易错易混`（❌/✅ 成对）

## 检索提示（给家教老师）

- **基础薄弱学生先讲**：受力分析（必修一第三章）→ 牛顿第二定律动力学两类问题（必修一第四章）→ 动能定理/机械能（必修二第八章），这是力学主干。
- **查缺补漏顺序建议**：先翻每章"六、易错易混"对照学生错题，再回到"二、核心概念"补基础，最后用"五、典型题型"练手。
- **公式速查**：直接定位"三、定理、公式与结论"。
- **矢量方向类错误最多**：力学、电场、磁场题目一律"先定正方向/用左手定则"。
- 必修为全体学生要求；选择性必修为选考内容，按学生选科情况使用。

## 统一约定

- $g=9.8\,\text{m/s}^2$（题目另给"粗略计算 $10$"时按题目）。
- 元电荷 $e=1.60\times10^{-19}\,\text{C}$；静电力常量 $k=9.0\times10^9\,\text{N}\cdot\text{m}^2/\text{C}^2$；引力常量 $G=6.67\times10^{-11}\,\text{N}\cdot\text{m}^2/\text{kg}^2$；普朗克常量 $h=6.626\times10^{-34}\,\text{J}\cdot\text{s}$；真空中光速 $c=3.0\times10^8\,\text{m/s}$；$N_A=6.02\times10^{23}\,\text{mol}^{-1}$。
- 章号、节号均"以教材目录为准"，未臆造。
