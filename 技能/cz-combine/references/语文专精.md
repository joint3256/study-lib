## 一、本科定位与思维纹理

语文是「读写一体、按点给分」的科目，跟数理化最大的不同是：它没有唯一标准答案，但每道主观题都有固定的**采分点**。中考语文的能力线是四条：

1. **基础线**（字音字形、词语成语、病句、标点、文学文化常识、默写）——靠逐条判定，判定时必须说清理由，不能凭语感蒙。
2. **古诗文线**——文言实词虚词、特殊句式、翻译、古诗词鉴赏、理解性默写。翻译口诀统一用「留删补换调」；默写丢分八成错在**看错提示词、写错字**。
3. **现代文阅读线**——记叙文、说明文、议论文、非连续性文本四类，各有各的答题范式。通用总纲是「三层答题」：**内容层（写了什么）→ 手法层（怎么写的）→ 情感/主旨层（为什么写）**，按 1、2、3 列点，阅卷按点给分。
4. **作文线**——审题立意 + 结构提纲 + 开头结尾 + 细节片段；草稿快解靠「万能结构、三句开头、三类素材」。

这一科「怎么想」：先判断题型，再调对应模板，再回原文找词句，最后分点表述。**不能空着感觉写，也不能整句照抄原文**。

## 二、科目识别与版本册次

**如何判定这是语文题**：出现拼音/错别字/词语辨析/病句/标点选择；出现文言文断句翻译/古诗词赏析/名句默写；出现「概括内容、赏析句子、分析人物、说明方法、论证方法、谈谈主旨」；或出现命题/半命题/材料作文要求。据此即可路由到本科。

## 四、核心模型 / 答题模板库（题型 → 识别信号 → 模板步骤）

> 每条标注对应 LIB 方法套路文件，便于回查完整例题。

### A. 基础知识（对应 `01_基础知识_字音字形词语病句标点.md`）

- **字音字形「读半边+记声旁」**：识别＝「注音/字形完全正确的一项」。步骤：看形旁猜义 → 声旁只作参考 → 形近字成对记（燥/躁、辍/缀/掇）→ 拿不准手写一遍。
- **多音字形据义定音**：识别＝同字不同词读音。步骤：先判书面/口语，再判词义，音随义转（薄 báo 口语 / bó 书面 / bò 薄荷）。
- **词语成语「四看」**：识别＝选词填空、成语使用恰当。四看＝看词义轻重、看使用对象、看感情褒贬、看搭配与重复。
- **病句「主干压缩」判型**：识别＝「没有语病的一项」。步骤：找谓语动词 → 找主语 → 找宾语 → 念主干通不通 → 再看枝叶。
- **病句「七看」快排**：看两面词（能否/是否）、看介词开头（通过/经过/由于…使）、看动词、看关联词、看并列成分、看数量词（大约/左右/倍数）、看否定词（不/防止/避免）。
- **标点「引号句末点号位置」**：完整引用句号在引号内；作句子成分时句号在外；省略号不与「等」连用；概数之间不用顿号。
- **文学文化常识「时代+流派+代表作」锚点**：每个作家记三个锚——朝代、流派/风格、课本代表作。
- **句子排序「首尾句+关联词」**：首句不能有代词/关联词；找「这/那/他」的上家；按时间或逻辑排。
- **对联仿写「字数+结构+对仗」**：字数相等、词性相对、主题相关；例句用什么修辞，仿写也用什么。

### B. 古诗文（对应 `02_古诗文_文言文阅读与古诗词鉴赏.md`）

- **文言实词「组词+迁移」**：识别＝解释加点词。把单字组现代双音节词，代入原文；组不通就迁移到课本同字用法。
- **虚词「之其而以于」**：识别＝同虚词不同用法比较。之（代词/的/去往/取消独立性）、其（他的/大概难道）、而（并列/承接/转折/修饰）、以（用凭按/来）、于（在/从/向/比）。用代入法。
- **词类活用识别**：名词/形容词跑到动词位置即活用（洞其中＝打洞；犬坐＝像狗一样；苦其心志＝使…痛苦；异之＝认为…奇怪）。
- **特殊句式「倒装四式」**：宾语前置（何陋之有＝有何陋）、状语后置（战于长勺＝在长勺作战）、定语后置（马之千里者＝千里马）、主谓倒装；判断句加「是」，被动句加「被」。
- **文言断句「找名词+找虚词+找对称」**：名词前后断；夫/盖/若夫/故在其前断；曰/云后断；对称结构两边断；限断几处就断几处。
- **句子翻译「留删补换调」五字诀**：留（人名地名官名书名）、删（无实义虚词）、补（省略的主语宾语）、换（单音节换双音节、古今异义、通假、活用）、调（倒装调回语序）。每个加点词都是得分点。
- **古诗词「意象—意境—情感」三步**：找意象 → 拼意境（萧瑟凄凉/雄浑壮阔/恬静优美）→ 推情感。套句：「通过描写……意象，营造了……意境，表达了诗人……情感。」
- **古诗词炼字「释义+描绘+效果+情感」**：先释义，再描画面，点修辞（拟人/比喻/化静为动），落情感。
- **理解性默写「抓提示词+防错字」**：圈提示词 → 定位诗句 → 盯易错字（罔≠惘、雁≠燕、腊≠蜡）。

### C. 现代文·记叙文（对应 `03_现代文_记叙文与文学作品阅读.md`）

- **内容概括「谁+干什么+结果」**：识别＝概括主要内容/梳理情节。一句话串起，20~30 字，多件事分点。
- **词句赏析「手法+内容+情感」三步**：识别＝画线句/加点词赏析。步骤：点手法（修辞/描写/关键词）→ 说内容（写出什么景象/状态）→ 点情感。套句：「运用了……手法，生动形象地写出了……，表达了……。」
- **人物形象「事件+描写+性格」**：识别＝分析人物形象。每点＝性格词 + 原文事例，只写形容词不举例不给分。
- **标题作用「内容+结构+效果」三层**：内容（概括什么/点明主旨）、结构（线索/悬念/呼应）、效果（修辞/吸引读者）。
- **段落作用「开头/中间/结尾」位置法**：开头总起设悬念引下文；中间承上启下推动情节；结尾总结点明主旨照应开头。
- **记叙顺序与线索**：顺叙/倒叙（设悬念）/插叙（补充交代）；线索找标题和反复出现的物/情/事。
- **表现手法判别**：对比/衬托/欲扬先抑/象征/借景抒情/托物言志，与句子层面的修辞区分开。
- **环境描写作用「四要素」**：交代背景、渲染气氛、烘托人物心情、推动情节（为下文铺垫）。
- **句段含义「表层+深层+情感」**：先字面义，再挖比喻义/象征义（挂钩主旨），后点情感道理。
- **主旨情感「找首尾+找反复句」**：看首尾议论抒情句、找反复出现的词句、看标题含义。

### D. 现代文·说明文（对应 `04_现代文_说明文阅读.md`）

- **说明对象及特征「找中心句+段首句」**：看标题、开头段、各段段首句。
- **说明顺序「时间/空间/逻辑」**：找标志词；逻辑顺序最常考（由主到次、由现象到本质、由整体到局部）。
- **说明方法及作用「方法+内容+效果」**：九种（举例子、列数字、作比较、打比方、分类别、下定义、作诠释、列图表、摹状貌），各配固定作用词。套句：「运用了××说明方法，××地说明了说明对象××的××特征。」
- **说明文语言「加点词能否删/换」四步**：表态不能删 → 解词（表什么限制）→ 说原句意思 → 删后太绝对与事实不符 → 点「体现说明文语言准确严密」。
- **材料链接「材料+原文+结论」**：读材料抓核心 → 回原文找对应 → 结合作答、分点、有正向结论。

### E. 现代文·议论文与非连续性文本（对应 `05_现代文_议论文与非连续性文本.md`）

- **中心论点「位置+标志词」**：论点必须是完整判断句；找标题/开头/结尾/「所以可见总之」后。
- **论据类型与补写**：事实论据（事例/数据）、道理论据（名言/原理）；补写须与论点一致、典型、简洁。
- **论证方法及作用「四法」**：举例论证/道理论证/对比论证/比喻论证，各配固定作用词，就近找被证明的分论点。
- **论证思路「首先—其次—最后」**：按「提出问题—分析问题—解决问题」分层，点出每层用的论证方法。
- **议论文语言「严密性」**：与说明文「能否删」套路一致，落脚点改为「体现议论文语言的严密性」。
- **非连续性文本信息筛选**：题干划关键词 → 回原文定位比对 → 警惕偷换概念/以偏概全/无中生有；「根据材料」不用课外知识。
- **图表解读「标题+数据+趋势+结论」**：看标题、看坐标图例、读最高最低与趋势、分点写结论。

### F. 作文（对应 `06_作文_中考写作模板与素材.md`）

- **审题立意「抓题眼+补隐藏要求」**：圈题眼（形容词/动词），补三要求——写「我」的亲身经历、有成长感悟、积极向上；半命题先补题、补的词即题眼。
- **选材「小真细新」**：写小事、写真事、加细节、角度新；避开送医院/送伞/考试失利三件套。
- **结构「总分总/并列/递进/小标题」**：基础弱先用总分总；字数分配约开头 100、中间 400、结尾 100。
- **开头三式**：开门见山 / 环境烘托 / 引用；结尾两式：呼应开头 + 升华道理。
- **细节「动作+神态+语言」三镜头**：用一连串动词、一个眼神表情、一句具体的话把人写活。
- **素材速用「成长/亲情/感悟」三主题**：考前备 3 个自己的真实故事，各配一个细节物件、一个触发瞬间、一句升华句；只备素材不背整篇范文。

### G. 名著导读·综合性学习（对应各册 `板块四`）

- **名著考查「人物+情节+主题」锚点**：考《朝花夕拾》《西游记》《骆驼祥子》《海底两万里》《红星照耀中国》《昆虫记》《傅雷家书》《钢铁是怎样炼成的》等统编推荐篇目时，每部记三件事——主要人物是谁、核心情节一两件、作者借此表达什么。
- **综合性学习/口语交际**：材料探究题按「读材料—找共性—下结论」三步走；转述信息要保留关键时间地点人物，不改原意。
- **跨学科/图文转换**：见第一节基础知识「图文转换三要素」——读标题、读数据/画面、写结论。

## 五、快解 / 速判（草稿快解，仅草稿禁上卷面）

- **病句一把梭**：拿到句子先找两面词「能否/是否」、介词开头「通过…使…」、否定词「防止…不再」——三者其一几乎必有病；「大约…左右」「下降了一倍」直接判重复/不合逻辑。
- **成语不认识就看三样**：用错对象（美轮美奂只形容房屋、汗牛充栋只形容书）、褒贬颠倒（处心积虑贬）、望文生义（不刊之论＝不可改动，不是不能登）。
- **文言词看不懂就组词**：单字组现代双音节词，代进原文顺不顺；再不懂就想课本里同一句。
- **翻译先抓加点词**：每个加点词必译，缺一个丢一个点；倒装句先掰语序再逐字。
- **阅读主观题一律分三点**：手法/方法 1 分、内容 1 分、情感/效果 1 分；只写「生动形象」不给分，必须写出把什么比作什么、写出了什么。
- **默写最后三秒盯易错字**：罔/惘、雁/燕、腊/蜡、竞/竟、长/常。
- **作文列提纲再起笔**：题眼词 → 一件小事 → 一个触发瞬间 → 一句升华，四段够用。

## 六、高频易错 / 易混清单（错例 → 正解）

- 术语串科：说明文「打比方」与记叙文「比喻」是同一手法在不同文体的叫法，别在说明文里写「比喻」、在记叙文里写「打比方」。
- 论证方法 vs 说明方法：议论文叫举例论证、道理论证；说明文叫举例子、作比较；不可互套。
- 赏析空泛：只写「用了比喻，生动形象」（错）→ 必须写出把什么比作什么、写出了什么状态、表达了什么情（对）。
- 人物形象只贴标签：只写「他很善良」（错）→ 性格词后必须配原文一件事（对）。
- 含义题当作用题答：含义题答「表层+深层+情感」；作用题答「结构+内容+效果」，二者不可混。
- 病句「通过…使…」：同时出现必缺主语，删其一（对）。
- 两面词：「能否努力是取得好成绩的关键」两面对一面（错）→ 后句也要加「能否」。
- 下降/缩短用倍数：「缩短了一倍」（错，下降不能用倍数）→ 用分数或百分数。
- 否定不当：「防止不再发生」＝让它发生（错）→ 删「不」。
- 文言古今异义硬套现代义：「妻子」是妻子和儿女、「绝境」是与世隔绝之地（对）。
- 《论语》不是孔子本人写的（是弟子及再传弟子记录）；《世说新语》是刘义庆组织门客编写（对）。
- 默写错一字整句零分：写完必回读一遍核对易错字。
- 作文跑题：写「我今年 15 岁长大了」是字面长大（错）→ 要写心理/责任上的蜕变与触发瞬间（对）；不要写名人伟人，要写「我」的生活。

## 七、名师大白话讲法 / 口诀 / 比喻（指向讲法话术文件）

> 完整话术与公开来源链接见 `$LIB/方法套路/语文/初中/讲法话术_语文.md`。

- **三层答题总口诀**：阅读题逃不出三层——作者写了啥、用啥写的、为啥这么写；按 1、2、3 列清楚，阅卷按点给分。
- **翻译五字诀**：留（人名地名不翻）、删（没用的语气词删掉）、补（缺的主语补上）、换（难词换现代词）、调（倒装句掰正）。
- **句子像一棵树**：主干是「谁+干什么+什么」，把树叶（定语状语）剪掉看树干；「精神浮现」这种抽象词配具体动作，准是搭配不当。
- **赏析别一上来就写生动形象**：先告诉老师这个词啥意思、把啥比作啥、写出了啥、最后让作者啥心情。
- **人物只写形容词不给分**：从哪件事、哪句话看出他这个性格，性格词 + 原文事例缺一不可。
- **作文首尾是黄金评分点**：开头三句内点题别绕，结尾把开头那个意象（灯/粥/伞）再写一遍、升华一下，别喊口号。
- **考前不背整篇范文**：撞题就完；备 3 个自己的真实故事，考场换个开头结尾就能用。

### 7.1 网上名师招牌套路（精选·署名·已甄别）

> 本节只收「本地方法套路 01~06 里没有、确有增量」的公开讲法。凡本地方法套路已有的（翻译五字诀、人物形象、加点词能否删、论证思路、古诗词意象炼字、作文审题首尾等）一律不重复列入，直接调用本地对应方法号，见本节末尾「已覆盖不重复」清单。术语与统编教材、2022 版语文课标一致；答题一律回原文找词句，作文不偏题。数十年公共方法（如翻译五字诀）不归属任何真人；公开短视频页未显示老师实名的，只标「平台公开讲法」与链接，不编「某名师说」。

- **套路名：课外实词「三招补断」——形旁定类·成分定词性·同音通假**
  - 来源：平台公开讲法（抖音《期末考前抢分，课外文言文做题技巧》 https://www.iesdouyin.com/share/video/7650435442684218630 ；老师实名未在页内显示，不署名到个人）。是本地 `02-1 组词+迁移法` 的课外补招，不是另起炉灶。
  - 怎么操作：先按本地 02-1 走「组词→代入→课本迁移→上下文猜」四步；这四步还推不出时，再补三招——①看形旁猜大类（"氵"旁多与水有关、"讠"旁多与言语有关，只定大概方向不写死）；②看句法成分定词性（这个字放在主语/宾语位置还是谓语位置，跑到谓语位置往往就是词类活用，如"洞其中"的"洞"由名词动用＝打洞）；③猜同音通假（字音相近又讲不通时，想想它通哪个常用字，如"不亦说乎"的"说"通"悦"）。
  - 原理（为什么）：组词、迁移、语境这三招本地 02-1 已讲透；真正卡住课外实词的，是那些组词组不通、课本又没见过的字。形旁是汉字造字时留下的义类线索，句法位置是文言语法留下的词性线索，同音通假是古人写别字的常见现象——这三招把"蒙"变成有依据的推断。
  - 适用：课外文言文「解释加点词」、翻译里 02-1 三招推不出的冷门实词。局限/坑：形旁只定大类、不能定具体义，最终还要代回原文读通；通假是最后一招，别一上来就猜通假；古今异义（"妻子""绝境"）仍要单独记，这三招套不上。

**已覆盖不重复（本地方法套路已有，7.1 不再单列，讲题直接调本地方法号）：**

- 翻译「留删补换调」五字诀 → 本地 `02-6`（初中通用公共方法，不归属真人）。
- 人物形象「事件+描写+性格」（含"性格词+原文事例"、概括型只答词/分析型配事例）→ 本地 `03-3`。
- 说明文/议论文「加点词能否删」四步（表态→解词→删后后果→点准确严密）→ 本地 `04-4`、`05-5`。
- 议论文「论证思路」分层串联（提出问题—分析问题—解决问题，首先/其次/最后）→ 本地 `05-4`。
- 古诗词「意象—意境—情感」三步＋炼字「释义+描绘+效果+情感」→ 本地 `02-7`、`02-8`。
- 现代文「题干关键词回原文定位」→ 本地 `05-6`（非连续性文本）；主观题"回原文找词句"已写入本文件第三节解题思路，不单列。
- 作文「抓题眼+补三要求」＋开头三式/结尾两式点题 → 本地 `06-1`、`06-4`、`06-5`。

### 7.2 已剔除的「大招/秒杀」及原因

> 以下几类在短视频平台常见，但不进入本技能的讲法库，也不进「规范解答」。讲题遇到时，要告诉孩子这些为什么不能用。

- **摒弃 「万能赏析模板」只填套话、不写具体内容**：如"运用了比喻的修辞手法，生动形象地写出了……，表达了作者……"，但空着不写把什么比作什么、写出了什么状态。抖音自己的讲题视频（https://www.iesdouyin.com/share/video/7641516727746006299 ）都承认"你要这样写经常会扣一两分"。剔除原因：只记结论不讲原理、换文本就错；与"答题必须结合原文词句、写出具体内容"的中考给分点直接冲突。
- **摒弃 「万能开头/万能结尾」辞藻堆砌**：如"时光匆匆，岁月如梭""成长是一场无声的远行，不必追赶日月……"这类不扣题眼、放哪篇都能用的语段。人民网 2020 年《套路作文能应付当下考试》一文专门批评此类拼凑（http://edu.people.com.cn/n1/2020/0810/c1053-31816429.html ）；公开讲法（https://www.iesdouyin.com/share/video/7677572634539740443 ）也提到：四川遂宁 2025 中考《奋进》题约三成考生用"时光匆匆，我在成长中学会奋进"开篇，被定为模板化作文、基准分压到三类文。剔除原因：玄学套话、与题眼无关、阅卷反套路；属于"只背结论不讲原理"。
- **摒弃 「99% 考 / 秒杀满分 / 听话照做不低于 45 分」营销话术**：如短视频里"初一期末 99% 考人物类阅读，套模板直接秒""一套万能思路全覆盖"。剔除原因：夸大适用范围、制造焦虑，且故意隐去前提（必须回原文找词句、必须结合文本）；这不是方法，是卖课话术，不能讲给基础薄弱的孩子当教条。
- **摒弃 「背整篇范文上考场」**：把别人写好的整篇记叙文背下来硬套。剔除原因：适用极窄——题材一旦不对就全盘皆输、还可能被判雷同卷；与本技能"考前不背整篇范文、备 3 个自己的真实故事"的口径冲突；只记结论，不讲"审题—选材—点题"的原理。
