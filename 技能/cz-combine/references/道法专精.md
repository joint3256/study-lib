## 一、本科定位与思维纹理

**学科本质。** 道法不是靠背年代、背公式拿分的课，它是一门「**用教材上的关键句，去判断和解决现实情境问题**」的课。一道题给你一段时政新闻、一个生活冲突、一条法律案例，要你说出它体现了什么道理、为什么、该怎么做。阅卷按点给分，一个采分点 =「**教材观点一句 + 材料对应一句**」，缺一条腿都扣分。

**中考怎么考。**
- 选择题：占分高，考概念辨析、主体判断、价值观判断。最容易「会而做错」——题干问「错误的是」你选了对的，选项说法都对但和材料不搭。
- 材料分析题（大题）：给一段或几段材料，设问落在「是什么 / 为什么 / 怎么做 / 评析 / 建议 / 启示 / 体现说明 / 谈认识」上，要求分点作答、观点与材料结合。
- 时政结合题：材料常是当年的大会、国策、法治事件、榜样人物，落点仍是教材观点，不要求你押时政原文，只要求你把时政「翻译」成课本术语。

**这一科怎么想（与其他科的区别）。**
- 不像历史要记准「哪一年发生了什么」，道法记的是「这句话在课本里怎么说、它的地位/作用是什么」。
- 不像理科要推演计算，道法的「推」是：先判设问类型（为什么？怎么做？）→ 再定作答主体（国家？政府？青少年？）→ 然后从课本里把对应的关键句调出来 → 最后一句观点配一句材料。
- 道法是**正向价值观学科**：答案一定导向积极、守法、向上的立场；消极、悲观、极端的说法在选择题里直接排除。
- 标准答案纹理：**观点（课本关键句）＋ 材料（引述或概括）＋ 做法（按主体分点）**。观点引领、材料佐证；「怎么做」按国家、政府、社会、企业、学校、家庭、公民/青少年分主体写，主体与做法不能错位。

## 二、科目识别与版本册次

**怎么判定这是道法题。** 满足任一即判本科：
- 材料是一段时政新闻、法治案例、道德两难、榜样事迹、制度与国策介绍；
- 设问出现「这体现了 / 说明了什么」「为什么要」「应该怎么做 / 提建议」「请辨析 / 评析」「有什么启示」「谈谈你的认识」；
- 关键词：宪法、法律、违法犯罪、权利义务、创新、改革开放、共同富裕、生态文明、社会主义核心价值观、中国梦、人类命运共同体、国家安全、责任、诚信、友谊、情绪、集体。
- （对照区分：考历史事件因果、条约年代的归历史；考心理实验、统计图表数字计算的归其他。）

### 4.3 知识专题模型（→ `01`~`04` 方法套路分册）

- **成长心理与道德修养**（`01_成长心理与道德修养.md`）：学习、认识自己、友谊讲原则、情绪情感、集体、尊重礼貌诚信、责任、亲社会与合理用网。
- **法治基础与宪法专册**（`02_法治基础与宪法专册.md`）：
  - 未成年人**六大保护**——看主体定保护：家、校、社、网、政、司；
  - 违法**三分类**——看违反哪部法＋看危害轻重（民事/行政/刑事）；
  - 犯罪**三特征**——严重社会危害性（最本质）、刑事违法性、应受刑罚处罚性；主刑只能单独用一个，附加刑可并用；
  - 宪法是根本法——**内容 / 法律效力 / 制定修改程序**三层比；坚持依法治国首先要依宪治国；
  - 权利义务相统一——既是享有者又是承担者；劳动和受教育既是权利也是义务；
  - 国家机构职权——人大（立法/决定/任免/监督）、政府（行政）、法院（审判）、检察院（法律监督/公诉）。
- **国情国策与中国梦**（`03_国情国策与中国梦.md`）：改革开放与共同富裕、创新驱动与科教兴国、民主与法治政府、文化自信与社会主义核心价值观、生态文明与绿色发展、民族团结与祖国统一、中国梦与「两个一百年」、总体国家安全观。
- **全球视野与中国担当**（`04_全球视野与中国担当.md`）：经济全球化、世界多极化、和平与发展、人类命运共同体、中国担当、少年自强与职业选择。

### 4.4 两个高频通用落点（背下来直接套）

- **青少年「怎么做」万能落点**（凡问「我们青少年应该怎么做」都从这三条里挑，落到可照做的小事）：
  1. **树立意识**——树立法治观念/环保意识/责任意识/国家观念，增强社会责任感；
  2. **从小事做起**——努力学习、提高素质，从身边点滴做起（节约水电、绿色出行、垃圾分类、诚信待人、文明上网）；
  3. **勇于斗争/建言**——正确行使建议监督权，同不良行为作斗争，必要时依法维权（未成年人见义智为，先保护自己）。
- **意义/「有利于」四层展开**（问意义、作用、重要性时套）：
  1. 对**个人**——有利于提高素质、实现人生价值、保障合法权益；
  2. 对**社会**——有利于维护公平正义、营造良好风尚、构建和谐社会；
  3. 对**国家/民族**——有利于增强综合国力、实现中华民族伟大复兴、推进国家治理现代化；
  4. （问中国国际作为时才补）对**世界**——有利于促进世界和平与发展、构建人类命运共同体。

## 五、快解 / 速判（草稿快解）

- **倒读审题法**：原理——材料长，先知道问啥才不白读。操作——先看设问问「正确还是错误、问原因还是做法、问哪个主体」，圈出来，再读材料。局限——倒读是定位工具，最终卷面仍要按规范写全。
- **四排排雷法**：原理——选择题错法就四种。操作——先排知识点错的，再排绝对化的，再排消极价值观的，最后排「说得对但和材料无关」的。局限——排无关最隐蔽，四个选项都对时务必回到材料对关键词。
- **极端词清单（先怀疑，不一刀切）**：高频坑词——最、唯一、彻底、根除、杜绝、只要……就、只有……才、一切、任何、所有、完全、必然、绝对、消除、根本解决。**例外（教材定论，不能误杀）**：「宪法是国家的根本法」「严重社会危害性是犯罪的最本质特征」「改革开放是决定当代中国命运的关键一招」这类教材原话里的「根本/最本质」是对的，要结合知识判断。
- **二选一看主体**：原理——两个选项都像对，差别常在「谁来做」。操作——看材料主体是国家/政府还是公民/青少年，主体对不上的那个排除。局限——主体对了还要看表述是否绝对化。
- **组合题抓铁定项**：原理——确定一个小项即可排除一组。操作——先找最有把握的小项，它错就删含它的，它对就删不含它的。局限——别四个小项平均用力纠结。
- **材料→课本话「翻译」小抄**（把材料大白话换成教材术语，答案就藏在材料里）：
  - 材料说「人不能离开别人一个人活」→ 课本「个人是社会的有机组成部分，人的生存和发展离不开社会」；
  - 材料说「小店老板宁可少赚钱也不用过期食材」→ 课本「诚信是一个人安身立命之本，是企业的无形资产」；
  - 材料说「国家投钱搞脱贫、建高铁、搞医保」→ 课本「党和政府坚持以人民为中心，让人民群众共享发展成果，朝着共同富裕方向稳步前进」；
  - 材料说「政府把办事流程晒到网上、接受群众挑错」→ 课本「政府依法行政，全面推进政务公开，保障公民的监督权」。

## 六、高频易错 / 易混清单（错例 → 正确做法）

- 错：问「青少年怎么做」，写成「国家完善立法」——主体错位。正确：青少年落到「树立意识＋身边小事＋勇于作斗争」。
- 错：把「罚款」当刑罚——罚款是行政责任（行政机关罚）；**罚金**才是刑罚附加刑（法院判）。
- 错：把「拘役」当行政拘留——拘役是刑罚主刑；**拘留**是行政责任。
- 错：把「人民代表大会」（机关）和「人民代表大会制度」（根本政治制度）混；把根本政治制度和基本政治制度（政党制度、民族区域自治、基层群众自治）混。
- 错：把「垃圾分类/志愿活动」说成国家中心工作——中心工作是**经济建设**。
- 错：把共同富裕写成「同时、同步、同等富裕」——共同富裕是渐进、有差别的过程，不是平均主义。
- 错：认为「违法＝犯罪」——违法分一般违法（民事、行政）和严重违法（刑事＝犯罪），犯罪一定违法，违法不一定犯罪。
- 错：评价网络影响只写一面——必须利弊两面（改变生活、促进交往；沉迷、谣言、隐私）。
- 错：把受教育只当权利——受教育**既是基本权利也是基本义务**，劳动同理。
- 错：友谊讲成「哥们儿义气」——友谊要讲原则，不能为朋友做违反校规法律的事。
- 错：把「网吧不让未成年人进」当网络保护——场所经营者的准入限制属**社会保护**；管上网内容/时长/个人信息才是网络保护（现在是**六大**保护，不是旧教材四大）。
- 错：意义题不写「有利于」——答意义要带「有利于/有助于」，方向是正面作用。
- 错：见到「根本法、最本质特征」这类教材定论也用极端词法排掉——见第五节例外。

## 七、名师大白话讲法 / 口诀 / 比喻

### 7.1 网上名师招牌套路（精选·已甄别·只留增量）

> 已与本节原有口诀/比喻/句式逐条比对去重：「倒读口诀」「四排口诀」「材料题万能句式（亮观点→引材料→析原理→落做法）」「原因题四层」「做法题主体清单」「六大保护/犯罪三特征/宪法/权利义务比喻」「新发展理念/中国梦时间轴」等原有内容一律不再重复收录，对应网上同名讲法（"审转答"三步、"三审四排"、原因类四层展开、做法题先圈主体、通用四步链）视为已覆盖，不列。下列 3 条确有增量；署名只挂可核实的公开来源，通用方法不归属真人。

- **体现类公式：「谁做了什么事 → 体现了什么知识点 → 带来什么好处」**
  - 来源：抖音公开讲法（https://www.iesdouyin.com/share/video/7640061371414270692 、https://www.iesdouyin.com/share/video/7688275422237672422 ）；光明日报《中考道德与法治复习指导》（https://epaper.gmw.cn/wzb/html/2025-04/26/nw.D110000wzb_20250426_5-02.htm ）"材料关键词→教材观点"同思路。
  - 怎么操作：设问出现"这体现了/说明了/反映了什么"时，第一步用十个字以内缩写材料"谁+做了什么"（不整段抄）；第二步对到课本一个观点句；第三步（问意义时）补一句"有利于……"。与原有「材料题万能句式」的差别：万能句式是所有大题通用骨架，本公式是专门给"体现/说明"类设问的三步踩点顺序，强制先缩材料再落观点。
  - 原理：体现类采分点就三条腿——材料概括、教材观点、（必要时）意义；缺材料概括老师看不到你真读懂了材料，缺教材观点就没踩到分。
  - 适用："体现/说明/反映了什么"类设问。局限/坑：一个材料分层多时一层对一个观点句，不要一个观点套三段材料；材料缩写要用自己的话，不能照抄原句。

- **启示类「道理 + 行动」双段，落脚青少年**
  - 来源：抖音公开讲法（https://www.iesdouyin.com/share/video/7576174527672384997 、https://www.iesdouyin.com/share/video/7671223518763175210 ）；21 世纪教育网"示—理—启"三步同思路。
  - 怎么操作：设问"给我们什么启示/向他学习什么"时，第一段先概括材料里人物或事件体现的教材道理/品质（如"法律是最刚性的社会规则，不违法是人们行为的底线"）；第二段落到青少年怎么做（树立意识+努力学习+身边小事+勇于作斗争）。与原有「材料题万能句式」的差别：万能句式不区分问法，本公式专门针对启示类，强制双段、强制落脚青少年。
  - 原理：启示题 = 是什么（道理）+ 如何做（行动），落脚点几乎都是青少年；只写道理不写行动缺腿，只写行动不说道理没高度。
  - 适用："启示/感悟/学习榜样"类设问。局限/坑：别写成空口号"我们要努力奋斗"，行动要对应材料里人物做对的那件具体事（如材料讲小陈报消防隐患，行动就写"发现隐患及时向物业/有关部门反映"）。

- **时政材料「翻译」法：圈三类词 → 对课本术语**
  - 来源：北京教育考试院《理解教材观点融合时事热点》（https://www.bjeea.cn/uploads/soft/251203/1879%E6%9C%9F6%E7%89%88.pdf ）；光明日报中考复习指导（同上）；河南省政府网中招指导"先看问题再读材料、圈转折词"（https://m.henan.gov.cn/2026/06-18/3367027.html ）。
  - 怎么操作：时政材料不用背原文，读材料时圈三类词——① 政策新词（如"新质生产力""高质量发展"）；② 数据变化（增/减、差距）；③ 转折词后面那句（"但是/然而/可是"后往往是重点）；然后把每个词翻译成课本术语："新质生产力"→创新驱动发展、科教兴国、人才强国；"政府把办事晒到网上"→依法行政、政务公开、保障监督权；"国家投钱搞脱贫医保"→以人民为中心、共享发展成果、共同富裕。与原有「讲题提醒」的差别：提醒只说"翻译成课本四个字"，本法给出具体圈哪三类词、怎么对到课本哪一课。
  - 原理：中考时政题不考背新闻原文，考把时事"翻译"成课本观点的能力；翻译对了答案就藏在材料里。
  - 适用：结合当年大会、国策、法治事件、榜样人物的材料题。局限/坑：一个时政词可能对应两三个课本观点，要按设问圈定的知识范围选，别把全书观点都堆上去；不押时政原文、不抄新闻口号。

### 7.2 已剔除的「大招 / 秒杀」及原因

- 摒弃 **「见到绝对化词（只要…就/彻底/唯一/所有/一切）就直接排除，九成九是错的」一刀切排雷**——剔除原因：属于「只记结论不讲原理」＋换条件就错。教材与现行宪法法律原文里大量带"根本/最/任何/一切/都"的表述本来就是对的（如"宪法是国家的根本法""一切法律、行政法规都不得同宪法相抵触""任何违法行为都要承担相应的法律责任""严重社会危害性是犯罪的最本质特征"）。本技能第五节已明确"极端词先怀疑、不一刀切、教材定论例外"，只在草稿快解里作为提示，不进规范解答，不采纳"见绝对词就排"的粗暴版。
- 摒弃 **「开卷考就是闭卷学透、上考场照抄课本段落即得分」/「开卷=抄书比赛」**——剔除原因：与现行中考命题方向冲突、不严谨。北京教育考试院、光明日报、河南省中招指导均明确：开卷考不再是抄书比赛，照抄课本原话不得分，考的是材料结合与知识迁移；正确姿势是"平时闭卷储备、考场上开卷补充定位"，材料与观点要用关联词连起来（"材料中……体现了……"）。此说会误导学生不做材料对应。
- 摒弃 **「邪修/秒杀口诀」型——把知识点压成两字缩略语（如"两转一优一健一高""有机统一三兄弟"），只背结论不讲原理**——剔除原因：属于「只记结论不讲原理」＋玄学口诀，且缩略语非教材原文，脱离原句后换个情境就张冠李戴（"有机统一"指党的领导、人民当家作主、依法治国三者统一，压成"三兄弟"学生根本不知道是哪三个）。本技能只保留能回到课本原句、能讲清"为什么"的讲法，不收录这类口诀缩略。
- 摒弃 **「万能结尾套话」——任何大题最后都加一句"我们要为实现中华民族伟大复兴而努力奋斗"**——剔除原因：适用极窄、空洞口号不踩分点、易主体错位。案例分析题结尾确实要写价值表态，但表态必须对应材料里的具体做法和设问主体（问青少年就落到青少年具体行动，不能每题都喊一句中国梦口号凑数）；空喊口号阅卷老师找不到采分点，反而稀释前面正确分。
