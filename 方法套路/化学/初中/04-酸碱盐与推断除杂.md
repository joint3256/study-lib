# 初中化学 · 酸碱盐、物质推断与除杂分离

## 方法 7　酸碱盐通性与复分解反应条件

### ① 方法名
**"双交换、看产物三条件"复分解判断法**

### ② 适用题型 / 物质
判断酸、碱、盐之间能否发生反应，写化学方程式，物质转化关系图。

### ③ 原理（为什么）
- 复分解反应：两种化合物互相交换成分，生成另外两种化合物（"双交换，价不变"）。
- 发生条件：生成物中必须有 **沉淀↓、气体↑ 或水**（满足其一即可）。因为这样溶液中离子浓度才会减小，反应才能进行到底。
- 常见沉淀：AgCl、BaSO₄（不溶于稀硝酸）；CaCO₃、BaCO₃（溶于酸）；Cu(OH)₂（蓝色）、Fe(OH)₃（红褐色）。
- 酸碱中和反应一定生成水，所以酸和碱一定能反应。

### ④ 操作步骤
1. 写出反应物，按"正价找负价、互换成分"写出两种可能的产物。
2. 对照溶解性表，判断产物里有没有沉淀/气体/水。
3. 三者都没有 → 不反应；有任一 → 反应，写方程式并标注 ↓↑。

### ⑤ 例题完整演示
判断下列两组物质能否反应，能反应写出方程式。

(1) 碳酸钠溶液 + 澄清石灰水：
$$\mathrm{Na_2CO_3 + Ca(OH)_2 = CaCO_3\downarrow + 2NaOH}$$
交换成分后生成 CaCO₃ 沉淀 → 反应能发生。

(2) 硝酸钾溶液 + 氯化钠溶液：
交换成分得到 NaNO₃ 和 KCl，两者都可溶，**既无沉淀、也无气体和水** → 不反应。

### ⑥ ❌ 易错提醒
- 复分解是"交换成分"，不是随便把两种物质相加。
- 记牢几类特征产物：碳酸根 + 酸 → CO₂↑；铵盐 + 碱 → NH₃↑；Cl⁻ + Ag⁺ → AgCl↓；SO₄²⁻ + Ba²⁺ → BaSO₄↓。
- 酸 + 碱 → 盐 + 水（中和，一定发生）；酸 + 碳酸盐 → 盐 + 水 + CO₂↑。
- 碱 + 非金属氧化物（如 CO₂+NaOH）**不属于**复分解，别硬套条件。
- 沉淀符号 ↓ 只标在生成的不溶物上，反应物若是溶液则不标。

## 方法 8　物质推断与除杂、分离、提纯

### ① 方法名
**"抓题眼顺/逆推" + "不增不减易分"除杂三原则**

### ② 适用题型 / 物质
框图推断题、文字推断题、选择题/填空题除杂、混合物分离提纯。

### ③ 原理（为什么）
- 推断题靠**特征现象（题眼）**锁定物质：颜色（蓝色 CuSO₄ 溶液、红褐色 Fe(OH)₃、黑色 CuO/Fe₃O₄/C）、特征气体（CO₂、O₂、NH₃）、特征沉淀。
- 除杂三原则：**不增**（不引入新杂质）、**不减**（不减少被提纯物）、**易分**（杂质转化为沉淀/气体便于分离）。
- 分离则要把各组分**都恢复到原来的状态**。

### ④ 操作步骤
- 推断：①找题眼（颜色/现象）→ ②顺推或逆推 → ③把结论代回原题验证。
- 除杂：①明确保留谁、去掉谁 → ②选只与杂质反应的试剂 → ③保证不引入难除新杂质 → ④必要时过滤/蒸发。

### ⑤ 例题完整演示
(1) 除杂：除去 NaCl 溶液中少量 Na₂CO₃，应加什么试剂？
选**适量稀盐酸**：
$$\mathrm{Na_2CO_3 + 2HCl = 2NaCl + H_2O + CO_2\uparrow}$$
不能用稀硫酸（会引入 Na₂SO₄ 新杂质）；不能加过量 CaCl₂（过量 Ca²⁺ 成新杂质）。

(2) 推断：某蓝色溶液 A 加 NaOH 溶液生成蓝色沉淀 B 和无色溶液；B 加热变成黑色固体 C。
- A 为可溶性铜盐（如 CuSO₄ 或 CuCl₂）；B 为 Cu(OH)₂；C 为 CuO。
$$\mathrm{CuSO_4 + 2NaOH = Cu(OH)_2\downarrow + Na_2SO_4}$$
$$\mathrm{Cu(OH)_2 \xlongequal{\Delta} CuO + H_2O}$$

### ⑥ ❌ 易错提醒
- 除 CO 中混有的 CO₂：通过 NaOH 溶液（不是点燃，CO₂ 点不着）。
- 除 CO₂ 中混有的少量 CO：**不能点燃**（CO₂ 多、CO 少点不着），应通过灼热 CuO：CO+CuO=Δ=Cu+CO₂。
- 分离 KCl 和 MnO₂：MnO₂ 不溶于水，靠"溶解→过滤→蒸发滤液得 KCl，滤渣洗涤干燥得 MnO₂"。
- 注意"适量"与"过量"：除杂试剂过量会成为新杂质。
- 推断结论代回原题必须全部现象都吻合，不能只满足一处。
