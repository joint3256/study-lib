## 方法 H9　化学反应与能量（热化学方程式 / 盖斯定律）

### ① 方法名
**"消中间物，ΔH 同步代数运算"盖斯定律法**

### ② 适用题型 / 物质
热化学方程式书写与正误判断；由几个已知热化学方程式求未知反应的 ΔH。

### ③ 原理（为什么）
- 反应热（ΔH）只与反应体系的始态和终态有关，与途径无关（盖斯定律）。
- 放热反应 ΔH < 0，吸热反应 ΔH > 0；ΔH 单位 kJ/mol。
- 热化学方程式必须注明各物质聚集状态（s/l/g/aq）。

### ④ 操作步骤
1. 写出目标方程式。
2. 把已知方程式相加/相减（必要时乘系数），消去中间产物，凑出目标式。
3. ΔH 随之做相同的代数运算（乘系数则 ΔH 也乘，反写则 ΔH 变号）。

### ⑤ 例题完整演示
已知：
① C(s) + O₂(g) = CO₂(g)　ΔH₁ = −393.5 kJ/mol
② CO(g) + ½O₂(g) = CO₂(g)　ΔH₂ = −283.0 kJ/mol
求：C(s) + ½O₂(g) = CO(g) 的 ΔH。

用 ① − ②（消去 CO₂ 这个中间产物）：
ΔH = ΔH₁ − ΔH₂ = −393.5 − (−283.0) = **−110.5 kJ/mol**（已验算）

### ⑥ ❌ 易错提醒
- 热化学方程式必须标物质状态（g/l/s/aq），状态不同 ΔH 不同。
- 系数加倍，ΔH 加倍；方程式反写，ΔH 变号。
- 比较 ΔH 大小要**带符号**比：放热越多，ΔH 越小（越负）。
- 燃烧热是 1 mol 纯物质完全燃烧生成稳定氧化物放出的热，注意"1 mol"。

## 方法 H10　化学反应速率与化学平衡（移动 / 图像 / 三段式）

### ① 方法名
**"三段式（起始—转化—平衡）+ 勒夏特列原理"综合法**

### ② 适用题型 / 物质
反应速率计算；平衡移动方向判断；v-t 图、含量-时间图分析；平衡常数与转化率计算。

### ③ 原理（为什么）
- 反应速率 v = Δc / Δt，用单位时间内浓度变化表示。
- 勒夏特列原理：平衡体系若改变条件，平衡就向**减弱这种改变**的方向移动。
- 平衡常数 K 只与温度有关，与浓度、压强无关；固体、纯液体浓度不写入 K。

### ④ 操作步骤（三段式）
1. 列各物质**起始浓度**。
2. 按化学计量数列**转化浓度**。
3. 平衡浓度 = 起始 − 转化。
4. 代入 K = [生成物]^系数 / [反应物]^系数 计算。

### ⑤ 例题完整演示
密闭容器中 N₂ + 3H₂ ⇌ 2NH₃，起始 [N₂]=1 mol/L、[H₂]=3 mol/L，达平衡时 N₂ 转化率 40%。求平衡浓度与 K。
- 转化：[N₂] 减 0.4、[H₂] 减 1.2、[NH₃] 增 0.8。
- 平衡：[N₂]=0.6，[H₂]=1.8，[NH₃]=0.8。
- K = [NH₃]² / ([N₂][H₂]³) = 0.8² / (0.6 × 1.8³) = 0.64 / 3.499 ≈ **0.183**（已验算）。

### ⑥ ❌ 易错提醒
- 增大压强，平衡向气体体积**减小**方向移动；升高温度，平衡向**吸热**方向移动。
- 催化剂只加快速率、缩短达到平衡时间，**不使平衡移动**。
- K 只随温度变；浓度、压强改变 K 不变。
- 转化率与平衡移动方向别混淆：平衡正向移动，反应物转化率一般增大。

## 方法 H11　水溶液中的离子平衡（弱电解质 / 水解 / pH / 沉淀溶解）

### ① 方法名
**"先定强弱，再列守恒"离子浓度与 pH 计算法**

### ② 适用题型 / 物质
弱电解质电离、盐类水解规律、溶液 pH 计算、离子浓度大小比较、Ksp 与沉淀转化。

### ③ 原理（为什么）
- 弱电解质（弱酸、弱碱）部分电离、可逆；盐类水解"有弱才水解，谁弱谁水解，谁强显谁性"。
- pH = −lg c(H⁺)；25 ℃ 时中性溶液 pH = 7。
- 沉淀溶解平衡：AmBn(s) ⇌ mAⁿ⁺ + nBᵐ⁻，Ksp = c(Aⁿ⁺)^m · c(Bᵐ⁻)^n。

### ④ 操作步骤
1. 判断溶质是强/弱电解质、盐是否水解。
2. 求 c(H⁺) 后算 pH；涉及离子浓度比较时列电荷守恒、物料守恒。
3. 沉淀问题用 Ksp 与溶解度关系。

### ⑤ 例题完整演示
(1) 求 0.01 mol/L 盐酸的 pH。
- HCl 完全电离，c(H⁺) = 0.01 mol/L，pH = −lg(0.01) = **2**（已验算）。

(2) AgCl 的 Ksp = 1.8×10⁻¹⁰，求其饱和溶液溶解度 s（mol/L）。
- AgCl ⇌ Ag⁺ + Cl⁻，Ksp = s²，s = √(1.8×10⁻¹⁰) ≈ **1.34×10⁻⁵ mol/L**（已验算）。

(3) 盐类水解判断：Na₂CO₃ 溶液显碱性（CO₃²⁻ 水解）；NH₄Cl 溶液显酸性（NH₄⁺ 水解）。

### ⑥ ❌ 易错提醒
- pH = 7 中性只在**常温（25 ℃）**成立；升温后纯水 pH < 7 但仍中性。
- 盐类水解是微弱、可逆、吸热的，方程式用 ⇌，不标 ↓↑。
- 比较离子浓度先写电荷守恒（正电荷总浓度 = 负电荷总浓度）。
- 沉淀一般向生成 Ksp 更小的方向转化（类型相同时）。

## 方法 H12　电化学（原电池 / 电解池 / 金属腐蚀防护）

### ① 方法名
**"判池—定极—写电极反应"三步法**

### ② 适用题型 / 物质
原电池正负极判断与电极反应；电解池阴阳极判断与电极反应；金属腐蚀与防护、电镀。

### ③ 原理（为什么）
- 原电池（无外接电源）：**负极氧化（失电子）、正极还原（得电子）**；活泼金属一般作负极。
- 电解池（有外接电源）：**阳极氧化、阴极还原**；接电源正极的是阳极。
- 电子从负极流出，经外电路流向正极。

### ④ 操作步骤
1. 看有无外接电源，判断是原电池还是电解池。
2. 定电极（原电池：活泼金属为负极；电解池：接正极为阳极）。
3. 按放电顺序写电极反应式。

### ⑤ 例题完整演示
(1) 铜锌原电池（稀硫酸）：
- 负极：Zn − 2e⁻ = Zn²⁺
- 正极：2H⁺ + 2e⁻ = H₂↑
- 总：Zn + H₂SO₄ = ZnSO₄ + H₂↑

(2) 电解饱和食盐水：
- 阳极：2Cl⁻ − 2e⁻ = Cl₂↑
- 阴极：2H₂O + 2e⁻ = H₂↑ + 2OH⁻
- 总：2NaCl + 2H₂O =电解= 2NaOH + H₂↑ + Cl₂↑

(3) 钢铁吸氧腐蚀（中性/弱酸性水膜）正极：O₂ + 2H₂O + 4e⁻ = 4OH⁻。

### ⑥ ❌ 易错提醒
- 原电池负极溶解、正极常出气体或析出金属；电解池阳极失电子。
- 活性电极（Ag 及之前金属）作阳极时，电极自身溶解。
- 电镀：镀层金属作阳极、镀件作阴极、含镀层金属离子的溶液作电解液。
- 写电极反应别忘电荷与原子守恒；燃料电池燃料在负极。
