## 第一单元 古代亚非文明

> 课时：第1课 古代埃及；第2课 古代两河流域；第3课 古代印度（课号以教材目录为准）。

### 一、本单元时空脉络（知识结构）

```
亚非四大文明古国（都诞生于大河流域）
│
├─ 古埃及（尼罗河流域，非洲东北角）
│   └─ 约前3500年出现小国 → 约前3100年初步统一 → 金字塔、象形文字 → 前525年被波斯所灭
├─ 古巴比伦（两河流域＝幼发拉底河＋底格里斯河，今伊拉克一带）
│   └─ 约前3500年苏美尔人 → 前18世纪汉谟拉比统一 →《汉谟拉比法典》、楔形文字
├─ 古代印度（印度河、恒河流域）
│   └─ 哈拉帕文明 → 雅利安人进入 → 种姓制度 → 前6世纪释迦牟尼创佛教 → 前3世纪向外传播
└─ 古代中国（黄河、长江流域，本册不作重点）

年代轴：约前3500（小国出现）→ 约前3100（埃及统一）→ 前18世纪（汉谟拉比）
        → 前6世纪（佛教产生）→ 前525（埃及亡于波斯）
```

记忆口诀：**"大河文明"——埃及靠尼罗河、巴比伦靠两河、印度靠印度河恒河、中国靠黄河长江。**

### 二、核心史事（时间·人物·经过，通俗→严谨）

**1. 古代埃及**
- 通俗：埃及人住在尼罗河边上，河水每年定时泛滥，留下黑油油的肥泥，种粮特别方便，所以古埃及被叫作"尼罗河的赠礼"。法老死后，后人给他修巨大的石头陵墓，就是金字塔。
- 严谨：古埃及位于非洲东北角，尼罗河贯穿南北。约从公元前3500年开始出现若干小国；**约公元前3100年初步实现统一**，后经历古王国、中王国、新王国等时期。**金字塔**是古埃及文明的象征，最大的是胡夫金字塔，它既是法老的陵墓，也反映法老的无限权威。古埃及人发明**象形文字**，并制定了世界上最早的太阳历之一。公元前525年，古埃及被波斯帝国吞并。

**2. 古代两河流域与《汉谟拉比法典》**
- 通俗：两条大河之间（希腊语叫"美索不达米亚"）住过苏美尔人；后来出了个国王叫汉谟拉比，把两河流域基本统一了，还把国家规矩刻在一根大石柱上，让人人都能看。
- 严谨：两河流域的苏美尔人约公元前3500年兴起，发明**楔形文字**。**公元前18世纪，古巴比伦王国国王汉谟拉比**完成了两河流域中下游的统一，建立了统一、强大的奴隶制国家。他为了巩固统治，制定了**《汉谟拉比法典》**——条文刻在黑色石柱上，严格规定奴隶、自由民的地位，是**迄今已知世界上第一部较为完整的成文法典**，也是古巴比伦王国留给人类的宝贵文化遗产，表明人类社会的法制传统源远流长。

**3. 古代印度的种姓制度与佛教**
- 通俗：印度社会把人分成四等，世代相传、不能通婚，这就是种姓制度；后来一个叫乔达摩·悉达多的王子觉得人太苦，悟出道理创了佛教，主张"众生平等"，反对婆罗门的特权。
- 严谨：古代印度在印度河、恒河流域兴起。雅利安人进入印度后，逐渐建立严格的**种姓制度**，四个等级依次是：
  - **婆罗门**（掌管祭祀）、**刹帝利**（掌管军事和行政，国王属于这一等）、**吠舍**（从事农业、畜牧业、商业）、**首陀罗**（主要由被征服居民构成，从事农业、畜牧业、捕鱼业和手工业）。
  - 等级之间贵贱分明，世代相袭，不得通婚。
- **佛教**：**公元前6世纪**，**乔达摩·悉达多**（后被称为"释迦牟尼"）创立佛教。教义反对婆罗门的特权，宣扬"**众生平等**"，主张忍耐顺从。公元前3世纪，在阿育王统治时期佛教向外传播，主要经两条路：向北经中亚传入中国，再传到朝鲜、日本；向南传入东南亚。

### 三、历史意义·阶段特征与重要结论

- **阶段特征**：亚非文明都发源于**大河流域**，属于大河文明；经济上以农业为主，政治上多实行君主专制，形成了最早一批奴隶制国家。
- 课本结论：
  - 金字塔是**古埃及文明的象征**，反映了古埃及社会经济发展的较高水平，是古埃及人智慧的结晶。
  - **《汉谟拉比法典》是迄今已知世界上第一部较为完整的成文法典**，是古巴比伦留给世界文明的重要遗产。
  - 种姓制度**激化了社会矛盾**，也成为后来佛教在印度兴起的社会背景之一。
  - 佛教提倡"众生平等"，早期教义对贫苦民众有吸引力；西汉末年经丝绸之路传入中国，对中国文化影响深远。

### 四、因果线索与常用史观·答题模型

- 因果链：**大河定期泛滥→肥沃平原→农业发达→人口聚集→国家出现→文字、历法、建筑、法典诞生**。
- 唯物史观角度：
  - **地理环境影响文明类型**——大河流域→农耕文明→中央集权；这是"自然地理环境对早期文明的影响"，但不是地理决定论。
  - **国家本质是阶级统治的工具**——法典、种姓制度、金字塔都是维护奴隶主统治的工具。
- 答题模型（"文明古国"类材料题）：先从**地理位置（哪条河）、出现时间、文明标志（建筑/文字/制度）**三方面定位，再答"大河流域、农业文明、奴隶制"的共同特征。

### 五、考点与典型题型·方法

**题型1：四大文明古国与大河流域配对（选择题）**
- 通法：口诀"埃尼罗河、巴两河、印度河恒河、中黄河"。
- 例：发明楔形文字、刻有《汉谟拉比法典》的文明位于（　）——**两河流域**。

**题型2：判断"迄今已知世界上第一部较为完整的成文法典"**
- 通法：看到"第一部成文法典"直接锁定《汉谟拉比法典》，不要写成《十二铜表法》（那是罗马的）。

**题型3：佛教材料题**
- 例：材料"……宣扬众生平等，反对婆罗门的特权……"
  - 分点答案：①该宗教是**佛教**，公元前6世纪由**乔达摩·悉达多（释迦牟尼）**创立于古代印度；②教义：反对婆罗门特权、主张**众生平等**、宣扬**忍耐顺从**；③传播：公元前3世纪阿育王时向外传播，经中亚传入中国（丝绸之路）。

**题型4：种姓制度等级排序**
- 通法：从上到下"婆刹吠首"——婆罗门（祭祀）、刹帝利（国王武士）、吠舍（商人农民）、首陀罗（劳动者）。

### 六、易错易混

- ❌ 把金字塔说成"法老的宫殿" → ✅ 金字塔是法老的**陵墓**。
- ❌ 把"迄今已知世界上第一部较为完整的成文法典"答成《十二铜表法》→ ✅ 是**《汉谟拉比法典》**（古巴比伦，前18世纪）；《十二铜表法》是罗马共和国的。
- ❌ 把楔形文字当成古埃及的 → ✅ 古埃及是**象形文字**，两河流域苏美尔人是**楔形文字**。
- ❌ 种姓制度四等顺序记反 → ✅ 婆罗门最高，首陀罗最低，**世代相袭、不得通婚**。
- ❌ 把佛教创始人写成阿育王 → ✅ 创始人是**乔达摩·悉达多（释迦牟尼）**；阿育王是公元前3世纪大力推广佛教的国王。
- ❌ 认为亚非文明都发源于沿海 → ✅ 都发源于**大河流域**（尼罗河、两河、印度河恒河、黄河）。

## 第二单元 古代欧洲文明

> 课时：第4课 希腊城邦和亚历山大帝国；第5课 罗马城邦和罗马帝国；第6课 希腊罗马古典文化（课号以教材目录为准）。

### 一、本单元时空脉络（知识结构）

```
古代欧洲文明（海洋文明，以地中海为中心）
│
├─ 古希腊（西方文明之源）
│   ├─ 前8世纪 希腊城邦出现（小国寡民）
│   ├─ 雅典：伯里克利时代（前5世纪中后期）奴隶制民主政治发展到高峰
│   ├─ 斯巴达（尚武）
│   └─ 前4世纪 亚历山大（前334年起东征）→ 地跨欧亚非三洲的大帝国
├─ 古罗马
│   ├─ 前509年 罗马共和国建立
│   │   └─《十二铜表法》（前450年左右）；前73年斯巴达克起义
│   ├─ 前27年 屋大维建立罗马帝国
│   └─ 2世纪 罗马帝国地跨三洲、地中海成"内湖" → 395年分裂 → 476年西罗马帝国亡
└─ 希腊罗马古典文化：《荷马史诗》、哲学、帕特农神庙、儒略历

年代轴：前8世纪（城邦）→ 前509（罗马共和国）→ 前5世纪中后期（伯里克利）
        → 前4世纪（亚历山大东征）→ 前27（罗马帝国）→ 2世纪（罗马全盛）→ 395（分裂）→ 476（西罗马亡）
```

### 二、核心史事（时间·人物·经过，通俗→严谨）

**1. 希腊城邦与雅典的民主政治**
- 通俗：希腊多山多岛，国家都很小，叫"城邦"。其中雅典最厉害的地方是：大事不靠国王一个人说了算，而由全体成年男性公民开会投票决定，伯里克利当政时这种民主最盛。但要注意：奴隶、外邦人、妇女都没有投票权。
- 严谨：公元前8世纪，希腊出现了城邦，突出特点是**"小国寡民"**，最大的是斯巴达和雅典。雅典的奴隶制民主政治在**伯里克利主政时期（公元前5世纪中后期）**发展到高峰：
  - **公民大会**是最高权力机构，具有立法、司法等多种职能；
  - 公职人员几乎都从全体公民中抽签产生；
  - 为了保证贫穷公民参政，建立了**津贴制度**。
  - 但占雅典人口绝大多数的**外邦人、奴隶、妇女没有任何政治权利**。

**2. 亚历山大帝国**
- 通俗：希腊北边马其顿出了个年轻国王亚历山大，带着军队一路打到印度河，把欧亚非一大片连成一个大帝国，还把希腊文化带到了东方。
- 严谨：公元前4世纪，希腊北部的**马其顿**成为军事强国。**亚历山大**率军东征（前334年起），先后灭波斯，一直打到印度河流域，建立了地跨欧、亚、非三洲的大帝国。亚历山大东征具有**侵略性质**，给东方人民带来灾难；但客观上**促进了东西方文化的大交汇**，加强了东西方之间的经济联系和贸易往来。

**3. 罗马：从共和国到帝国**
- 通俗：罗马人先搞了个"共和国"（两个执政官掌权），后来地盘越打越大，奴隶起义不断；最后屋大维拿到实权，改称"奥古斯都"，罗马进入帝国时代；公元2世纪时地跨欧亚非，地中海成了它的内湖；到476年西罗马帝国被日耳曼人灭掉。
- 严谨：
  - **公元前509年**，罗马建立共和国。国家统治的决策权掌握在由贵族组成的**元老院**手里。公元前450年左右颁布**《十二铜表法》**，使量刑定罪有了文字依据，是罗马法制建设的第一步，是后世罗马法典乃至欧洲法学的渊源。
  - 公元前73年，**斯巴达克起义**沉重打击了奴隶制，加速了罗马共和国的衰落。
  - **公元前27年，屋大维**首创"元首制"，被尊为"奥古斯都"，**罗马共和国演变为罗马帝国**。
  - **2世纪**，罗马帝国进入黄金时期，地跨欧、亚、非三洲，**地中海成了罗马帝国的"内湖"**。
  - 395年罗马帝国分裂为东西两部分；**476年，西罗马帝国在日耳曼人的打击下灭亡**，标志西欧奴隶社会结束。

**4. 希腊罗马古典文化**
- 通俗：希腊留下了《荷马史诗》、好多哲学家（苏格拉底、亚里士多德）、漂亮的帕特农神庙；罗马人修了大竞技场、凯旋门、万神殿，还编了"儒略历"，就是现在公历的前身。
- 严谨：
  - 文学：希腊的**《荷马史诗》**（《伊利亚特》《奥德赛》）是宝贵的文学遗产。
  - 哲学：**德谟克利特**提出"原子论"；**苏格拉底**主张"认识你自己"；**亚里士多德**是一位百科全书式的学者，创立了逻辑学等新学科。
  - 建筑：希腊代表是**雅典帕特农神庙**；罗马代表有**大竞技场、凯旋门、方尖碑、万神庙**。
  - 历法：罗马凯撒命人以古埃及太阳历为蓝本编制新历法，称**"儒略历"**，成为今天公历的基础。

### 三、历史意义·阶段特征与重要结论

- **阶段特征**：古希腊、罗马是**西方文明的源头**，属于海洋文明；雅典民主政治、罗马法是留给后世最重要的两份遗产。
- 课本结论：
  - 雅典的民主是**奴隶制民主政治**，本质是奴隶主对奴隶的统治，进步性与局限性并存。
  - 亚历山大东征**客观上促进了东西方文化的大交汇**。
  - 《十二铜表法》是**罗马法制建设的第一步**，是后世罗马法典乃至欧洲法学的渊源。
  - **476年西罗马帝国灭亡**，标志着西欧奴隶社会的结束、封建社会的开始（欧洲进入中世纪）。

### 四、因果线索与常用史观·答题模型

- 因果链（罗马）：不断扩张→奴隶大量使用→社会矛盾激化（斯巴达克起义）→共和国危机→军事独裁→屋大维建立帝国→2世纪达到全盛→3世纪危机→分裂→476年灭亡。
- 辩证一分为二：**亚历山大东征**、罗马扩张，既有侵略、掠夺的一面，又客观上传播了文明、促进了交流。
- 答题模型（评价战争/扩张）：先答**性质（侵略性）**→再答**给被征服地区带来的灾难**→最后答**客观上促进了文化交流/经济往来**。

### 五、考点与典型题型·方法

**题型1：雅典民主政治的"高峰"与局限**
- 通法：看到"伯里克利"就选"雅典奴隶制民主政治发展到高峰"；看到"谁有民主权利"，记住只有**成年男性公民**。
- 例："雅典的一切公职人员由抽签产生，成年男性公民均可参加公民大会。"——这描述的是**伯里克利时代**的雅典民主；其局限性是**妇女、奴隶、外邦人没有政治权利**。

**题型2：罗马共和国→帝国的关键年份**
- 通法：前509年（共和国）→ 前27年（屋大维、帝国开始）→ 476年（西罗马亡）。

**题型3：《十二铜表法》意义**
- 分点答案：①颁布于**公元前450年左右**；②使量刑定罪有了文字依据，在一定程度上遏制了贵族对法律的曲解和垄断；③是**罗马法制建设的第一步，是后世罗马法典乃至欧洲法学的渊源**。

**题型4：评价亚历山大东征（材料题）**
- 分点答案：①性质：**具有侵略性质**，给东方人民带来了巨大灾难，掠夺了无数财富；②客观作用：促进了**东西方文化的大交汇**，加强了东西方经济联系和贸易往来；③帝国地跨欧亚非三洲。

### 六、易错易混

- ❌ 认为雅典民主"人人都能投票" → ✅ 只有**成年男性公民**能参政，奴隶、妇女、外邦人被排除在外，本质是奴隶制民主。
- ❌ 把"伯里克利"说成罗马的 → ✅ 伯里克利是**古希腊雅典**的政治家。
- ❌ 把"罗马帝国建立时间"记成前509年 → ✅ 前509年是**罗马共和国**建立；**前27年屋大维**才建立罗马帝国。
- ❌ 把西罗马灭亡年当成公元4世纪 → ✅ 是**476年（5世纪后期）**，换算：476年属于**5世纪**（401—500年）。
- ❌ 把《十二铜表法》当成世界第一部成文法典 → ✅ 它是罗马法制建设的第一步；"迄今已知世界上第一部较为完整的成文法典"是**《汉谟拉比法典》**。
- ❌ 只说亚历山大东征"好"或只说"坏" → ✅ 要**一分为二**：有侵略性，也客观促进了东西方文化交汇。

## 第三单元 封建时代的欧洲

> 课时：第7课 基督教的兴起和法兰克王国；第8课 西欧庄园；第9课 中世纪城市和大学的兴起；第10课 拜占庭帝国和《查士丁尼法典》（课号以教材目录为准）。

### 一、本单元时空脉络（知识结构）

```
封建时代的欧洲（中世纪，约5—15世纪）
│
├─ 思想：基督教（1世纪，罗马统治下的巴勒斯坦）→ 中世纪欧洲占统治地位的思想
├─ 政治：法兰克王国
│   ├─ 克洛维（481年前后）皈依基督教
│   ├─ 8世纪前期 查理·马特改革 → 封君封臣制度（"我的附庸的附庸，不是我的附庸"）
│   ├─ 800年 查理曼被加冕为"罗马人的皇帝" → 查理曼帝国
│   └─ 843年《凡尔登条约》帝国一分为三 → 法兰西、德意志、意大利的雏形
├─ 经济：西欧庄园（9—13世纪，独立的自给自足的经济和政治单位）
├─ 新生：10世纪起 西欧城市兴起；12世纪 大学兴起（"中世纪最美好的花朵"）
└─ 东罗马（拜占庭）帝国
    └─ 查士丁尼（529年起《查士丁尼法典》→《罗马民法大全》）→ 1453年被奥斯曼帝国所灭

年代轴：1世纪（基督教兴起）→ 476（西罗马亡，欧洲进入中世纪）
        → 8世纪前期（封君封臣制）→ 800（查理曼帝国）→ 843（三分）
        → 9—13世纪（庄园）→ 10世纪（城市兴起）→ 12世纪（大学）→ 1453（拜占庭亡）
```

### 二、核心史事（时间·人物·经过，通俗→严谨）

**1. 基督教的兴起**
- 通俗：1世纪时，在罗马帝国统治下的巴勒斯坦一带，犹太人受不了压迫，就盼着救世主。传说耶稣就是"基督"（救世主），他教人忍受苦难，死后可以升天堂。这个信仰后来传遍欧洲。
- 严谨：**1世纪**，基督教在罗马帝国统治下的**巴勒斯坦**地区兴起，传道者说耶稣就是"基督"（救世主）。早期基督教主张忍受苦难，后来逐渐被罗马统治者利用，4世纪末被定为罗马国教，到中世纪成为欧洲占统治地位的思想。

**2. 法兰克王国与封君封臣制度**
- 通俗：日耳曼人在西罗马的废墟上建了法兰克王国。国王把土地当"礼物"分给部下，部下要宣誓效忠、服骑兵役；一层一层分下去，就形成"封君—封臣"关系。但规矩很怪：附庸只效忠自己的直接封君，"我的附庸的附庸，不是我的附庸"。
- 严谨：
  - **克洛维**建立法兰克王国，皈依基督教，承认罗马教会在欧洲的重要地位。
  - **8世纪前期（查理·马特改革）**，形成了**封君封臣制度**：封君把土地有条件地分封给封臣，封臣要为封君服兵役、提供金钱等。封君封臣关系有着严格的等级性，权利、义务交织在一起，有一定的契约意义。
  - **800年**，**查理**被罗马教皇加冕为"罗马人的皇帝"，他统治的法兰克王国史称"查理曼帝国"。
  - **843年**，查理曼的三个孙子缔结条约，帝国一分为三，形成以后**法兰西、德意志、意大利**三个国家的雏形。

**3. 西欧庄园**
- 通俗：中世纪农村的基本单位是庄园，庄主（领主）有自己的自营地，农奴种的是份地；庄园几乎什么都自己生产，连铁匠、面包师都有，还设庄园法庭处理纠纷。
- 严谨：从9世纪开始，**西欧庄园**逐渐流行，大约到11世纪遍布欧洲。它是一个**独立的自给自足的经济和政治单位**。庄园的居民均为领主的佃户，包括自由的农民和缺少自由的**农奴**。土地分为**自营地**（领主直接经营）和**份地**（佃户的生活来源）。庄园还设有**庄园法庭**，既维护领主的利益，也在一定程度上限制领主的特权。

**4. 中世纪城市和大学的兴起**
- 通俗：10世纪起，欧洲到处开始冒出城市，很多市民用钱或武力从领主手里"赎买"了自治权；城市里手工业者、商人聚集，还办起了大学，被称为"中世纪最美好的花朵"。
- 严谨：
  - 从10世纪起，西欧旧的城市开始复苏，新的城市不断产生。城市居民通过**金钱赎买**和**武力斗争**等方式争取城市的自由和自治，如法兰西的琅城市民起义。
  - 市民阶层逐渐形成，其中富裕的大手工业作坊主、商人和银行家等，成为**早期的资产阶级**。
  - **12世纪**，西欧的教育与学术出现了新的气象，**大学的兴起**被认为是**欧洲中世纪教育"最美好的花朵"**。

**5. 拜占庭帝国与《查士丁尼法典》**
- 通俗：东罗马帝国首都在拜占庭（后来叫君士坦丁堡），国力一直很强。皇帝查士丁尼让人把过去罗马的法律整理成一套完整法典，叫《罗马民法大全》，是欧洲法学的基础；可它后来越来越保守，1453年被奥斯曼土耳其人灭掉。
- 严谨：
  - 东罗马帝国（即**拜占庭帝国**）的首都君士坦丁堡旧址就是古希腊的殖民城市拜占庭。
  - **529年起，查士丁尼**组织编纂了《查士丁尼法典》，后来又陆续编成《法学汇纂》《法理概要》《新法典》，这4部法律文献统称为**《罗马民法大全》**。它**仍然承认奴隶制，但在一定程度上改善了奴隶的地位**，还对财产、买卖、债务、契约关系等作出明确规定，**奠定了欧洲民法的基础**。
  - **1453年，奥斯曼帝国攻破君士坦丁堡，拜占庭帝国最终灭亡**。

### 三、历史意义·阶段特征与重要结论

- **阶段特征**：欧洲进入封建社会（中世纪），政治上分裂割据（封君封臣制）、经济上以庄园农奴制为基础、思想上基督教占统治地位；到中世纪后期，城市和大学兴起，孕育出新的社会因素（早期资产阶级）。
- 课本结论：
  - 封君封臣制度以**土地的封赐**为纽带，形成严格的封建等级。
  - 西欧庄园是**独立的自给自足的经济和政治单位**。
  - 城市的兴起和 **大学的兴起**为后来的文艺复兴准备了条件。
  - **《罗马民法大全》奠定了欧洲民法的基础**。
  - 拜占庭帝国对东西方文化兼收并蓄，为后来文艺复兴提供了丰富的精神营养。

### 四、因果线索与常用史观·答题模型

- 因果链：西罗马灭亡（476）→ 日耳曼人建国 → 土地分封 → 封君封臣制 → 封建等级；生产力恢复 → 农业手工业发展 → 10世纪城市复苏 → 市民阶层/早期资产阶级 → 大学兴起。
- 唯物史观：**经济基础决定上层建筑**——庄园经济决定了封君封臣的政治关系；城市商品经济发展，才催生市民阶层和早期资产阶级。
- 答题模型（"中世纪西欧"类题）：从**政治（封君封臣、分裂）、经济（庄园）、思想（基督教）、新因素（城市、大学）**四个角度概括阶段特征。

### 五、考点与典型题型·方法

**题型1：封君封臣制的纽带**
- 通法：看到"我的附庸的附庸，不是我的附庸"，直接选**以土地的封赐为纽带的封建等级制度**。

**题型2：查理曼帝国一分为三**
- 例：843年查理曼帝国分裂，形成后来哪三个国家的雏形？——**法兰西、德意志、意大利**。

**题型3：西欧庄园性质**
- 分点答案：①庄园是一个**独立的自给自足的经济和政治单位**；②土地分自营地和份地；③居民是领主的佃户，包括自由农民和农奴；④设庄园法庭维护秩序。

**题型4：城市争取自治的方式**
- 通法：两种——**金钱赎买**和**武力斗争**（典型：法兰西琅城市民起义）。

**题型5：《罗马民法大全》**
- 例：材料"查士丁尼……把历代罗马法加以系统化和法典化……"
  - 分点答案：①法典总称**《罗马民法大全》**（含《查士丁尼法典》等4部）；②仍然承认奴隶制，但一定程度上改善了奴隶地位；③**奠定了欧洲民法的基础**；④帝国最终于**1453年**被奥斯曼帝国所灭。

### 六、易错易混

- ❌ 把基督教兴起时间写成4世纪 → ✅ 基督教**1世纪**兴起于巴勒斯坦；4世纪末才被定为罗马国教。
- ❌ 把"我的附庸的附庸，不是我的附庸"当成中国西周分封制 → ✅ 这是**西欧封君封臣制**的特点。
- ❌ 认为中世纪城市"生来就自由" → ✅ 城市通过**金钱赎买或武力斗争**争得自治。
- ❌ 把《罗马民法大全》说成"世界上第一部成文法典" → ✅ 那是《汉谟拉比法典》；《罗马民法大全》的定位是**奠定欧洲民法基础**。
- ❌ 把拜占庭灭亡年写成476年 → ✅ 476年是**西罗马帝国**灭亡；拜占庭（东罗马）是**1453年**才被奥斯曼帝国所灭。
- ❌ 把大学兴起时间说成10世纪 → ✅ **12世纪**大学兴起，被称为"中世纪最美好的花朵"；10世纪是城市开始复苏。

## 第四单元 封建时代的亚洲国家

> 课时：第11课 古代日本；第12课 阿拉伯帝国（课号以教材目录为准）。

### 一、本单元时空脉络（知识结构）

```
封建时代的亚洲
│
├─ 古代日本
│   ├─ 5世纪 大和政权统一日本
│   ├─ 646年 孝德天皇"大化改新"（学习唐朝）→ 发展为中央集权制封建国家
│   └─ 12世纪晚期 源赖朝建镰仓幕府 → 近700年幕府统治（天皇大权旁落）
└─ 阿拉伯
    ├─ 7世纪初 穆罕默德在麦加创立伊斯兰教
    │   ├─ 622年 徙志麦地那（伊斯兰教历元年）
    │   └─ 630年 占领麦加
    ├─ 8世纪中期 阿拉伯帝国地跨欧亚非三洲
    └─ 文化：改造并传播"阿拉伯数字"、《天方夜谭》（《一千零一夜》）

年代轴：5世纪（日本统一）→ 622（伊斯兰教历元年）→ 630（穆罕默德占麦加）
        → 646（大化改新）→ 8世纪中期（阿拉伯帝国全盛）→ 12世纪晚期（日本幕府开始）
```

### 二、核心史事（时间·人物·经过，通俗→严谨）

**1. 古代日本：大化改新与幕府统治**
- 通俗：日本古代本来学中国——646年孝德天皇仿唐朝制度搞改革，把贵族土地收归国有、中央集权，日本从此变成封建国家；后来武士集团势力越来越大，12世纪源赖朝建镰仓幕府，天皇成了摆设，这种"幕府将军掌权"的局面持续近700年。
- 严谨：
  - **5世纪**，在本州中部兴起的**大和政权**统一了日本。
  - **从646年开始，日本仿效唐朝的典章制度，进行了一系列改革，史称"大化改新"**。政治上建立以天皇为中心的中央集权制度，地方设国、郡、里三级；经济上废除一切私地、私民，将土地、部民收归国有，成为公地、公民。**大化改新使日本发展成为一个中央集权制的封建国家**。
  - 日本幕府统治：**12世纪晚期，源氏武士集团首领源赖朝获得"征夷大将军"称号，设幕府于镰仓**。镰仓幕府拥有独立于朝廷的政治、军事权力，日本由此进入近700年的**幕府统治时期**，天皇大权旁落，实权掌握在以武士为主体的幕府将军手中。

**2. 阿拉伯帝国、伊斯兰教与阿拉伯文化**
- 通俗：阿拉伯半岛上穆罕默德7世纪初在麦加创伊斯兰教，622年被迫迁到麦地那（这年后来被定为伊斯兰教历元年），630年回师麦加；到8世纪中期建成地跨欧亚非三洲的大帝国。阿拉伯人还担当了东西方文化的"使者"，把印度人发明的数字改造后传到欧洲，就是今天的"阿拉伯数字"。
- 严谨：
  - **7世纪初，穆罕默德**在阿拉伯半岛的**麦加**创立**伊斯兰教**，主张独尊真主安拉。
  - **622年，穆罕默德率领一些信徒迁居麦地那**，建立了一个以共同信仰为基础的宗教社团，这一年被定为**伊斯兰教历元年**。
  - **630年，穆罕默德率穆斯林占领麦加**，此后半岛基本统一。
  - **8世纪中期，阿拉伯帝国的版图地跨亚、欧、非三洲**，是当时世界上疆域最大的帝国之一。
  - 阿拉伯人担当了沟通东西方文化的角色：**改造了古印度人从0到9的计数法**，形成现在的"**阿拉伯数字**"；编写成《**天方夜谭**》（又名《一千零一夜》）等文学作品。

### 三、历史意义·阶段特征与重要结论

- **阶段特征**：亚洲在封建时代既出现了学习先进制度成功转型的日本（大化改新），也出现了凭借宗教迅速统一并建立大帝国的阿拉伯。
- 课本结论：
  - **大化改新是日本从奴隶社会向封建社会过渡的标志**，使日本发展成为中央集权制封建国家。
  - 伊斯兰教的产生与阿拉伯半岛的统一**互相促进**：宗教打破了部落界限，成为统一的纽带。
  - 阿拉伯人是**东西方文化交流的使者**，阿拉伯数字的传播就是典型例证。

### 四、因果线索与常用史观·答题模型

- 因果链（日本）：阶级矛盾尖锐 + 中国唐朝制度先进 → 派遣唐使学习 → 646年大化改新 → 中央集权封建国家；后来武士集团壮大 → 幕府统治。
- 因果链（阿拉伯）：半岛分裂、商业不畅 → 穆罕默德创伊斯兰教（一神教利于统一）→ 政教合一政权 → 不断扩张 → 8世纪中期地跨三洲。
- 答题模型（"改革类"题）：先答**背景**（内外矛盾/学习对象）→ 再答**内容**（政治、经济）→ 最后答**性质与影响**（使社会形态转变）。

### 五、考点与典型题型·方法

**题型1：大化改新的性质与影响**
- 通法：看到"仿效唐朝""646年"直接锁定大化改新；答"使日本发展成为中央集权制封建国家"。
- 例：日本历史上一次以学习唐朝为核心的改革是？——**大化改新（646年，孝德天皇）**；影响：**使日本发展成为一个中央集权制的封建国家**。

**题型2：日本幕府统治开始的标志**
- 例：12世纪晚期，获得"征夷大将军"称号、设镰仓幕府的是——**源赖朝**；从此日本进入近700年的幕府统治，天皇大权旁落。

**题型3：伊斯兰教历元年**
- 通法：**622年（穆罕默德迁居麦地那）**为伊斯兰教历元年；630年占领麦加。

**题型4：阿拉伯文化的贡献**
- 分点答案：①改造并传播**阿拉伯数字**；②把中国的造纸术、指南针、火药等重大发明和印度的棉花、食糖等传入欧洲；③文学作品《**天方夜谭**》；④担当了**沟通东西方文化的使者**。

### 六、易错易混

- ❌ 把大化改新说成"学习欧美" → ✅ 大化改新是**学习中国唐朝**；学习欧美是后来的明治维新（九下）。
- ❌ 把幕府开始时间写成646年 → ✅ 646年是**大化改新**；**12世纪晚期**源赖朝镰仓幕府才开始。
- ❌ 把伊斯兰教创立地写成麦地那 → ✅ 7世纪初穆罕默德在**麦加**创教；**622年迁居麦地那**（伊斯兰教历元年）。
- ❌ 认为阿拉伯数字是阿拉伯人发明的 → ✅ 是**古印度人**发明的，阿拉伯人**改造并传到欧洲**，所以叫阿拉伯数字。
- ❌ 把《天方夜谭》当成古希腊作品 → ✅ 它是**阿拉伯**民间故事集（《一千零一夜》）。
- ❌ 混淆日本两次改革 → ✅ 大化改新（646，学唐，进入封建社会）；明治维新（1868，学欧美，走上资本主义道路，见九下）。

## 第五单元 走向近代

> 课时：第13课 西欧经济和社会的发展（租地农场与手工工场）；第14课 文艺复兴运动；第15课 探寻新航路；第16课 早期殖民掠夺（课号以教材目录为准）。

### 一、本单元时空脉络（知识结构）

```
走向近代（14—16世纪，欧洲从封建社会向资本主义社会过渡）
│
├─ 经济基础：租地农场、手工工场（雇佣关系＝资本主义萌芽）
├─ 思想解放：文艺复兴（14世纪中叶，意大利）
│   ├─ 核心思潮：人文主义
│   └─ 代表：但丁《神曲》；达·芬奇《蒙娜丽莎》《最后的晚餐》；莎士比亚

│   ├─ 1487 迪亚士（好望角）
│   ├─ 1492 哥伦布（发现美洲）

        → 1588（英国败西班牙"无敌舰队"）→ 16—19世纪（三角贸易）
```

### 二、核心史事（时间·人物·经过，通俗→严谨）

**1. 租地农场和手工工场（资本主义萌芽）**
- 通俗：农村里一些富裕农民租地、雇佣没地的人种地，叫"租地农场"；城里商人把活分给出资的手工业者，按件计酬，叫"手工工场"。不管哪种，关键是"老板出钱、工人出力、拿工资"——这就是资本主义生产关系的萌芽。
- 严谨：
  - 14世纪中叶以后，西欧一些富裕农民通过承租、购买等方式建立**租地农场**，雇佣少地或无地的农民耕种，将产品推向市场。
  - 集中的**手工工场**也逐渐形成：商人将统一配备的生产工具出租给分散的工匠，或把工匠集中在同一厂房里劳动，工人成为出卖劳动力的雇佣劳动者。
  - 土地关系的变化和手工业的发展，**推动农业和手工业生产组织逐渐资本主义化**，开始改变中世纪欧洲社会的整体面貌。

**2. 文艺复兴**
- 通俗：14世纪意大利人觉得中世纪天天讲神、不讲人，太压抑。于是他们借复兴古希腊罗马文化的名义，大讲"人应该享受现世幸福、要发挥聪明才智"——这就是人文主义。这场思想解放运动叫文艺复兴。
- 严谨：
  - **14世纪中叶，意大利**的佛罗伦萨、威尼斯等地兴起**文艺复兴运动**，它的**核心思潮是人文主义**——主张以人为中心而不是以神为中心，肯定人的价值和尊严，提倡追求现世幸福。
  - 文艺复兴**不是简单复兴古典文化，而是新兴资产阶级的思想解放运动**。
  - 代表人物：
    - **但丁**（文艺复兴的先驱），代表作《**神曲**》；
    - **达·芬奇**，代表作《**蒙娜丽莎**》《**最后的晚餐**》；
    - 英国的**莎士比亚**，代表作《哈姆雷特》《罗密欧与朱丽叶》。

**3. 新航路开辟**
- 通俗：欧洲人想到东方（印度、中国）赚香料、丝绸，可旧路被阿拉伯人和土耳其人控制，于是干脆从海上绕着走。四个关键人物：迪亚士到好望角；哥伦布误打误撞到了美洲；达·伽马绕过好望角真到了印度；麦哲伦的船队第一次绕地球一圈，证明了地圆说。
- 严谨：
  - 1487年，**迪亚士**沿非洲西海岸南下，到达非洲好望角；
  - **1492年，哥伦布**在西班牙王室资助下横渡大西洋，到达今天美洲的巴哈马群岛，"发现"美洲，他把当地人称为"印第安人"；
  - 1497—1498年，**达·伽马**沿迪亚士航线继续前行，到达印度西海岸，找到了通往东方的新航路；
  - **1519—1522年，麦哲伦率领的船队**完成了**环球航行**，证明了地圆说的正确。
  - 影响：欧洲大西洋沿岸工商业经济繁荣起来，促进了资本主义的产生和发展；欧洲与亚洲、非洲、美洲之间建立起了直接的商业联系，世界开始连为一个整体，**世界的观念也从此逐步确立起来**。

**4. 早期殖民掠夺与三角贸易**
- 通俗：新航路一开，葡萄牙、西班牙、英国这些国家就在美洲、非洲、亚洲抢殖民地、抢金银；还把非洲黑人当奴隶贩运到美洲干活，路线是"欧洲→非洲→美洲→欧洲"，船上装的货换来换去，史称"三角贸易"。
- 严谨：
  - 最早进行殖民的国家是**葡萄牙和西班牙**；1588年英国打败西班牙"无敌舰队"，逐渐成为海上霸主。
  - 英国以贩卖黑奴为中心，进行了以**三角贸易**为名的黑奴贸易：商船从欧洲出发，满载火器、机械制品到非洲掳获黑人，运往美洲卖给种植园主，再把美洲的蔗糖、烟草等运回欧洲。
  - 殖民掠夺为欧洲带来了巨额利润，是**资本原始积累**的重要途径；但也给美洲、非洲、亚洲人民带来了深重灾难。

### 三、历史意义·阶段特征与重要结论

- **阶段特征**：14—16世纪，欧洲在经济、思想、对外关系三方面同步"走向近代"——资本主义萌芽（经济）、文艺复兴（思想）、新航路开辟与殖民扩张（世界市场雏形）。
- 课本结论：
  - 租地农场、手工工场的出现，标志**资本主义生产关系的萌芽**。
  - 文艺复兴是一场**反对教会"神权至上"、提倡人文主义的资产阶级思想解放运动**，为欧洲资本主义的产生和发展奠定了思想文化基础。
  - 新航路开辟后，**世界开始连为一个整体**，世界的观念逐步确立；欧洲大西洋沿岸工商业繁荣起来。
  - 早期殖民掠夺是欧洲**资本原始积累**的重要手段，具有野蛮性和血腥性。

### 四、因果线索与常用史观·答题模型

- 因果链：资本主义萌芽（经济）→ 资产阶级要求打破神学束缚（思想）→ 文艺复兴；商品经济发展、寻金热、商路受阻、地圆说、航海技术进步 → 新航路开辟 → 世界市场雏形 + 殖民掠夺 → 资本原始积累 → 资本主义进一步发展。
- 唯物史观：**经济基础（资本主义萌芽）决定思想上层建筑（文艺复兴）**；生产力发展推动世界从分散走向整体。
- 一分为二：**哥伦布发现美洲、殖民扩张**——对欧洲是资本原始积累，对亚非美是灾难。
- 答题模型（"走向近代"综合题）：从**经济（资本主义萌芽）、思想（文艺复兴）、世界联系（新航路）、资本积累（殖民掠夺）**四方面作答。

### 五、考点与典型题型·方法

**题型1：文艺复兴的核心思潮**
- 通法：看到"以人为中心""提倡人性"直接选**人文主义**；性质是**资产阶级思想解放运动**。

**题型2：文艺复兴代表人物与作品配对**
- 通法：但丁—《神曲》；达·芬奇—《蒙娜丽莎》《最后的晚餐》；莎士比亚—《哈姆雷特》《罗密欧与朱丽叶》。

**题型3：新航路开辟人物事迹**
- 例："他始终认为自己到达的是亚洲的印度，因而把当地居民称为印第安人。"——这个人是**哥伦布**（1492年，到达美洲）。
- 例：第一次完成环球航行、证明地圆说的是——**麦哲伦船队**（1519—1522）。

**题型4：新航路开辟的影响（材料题）**
- 分点答案：①欧洲大西洋沿岸工商业经济繁荣起来，**促进了资本主义的产生和发展**；②欧、亚、非、美洲之间建立起直接商业联系；③**世界开始连为一个整体，世界的观念逐步确立**；④随之而来的殖民掠夺给亚非美人民带来灾难。

**题型5：三角贸易路线**
- 通法：欧洲（出程，工业品）→ 非洲（中程，掳黑奴）→ 美洲（归程，蔗糖烟草回欧洲）。

### 六、易错易混

- ❌ 认为文艺复兴就是"复兴古希腊罗马文化" → ✅ 它是**新兴资产阶级的思想解放运动**，借古典文化之名，行反封建之实。

- ❌ 把新航路开辟的根本原因说成"地圆说流行" → ✅ 根本原因是**欧洲商品经济发展、资本主义萌芽，渴求黄金和市场**；地圆说、航海技术只是条件。
- ❌ 只说新航路开辟"好" → ✅ 要答**世界连为整体 + 欧洲资本主义发展**，同时指出**给亚非美带来殖民灾难**。
- ❌ 混淆最早殖民国家 → ✅ 最早进行殖民的是**葡萄牙和西班牙**；英国后来居上，进行"三角贸易"。

## 第六单元 资本主义制度的初步确立

> 课时：第17课 君主立宪制的英国；第18课 美国的独立；第19课 法国大革命和拿破仑帝国（课号以教材目录为准）。

### 一、本单元时空脉络（知识结构）

```
资本主义制度初步确立（17—18世纪资产阶级革命）
│
├─ 英国
│   ├─ 1640 议会重新召开（革命开始）
│   ├─ 1649 查理一世被推上断头台
│   ├─ 1688 光荣革命
│   └─ 1689《权利法案》→ 君主立宪制确立
├─ 美国（独立战争＝资产阶级革命＋民族解放战争）
│   ├─ 1775 来克星顿枪声（开始）
│   ├─ 1776.7.4《独立宣言》（建国）

└─ 法国

        → 1787（美国宪法）→ 1789（法国大革命）→ 1804（拿破仑帝国）
```

### 二、核心史事（时间·人物·经过，通俗→严谨）

**1. 英国资产阶级革命与《权利法案》**
- 通俗：英国国王想独揽大权，还乱收税，议会不答应，两边打了起来。1688年一帮人和荷兰来的威廉合作"和平政变"（光荣革命），1689年议会通过《权利法案》，把国王的权力关进了法律的笼子——国王逐渐"统而不治"，议会掌权，这就是君主立宪制。
- 严谨：
  - **1640年，议会重新召开**，议员们抨击国王查理一世专横，标志英国资产阶级革命开始。
  - 1649年，**查理一世被推上断头台**，英国宣布为共和国。
  - 1688年，英国发生**"光荣革命"**，废黜詹姆士二世，迎请威廉和玛丽入主英国。
  - **1689年，议会通过《权利法案》**，重申英国人"自古就有的权利"，如定期召开议会、议员言论自由、征税权属于议会等。此后**英国议会的权力日益超过国王，君主立宪制逐渐形成**。

**2. 美国独立战争、《独立宣言》与1787年宪法**
- 通俗：北美13个殖民地受不了英国的税和压迫，1775年来克星顿一声枪响，独立战争开打；1776年7月4日大陆会议发表《独立宣言》，宣告美国诞生；1777年萨拉托加大捷扭转战局；1783年英国承认美国独立；随后华盛顿主持制定1787年宪法，按"三权分立"组建政府。
- 严谨：
  - **1775年4月，来克星顿的枪声**，标志美国独立战争爆发。
  - **1776年7月4日，大陆会议发表由杰斐逊起草的《独立宣言》**，宣布人人生而平等，享有生命权、自由权和追求幸福的权利，列举英国殖民者的暴政，**宣告北美13个殖民地脱离英国而独立**。《独立宣言》是**第一个以国家名义明确表述资产阶级政治要求的纲领性文献**，被称为"第一个人权宣言"。7月4日后成为美国国庆日。
  - **1777年萨拉托加大捷**是独立战争的转折点。
  - **1783年，英国被迫承认美国独立**。美国独立战争既是一次**民族解放战争**，也是一场**资产阶级革命**。
  - **1787年，美国制定宪法**：依据**分权制衡**原则设计了一个联邦制共和国——行政、立法、司法三权分立，总统、国会与最高法院及其相关机构各司其职，相互制衡。**1787年美国宪法是世界上第一部资产阶级成文宪法**。**华盛顿**当选第一任总统。

**3. 法国大革命、《人权宣言》与拿破仑帝国**
- 通俗：法国当时分成三个等级，教士、贵族骑在第三等级（平民、资产阶级）头上。1789年7月14日巴黎人民攻占巴士底狱，革命爆发；随后颁布《人权宣言》，说"人生来而且始终是自由平等的"。革命跌宕起伏，最后军事家拿破仑上台，1804年称帝，还颁布了《拿破仑法典》，但远征俄国失败，1815年滑铁卢一败涂地。
- 严谨：
  - **1789年7月14日，巴黎人民攻占巴士底狱**，法国大革命开始。
  - 随后制宪议会通过《**人权宣言**》，宣告**人权、法治、自由、分权、平等和保护私有财产**等基本原则（"在权利方面，人们生来是而且始终是自由平等的"）。
  - 1792年建立**法兰西第一共和国**；1793年国王**路易十六被送上断头台**；以罗伯斯庇尔为首的雅各宾派把革命推向高潮。
  - **1799年，拿破仑发动政变**；**1804年建立法兰西第一帝国**。为整理革命以来的立法成果，拿破仑主持制定了**《拿破仑法典》**（又称《法国民法典》），体现了自由平等和私有财产神圣不可侵犯等原则，**成为近代欧洲各国资产阶级法典的范本**。
  - 1812年拿破仑远征俄国大败；1815年**滑铁卢战役**后帝国覆灭。

### 三、历史意义·阶段特征与重要结论

- **阶段特征**：17—18世纪，英、美、法先后通过革命确立资本主义制度，法治取代人治、民主取代专制是主流。
- 课本结论：
  - 英国资产阶级革命和《权利法案》使英国**逐渐确立了君主立宪制**，为资本主义发展开辟了道路。
  - 美国独立战争**既是民族解放战争，也是资产阶级革命**，实现了国家独立，确立了比较民主的资产阶级政治体制。
  - 法国大革命摧毁了法国的君主统治，**传播了资产阶级自由民主思想，具有世界性影响**。
  - 《拿破仑法典》**成为近代欧洲资产阶级法典的范本**。

### 四、因果线索与常用史观·答题模型

- 因果链：资本主义发展 → 资产阶级要求掌权 → 革命（英国议会、美国抗英、法国反封建）→ 颁布法律（《权利法案》《独立宣言》1787年宪法《人权宣言》《拿破仑法典》）→ 确立资本主义制度。
- 唯物史观：**新的资本主义生产力要求打破旧的封建（或殖民）生产关系**，革命就是这种生产关系适应生产力的表现。
- 答题模型（"比较三国革命"题）：从**根本原因、开始标志、重要文献、政体、性质、意义**六个角度列表比较。

### 五、考点与典型题型·方法

**题型1：英国《权利法案》的意义**
- 分点答案：①1689年由议会通过；②限制国王权力，保证议会的立法权、财政权等；③**议会权力日益超过国王，君主立宪制逐渐形成**。

**题型2：《独立宣言》**
- 例："我们以这些殖民地的善良人民的名义和权力，谨庄严宣告：这些联合殖民地从此成为、而且名正言顺地应当成为自由独立的合众国……"
  - 分点答案：①出自1776年7月4日**《独立宣言》**（杰斐逊起草）；②宣告**北美13个殖民地脱离英国独立**，美国诞生；③被称为"**第一个人权宣言**"；④7月4日为美国国庆日。

**题型3：1787年美国宪法**
- 通法：世界上**第一部资产阶级成文宪法**；原则是**分权制衡（三权分立）**；行政—总统、立法—国会、司法—最高法院。

**题型4：法国大革命开始标志**
- 通法：**1789年7月14日攻占巴士底狱**；《人权宣言》核心：人权、自由、平等、保护私有财产。

**题型5：评价拿破仑**
- 分点答案：①颁布《拿破仑法典》，成为近代欧洲资产阶级法典范本；②对外战争前期打击了欧洲封建势力，传播了革命思想；③后期战争具有侵略性，引起被征服民族反抗；④1812年远征俄国失败，1815年滑铁卢战败。

### 六、易错易混

- ❌ 把英国革命开始标志写成1688光荣革命 → ✅ 开始标志是**1640年议会重新召开**；1688是光荣革命，1689是《权利法案》。
- ❌ 认为《权利法案》颁布后英国国王立刻没有任何权力 → ✅ 是**逐渐**形成君主立宪制，国王后来"统而不治"。
- ❌ 把《独立宣言》发表时间写成1783年 → ✅ **1776年7月4日**发表（建国）；1783年是英国**承认**美国独立。
- ❌ 把美国独立战争只说成"资产阶级革命" → ✅ 它**既是民族解放战争，也是资产阶级革命**。
- ❌ 把法国大革命开始写成"处死路易十六" → ✅ 开始标志是**1789年7月14日攻占巴士底狱**；1793年才处死路易十六。
- ❌ 把《拿破仑法典》等同于《人权宣言》 → ✅ 《人权宣言》是革命初期的纲领性宣言；《拿破仑法典》是拿破仑主持制定的民法典，是**近代欧洲资产阶级法典的范本**。

## 第七单元 工业革命和国际共产主义运动的兴起

> 课时：第20课 第一次工业革命；第21课 马克思主义的诞生和国际工人运动的兴起（课号以教材目录为准）。

### 一、本单元时空脉络（知识结构）

```
工业革命与马克思主义诞生（18世纪60年代—19世纪70年代）
│
├─ 第一次工业革命（18世纪60年代起，英国）
│   ├─ 1765 哈格里夫斯发明"珍妮机"（开始标志）
│   ├─ 1785 瓦特改良蒸汽机（核心标志，进入"蒸汽时代"）
│   ├─ 工厂制度确立（现代工厂制度最终确立）
│   ├─ 交通：1825 斯蒂芬森蒸汽机车试车成功（铁路时代）
│   └─ 19世纪中期（约1840年前后）英国率先完成
├─ 马克思主义诞生
│   ├─ 1848《共产党宣言》发表（马克思、恩格斯）→ 马克思主义诞生
│   ├─ 1864 第一国际成立
│   └─ 1871 巴黎公社（无产阶级建立政权的第一次伟大尝试）
└─ 同时期社会变化：工业资产阶级、工业无产阶级两大阶级形成

年代轴：1765（珍妮机）→ 1785（瓦特改良蒸汽机）→ 1825（蒸汽机车）
        → 1848（《共产党宣言》）→ 1864（第一国际）→ 1871（巴黎公社）
```

### 二、核心史事（时间·人物·经过，通俗→严谨）

**1. 第一次工业革命**
- 通俗：18世纪60年代起，英国棉纺织业先革命——手工工具变成机器；瓦特改良蒸汽机后，工厂不必再靠河边水车，可以随便建，人类进入"蒸汽时代"；后来斯蒂芬森造出蒸汽机车（火车），铁路时代来了。整个过程从手工工场过渡到大工厂。
- 严谨：
  - **18世纪60年代**，工业革命首先发生在**英国**的棉纺织业。**1765年，哈格里夫斯发明"珍妮机"**，大大提高了纺纱效率，标志工业革命开始。
  - **1785年，瓦特改进的蒸汽机**开始在纺织部门投入使用，后来化工、冶金、采矿等部门也使用蒸汽机。**蒸汽机成为主要的动力来源**，**传统的手工工场逐渐被大工厂替代，现代工厂制度最终确立**，人类进入"**蒸汽时代**"。
  - 1825年，由**斯蒂芬森**设计制造的**蒸汽机车**试车成功，标志着**铁路时代的开始**。
  - 工业革命极大地提高了社会生产力水平，**人类进入"蒸汽时代"**；19世纪中期（约1840年前后），英国已成为世界上第一个工业国家。

**2. 马克思主义的诞生**
- 通俗：工业革命后，资本家越来越富，工人却很累、很穷，社会矛盾越来越尖。马克思、恩格斯研究资本主义，写出理论，告诉工人：要联合起来推翻资产阶级。1848年《共产党宣言》一发表，马克思主义诞生，工人运动有了科学理论指导。
- 严谨：
  - **1848年，马克思、恩格斯为共产主义者同盟起草的纲领《共产党宣言》在伦敦正式出版**。《共产党宣言》号召工人阶级组织起来，用暴力推翻资产阶级统治，进行无产阶级革命。
  - **《共产党宣言》的发表，标志着马克思主义的诞生**。从此，无产阶级的斗争有了科学理论的指导，国际共产主义运动兴起并蓬勃发展。
  - 1864年，英国、法国、德国等国的工人代表联合起来成立了**国际工人协会**，史称"**第一国际**"。
  - **1871年3月18日，巴黎的无产阶级和人民群众**举行武装起义，推翻了资产阶级反动统治，建立了世界上第一个无产阶级政权——**巴黎公社**。5月28日公社失败。**巴黎公社是无产阶级建立政权的第一次伟大尝试**，它的革命实践丰富了马克思主义关于无产阶级革命和无产阶级专政的学说。

### 三、历史意义·阶段特征与重要结论

- **阶段特征**：工业革命使人类进入"蒸汽时代"，资本主义生产力飞速发展；同时使社会日益分裂为**工业资产阶级和工业无产阶级**两大对立阶级，工人运动兴起，马克思主义诞生。
- 课本结论：
  - 工业革命极大地提高了社会生产力水平，**人类进入"蒸汽时代"**，现代工厂制度最终确立。
  - **《共产党宣言》的发表，标志着马克思主义的诞生**。
  - **巴黎公社是无产阶级建立政权的第一次伟大尝试**。

### 四、因果线索与常用史观·答题模型

- 因果链：海外市场扩大→手工工场供不应求→机器发明（珍妮机）→动力革新（瓦特蒸汽机）→工厂制度→交通运输革命（蒸汽机车）→生产力飞跃→两大阶级形成→工人运动→马克思主义诞生。
- 唯物史观：
  - **生产力决定生产关系**——蒸汽机代表的新生产力，要求建立现代工厂制度；
  - **经济基础决定上层建筑**——工业资本主义发展，既造就资产阶级，也造就掘墓人无产阶级；
  - **马克思主义是时代的产物**——工业革命后资本主义矛盾激化、工人运动发展，为马克思主义诞生提供了客观条件。
- 答题模型（"工业革命影响"题）：从**生产力、生产组织形式（工厂）、社会阶级结构、城市化、世界市场、环境问题**多角度作答。

### 五、考点与典型题型·方法

**题型1：工业革命开始与核心标志**
- 通法：开始标志——**1765年哈格里夫斯"珍妮机"**；核心标志——**瓦特改良蒸汽机**（人类进入蒸汽时代）。
- 例："18世纪60年代，从英国开始的工业革命，最早出现于哪个行业？"——**棉纺织业**。

**题型2：瓦特蒸汽机的意义**
- 分点答案：①1785年起在工业部门广泛使用；②成为主要动力来源；③打破了工厂必须靠近河流的限制；④**传统手工工场被大工厂替代，现代工厂制度最终确立**；⑤人类进入"蒸汽时代"。

**题型3：铁路时代**
- 通法：**1825年斯蒂芬森设计的蒸汽机车试车成功**，标志铁路时代开始。

**题型4：《共产党宣言》**
- 分点答案：①1848年由**马克思、恩格斯**为共产主义者同盟起草、在伦敦出版；②系统阐述了马克思主义基本原理，号召工人阶级用暴力推翻资产阶级统治；③**《共产党宣言》的发表，标志着马克思主义的诞生**；④从此无产阶级斗争有了科学理论指导。

**题型5：巴黎公社**
- 例："它是无产阶级建立政权的第一次伟大尝试。"——**1871年巴黎公社**；性质：世界上**第一个无产阶级政权**。

### 六、易错易混

- ❌ 把工业革命开始标志写成"瓦特改良蒸汽机" → ✅ 开始标志是**1765年哈格里夫斯发明"珍妮机"**；瓦特改良蒸汽机是**核心标志**，使人类进入蒸汽时代。
- ❌ 说工业革命"首先发生在交通运输业" → ✅ 首先发生在**棉纺织业**。
- ❌ 把蒸汽机车发明者写成瓦特 → ✅ 瓦特改良的是**蒸汽机**；发明蒸汽机车（火车）的是**斯蒂芬森**（1825年试车成功）。
- ❌ 把马克思主义诞生标志写成"第一国际成立" → ✅ 标志是**1848年《共产党宣言》发表**；第一国际是1864年成立的工人联合组织。
- ❌ 把巴黎公社说成"第一个社会主义国家" → ✅ 巴黎公社是**无产阶级建立政权的第一次伟大尝试**；第一个社会主义国家是1917年俄国十月革命后建立的（见九下）。
- ❌ 以为工业革命只有好处 → ✅ 还要答**负面影响**：贫富分化加剧、环境污染、工人遭受残酷剥削。
