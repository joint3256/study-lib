## 方法18：全等三角形判定「找条件套定理」法

### 适用题型
- 证明两个三角形全等，以及利用全等证明边相等或角相等。
- 题目特征："求证 $\triangle ABC \cong \triangle DEF$"或"求证某条线段相等/某个角相等"。

### 原理/公式
- 全等三角形判定定理（必须背熟）：
  - **SSS（边边边）**：三边对应相等。
  - **SAS（边角边）**：两边及其夹角对应相等。
  - **ASA（角边角）**：两角及其夹边对应相等。
  - **AAS（角角边）**：两角及其中一角的对边对应相等。
  - **HL（斜边直角边）**：只适用于直角三角形，斜边和一条直角边对应相等。
- **注意**：SSA 和 AAA 不能判定全等！

### 操作步骤
1. **找要证全等的两个三角形**。
2. **列已知条件**：从题目里直接能找到的边相等、角相等写出来。
3. **找隐含条件**：公共边、公共角、对顶角、平行线推出的同位角/内错角。
4. **凑齐三个条件**：对照 SSS/SAS/ASA/AAS/HL，看还差哪个。
5. **写证明过程**：按"在 $\triangle \dots$ 和 $\triangle \dots$ 中"的格式，列出条件，写出全等结论。

### 例题演示
**题干**：如图，点 $B, E, C, F$ 在同一直线上，$AB = DE$，$AC = DF$，$BE = CF$。求证：$\triangle ABC \cong \triangle DEF$。

**分步解答**：
1. 要证的两个三角形：$\triangle ABC$ 和 $\triangle DEF$。
2. 已知条件：$AB = DE$，$AC = DF$。
3. 找第三边：已知 $BE = CF$，两边同时加 $EC$：
   $$BE + EC = CF + EC \quad \Rightarrow \quad BC = EF$$
4. 三个条件齐了：三边对应相等 → SSS。
5. 写证明：
   在 $\triangle ABC$ 和 $\triangle DEF$ 中：
   $$\begin{cases}
   AB = DE \quad (\text{已知}) \\
   AC = DF \quad (\text{已知}) \\
   BC = EF \quad (\text{已证})
   \end{cases}$$
   $\therefore \triangle ABC \cong \triangle DEF$（SSS）。

**最终答案**：$\boldsymbol{\triangle ABC \cong \triangle DEF}$（SSS），得证。

### ❌ 易错提醒
- **用错判定定理**：SSA（两边及其中一边的对角）不能判定全等，别乱用。
- **角不是夹角**：SAS 必须是两边的夹角，不是随便一个角。
- **对应关系写错**：$A$ 对应 $D$，$B$ 对应 $E$，$C$ 对应 $F$，写全等时顶点顺序要对应好。

## 方法19：勾股定理「知二求三 + 逆定理判直角」法

### 适用题型
- 直角三角形中已知两边求第三边；
- 判断一个三角形是不是直角三角形；
- 立体图形表面最短路径（展开图）。
- 题目特征：直角三角形，给了两条边，求第三条。

### 原理/公式
- **勾股定理**：直角三角形两直角边的平方和等于斜边的平方。
  $$a^2 + b^2 = c^2$$
  其中 $c$ 是斜边（最长边，对着直角），$a, b$ 是两条直角边。
- **变形公式**：
  - 已知斜边和一条直角边：$b = \sqrt{c^2 - a^2}$
- **逆定理**：如果三角形三边长 $a, b, c$ 满足 $a^2 + b^2 = c^2$，那么这个三角形是直角三角形。

### 操作步骤
1. 确认是直角三角形（或用逆定理判断）。
2. 找哪条是斜边（最长边、对着直角的边）。
3. 代入公式：两条直角边的平方和 = 斜边的平方。
4. 开方求边长，注意边长是正数，取正根。
5. 实际问题中：折叠问题、梯子问题、最短路径问题，都是先找直角三角形再用勾股。

### 例题演示
**题干**：在 $Rt\triangle ABC$ 中，$\angle C = 90^\circ$，$AC = 6$，$BC = 8$，求斜边 $AB$ 的长。

**分步解答**：
1. 确认直角：$\angle C = 90^\circ$，所以 $AB$ 是斜边。
2. 设 $AC = 6$，$BC = 8$，求 $AB$。
3. 代入勾股定理：
   $$AB^2 = AC^2 + BC^2 = 6^2 + 8^2 = 36 + 64 = 100$$
4. 开方：$AB = \sqrt{100} = 10$（边长取正）。

**最终答案**：斜边 $AB$ 的长为 $\boldsymbol{10}$。

### ❌ 易错提醒
- **斜边找错**：斜边一定是最长边，对着直角的那条。不知道哪边是斜边时，先找直角。
- **平方和算错**：$6^2 + 8^2 = 36 + 64 = 100$，别写成 $(6+8)^2$。
- **忘记开方**：算出 $AB^2=100$ 之后，还要开方得到 $AB=10$，别直接写 $AB=100$。

## 方法20：相似三角形「A型/X型识别 + 比例列方程」法

### 适用题型
- 证明两个三角形相似，利用相似求边长、求面积比。
- 题目特征：有平行线、有公共角、有对顶角，或者有两个角对应相等。

### 原理/公式
- **相似三角形判定**（最常用的两个）：
  - 两角分别相等 → 两三角形相似（AA）。
  - 平行于三角形一边的直线截其他两边 → 截得的三角形与原三角形相似（A型/X型）。
- **相似性质**：
  - 对应边成比例，对应角相等。
  - 相似比 = 对应边的比。
  - 周长比 = 相似比。
  - 面积比 = 相似比的平方。
- **两种基本模型**：
  - **A型**：小三角形在大三角形内部，顶点重合，底边平行。
  - **X型（8字型）**：两个三角形交叉，对顶角相等，两边线段成比例。

### 操作步骤
1. **找平行**：题目有平行线，立刻想到相似。
2. **找等角**：公共角、对顶角、平行线推出的同位角/内错角。
3. **判定相似**：两个角对应相等就够了。
4. **写比例式**：对应边按顺序写好，比如 $\dfrac{AB}{DE} = \dfrac{BC}{EF} = \dfrac{AC}{DF}$。
5. **列方程求解**：把已知边代进去，解未知边。

### 例题演示
**题干**：如图，在 $\triangle ABC$ 中，$DE \parallel BC$，$D$ 在 $AB$ 上，$E$ 在 $AC$ 上。已知 $AD = 2$，$DB = 3$，$AE = 4$，求 $EC$ 的长。

**分步解答**：
1. 识别模型：$DE \parallel BC$，这是 A 型相似。
2. 判定相似：$\because DE \parallel BC$，$\therefore \triangle ADE \sim \triangle ABC$（AA，公共角 $\angle A$ 加同位角相等）。
3. 写比例式：对应边成比例
   $$\frac{AD}{AB} = \frac{AE}{AC}$$
4. 代入已知：$AD=2$，$DB=3$，所以 $AB = AD + DB = 5$。设 $EC = x$，则 $AC = AE + EC = 4 + x$。
   $$\frac{2}{5} = \frac{4}{4+x}$$
5. 解方程：
   $$2(4+x) = 20$$
   $$8 + 2x = 20$$
   $$2x = 12$$
   $$x = 6$$

**最终答案**：$EC$ 的长为 $\boldsymbol{6}$。

### ❌ 易错提醒
- **对应边写错**：相似三角形的边要按对应关系写，别把 $AD$ 和 $AC$ 对应上。
- **比例式列错**：小三角形边比大三角形边，别写反。
- **面积比是平方关系**：相似比是 2:3，面积比是 4:9，不是 2:3。

## 方法21：解直角三角形「选函数 + 列方程」法

### 适用题型
- 直角三角形中，已知一边一锐角，求其他边和角；
- 仰角、俯角、坡度、方向角等实际测量问题。
- 题目特征：有直角三角形，有角度（$30^\circ, 45^\circ, 60^\circ$ 或给了三角函数值），求高度、距离。

### 原理/公式
- 锐角三角函数定义（在 $Rt\triangle$ 中，$\angle C = 90^\circ$）：
  $$\sin A = \frac{\text{对边}}{\text{斜边}}, \quad \cos A = \frac{\text{邻边}}{\text{斜边}}, \quad \tan A = \frac{\text{对边}}{\text{邻边}}$$
- 特殊角三角函数值（必背）：
  | 角度 | $\sin$ | $\cos$ | $\tan$ |
  |---|---|---|---|
  | $30^\circ$ | $\dfrac{1}{2}$ | $\dfrac{\sqrt{3}}{2}$ | $\dfrac{\sqrt{3}}{3}$ |
  | $45^\circ$ | $\dfrac{\sqrt{2}}{2}$ | $\dfrac{\sqrt{2}}{2}$ | $1$ |
  | $60^\circ$ | $\dfrac{\sqrt{3}}{2}$ | $\dfrac{1}{2}$ | $\sqrt{3}$ |
- 实际问题关键：**仰角**是从低处往上看，视线与水平线的夹角；**俯角**是从高处往下看的夹角。

### 操作步骤
1. **画直角三角形**：把实际问题中的高度、距离、角度标在图上。
2. **确定已知和未知**：已知哪条边、哪个角，求哪条边。
3. **选三角函数**：看已知边和未知边分别是所求角的对边、邻边还是斜边，选 sin/cos/tan。
4. **列方程**：代入三角函数值，解方程求未知边。
5. **写答案**：按题目要求保留小数或保留根号。

### 例题演示
**题干**：小明站在地面上，测得一棵树顶端的仰角为 $$ 仰角 $30^\circ$，已知小明到树的水平距离是 $10$ 米，求这棵树的高度（结果保留根号）。

**分步解答**：
1. 画直角三角形：水平距离 10 米是邻边，树高是对边，仰角 $30^\circ$。
2. 已知邻边求对边 → 选 $\tan$（对边比邻边）。
3. 设树高为 $h$ 米。
4. 列方程：
   $$\tan 30^\circ = \frac{h}{10}$$
5. 代入 $\tan 30^\circ = \dfrac{\sqrt{3}}{3}$：
   $$\frac{\sqrt{3}}{3} = \frac{h}{10}$$
   $$h = \frac{10\sqrt{3}}{3}$$

**最终答案**：树高为 $\boldsymbol{\dfrac{10\sqrt{3}}{3}}$ 米。

### ❌ 易错提醒
- **三角函数定义记混**：sin 是对边比斜边，cos 是邻边比斜边，tan 是对边比邻边，别搞反。
- **仰角俯角找错位置**：仰角是视线和水平线的夹角，不是和竖直线的夹角。
- **忘记加测角仪高度**：实际题目里如果给了测角仪（或人）的高度，最后要加上。
