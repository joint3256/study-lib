# 初中数学 · 解题方法套路库

> 面向**基础薄弱学生**的讲题工具书。每个方法都按「方法名 → 适用题型 → 原理/公式 → 操作步骤 → 例题演示 → 易错提醒」六块组织，可直接拿去讲题。
>
> 共 **7 个板块、34 个方法**，覆盖初中数学全部核心考点。

---

## 使用说明

1. **先看适用题型**：判断你要讲的题属于哪种特征，再去找对应的方法。
2. **讲题时按六步走**：先讲为什么（原理），再一步步操作，最后提醒哪里容易错。
3. **例题数字都很简单**：方便学生当堂验算，不用计算器也能算对。
4. **❌ 易错提醒**部分是高频踩坑点，讲题时一定要强调。
