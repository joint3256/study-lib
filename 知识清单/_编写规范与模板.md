# 知识清单 · 编写规范与统一模板（所有学科必须遵守）

本文件是各学科板块的**统一编写规范**。目的：给线上家教做一套**可快速检索、能直接给基础薄弱学生讲题、查缺补漏**的本地知识库。每位编写者只负责一个板块目录，但格式、术语、深度必须与本规范完全一致。初中段已扩展为**全科**：数学、物理、化学、历史、道德与法治（道法）、语文（英语库已另建，不在 cz-combine 触发范围）。

## 一、范围与版本（不得超范围）

- 初中**全科 6 科**（cz-combine 覆盖）：数学、物理、化学、历史、道德与法治、语文。
  - 数学 / 物理 / 化学 = **人教版（按 2022 课标修订的新版）**：物理 3 册（八上、八下、九年级全一册），化学 2 册（九上、九下）。
  - **历史、道德与法治、语文 = 全国统编（部编 / 人教）版，各 6 册（七上～九下）**；历史为中国史（七上、七下、八上、八下）＋世界史（九上、九下）。
- 高中段：数学、物理、化学、英语（沿用原约定，本次不改动）。
- 依据课标：初中用 **《义务教育课程标准（2022 年版）》**；高中用 **《普通高中课程标准（2017 年版 2020 修订）》**。
- **不超纲**：不把高中/大学内容、竞赛技巧当作初中必讲知识点；可在"拓展/选学"里点到为止并明确标注。
- **单元号/课号不臆造**：统编教材按"单元→课"组织。拿不准精确序号时，**按主题组织**，并在标题下注明"序号以教材目录为准"，绝不编造看似精确但无依据的单元/课/目号。

## 二、目录与文件约定

- 每个板块一个目录：`知识清单/<学段>/<学科>/`（初中全科目录：`初中/数学`、`初中/物理`、`初中/化学`、`初中/历史`、`初中/道法`、`初中/语文`）。
- **每一"册"一个 Markdown 文件**，文件名即册次名：
  - 初中：`七年级上册.md`、`七年级下册.md`、`八年级上册.md`、`八年级下册.md`、`九年级上册.md`、`九年级下册.md`；物理用 `九年级全一册.md`（无九上/九下）。
  - 高中：`必修第一册.md`、`必修第二册.md`、`必修第三册.md`、`选择性必修第一册.md`、`选择性必修第二册.md`、`选择性必修第三册.md`、`选择性必修第四册.md`（仅高中英语有第四册）。
- 每个板块目录内还必须有：
  - `README.md`：本板块索引（列出所有册文件、每册主题/章节、检索提示）。
  - `资料来源.md`：课标、教材版本、国家平台、以及**实际参考过的**开源仓库（URL + 协议）；若内容为依据课标与教材目录自行编写，也要如实写明。**不得编造仓库许可证**。
- **纯 Markdown 小文件**：不放 PDF、图片、音频等大体积二进制（便于以后 git 私有库跨设备同步）。公式用 LaTeX（行内 `$...$`，独立成行 `$$...$$`）。
- 层级：理科册文件内 `#` = 册名，`##` = 章，`###` = 六要素小节；**历史 / 道法 `##` = 单元**（下含若干课，开头列"课时"行）；**语文 `##` = 知识板块**（见第六节）。

## 三、每章六要素（理科：数学/物理/化学，标题固定）

每个 `## 第N章 章名` 之下，**依次**包含以下六个 `###`，缺一不可，且不得写"略/待补充/同上"：

1. `### 一、本章知识结构`
   - 用 Markdown 缩进树形（或 `→` 箭头流程）画出本章知识地图，体现概念之间的从属与先后；不依赖 mermaid 等可能不渲染的组件。
   - 开头先用一行列出本章**节次**：`> 节次：第1节 …；第2节 …；…（节号以教材目录为准）`。
2. `### 二、核心概念（通俗→严谨）`
   - 按节组织。每个概念先**一句话大白话**（让基础弱的学生秒懂），再给**严谨定义**。
   - 物理量须写明**符号、单位（含常用倍数单位）、标/矢量**；化学概念须点明条件与适用范围。
3. `### 三、定理、公式与结论`
   - 用 LaTeX 准确书写；**每个符号都要解释**，标注**成立条件/适用范围/单位**。
   - 化学方程式、物理公式中的常数取值要注明（如 $g$ 取 $9.8\,\text{N/kg}$，粗略计算取 $10\,\N/kg$）。
4. `### 四、公式推导要点与常用模型`
   - 给出关键公式的**推导思路链**（不必每步都写，但要让学生知道"从哪来"）。
   - 归纳本章**常用物理/数学/化学模型**（如"相遇/追及模型""板块模型""守恒法""差量法"），说明识别特征与通法。
5. `### 五、考点与典型题型·方法`
   - 列出常考题型，每种给：**题型名 → 解题步骤/通法 → 一个简短范例（含解答）**。
   - 范例数字要简单、典型，解答过程完整、可核验。
6. `### 六、易错易混`
   - 用 `❌ 错误：…` / `✅ 正确：…` 成对列出，直击基础薄弱学生高频错误（符号、单位、定义域、条件遗漏、概念混淆等）。

## 四、英语学科的六要素（标题固定）

英语按教材的 **Module（初中）/ Unit（高中）** 组织，每个 Module/Unit 之下依次：

1. `### 一、模块地图与话题主线`：本模块在整册中的位置、**话题（topic）**、功能意念；开头一行列出本模块的 Unit/板块构成。
2. `### 二、核心词汇与短语`：按单元列**高频词（词性 + 中文释义 + 常见搭配 + 一个简单例句）**与重点短语；标注课标要求层级（初中 1500 词范围、高中 3000 词范围，超纲词标 *）。
3. `### 三、语法要点`：**语法结构（form）+ 用法/意义（use）+ 例句 + 易错提示**；初中覆盖课标语法项目表，高中覆盖词法、句法（三大从句、非谓语、特殊句式等）。
4. `### 四、话题表达与写作`：本话题**功能句/话题语块**、可套用句型、简短范文或写作框架（应用文/记叙文；高中含概要写作、读后续写的素材与方法）。
5. `### 五、常考题型与解题方法`：按学段覆盖听力、单项/语法填空、完形填空、阅读理解、书面表达等；给**题型 → 方法步骤 → 示例**。
6. `### 六、易错易混`：词形变化、近义词/近形词、时态语态、搭配、中式英语等，`❌/✅` 成对。

## 五、文科六要素（历史 / 道法，按"单元"组织，标题固定）

统编历史、道法以 **单元 → 课** 编排。每个 `## 第N单元 单元名` 之下，先写一行 `> 课时：第1课 …；第2课 …；…（课号以教材目录为准）`，再**依次**含以下六个 `###`，缺一不可，不写"略/待补"。

**历史（六要素标题固定）：**
1. `### 一、本单元时空脉络（知识结构）`：用年代轴（`前221 → 前202 …`）＋缩进树形，画出事件先后、政权更迭与从属关系；体现"时空观念"。
2. `### 二、核心史事（时间·人物·经过，通俗→严谨）`：按课组织。每件事先**一句大白话**（讲了件什么事），再给**严谨表述**：时间（世纪/朝代/年号/公元）、地点、人物、经过、结果。
3. `### 三、历史意义·阶段特征与重要结论`：写事件的性质、意义/影响、教训，以及该时期**阶段特征**；用中考认可的规范表述（"答题语言"），关键句可标"课本结论"。
4. `### 四、因果线索与常用史观·答题模型`：梳理背景/原因（根本·直接·主观·客观）→ 经过 → 结果 → 影响的因果链；归纳唯物史观（生产力/经济基础、人民群众、辩证一分为二）；给材料题模型（见方法套路）。
5. `### 五、考点与典型题型·方法`：列常考选择题、材料题；每种给 **题型 → 通法 → 简短材料/示例（含分点答案）**。
6. `### 六、易错易混`：`❌/✅` 成对——年代/世纪换算、人物事件张冠李戴、朝代/政权顺序、历史概念（如"半殖民地半封建"）、意义与事件错配、史料类型与史料实证。

**道德与法治（六要素标题固定）：**
1. `### 一、本单元知识结构（逻辑框架图）`：用树形/流程画出"**是什么 → 为什么 → 怎么做**"的逻辑，标明课/框之间的包含与递进。
2. `### 二、核心观点（是什么，通俗→严谨）`：按课/框组织。每条先**大白话**，再给**课本规范观点句（关键词、关键句）**；专有名词（如宪法、人权、自由）给严谨定义。
3. `### 三、原理依据·意义作用（为什么）`：写理论/法律依据、重要性、必要性、意义或作用，用分点规范句（这些就是材料题"为什么"类的得分点）。
4. `### 四、观点联系与做法模型（怎么做）`：打通相关/易混观点；按**主体**（国家、政府、社会、学校、家庭、公民/青少年等）列做法；给材料题模型（观点＋材料＋做法，见方法套路）。
5. `### 五、考点与典型题型·方法`：选择题（排除法/抓关键词）与材料分析题（是什么/为什么/怎么做/评析/建议/启示）；每种给 **题型 → 通法 → 示例（含分点答案）**。
6. `### 六、易错易混`：`❌/✅` 成对——相近观点混淆、**绝对化表述**（"最/唯一/彻底/只要…就/根除"）、主体与做法错位、权利与义务/根本制度与基本制度等概念、材料与观点不对应、把"道德"当"法律"。

## 六、语文学科六要素（按"知识板块"组织，标题固定）

统编语文一册内先放一张 `> 本册单元与课文一览（以教材目录为准）` 表（单元｜主题｜教读/自读课文｜写作｜综合性学习·名著导读），随后按**五个固定知识板块**各写一个 `##`，每个板块之下**依次**含六个 `###`（标题固定）：

`## 板块一　基础知识（字音字形·词语·病句·标点·文学文化常识）`
`## 板块二　古诗文阅读（文言文·古诗词曲·理解性默写）`
`## 板块三　现代文阅读（按本册文体：记叙文/说明文/议论文/文学作品/非连续性文本）`
`## 板块四　名著导读·综合性学习与口语交际`
`## 板块五　写作（审题立意·选材结构·语言·范文框架）`

每个板块之下依次：
1. `### 一、本板块知识结构（考点地图）`：树形列出本板块考点及在中考中的位置；古诗文板块须列出**本册必背篇目清单**（篇名｜作者｜朝代｜体裁｜默写高频句）。
2. `### 二、核心知识（通俗→严谨）`：本册具体内容——字音字形成语、文言实词虚词/通假/词类活用/特殊句式、文学文化常识、课文主旨与写法；每条给大白话＋严谨表述。
3. `### 三、规律·方法·答题模板（讲清为什么）`：阅读各考点的**答题角度＋规范表述模板**（如概括内容、赏析句子、说明方法及作用、论证方法及作用、标题/段落作用、人物形象），写清"为什么从这几个角度答"。
4. `### 四、常用模型与识别特征`：审题信号词→对应考点/模板（如"结合全文说说"=概括，"某词能否删去"=说明文语言准确性，"运用了什么论证"=议论文）；作文的审题/结构模型。
5. `### 五、考点与典型例题·示范`：按本板块考点给 **例题 → 分点规范作答**；现代文须用简短文段示范；作文给审题立意＋提纲＋片段示范。
6. `### 六、易错易混`：`❌/✅` 成对——易错字/多音字、成语误用、病句类型、文言词语、文体与答题模板错配（把说明文答成议论文）、答题空泛无文本依据、作文偏题/文体不清。

> 各年级文体侧重（用于"板块三"取材）：七年级以**记叙文（写人记事、写景抒情）、童话散文**为主；八上重**事物说明文**、八下重**事理说明文、游记、演讲**；九上重**议论文**、九下重**小说、戏剧**。古诗文与基础知识各册全覆盖。

## 七、质量底线（写完先自查）

- **六要素齐全**：用脚本统计每个 `##`（理科章 / 文科单元 / 语文板块）下是否都含六个 `###` 标题；缺一个即不合格。
- **公式/事实可核验、正确**：年代、人物、数据、法条、观点、文言词语宁可写"以教材为准/选学"，也不臆造；关键事实须能在课标、国家平台元数据或权威公开来源中核对。
- **面向薄弱学生**：先通俗后严谨，多用类比、步骤化、口诀（口诀要科学）。
- 每个范例必须能得出正确结果；涉及计算的结论要实际算过，不写"约为"而无依据。
- 文件全部落在自己板块目录的**绝对路径**下；返回时给出：文件绝对路径清单、各册单元/课或板块数量、六要素自查结果、每科至少 1 个可 grep 命中的代表知识点证据、参考来源清单。
