# 05 四边形与圆 · 解题方法套路库

> 本板块覆盖平行四边形及特殊平行四边形证明、圆的三大定理（垂径、圆周角、切线）。证明题的套路是「性质反过来用就是判定，一步步往上升级」。

---

## 方法22：平行四边形证明「性质判定互推」法

### 适用题型
- 证明一个四边形是平行四边形；
- 利用平行四边形性质证明边相等、角相等、对角线互相平分。
- 题目特征：四边形中给了边/角/对角线的关系，要求证明是平行四边形。

### 原理/公式
- **平行四边形性质**（已知是平行四边形，可以推出）：
  1. 对边平行且相等。
  2. 对角相等。
  3. 对角线互相平分。
- **平行四边形判定**（满足以下之一就是平行四边形）：
  1. 两组对边分别平行 → 平行四边形。
  2. 两组对边分别相等 → 平行四边形。
  3. 一组对边平行且相等 → 平行四边形。
  4. 对角线互相平分 → 平行四边形。
- **核心思路**：性质和判定是反着的——要证平行四边形，就从边或对角线入手凑条件。

### 操作步骤
1. **看题目给了什么条件**：给了边相等？边平行？对角线互相平分？
2. **选对应判定定理**：
   - 有一组对边平行且相等 → 直接用"一组对边平行且相等"判定。
   - 有两组对边相等 → 用"两组对边分别相等"。
   - 对角线互相平分 → 用"对角线互相平分"。
3. **写证明过程**：从已知出发，一步步推出判定条件，最后下结论。
4. 如果题目是"已知平行四边形，求证某结论"，就反过来用性质。

### 例题演示
**题干**：如图，在四边形 $ABCD$ 中，$AB \parallel CD$，$AB = CD$。求证：四边形 $ABCD$ 是平行四边形。

**分步解答**：
1. 已知条件：$AB \parallel CD$ 且 $AB = CD$。
2. 对应判定定理：**一组对边平行且相等的四边形是平行四边形**。
3. 直接下结论：
   $\because AB \parallel CD$ 且 $AB = CD$（已知），
   $\therefore$ 四边形 $ABCD$ 是平行四边形（一组对边平行且相等的四边形是平行四边形）。

**最终答案**：四边形 $ABCD$ 是 $\boldsymbol{平行四边形}$，得证。

### ❌ 易错提醒
- **混淆性质和判定**：性质是"已知是平行四边形，推出结论"；判定是"已知条件，推出是平行四边形"。方向别反。
- **"一组对边平行，另一组对边相等"不能判定平行四边形**：等腰梯形也满足这个条件，但不是平行四边形。
- **对角线条件看错**：必须是"互相平分"（即两条对角线的交点是各自中点），不是对角线相等。

## 方法23：特殊平行四边形「先判平行四边形再升级」法

### 适用题型
- 证明一个四边形是矩形、菱形、正方形。
- 题目特征：先给平行四边形，再加一个条件（一个直角 / 一组邻边相等），问变成什么图形。

### 原理/公式
- **矩形判定**（在平行四边形基础上）：
  1. 有一个角是直角的平行四边形是矩形。
  2. 对角线相等的平行四边形是矩形。
  3. 有三个角是直角的四边形是矩形。
- **菱形判定**（在平行四边形基础上）：
  1. 有一组邻边相等的平行四边形是菱形。
  2. 对角线互相垂直的平行四边形是菱形。
  3. 四条边都相等的四边形是菱形。
- **正方形判定**：既是矩形又是菱形的四边形是正方形。
  - 先证是矩形，再证一组邻边相等。
  - 或先证是菱形，再证有一个角是直角。

### 操作步骤
1. **先证它是平行四边形**（用方法22）。
2. **再看升级条件**：
   - 要变矩形：找有没有直角、对角线相不相等。
   - 要变菱形：找有没有邻边相等、对角线垂不垂直。
3. **正方形就是双重身份**：矩形 + 菱形 = 正方形。
4. 写证明时层次要清楚：第一步证平行四边形，第二步证特殊条件。

### 例题演示
**题干**：已知平行四边形 $ABCD$ 中，$\angle A = 90^\circ$。求证：平行四边形 $ABCD$ 是矩形。

**分步解答**：
1. 已知它已经是平行四边形。
2. 条件：$\angle A = 90^\circ$（有一个角是直角）。
3. 套用矩形判定：**有一个角是直角的平行四边形是矩形**。
4. 写结论：
   $\because$ 四边形 $ABCD$ 是平行四边形，且 $\angle A = 90^\circ$，
   $\therefore$ 平行四边形 $ABCD$ 是矩形。

**最终答案**：平行四边形 $ABCD$ 是 $\boldsymbol{矩形}$，得证。

### ❌ 易错提醒
- **跳过平行四边形直接证矩形/菱形**：判定矩形和菱形的很多定理是"在平行四边形基础上"的，不先证平行四边形就不成立。
- **对角线相等 ≠ 矩形（对任意四边形）**：必须是平行四边形 + 对角线相等才是矩形。
- **正方形判定漏条件**：正方形需要同时满足矩形和菱形的条件，别只给一个条件就下结论。

## 方法24：垂径定理「半弦 + 半距 + 半径，勾股三连」法

### 适用题型
- 圆中求弦长、求半径、求圆心到弦的距离。
- 题目特征：圆里有一条弦，过圆心作弦的垂线，求线段长度。

### 原理/公式
- **垂径定理**：垂直于弦的直径平分这条弦，并且平分弦所对的两条弧。
- 由垂径定理推出的直角三角形：
  过圆心 $O$ 作 $OC \perp AB$ 于 $C$，则 $\triangle OAC$ 是直角三角形：
  - 斜边 $OA$ = 半径 $r$
  - 一条直角边 $AC = \dfrac{1}{2}AB$（半弦长）
  - 另一条直角边 $OC$ = 圆心到弦的距离
- 勾股定理套上去：
  $$\left(\frac{AB}{2}\right)^2 + OC^2 = r^2$$

### 操作步骤
1. 找到圆心、弦、以及圆心到弦的垂线段。
2. 确认垂足是弦的中点（垂径定理）。
3. 构成直角三角形：半径为斜边，半弦长和圆心距为两条直角边。
4. 用勾股定理列方程，知二求一。

### 例题演示
**题干**：已知 $\odot O$ 的半径为 $5$，一条弦 $AB = 8$，求圆心 $O$ 到弦 $AB$ 的距离。

**分步解答**：
1. 过 $O$ 作 $OC \perp AB$ 于 $C$，则 $C$ 是 $AB$ 中点（垂径定理）。
2. 半弦长 $AC = \dfrac{AB}{2} = 4$。
3. 直角三角形 $\triangle OAC$ 中：
   - 斜边 $OA = 5$（半径）
   - 直角边 $AC = 4$
   - 另一直角边 $OC = $ 圆心距（未知）
4. 勾股定理：
   $$OC^2 + AC^2 = OA^2$$
   $$OC^2 + 4^2 = 5^2$$
   $$OC^2 + 16 = 25$$
   $$OC^2 = 9$$
   $$OC = 3$$（距离取正）

**最终答案**：圆心到弦的距离为 $\boldsymbol{3}$。

### ❌ 易错提醒
- **忘记垂足是中点**：垂径定理的关键就是"垂直→平分"，不这个推论就列不出直角三角形。
- **半弦长算错**：弦长是整个弦的长度，除以2才是直角三角形的直角边。
- **半径和直径搞混**：题目给的是直径就要先除以2变成半径再用。

## 方法25：切线证明「连半径，证垂直」法

### 适用题型
- 证明一条直线是圆的切线（解答题常考）。
- 题目特征：直线经过圆上某一点，要求证明它是切线。

### 原理/公式
- **切线的判定定理**：经过半径外端，并且垂直于这条半径的直线是圆的切线。
- **证明套路**：
  - 如果已知直线和圆有公共点 → **连半径，证垂直**。
  - 如果不知道公共点（没说直线过圆上哪一点）→ **作垂直，证等于半径**。
- **切线性质**：圆的切线垂直于过切点的半径（反过来用来算角度、边长）。

### 操作步骤（已知公共点的情况，最常见）
1. 连接圆心和这个公共点，得到一条半径。
2. 证明这条半径和直线垂直（夹角是 $90^\circ$）。
3. 下结论：直线垂直于半径且过半径外端，所以是切线。
4. 证明垂直的常用方法：
   - 已知直角直接用。
   - 通过平行、全等、互余等关系推出 $90^\circ$。

### 例题演示
**题干**：如图，$AB$ 是 $\odot O$ 的直径，点 $C$ 在 $\odot O$ 上，过 $C$ 作直线 $l$，使 $\angle PCA = \angle B$。求证：直线 $l$ 是 $\odot O$ 的切线。

**分步解答**：
1. 连半径 $OC$。
2. 要证 $l$ 是切线，只需证 $OC \perp l$，即 $\angle OCP = 90^\circ$。
3. $\because AB$ 是直径，$\therefore \angle ACB = 90^\circ$（直径所对的圆周角是直角）。
   $\therefore \angle ACO + \angle OCB = 90^\circ$。
4. $\because OC = OB$（都是半径），$\therefore \angle OCB = \angle B$。
5. 已知 $\angle PCA = \angle B$，$\therefore \angle PCA = \angle OCB$。
6. 代入：
   $$\angle OCP = \angle OCA + \angle PCA = \angle OCA + \angle OCB = 90^\circ$$
   $\therefore OC \perp l$。
7. 又 $\because C$ 在圆上（$OC$ 是半径外端），
   $\therefore$ 直线 $l$ 是 $\odot O$ 的切线。

**最终答案**：直线 $l$ 是 $\odot O$ 的 $\boldsymbol{切线}$，得证。

### ❌ 易错提醒
- **不连半径就直接说垂直**：证明切线必须先连半径，没有半径就谈不上"垂直于半径"。
- **判定和性质搞混**：判定是"证垂直→得切线"；性质是"已知切线→得垂直"。方向别反。
- **不知道公共点时也去连半径**：如果题目没说直线过圆上哪一点，就不能连半径，要改成"作垂线，证垂线段等于半径"。

## 方法36：正多边形与圆·弧长·扇形面积「中心角定一切」法

### 适用题型
- 求正多边形的中心角、边长、边心距；求弧长、扇形面积；割圆术类用圆内接正多边形面积估计圆面积。
- 题目特征：出现"正 $n$ 边形""中心角""弧""扇形"，或借刘徽割圆术等数学文化包装。

### 原理/公式
- **正 $n$ 边形**：中心角 $=\dfrac{360^\circ}{n}$。
  - 外接圆半径 $R$：边长 $a_n=2R\sin\dfrac{180^\circ}{n}$；边心距 $=R\cos\dfrac{180^\circ}{n}$。
  - 特例：正六边形边长 $=R$；正方形边长 $=\sqrt2 R$。
  - 圆内接正 $n$ 边形面积 $S=\dfrac{n}{2}R^2\sin\dfrac{360^\circ}{n}$（也等于 $n\cdot\tfrac12 a_n\cdot$ 边心距）。
- **弧长**（圆心角 $n^\circ$，半径 $R$）：$l=\dfrac{n\pi R}{180}$。
- **扇形面积**：$S=\dfrac{n\pi R^2}{360}=\tfrac12 l R$（$l$ 为弧长）。

### 操作步骤
1. **正多边形**：先算中心角 $\dfrac{360^\circ}{n}$；求边长就作边心距，半边长 $=R\sin\dfrac{180^\circ}{n}$。
2. **弧长**：代 $l=\dfrac{n\pi R}{180}$，注意 $n$ 是角度，不是弧度。
3. **扇形面积**：知圆心角用 $S=\dfrac{n\pi R^2}{360}$；已知弧长用 $S=\tfrac12 l R$ 更快。
4. **割圆术类**：把圆内接正 $n$ 边形面积当成圆面积 $\pi R^2$ 的近似值，反解 $\pi$。

### 例题演示
**题干**：半径为 $1$ 的圆，用其内接正十二边形的面积估计 $\pi$。

**分步解答**：
1. 中心角 $=\dfrac{360^\circ}{12}=30^\circ$。
2. 正十二边形面积：
   $$S=\frac{n}{2}R^2\sin\frac{360^\circ}{n}=\frac{12}{2}\cdot1^2\cdot\sin30^\circ=6\times\frac12=3$$
3. 圆面积 $=\pi R^2=\pi$，令 $\pi\approx S=3$。

**最终答案**：正十二边形面积为 $\boldsymbol{3}$，估计 $\pi\approx\boldsymbol{3}$。

### ❌ 易错提醒
- **中心角用错**：正 $n$ 边形中心角 $=\dfrac{360^\circ}{n}$；$\dfrac{180^\circ}{n}$ 是半边心距三角形的半顶角，别混。
- **弧长与扇形面积公式混**：弧长 $l=\dfrac{n\pi R}{180}$（$R$ 一次方），扇形 $S=\dfrac{n\pi R^2}{360}$（$R$ 二次方）。
- **扇形面积两式选错**：已知弧长 $l$ 时用 $S=\tfrac12 l R$ 最省事，不必再反求圆心角。
