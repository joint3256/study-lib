# 资料来源与编写说明

本文件说明「高中英语（外研版 2019）知识清单」的依据、参考来源与编写方式。所有内容**未抓取、未复制任何受版权保护的教材全文或教辅原文**，词汇、语法讲解与例句均为依据课标与教材话题**自行编写**。

## 一、政策与课标依据

- 《普通高中英语课程标准（2017 年版 2020 年修订）》（中华人民共和国教育部制定，人民教育出版社）。
  - 依据其规定的**三大主题语境**（人与自我、人与社会、人与自然）、**话题项目表**、**语法项目表**（句子成分与基本句型、时态与语态、情态动词、定语从句/名词性从句/状语从句、非谓语动词、倒装/强调/省略、主谓一致、构词法等）以及**词汇量要求（约 3000 词，必修约 2000 + 选必约 1000）**组织内容。
- 天津现行高中英语教材版本：**外研版（2019）**，必修三册 + 选择性必修四册，共 7 册。

## 三、词汇、语法与例句的编写方式（如实说明）

- **词汇**：依据课标约 3000 词范围，按单元话题选取高频词，标注词性、释义、常见搭配与自编例句；超出课标范围的词以 `*` 标注。未照搬任何教材词表或词表文件。
- **语法**：按课标语法项目表与高考常见考点自行归纳结构、用法、例句与易错点；例句为自造，语言力求自然、面向基础薄弱学生。
- **写作**：应用文/记叙文框架、概要写作三步法、读后续写两段式方法为依据高考写作题型与通用教学经验自行总结，语块为自编。
- **未参考具体开源词表/语法仓库**：为避免许可证与内容来源不清的问题，本清单未引入任何第三方开源词库或语法仓库的文本；因此**不存在需要声明的第三方开源 URL 与许可证**。如后续需要接入经核实许可证（如 CC0 / CC-BY 类）的公开词表，将另行补充 URL 与协议。
