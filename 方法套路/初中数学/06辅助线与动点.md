## 方法26：几何辅助线「见中点想中位线 / 倍长中线」通法

### 适用题型
- 几何证明题中出现"中点"条件，不知道怎么用。
- 题目特征：题目里说"$D$ 是 $BC$ 中点"或"$E$ 是 $AD$ 中点"，要证线段关系或角度关系。

### 原理/公式
- **看到一个中点**：想**倍长中线**——把中线延长一倍，构造全等三角形。
  - 做法：延长 $AD$ 到 $E$，使 $DE = AD$，连接 $BE$，就能得到 $\triangle ADC \cong \triangle EDB$。
- **看到两个中点**：想**中位线定理**——连接两个中点的线段是三角形中位线。
  - 中位线平行于第三边，且等于第三边的一半：
    $$DE \parallel BC, \quad DE = \frac{1}{2}BC$$
- **口诀**：一个中点倍长线，两个中点连中位。

### 操作步骤
1. **数中点个数**：题目里有几个中点？
2. **一个中点** → 倍长中线：把从这个中点出发的线段延长一倍，构造全等。
3. **两个中点** → 连中位线：把两个中点连起来，用中位线定理。
4. **连完之后**：利用全等或中位线的性质，得到边相等/平行/长度关系，继续推结论。

### 例题演示
**题干**：如图，在 $\triangle ABC$ 中，$D$ 是 $BC$ 的中点，$AB = 5$，$AC = 3$，求 $AD$ 的取值范围。

**分步解答**：
1. 看到一个中点 $D$ → 用倍长中线法。
2. 延长 $AD$ 到 $E$，使 $DE = AD$，连接 $BE$。
3. 证全等：
   - $BD = CD$（$D$ 是中点）
   - $\angle BDE = \angle CDA$（对顶角相等）
   - $DE = DA$（我们作的）
   $\therefore \triangle BDE \cong \triangle CDA$（SAS）
4. 由全等得：$BE = AC = 3$。
5. 在 $\triangle ABE$ 中，三角形三边关系：
   $$AB - BE < AE < AB + BE$$
   $$5 - 3 < AE < 5 + 3$$
   $$2 < AE < 8$$
6. 又 $\because AE = 2AD$，
   $$2 < 2AD < 8 \quad \Rightarrow \quad 1 < AD < 4$$

**最终答案**：$AD$ 的取值范围是 $\boldsymbol{1 < AD < 4}$。

### ❌ 易错提醒
- **看到中点不知道干嘛**：中点不是白给的，一定要用辅助线把它的作用发挥出来。
- **倍长中线时延长方向错**：是延长"从顶点到中点的那条线"，不是延长别的线。
- **中位线定理用错边**：中位线是连接两个中点的线段，它平行的是第三边（不是两个中点之间的边）。

## 方法27：折叠问题「折痕是对称轴，对应点连线被折痕垂直平分」法

### 适用题型
- 矩形/三角形折叠问题，求折叠后的边长、角度、面积。
- 题目特征："将矩形纸片沿某条线折叠，点 $A$ 落在 $A'$ 处，求线段长"。

### 原理/公式
- 折叠的本质是**轴对称**：折痕就是对称轴。
- 折叠前后：
  - 对应边相等，对应角相等。
  - 折痕垂直平分对应点的连线。
- **解题套路**：
  1. 找折叠前后相等的边和角。
  2. 设未知数（通常设要求的那条边为 $x$）。
  3. 在某个直角三角形里用勾股定理列方程。

### 操作步骤
1. **标相等**：把折叠后重合的边、角标出来（相等）。
2. **设未知数**：设某条未知线段为 $x$。
3. **找直角三角形**：折叠问题几乎都能凑出一个直角三角形。
4. **用勾股定理列方程**：三条边都用 $x$ 表示出来，代入 $a^2 + b^2 = c^2$。
5. **解方程**，求边长。

### 例题演示
**题干**：如图，矩形纸片 $ABCD$ 中，$AB = 8$，$BC = 6$。将纸片沿 $AE$ 折叠，点 $B$ 恰好落在 $CD$ 边上的 $B'$ 处，求 $BE$ 的长。

**分步解答**：
1. **标相等**（折叠前后）：
   - $AB' = AB = 8$
   - $BE = B'E$
2. **先在 $\triangle ADB'$ 里求 $DB'$**：
   - $AD = BC = 6$
   - $AB' = 8$，$\angle D = 90^\circ$
   - $DB' = \sqrt{AB'^2 - AD^2} = \sqrt{64 - 36} = \sqrt{28} = 2\sqrt{7}$（这里我们换个简单数字的题）

   换一道数字更简单的例题：

**例题（数字简化版）**：矩形 $ABCD$ 中，$AB = 10$，$BC = 6$。沿 $AE$ 折叠，使 $B$ 落在 $CD$ 上的 $F$ 处，已知 $AF = AB = 10$，求 $EF$。

**分步解答（简化版）**：
1. 折叠相等：$AF = AB = 10$，$EF = BE$。
2. 在 $Rt\triangle ADF$ 中：$AD = 6$，$AF = 10$，
   $$DF = \sqrt{AF^2 - AD^2} = \sqrt{100 - 36} = \sqrt{64} = 8$$
   $\therefore FC = DC - DF = 10 - 8 = 2$。
3. 设 $EF = x$，则 $BE = x$，$EC = BC - BE = 6 - x$。
4. 在 $Rt\triangle EFC$ 中：
   $$EF^2 = EC^2 + FC^2$$
   $$x^2 = (6-x)^2 + 2^2$$
5. 解方程：
   $$x^2 = 36 - 12x + x^2 + 4$$
   $$0 = 40 - 12x$$
   $$12x = 40$$
   $$x = \frac{10}{3}$$

**最终答案**：$EF$ 的长为 $\boldsymbol{\dfrac{10}{3}}$。

### ❌ 易错提醒
- **折叠后的等量关系找不全**：折叠前后对应边相等、对应角相等，别只找到一条。
- **设未知数不知道往哪放**：设完 $x$ 之后，一定要在一个直角三角形里把三条边都用 $x$ 表示出来。
- **勾股定理列错边**：斜边是最长边，别把斜边放到直角边位置。

## 方法28：旋转问题「旋转前后全等，对应点到旋转中心距离相等」法

### 适用题型
- 图形旋转后求边长、角度、证明线段关系。
- 题目特征："将 $\triangle ABC$ 绕点 $O$ 旋转一定角度得到 $\triangle A'B'C'$"。

### 原理/公式
- 旋转的性质：
  1. 旋转前后的图形**全等**。
  2. 对应点到旋转中心的距离**相等**（$OA = OA'$）。
  3. 对应点与旋转中心连线的夹角 = **旋转角**（$\angle AOA' = \angle BOB'$）。
- **解题套路**：
  - 看到旋转 → 立刻找全等。
  - 对应边相等、对应角相等。
  - 旋转角相等 → 找等腰三角形（$OA = OA'$ 就是等腰）。

### 操作步骤
1. **找旋转中心和旋转方向**。
2. **标对应点**：谁转到了谁的位置。
3. **写全等**：旋转前后两个三角形全等，对应边、对应角相等。
4. **找旋转角**：对应点和旋转中心连线的夹角，都相等。
5. 利用全等和等腰三角形的性质，推边长和角度。

### 例题演示
**题干**：如图，将 $Rt\triangle ABC$ 绕直角顶点 $C$ 顺时针旋转 $90^\circ$ 得到 $\triangle A'B'C$。若 $AC = 4$，求 $AA'$ 的长。

**分步解答**：
1. 旋转中心是 $C$，旋转角是 $90^\circ$。
2. 由旋转性质：$CA' = CA = 4$，且 $\angle ACA' = 90^\circ$（旋转角）。
3. $\therefore \triangle ACA'$ 是等腰直角三角形：直角边 $CA = CA' = 4$，直角 $\angle ACA' = 90^\circ$。
4. 求斜边 $AA'$：
   $$AA' = \sqrt{CA^2 + CA'^2} = \sqrt{4^2 + 4^2} = \sqrt{32} = 4\sqrt{2}$$

**最终答案**：$AA'$ 的长为 $\boldsymbol{4\sqrt{2}}$。

### ❌ 易错提醒
- **旋转角找错**：旋转角是对应点和旋转中心连线的夹角，不是随便两个边的夹角。
- **旋转前后的对应关系搞反**：$A$ 转到 $A'$，$B$ 转到 $B'$，别把 $A$ 和 $B'$ 对应上。
- **忘记旋转前后全等**：全等了才能用对应边相等，这是最基本的出发点。

## 方法29：动点问题「以静代动，设时间列函数」法

### 适用题型
- 几何图形中一个点（或几个点）沿着边运动，求某段时间内的面积、长度、函数关系。
- 题目特征："点 $P$ 从 $A$ 出发，以每秒 $1$ 个单位速度沿 $AB$ 运动，同时点 $Q$ 从 $B$ 出发……"。

### 原理/公式
- 动点问题的核心：**设运动时间为 $t$ 秒**，把所有动点走过的路程用 $t$ 表示出来，然后问题就变成了普通的几何计算题。
- 路程 = 速度 × 时间：$s = vt$。
- 常见类型：
  - 求面积关于 $t$ 的函数关系式。
  - 求什么时候 $\triangle PQB$ 是等腰三角形/直角三角形。
  - 求什么时候两条线段相等。

### 操作步骤
1. **设时间 $t$**：设运动了 $t$ 秒。
2. **表示各线段长度**：每个动点走了多远，用 $vt$ 算出来，剩下的边长也用 $t$ 表示。
3. **看问题类型**：
   - 求面积 → 用面积公式，底和高都用 $t$ 表示。
   - 求特殊三角形 → 按等腰/直角的条件列方程。
   - 求线段相等 → 让两个含 $t$ 的式子相等。
4. **写取值范围**：$t$ 不能是负数，点不能走出图形外面。
5. **解方程或写函数关系式**。

### 例题演示
**题干**：如图，在 $\triangle ABC$ 中，$\angle B = 90^\circ$，$AB = 6\ \text{cm}$，$BC = 8\ \text{cm}$。点 $P$ 从 $A$ 出发沿 $AB$ 向 $B$ 运动，速度 $1\ \text{cm/s}$；点 $Q$ 从 $B$ 出发沿 $BC$ 向 $C$ 运动，速度 $2\ \text{cm/s}$。两点同时出发，求经过几秒后 $\triangle PBQ$ 的面积为 $8\ \text{cm}^2$。

**分步解答**：
1. 设经过 $t$ 秒后面积为 $8\ \text{cm}^2$。
2. 表示线段：
   - $AP = 1 \times t = t$，$\therefore PB = AB - AP = 6 - t$。
   - $BQ = 2 \times t = 2t$。
3. $\triangle PBQ$ 是直角三角形（$\angle B = 90^\circ$），面积：
   $$S_{\triangle PBQ} = \frac{1}{2} \times PB \times BQ = \frac{1}{2}(6-t)(2t)$$
4. 令面积等于 8：
   $$\frac{1}{2}(6-t)(2t) = 8$$
   $$t(6-t) = 8$$
   $$6t - t^2 = 8$$
   $$t^2 - 6t + 8 = 0$$
   $$(t-2)(t-4) = 0$$
   $t_1 = 2, \, t_2 = 4$。
5. 检验取值范围：
   - $P$ 走完全程 $AB$ 需要 $6$ 秒，$Q$ 走完全程 $BC$ 需要 $4$ 秒。
   - $t=2$ 和 $t=4$ 都在范围内（$t=4$ 时 $Q$ 刚好到 $C$）。

**最终答案**：经过 $\boldsymbol{2}$ 秒或 $\boldsymbol{4}$ 秒后，$\triangle PBQ$ 的面积为 $8\ \text{cm}^2$。

### ❌ 易错提醒
- **不写取值范围**：$t$ 有上限（点走出边就停了），解出来的根要检查合不合理。
- **线段表示错**：$P$ 从 $A$ 出发走了 $t$，离 $B$ 的距离是 $6-t$，不是 $t$。
- **面积公式记错**：直角三角形面积是两直角边乘积的一半，别忘除以2。
- **两个答案都要写**：解一元二次方程出来两个根，都要检验，合理的都要写。
