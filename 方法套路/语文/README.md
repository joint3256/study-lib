## 二、高中板块

**暂留空。** 高中语文（论述类/文学类/文言文/古诗/作文/语言文字运用）方法库待后续按高考题型单独建设，不与初中混用——初高中答题规范、赋分点、术语口径差异较大，混编会误导基础薄弱学生。

## 三、合规与使用须知

- 方法主体依据《义务教育语文课程标准（2022 年版）》与统编（人教）版教材公开目录自行组织编写，术语与《知识清单 · 初中 · 语文》各册保持一致。
- 不收录、不复制教材全本、盗版"学霸笔记"扫描件、付费课程/内部讲义原文。
- 名师讲法部分仅提炼 B站/抖音/微博/公众号等**公开免费**内容里的"方法思路"，用自己的话重述；每位老师附公开链接，获取不到的在讲法文件末尾"未能获取清单"如实列出。
- 具体参考来源见 [资料来源.md](资料来源.md)。
