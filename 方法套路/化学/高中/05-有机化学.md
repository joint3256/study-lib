# 高中化学 · 有机化学

---

## 方法 H13　有机化学（官能团转化 / 同分异构 / 有机合成与推断）

### ① 方法名
**"不饱和度定骨架—特征反应定官能团—顺逆推定路线"三步法**

### ② 适用题型 / 物质
官能团性质判断、有机反应类型识别、同分异构体书写、有机合成路线设计、框图式有机推断。

### ③ 原理（为什么）
- **官能团决定有机物化学性质**：碳碳双键、羟基、醛基、羧基、酯基各有特征反应。
- 常见转化主线：烯烃 ⇌ 醇 ⇌ 醛 ⇌ 羧酸 ⇌ 酯。
- 同分异构三类：碳链异构、位置异构、官能团异构。
- 酯化反应可逆，"酸脱羟基、醇脱氢"，浓硫酸催化吸水。

### ④ 操作步骤
1. 由分子式算不饱和度，判断是否含双键/环。
2. 由特征反应/性质（使溴水褪色、与 NaHCO₃ 放气、银镜反应等）确定官能团。
3. 顺推或逆推定碳骨架与路线，写方程式时注明条件。
4. 书写同分异构按"碳链→位置→官能团"有序进行，不漏不重。

### ⑤ 例题完整演示
(1) 乙醇催化氧化：2CH₃CH₂OH + O₂ --(Cu/Ag,Δ)--> 2CH₃CHO + 2H₂O
(2) 乙酸乙酯生成（可逆）：CH₃COOH + C₂H₅OH ⇌(浓硫酸,Δ)⇌ CH₃COOC₂H₅ + H₂O
(3) 乙烯加溴水：CH₂=CH₂ + Br₂ → CH₂BrCH₂Br
(4) 同分异构：
- C₄H₁₀：正丁烷、异丁烷，共 2 种（碳链异构）。
- C₂H₆O：乙醇 CH₃CH₂OH 与二甲醚 CH₃OCH₃（官能团异构）。

### ⑥ ❌ 易错提醒
- 乙烯使溴水褪色是**加成**，使酸性 KMnO₄ 褪色是**氧化**，原理不同；不能用酸性 KMnO₄ 除去甲烷中混有的乙烯（会生成 CO₂ 新杂质），应用溴水。
- 反应条件不能混：酯化用浓硫酸加热；卤代烃水解用 NaOH 水溶液、消去用 NaOH 醇溶液。
- 酯化是可逆反应，方程式写 ⇌；产物别漏写水。
- 淀粉和纤维素 (C₆H₁₀O₅)n 中 n 值不同，不互为同分异构体。
- 写同分异构时按碳链由长到短、取代基位置由近到远有序列举，避免重复和遗漏。
