## 方法 H1　物质的量"四量互化"与阿伏加德罗常数判断

### ① 方法名
**"见量化摩，再按目标换算"中心量法**

### ② 适用题型 / 物质
物质的量 n、质量 m、气体体积 V、粒子数 N、物质的量浓度 c 之间互算；NA（阿伏加德罗常数）正误判断选择题。

### ③ 原理（为什么）
- 物质的量 n 是联系微观粒子与宏观质量的中心桥梁：
  - n = m / M（质量关系）
  - n = V(气体) / Vm（气体体积关系，标准状况 Vm ≈ 22.4 L/mol）
  - n = N / N_A（粒子数关系）
  - n = c · V(溶液)（浓度关系）
- 同温同压下，相同体积的任何气体都含有相同数目的分子（阿伏加德罗定律）。

### ④ 操作步骤
1. 把已知量先换算成物质的量 n（"见量化摩"）。
2. 再由 n 换算成目标量。
3. 做 NA 选择题时逐项排查四件事：**条件**（是否标况）、**状态**（标况下是否气态）、**微粒种类**（分子/原子/离子/电子）、**特殊过程**（弱电离、水解、可逆反应、电子转移）。

### ⑤ 例题完整演示
(1) 标准状况下 11.2 L O₂ 的物质的量、分子数、质量各是多少？
- n = V/Vm = 11.2 ÷ 22.4 = **0.5 mol**
- N = n·N_A = 0.5 × 6.02×10²³ = **3.01×10²³**
- m = n·M = 0.5 × 32 = **16 g**

(2) 配制 500 mL 0.100 mol/L NaCl 溶液，需称取 NaCl 多少克？
- n = c·V = 0.100 mol/L × 0.500 L = 0.0500 mol
- m = n·M = 0.0500 × 58.5 = **2.925 g ≈ 2.9 g**

(3) 物质的量浓度换算：98%、密度 1.84 g/mL 的浓硫酸，其物质的量浓度是多少？
- c = 1000·ρ·ω / M = 1000×1.84×98% ÷ 98 = **18.4 mol/L**（已验算）

### ⑥ ❌ 易错提醒
- 22.4 L/mol 只适用于**标准状况（0 ℃、101 kPa）下的气体**；标况下 H₂O、SO₃、己烷不是气体，不能用。
- 注意"粒子"是分子还是离子：如 Na₂SO₄ 溶液中 1 mol Na₂SO₄ 电离出 2 mol Na⁺ 和 1 mol SO₄²⁻。
- 弱电解质（醋酸）、盐类水解、可逆反应会使实际粒子数偏离"完全电离/完全反应"的数值。
- 转移电子数要按化合价变化数算（如 Na 反应每个 Na 失 1 e⁻）。

## 方法 H2　离子共存与离子方程式书写

### ① 方法名
**"拆—删—查"离子方程式四步法 + 不共存四因素排查法**

### ② 适用题型 / 物质
离子共存选择题、离子方程式正误判断、由化学方程式改写离子方程式。

### ③ 原理（为什么）
- 离子间若能结合生成**沉淀、气体、弱电解质（水/弱酸/弱碱）**，或发生**氧化还原反应**，就不能大量共存。
- 拆写规则：**强酸、强碱、可溶性盐**拆成离子；沉淀、气体、弱电解质、氧化物、单质、水保留化学式。
- 离子方程式必须同时满足**原子守恒**和**电荷守恒**。

### ④ 操作步骤
写离子方程式：
1. 写出并配平化学方程式。
2. 把易溶强电解质拆成离子，其余保留化学式。
3. 删去两边相同的离子。
4. 检查两边原子个数、电荷总数是否守恒。

### ⑤ 例题完整演示
(1) 碳酸钙与盐酸反应：
化学方程式：CaCO₃ + 2HCl = CaCl₂ + H₂O + CO₂↑
离子方程式：**CaCO₃ + 2H⁺ = Ca²⁺ + H₂O + CO₂↑**（CaCO₃ 难溶，不拆）

(2) 铜与稀硝酸反应：
$$\mathrm{3Cu + 8HNO_3(稀) = 3Cu(NO_3)_2 + 2NO\uparrow + 4H_2O}$$
离子方程式：**3Cu + 8H⁺ + 2NO₃⁻ = 3Cu²⁺ + 2NO↑ + 4H₂O**

(3) 共存判断：pH = 1 的强酸性溶液中，OH⁻、CO₃²⁻、HCO₃⁻ 不能大量存在（与 H⁺ 反应）；Fe³⁺ 与 SCN⁻、I⁻ 不共存。

### ⑥ ❌ 易错提醒
- 微溶物：澄清石灰水（Ca(OH)₂ 澄清）拆成离子；石灰乳（浑浊）不拆。
- "过量/少量"要分清：少量 CO₂ 通入石灰水生成 CaCO₃↓；过量 CO₂ 生成可溶 Ca(HCO₃)₂，沉淀溶解。
- 电荷守恒必查：如 Fe + Fe³⁺ → Fe²⁺ 配平应为 Fe + 2Fe³⁺ = 3Fe²⁺。
- 弱酸根（CH₃COO⁻、ClO⁻）在酸性条件下不能大量共存。

## 方法 H3　氧化还原反应（概念 / 配平 / 规律）

### ① 方法名
**"标变价—求升降—定系数"化合价升降配平法**

### ② 适用题型 / 物质
判断氧化剂/还原剂、标出电子转移方向数目、配平复杂氧化还原方程式、比较氧化性还原性强弱。

### ③ 原理（为什么）
- **升失氧还**：化合价升高 → 失电子 → 被氧化 → 是还原剂；化合价降低 → 得电子 → 被还原 → 是氧化剂。
- 配平依据：**得失电子守恒**（化合价升高总数 = 降低总数）。
- 强弱规律：氧化性 氧化剂 > 氧化产物；还原性 还原剂 > 还原产物。
- "高价氧化、低价还原、中间价态两头兼"：元素处最高价只显氧化性，最低价只显还原性。

### ④ 操作步骤
1. 标出变价元素化合价。
2. 算出每个原子的化合价升、降数值。
3. 求最小公倍数，确定氧化剂、还原剂（及对应产物）系数。
4. 配平其他原子，缺 H/O 时在酸性环境补 H₂O 和 H⁺。

### ⑤ 例题完整演示
配平：Cu + HNO₃(稀) → Cu(NO₃)₂ + NO↑ + H₂O
- Cu：0 → +2，每个升 2
- N：+5 → +2（NO 中），每个降 3
- 最小公倍数 6：Cu 系数 = 6÷2 = 3，NO 系数 = 6÷3 = 2
- 补全：3Cu + 8HNO₃(稀) = 3Cu(NO₃)₂ + 2NO↑ + 4H₂O
- 核对：N 右 = 3×2 + 2 = 8（=左 8）；H = 8 = 4×2；O = 24 = 18+2+4 = 24 ✔

### ⑥ ❌ 易错提醒
- 氧化剂、还原剂指反应物；氧化产物、还原产物指生成物，别叫错。
- 同种元素相邻价态之间一般不发生氧化还原（如浓 H₂SO₄ 与 SO₂ 不反应）。
- 配平时部分酸根（如硝酸根）既作氧化剂又起酸性成盐作用，系数别漏。
- 电子转移方向是"还原剂 → 氧化剂"。
