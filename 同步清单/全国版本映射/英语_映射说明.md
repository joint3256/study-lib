# 英语 · 全国版本章节映射 说明

> 配套文件：`英语_全国版本章节映射.md` / `.csv`（列：学段,版本,册,Module/Unit序号,标题/话题,对应通用知识清单主题,备注）。
> 生成日期：2026-10-10。

## 一、通用知识清单（映射目标）统一口径

通用英语知识清单**本身即按外研版教材编排**，因此外研版与清单为 1:1 直接对应，其余版本按"话题/语法"就近映射到下列主题：

- **初中 = 外研版2024新版（主编孙有中，按2022课标修订）**，6册，每册 6 个 Module：
  - 七上：M1个人情况与问候 / M2家庭成员与朋友 / M3校园生活与学习用品 / M4日常作息与时间 / M5饮食与购物 / M6颜色身体与外貌
  - 七下：M1日常活动与作息 / M2现在进行时 / M3方位与指路 / M4能力与许可(can·祈使) / M5节假日与过去的周末(一般过去) / M6天气与喜好
  - 八上：M1旅行与交通 / M2计划与打算(将来) / M3比较人与物(比较级) / M4规则与义务(must·have to) / M5兴趣与爱好(动名词) / M6自然与环境
  - 八下：M1过去进行时 / M2经历与成就(现在完成) / M3情感与人际交往(宾从that·感叹句) / M4最高级与推荐 / M5动物与保护(不定式) / M6科普常识与技术(被动入门)
  - 九上：M1现在完成时for/since / M2被动语态 / M3状语从句 / M4定语从句入门 / M5情态动词表推测 / M6社会与文化节日传统
  - 九下：专题一话题复习 / 专题二时态综合 / 专题三宾语从句深化 / 专题四定语从句深化 / 专题五状语从句深化 / 专题六书面表达（教材未上线，按中考复习专题）
- **高中 = 外研版2019**，必修一~三 + 选必一~四，每册 6 个 Unit（新校园/探索英语/家庭/友谊/荒野/与自然和谐；饮食文化/节日/运动/舞台银幕/旅行/环保；沟通/公益/战争和平/未来科技/自然文化/太空；幽默/成长/体育/文艺/自然/生存；成长/提升自我/时代变迁/新闻/脆弱世界/太空；外貌价值/事业/战争和平/未来科技/仿生/综合；探索冒险/文明文化/文学人生/可持续未来/科技人文/未来与我）。

## 三、元数据缺口（以权威索引/inventory_raw.json 为准）

1. **初中人教版九下缺失**：接口仅收录 七上/七下/八上/八下/九上；九年级仅有"旧版全一册"。本表九下按复习专题映射，单元标题以教材为准。
2. **初中外研社版（孙有中）九下缺失**：接口仅到九上；九下电子教材未上线，按中考复习专题映射。
3. **初中译林版最齐**：七上/七下/八上/八下/九上/九下均有记录。
4. 各版本同一"册"在接口中存在**多条重复记录**（不同印次/地区版，resource id 不同），本表按"册"归并，不逐一列 id。
5. 高中四个版本（人教/外研/译林/北师大）均为**必修一~三 + 选必一~四 共 7 册**，元数据齐全，本表已做到**每册独立成行、零缺册**。其中：
   - 人教：必修一~三、选必一~五已逐 Unit 列出真实标题。
   - 外研：7 册全部 1:1 对应知识清单。
   - 译林：必修一~三逐 Unit；选必一~四已独立成册，但每册仅按"主题群"给一行映射（Unit 序号以教材目录为准）。
   - 北师大：必修一 U1-U4、必修三 U7(Art)/U8(Green Living)、选必一 U1-U3、选必三 U7(U7 Careers)/U8(Literature) 已列真实标题；其余册按主题群给行。
