# 知识清单 · 编写规范与统一模板（所有学科必须遵守）

本文件是 8 个学科板块（初中/高中 × 数学/物理/化学/英语）的**统一编写规范**。目的：给天津的线上家教做一套**可快速检索、能直接给基础薄弱学生讲题、查缺补漏**的本地知识库。每位编写者只负责一个板块目录，但格式、术语、深度必须与本规范完全一致。

## 一、范围与版本（天津，不得超范围）

- 只做 **初中、高中** 的 **数学、物理、化学、英语** 四科，其他学科一律不写。
- 学段与版本（天津现行）：
  - 初中：数学/物理/化学 = **人教版（按 2022 课标修订的 2024 新版）**；英语 = **外研版 2024 新版（主编：孙有中，平台标签"外研社版"）**。
  - 高中：数学 = **人教 A 版（2019）**；物理/化学 = **人教版（2019）**；英语 = **外研版（2019）**。
- 依据课标：初中用 **《义务教育课程标准（2022 年版）》**；高中用 **《普通高中课程标准（2017 年版 2020 年修订）》**。
- **不超纲**：高中不把大学内容、竞赛技巧当作必讲知识点；初中不提前灌输高中内容。可在"拓展/视野"里点到为止并明确标注"选学/超纲，仅供尖子生"。
- **章号不臆造**：2024 新版初中教材章目与旧版不同。拿不准精确章号时，**按主题组织**，并在该章标题下注明"章号以教材目录为准"。绝不编造看似精确但无依据的章/节号。

## 二、目录与文件约定

- 每个板块一个目录：`知识清单/<学段>/<学科>/`。
- **每一"册"一个 Markdown 文件**，文件名即册次名：
  - 初中：`七年级上册.md`、`七年级下册.md`、`八年级上册.md`、`八年级下册.md`、`九年级上册.md`、`九年级下册.md`、`九年级全一册.md`（物理）。
  - 高中：`必修第一册.md`、`必修第二册.md`、`必修第三册.md`、`选择性必修第一册.md`、`选择性必修第二册.md`、`选择性必修第三册.md`、`选择性必修第四册.md`（仅高中英语有第四册）。
- 每个板块目录内还必须有：
  - `README.md`：本板块索引（列出所有册文件、每册主题/章节、检索提示）。
  - `资料来源.md`：课标、教材版本、国家平台、以及**实际参考过的**开源仓库（URL + 协议）；若内容为依据课标与教材目录自行编写，也要如实写明。**不得编造仓库许可证**。
- **纯 Markdown 小文件**：不放 PDF、图片、音频等大体积二进制（便于以后 git 私有库跨设备同步）。公式用 LaTeX（行内 `$...$`，独立成行 `$$...$$`）。
- 层级：册文件内 `#` = 册名，`##` = 章（英语为 Module/Unit），`###` = 统一的六要素小节，`####` = 节/单元细分。

## 三、每章六要素（理科：数学/物理/化学，标题固定）

每个 `## 第N章 章名` 之下，**依次**包含以下六个 `###`，缺一不可，且不得写"略/待补充/同上"：

1. `### 一、本章知识结构`
   - 用 Markdown 缩进树形（或 `→` 箭头流程）画出本章知识地图，体现概念之间的从属与先后；不依赖 mermaid 等可能不渲染的组件。
   - 开头先用一行列出本章**节次**：`> 节次：第1节 …；第2节 …；…（节号以教材目录为准）`。
2. `### 二、核心概念（通俗→严谨）`
   - 按节组织。每个概念先**一句话大白话**（让基础弱的学生秒懂），再给**严谨定义**。
   - 物理量须写明**符号、单位（含常用倍数单位）、标/矢量**；化学概念须点明条件与适用范围。
3. `### 三、定理、公式与结论`
   - 用 LaTeX 准确书写；**每个符号都要解释**，标注**成立条件/适用范围/单位**。
   - 化学方程式、物理公式中的常数取值要注明（如 $g$ 取 $9.8\,\text{N/kg}$，粗略计算取 $10\,\N/kg$）。
4. `### 四、公式推导要点与常用模型`
   - 给出关键公式的**推导思路链**（不必每步都写，但要让学生知道"从哪来"）。
   - 归纳本章**常用物理/数学/化学模型**（如"相遇/追及模型""板块模型""守恒法""差量法"），说明识别特征与通法。
5. `### 五、考点与典型题型·方法`
   - 列出常考题型，每种给：**题型名 → 解题步骤/通法 → 一个简短范例（含解答）**。
   - 范例数字要简单、典型，解答过程完整、可核验。
6. `### 六、易错易混`
   - 用 `❌ 错误：…` / `✅ 正确：…` 成对列出，直击基础薄弱学生高频错误（符号、单位、定义域、条件遗漏、概念混淆等）。

## 四、英语学科的六要素（标题固定）

英语按教材的 **Module（初中）/ Unit（高中）** 组织，每个 Module/Unit 之下依次：

1. `### 一、模块地图与话题主线`：本模块在整册中的位置、**话题（topic）**、功能意念；开头一行列出本模块的 Unit/板块构成。
2. `### 二、核心词汇与短语`：按单元列**高频词（词性 + 中文释义 + 常见搭配 + 一个简单例句）**与重点短语；标注课标要求层级（初中 1500 词范围、高中 3000 词范围，超纲词标 *）。
3. `### 三、语法要点`：**语法结构（form）+ 用法/意义（use）+ 例句 + 易错提示**；初中覆盖课标语法项目表，高中覆盖词法、句法（三大从句、非谓语、特殊句式等）。
4. `### 四、话题表达与写作`：本话题**功能句/话题语块**、可套用句型、简短范文或写作框架（应用文/记叙文；高中含概要写作、读后续写的素材与方法）。
5. `### 五、常考题型与解题方法`：按学段覆盖听力、单项/语法填空、完形填空、阅读理解、书面表达等；给**题型 → 方法步骤 → 示例**。
6. `### 六、易错易混`：词形变化、近义词/近形词、时态语态、搭配、中式英语等，`❌/✅` 成对。

## 五、质量底线（写完先自查）

- **六要素齐全**：可用脚本统计每个 `##` 下是否都含六个 `###` 标题；缺一个即不合格。
- **公式/事实可核验、正确**：宁可写"以教材为准/选学"，也不臆造公式、常数、方程式、语法规则。
- **面向薄弱学生**：先通俗后严谨，多用类比、步骤化、口诀（口诀要科学）。
- 每个范例必须能算出正确结果；涉及计算的结论要实际算过，不写"约为"而无依据。
- 文件全部落在自己板块目录的**绝对路径**下；返回时给出：文件绝对路径清单、各册章/模块数量、六要素自查结果、参考来源清单。
