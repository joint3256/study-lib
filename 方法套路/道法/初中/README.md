## 二、怎么用这本库

1. **先判断题型**：选择还是材料？材料题问的是"是什么/为什么/怎么做/评析/启示/说明"哪一种？→ 先翻 `05`、`06` 两个通用模板。
2. **再定知识板块**：考成长心理看 01，考法律宪法看 02，考国情国策看 03，考世界与少年看 04。
3. **最后对观点**：方法只给"答题架子"，架子上摆哪句教材观点，回 `知识清单/初中/道法/` 对应册查。
