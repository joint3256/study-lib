## 第一单元 殖民地人民的反抗与资本主义制度的扩展

> 课时：第1课 殖民地人民的反抗斗争；第2课 俄国的改革；第3课 美国内战；第4课 日本明治维新（课号以教材目录为准）。

### 一、本单元时空脉络（知识结构）

```
19世纪中期：殖民地反抗 + 资本主义制度扩展
│
├─ 殖民地人民反抗
│   ├─ 拉丁美洲独立运动（玻利瓦尔、圣马丁，南美的"解放者"）
│   └─ 印度民族大起义（1857—1859，章西女王）
├─ 资本主义制度扩展（资产阶级性质的改革/革命）
│   ├─ 俄国：彼得一世改革（强化农奴制）→ 1861年亚历山大二世废除农奴制
│   ├─ 美国：内战（1861—1865，林肯，《解放黑人奴隶宣言》）
│   └─ 日本：1868年明治维新（学习欧美，走上资本主义道路）
└─ 时代主题：工业革命推动下，资产阶级统治在世界范围内巩固与扩大

年代轴：18世纪末19世纪初（拉美独立）→ 1857—1859（印度大起义）
        → 1861（俄国改革、美国内战爆发）→ 1862（《解放黑人奴隶宣言》）
        → 1865（内战北方胜利）→ 1868（日本明治维新开始）
```

### 二、核心史事（时间·人物·经过，通俗→严谨）

**1. 殖民地人民的反抗斗争**
- 通俗：拉丁美洲受不了西班牙、葡萄牙的殖民统治，在玻利瓦尔、圣马丁带领下闹独立，两人被称为南美的"解放者"；印度1857—1859年也爆发大起义，年轻的章西女王英勇抗英，最后牺牲。
- 严谨：
  - **拉丁美洲独立运动**：19世纪初，受美国独立和法国大革命影响，拉美人民掀起反抗西班牙、葡萄牙殖民统治的运动。**玻利瓦尔**和**圣马丁**先后领导起义军，解放了西班牙在南美洲的殖民地，被誉为南美的"**解放者**"。
  - **印度民族大起义（1857—1859）**：1857年，印度土兵首先起来反抗英国殖民者，起义浪潮席卷多地。**章西女王**是这次起义中的杰出女英雄，她领导军民与英军激战，壮烈牺牲。这次起义沉重打击了英国殖民统治，反映了印度民族意识的觉醒。

**2. 俄国的改革**
- 通俗：俄国本来又落后又保守。彼得一世学习西欧、强兵兴国，但不但没解放农奴，反而**强化**了农奴制；到1861年，农奴起义不断，亚历山大二世被迫下诏废除农奴制，让农奴获得"人身自由"，但赎买份地要交一大笔钱。
- 严谨：
  - **彼得一世改革**：以富国强兵为目的，学习西方技术，强化了农奴制，使俄国的经济、军事实力大大增强，一跃成为欧洲军事强国，为对外扩张准备了条件；但**农奴制进一步强化**，后来成为俄国社会发展的障碍。
  - **1861年改革（亚历山大二世）**：面对严重的农奴制危机，**亚历山大二世颁布了废除农奴制的法令**。法令规定：农奴获得人身自由，可以改变身份，自由转换职业；农奴在获得解放的同时，可以获得一份土地，但必须**出钱赎买**，所出的价钱高出当时的地价。**1861年改革是俄国历史上的一个重要转折点**：改革废除了农奴制，促使社会的各个方面出现了新的气象，**推动俄国走上了发展资本主义的道路**。但农奴制的残余仍然存在，影响着俄国经济与社会的发展。它是一次**自上而下的资产阶级性质的改革**。

**3. 美国内战（南北战争，1861—1865）**
- 通俗：美国独立后，北方搞资本主义工商业，需要自由劳动力；南方却种棉花、靠黑奴。两种制度矛盾越来越大。林肯当选总统后，南方挑起内战。一开始北方不利，林肯1862年颁布《宅地法》和《解放黑人奴隶宣言》，老百姓和黑人都站到北方一边，1865年北方胜利。
- 严谨：
  - 根本原因：**北方资本主义工商业经济和南方奴隶制种植园经济之间的矛盾**（焦点是奴隶制的存废问题）。
  - **1861年4月，南方军队挑起战争**，美国内战爆发，史称"南北战争"。
  - 1862年，林肯政府颁布**《宅地法》**和**《解放黑人奴隶宣言》**：规定从1863年元旦起，**废除叛乱各州的奴隶制**，并允许奴隶作为自由人参加北方军队。这两个法令深得人心，调动了农民尤其是黑人的积极性，他们踊跃参军参战，扭转了战局。
  - **1865年，内战以北方胜利告终**。美国内战**维护了国家统一**，**废除了奴隶制**，清除了资本主义发展的最大障碍，为以后经济的迅速发展创造了条件，是美国历史上的**第二次资产阶级革命**。

**4. 日本明治维新（1868年起）**
- 通俗：1853年美国黑船来航，日本被迫打开国门，幕府统治危机四伏。一部分中下级武士推翻幕府，还政天皇，从1868年起向欧美学习：政治上废藩置县加强中央集权，经济上"殖产兴业"办工厂，社会生活上"文明开化"穿西装学西方，军事上实行征兵制。日本从此走上资本主义道路，但保留了大量旧制度残余，很快走上对外侵略扩张道路。
- 严谨：
  - 背景：19世纪中期日本是闭关锁国的封建国家，天皇大权旁落，实权在幕府将军手中；1853年美国打开日本国门，民族危机严重。
  - 1868年，讨伐幕府的武装粉碎幕府统治，改年号为"**明治**"，开始一系列改革，史称"**明治维新**"。
  - 主要内容：政治上"**废藩置县**"，加强中央集权；军事上实行征兵制，建立新式军队；经济上推行"**殖产兴业**"，大力发展近代经济；社会生活上提倡"**文明开化**"，向西方学习，改造日本的教育、文化和生活方式。
  - 影响：明治维新是**日本历史的重大转折点**，通过改革，日本迅速走上了发展资本主义的道路，实现了富国强兵，开始跻身资本主义强国之列。但改革**保留了大量旧制度的残余，如天皇制、武士道精神，军国主义色彩浓厚**，日本很快走上了对外侵略扩张的道路。

### 三、历史意义·阶段特征与重要结论

- **阶段特征**：19世纪中期，在工业革命推动下，**资本主义制度在世界范围内迅速扩展**——俄国、日本通过自上而下的改革走上资本主义道路，美国通过内战废除奴隶制、维护统一。
- 课本结论：
  - 1861年改革**推动俄国走上发展资本主义的道路**，是俄国历史的重要转折点。
  - 美国内战是美国历史上**第二次资产阶级革命**，维护了国家统一、废除了奴隶制。
  - 明治维新是**日本历史的重大转折点**，使日本走上资本主义道路，但保留了大量残余并迅速对外扩张。

### 四、因果线索与常用史观·答题模型

- 因果链（俄、日）：封建统治危机 + 民族危机 + 工业文明冲击 → 自上而下改革 → 走上资本主义道路（但保留残余）。
- 因果链（美国）：两种经济制度矛盾 → 林肯当选（导火线）→ 内战 → 颁布法令扭转战局 → 北方胜利 → 废除奴隶制、维护统一。
- 比较模型（俄1861改革 vs 日本明治维新 vs 美国内战）：
  - 性质：俄、日是**自上而下的资产阶级性质改革**；美国内战是**第二次资产阶级革命**。
  - 方式：俄、日走改革道路，美国走战争（革命）道路。
  - 局限：俄保留农奴制残余；日保留军国主义残余。
- 唯物史观：**生产力（工业革命）推动生产关系变革**——工业资产阶级要求扫除劳动力、市场、制度上的障碍。

### 五、考点与典型题型·方法

**题型1：人物与事迹配对**
- 通法：玻利瓦尔、圣马丁—拉美"解放者"；章西女王—印度大起义；亚历山大二世—1861年俄国改革；林肯—美国内战；明治天皇—日本明治维新。

**题型2：1861年俄国改革**
- 例："诸位会深信，凡能够维护地主利益的措施，都一一做到了。"——这句话反映的是**1861年亚历山大二世废除农奴制改革**；影响：是俄国历史的重要转折点，**推动俄国走上发展资本主义的道路**，但保留大量封建残余。

**题型3：美国内战中两个法令**
- 分点答案：①1862年林肯政府颁布**《宅地法》**和**《解放黑人奴隶宣言》**；②规定从1863年元旦起废除叛乱各州奴隶制；③调动了农民和黑人的积极性，扭转了战局；④内战结果：北方胜利，**维护了国家统一，废除了奴隶制**，是美国历史上**第二次资产阶级革命**。

**题型4：明治维新内容与影响**
- 分点答案：①政治：废藩置县，加强中央集权；②经济：殖产兴业，发展近代工业；③社会生活：文明开化，向欧美学习；④军事：征兵制；⑤影响：日本走上资本主义道路，是重大转折点，但保留大量封建残余，迅速走上对外侵略扩张道路。

**题型5：拉美独立与印度大起义的性质**
- 通法：都是**殖民地人民反抗殖民统治的民族解放运动**。

### 六、易错易混

- ❌ 把美国内战的根源说成"南北矛盾"太笼统 → ✅ 根本原因是**北方资本主义工商业经济和南方奴隶制种植园经济的矛盾**，焦点是**奴隶制的存废**。
- ❌ 把《解放黑人奴隶宣言》说成"立即废除全国奴隶制" → ✅ 它只**废除叛乱各州的奴隶制**（从1863年元旦起），不是立即在全国废除。
- ❌ 把1861年俄国改革说成"自下而上" → ✅ 是**沙皇亚历山大二世自上而下**的改革；农奴获得解放还要**出钱赎买份地**。
- ❌ 把彼得一世改革说成"废除农奴制" → ✅ 彼得一世改革**强化了农奴制**；**1861年改革**才废除农奴制。
- ❌ 把明治维新说成"学习中国" → ✅ 明治维新是**学习欧美**（大化改新才是学习唐朝）。
- ❌ 只说明治维新"好" → ✅ 要指出它**保留大量封建残余（天皇制、武士道），使日本迅速走上对外侵略扩张道路**。
- ❌ 把玻利瓦尔、章西女王混为一谈 → ✅ 玻利瓦尔在**拉美**反抗西班牙；章西女王在**印度**反抗英国。

## 第二单元 第二次工业革命和近代科学文化

> 课时：第5课 第二次工业革命；第6课 工业化国家的社会变化；第7课 近代科学与文化（课号以教材目录为准）。

### 一、本单元时空脉络（知识结构）

```
第二次工业革命（19世纪六七十年代—20世纪初）
│
├─ 核心标志：电力的广泛应用（"电气时代"）
│   ├─ 爱迪生：耐用白炽灯泡（1879）等众多发明
│   └─ 发电机、电动机、电话、电报
├─ 内燃机与现代交通
│   ├─ 内燃机（19世纪七八十年代）
│   ├─ 1885 本茨制造出内燃机驱动的汽车
│   └─ 1903 莱特兄弟发明飞机
├─ 新兴工业：石油、化学工业（诺贝尔现代炸药）
├─ 生产关系：垄断组织出现（大企业时代）
├─ 社会变化：人口增长、劳动力结构、城市化、大众教育
└─ 近代科学与文化
    ├─ 牛顿（《自然哲学的数学原理》、力学三定律、万有引力）
    ├─ 达尔文（《物种起源》、进化论）
    ├─ 巴尔扎克《人间喜剧》、托尔斯泰
    ├─ 贝多芬《英雄交响曲》；梵高《向日葵》

年代轴：19世纪六七十年代（开始）→ 1879（爱迪生灯泡）→ 1885（本茨汽车）
        → 1903（莱特兄弟飞机）→ 20世纪初（主要资本主义国家向垄断阶段过渡）
```

### 二、核心史事（时间·人物·经过，通俗→严谨）

**1. 第二次工业革命**
- 通俗：第一次工业革命靠蒸汽，第二次靠电。19世纪六七十年代起，电力开始广泛使用，电灯、电话、电报相继出现；德国人又搞出内燃机，烧汽油的汽车、飞机都来了。生产越来越集中，形成垄断组织，主要资本主义国家开始向帝国主义（垄断）阶段过渡。
- 严谨：
  - **19世纪六七十年代**，各种新技术、新发明层出不穷，并被迅速应用于工业生产，促进了工业的蓬勃发展，这就是**第二次工业革命**。
  - **电力成为新的能源进入生产生活领域，是第二次工业革命最显著的成就**，人类社会进入"**电气时代**"。**爱迪生**在1879年成功研制出**耐用的白炽灯泡**，他在纽约建立了美国第一座火力发电站。
  - 19世纪七八十年代，**内燃机**发明。**1885年，德国本茨制造出一辆由内燃机驱动的汽车**；**1903年，美国莱特兄弟研制的飞机试飞成功**。
  - 现代化学工业产生：1867年**诺贝尔**发明了现代炸药。
  - 生产的集中和垄断：第二次工业革命使主要资本主义国家出现了**垄断组织**，资本主义由自由资本主义向**垄断资本主义（帝国主义）**阶段过渡。

**2. 工业化国家的社会变化**
- 通俗：工厂多了，城市人口暴涨，城里人越来越多；工人阶级壮大，各国开始普及大众教育；但也带来环境污染、贫富分化等问题。
- 严谨：工业革命推动欧洲国家城市化进程，人口快速增长，工人阶级队伍不断壮大。为了适应工业化发展的需要，欧洲国家开始推广大众教育。另一方面，工业化也带来了**环境污染、贫富分化加剧**等社会问题。

**3. 近代科学与文化**
- 通俗：牛顿发现了力学三大定律和万有引力，把天上地下的运动规律统一了；达尔文写《物种起源》，说人是由古猿进化来的，不是神造的；文学上有巴尔扎克、托尔斯泰，音乐上有贝多芬，绘画上有梵高。
- 严谨：
  - **牛顿**（英国）：是近代自然科学的奠基人之一。**1687年出版《自然哲学的数学原理》**，建立了完整的力学理论体系（**万有引力定律**、**力学三定律**），使物理学成为一门独立的学科。
  - **达尔文**（英国）：**1859年出版《物种起源》**，提出了**进化论**的观点，指出一切物种都是在长期的变异、遗传和自然选择中由简单到复杂、由低等到高等进化而来的。《物种起源》的出版，**打破了"神创论"**，在生物科学领域掀起一场伟大革命。
  - 文学：法国**巴尔扎克**的《人间喜剧》（含《高老头》《欧也妮·葛朗台》）；俄国**托尔斯泰**（《战争与和平》《安娜·卡列尼娜》《复活》），被列宁称为"俄国革命的镜子"。
  - 音乐：德国**贝多芬**的《**英雄交响曲**》（第三交响曲），是他第一部明确反映重大社会题材的作品。
  - 绘画：荷兰**梵高**的《**向日葵**》。

### 三、历史意义·阶段特征与重要结论

- **阶段特征**：第二次工业革命使人类进入"电气时代"，生产和资本高度集中形成垄断，主要资本主义国家向帝国主义阶段过渡，对外瓜分世界、争夺霸权。
- 课本结论：
  - **电力的广泛应用是第二次工业革命最显著的成就**，人类进入"电气时代"。
  - 内燃机、汽车、飞机的发明改变了人们的出行方式，促进了石油工业的发展。
  - 达尔文**《物种起源》的出版打破了"神创论"**，是生物学领域的革命。
  - 牛顿是**近代自然科学的奠基人之一**。

### 四、因果线索与常用史观·答题模型

- 因果链：自然科学突破（电磁学）→ 发电机、电动机 → 电力广泛应用 → 一系列新发明 → 重工业兴起 → 生产集中 → 垄断组织 → 帝国主义阶段 → 瓜分世界。
- 两次工业革命对比模型：
  - 第一次：蒸汽机，轻工业（棉纺织），英国一枝独秀，人类进入"蒸汽时代"。
  - 第二次：电力、内燃机，重工业（电力、汽车、石油、化工），几个资本主义国家同时进行，人类进入"电气时代"，产生垄断组织。
- 唯物史观：**科学技术是第一生产力**——科学理论（电磁学、进化论）→ 技术发明 → 生产力飞跃。

### 五、考点与典型题型·方法

**题型1：第二次工业革命的标志性成就**
- 通法：最显著成就＝**电力的广泛应用**；新能源＝电力、石油；新交通工具＝汽车（本茨，1885）、飞机（莱特兄弟，1903）；新通讯＝电话、电报。

**题型2：人物与贡献配对**
- 通法：爱迪生—电灯；本茨—汽车；莱特兄弟—飞机；诺贝尔—现代炸药；牛顿—力学三定律/万有引力；达尔文—《物种起源》进化论；贝多芬—《英雄交响曲》；梵高—《向日葵》。

**题型3：两次工业比较材料题**
- 例：请从核心标志、主要国家、时代特征三方面比较两次工业革命。
  - 分点答案：第一次：蒸汽机为核心，最早发生在英国，人类进入"蒸汽时代"；第二次：电力广泛应用为标志，美德等多国同时进行，人类进入"电气时代"，并产生垄断组织，主要资本主义国家向帝国主义阶段过渡。

**题型4：《物种起源》**
- 分点答案：①1859年达尔文出版；②提出**生物进化论**；③**打破了"神创论"**，在生物学领域掀起一场伟大革命。

**题型5：工业化社会问题**
- 通法：积极——城市化、大众教育、生产力提高；消极——**环境污染、贫富分化加剧**。

### 六、易错易混

- ❌ 把第二次工业革命的核心标志说成"蒸汽机" → ✅ 第一次工业革命核心是**蒸汽机**；第二次是**电力的广泛应用**（"电气时代"）。
- ❌ 把汽车发明者说成爱迪生 → ✅ 爱迪生发明/改进的是**电灯**；汽车是**本茨（1885）**，飞机是**莱特兄弟（1903）**。
- ❌ 把达尔文说成牛顿的同时代对手 → ✅ 牛顿是17—18世纪（力学）；达尔文是19世纪（进化论）。
- ❌ 把《英雄交响曲》作者说成梵高 → ✅ 贝多芬是音乐家（《英雄交响曲》）；梵高是画家（《向日葵》）。
- ❌ 认为第二次工业革命只发生在英国 → ✅ 是**美国、德国等多个资本主义国家同时发生**，且美国、德国后来居上。
- ❌ 忽视垄断组织 → ✅ 第二次工业革命后，生产集中产生**垄断组织**，主要资本主义国家向**帝国主义（垄断资本主义）**阶段过渡。

### 二、核心史事（时间·人物·经过，通俗→严谨）

**1. 第一次世界大战**
- 通俗：第二次工业革命后，帝国主义国家抢殖民地、抢市场，矛盾重重，结成"三国同盟"（德、奥匈、意）和"三国协约"（英、法、俄）两大集团。1914年6月一名塞尔维亚青年在萨拉热窝刺杀了奥匈帝国皇储，成了导火线；7月奥匈向塞尔维亚宣战，一战开打。最惨的是1916年的凡尔登战役，死伤上百万人，被叫作"绞肉机"。1917年美国参战、俄国革命，1918年德国投降。
- 严谨：
  - 根本原因：**帝国主义国家政治经济发展不平衡**。
  - 两大集团：**三国同盟（德国、奥匈帝国、意大利）**和**三国协约（英国、法国、俄国）**。
  - **1914年6月28日萨拉热窝事件**（奥匈皇储斐迪南被刺）是一战的**导火线**。
  - **1914年7月**，奥匈帝国向塞尔维亚宣战，一战爆发。
  - **1916年的凡尔登战役**，德法双方伤亡70多万人，被称为"**绞肉机**""地狱"，是一战的**转折点**。
  - 1917年，**美国参加协约国一方作战**；俄国爆发十月革命，退出一战。
  - **1918年11月，德国投降，一战以同盟国的失败而结束**。
  - 性质：第一次世界大战是**西方列强为重新瓜分世界、争夺世界霸权而发动的一场帝国主义战争**。

**2. 俄国十月革命**
- 通俗：一战把俄国拖得很惨，1917年先爆发二月革命推翻了沙皇，但临时政府还继续打一战。列宁号召"全部政权归苏维埃"，11月7日（俄历10月）彼得格勒武装起义，攻占冬宫，推翻临时政府，世界上第一个社会主义国家诞生。
- 严谨：
  - 1917年3月（俄历2月），俄国爆发**二月革命**，推翻了沙皇专制统治，建立了资产阶级临时政府。
  - **1917年11月6日晚（俄历10月），列宁领导彼得格勒武装起义**，11月7日（公历）起义攻克冬宫，推翻了资产阶级临时政府，这次起义被称为"**十月革命**"。
  - 十月革命是**人类历史上第一次取得胜利的社会主义革命**，建立了世界上**第一个无产阶级专政的国家**，推动了国际无产阶级革命运动，鼓舞了殖民地、半殖民地人民的解放斗争。

**3. 苏联的社会主义建设**
- 通俗：十月革命后，苏俄先是实行"战时共产主义"集中一切打内战；内战结束后农民不满，1921年列宁改行"新经济政策"，允许中小企业私人经营、恢复商品买卖，经济很快恢复；1922年苏联成立；斯大林时期搞两个五年计划，优先发展重工业，1936年通过新宪法，形成高度集中的计划经济体制（苏联模式）。
- 严谨：
  - **1921年春，苏维埃政府开始实施新经济政策**：以征收粮食税代替余粮征集制；允许使用雇佣劳动力和出租土地，农民可以自由买卖纳税后的剩余产品；允许私人经营中小企业；实行按劳取酬的工资制。**新经济政策从苏俄的国情出发，调动了生产者的积极性，迅速缓解了危机，巩固了工农联盟，促使国民经济稳步发展**。
  - **1922年，苏维埃社会主义共和国联盟成立，简称"苏联"**。
  - 1928—1937年，苏联先后完成第一个、第二个五年计划，重点发展**重工业**，由落后的农业国变为强大的工业国。
  - **1936年，苏联通过新宪法**，宣告社会主义制度在苏联建立，也标志着**苏联模式**（即高度集中的计划经济体制和高度集权的政治体制，又称"斯大林模式"）的形成。

**4. 凡尔赛—华盛顿体系**
- 通俗：一战打完，战胜国开会分赃。1919年在巴黎凡尔赛宫开巴黎和会，对德签订《凡尔赛条约》；1921—1922年又在华盛顿开会，签了针对中国的《九国公约》。这一圈条约把战后世界重新安排了一遍，叫"凡尔赛—华盛顿体系"，但它没有消除矛盾，反而埋下二战的种子。
- 严谨：
  - **1919年1月，巴黎和会**召开，战胜的协约国集团与德国签订了《**凡尔赛条约**》（对德和约）。条约重划德国疆界，禁止德国实行义务兵役制，德国的全部海外殖民地由英、法、日等国瓜分。和会还决定建立国际联盟。
  - **1921—1922年，华盛顿会议**召开，主导者是美国。会议针对中国问题签署了《**九国公约**》：宣称尊重中国的主权、独立与领土完整，**实际上使日本独霸中国的局面被打破，维持了几个帝国主义国家共同支配中国的局面**。
  - 巴黎和会和华盛顿会议所形成的战后帝国主义国际秩序，叫"**凡尔赛—华盛顿体系**"。它暂时调整了战胜国在欧洲、东亚和太平洋地区的关系，但**没有从根本上消除帝国主义国家之间的矛盾**，为二战埋下祸根。

### 三、历史意义·阶段特征与重要结论

- **阶段特征**：一战摧毁了四大帝国（俄、德、奥匈、奥斯曼）；俄国十月革命建立了**世界上第一个社会主义国家**，开创了社会主义现代化新模式；帝国主义通过凡尔赛—华盛顿体系重新瓜分世界。
- 课本结论：
  - 一战是**一场帝国主义战争**，给人类带来深重灾难。
  - 十月革命是**人类历史上第一次取得胜利的社会主义革命**。
  - **新经济政策从苏俄国情出发，调动了生产者积极性，促使国民经济稳步发展**。
  - 苏联模式（斯大林模式）在短时期内使苏联实现工业化，但**片面发展重工业，农业、轻工业长期落后**，高度集中的体制后来日益僵化。
  - 凡尔赛—华盛顿体系**没有从根本上消除帝国主义国家之间的矛盾**。

### 四、因果线索与常用史观·答题模型

- 因果链：帝国主义政治经济发展不平衡 → 两大军事集团扩军备战 → 萨拉热窝事件（导火线）→ 一战 → 俄国崩溃 → 十月革命 → 建立社会主义国家；一战削弱帝国主义 → 战胜国召开分赃会议 → 凡尔赛—华盛顿体系。
- 唯物史观：**战争引发革命，革命制止战争**——一战的灾难加速了俄国十月革命。
- 评价模型（评价凡尔赛—华盛顿体系）：先答"暂时调整矛盾、维持短暂和平"，再答"没有根除矛盾、对战败国苛刻、瓜分弱小民族"，最后答"为二战埋下祸根"。

### 五、考点与典型题型·方法

**题型1：一战导火线与性质**
- 通法：导火线——**1914年萨拉热窝事件**；性质——**帝国主义掠夺战争**；最惨烈战役——**凡尔登战役（1916）**。

**题型2：十月革命**
- 分点答案：①1917年11月（俄历10月）**列宁**领导彼得格勒武装起义；②推翻资产阶级临时政府；③是**人类历史上第一次取得胜利的社会主义革命**；④建立了世界上第一个无产阶级专政的国家，推动了国际无产阶级革命运动和殖民地半殖民地解放斗争。

**题型3：新经济政策**
- 例："我们还不能实现从小生产到社会主义的直接过渡……所以我们应该利用资本主义作为小生产和社会主义的中间环节。"
  - 分点答案：①这是**1921年列宁实施的新经济政策**；②特点：**利用市场和商品货币关系**发展经济，允许私人经营中小企业、自由贸易；③作用：从国情出发，调动了生产者积极性，迅速缓解危机，巩固了工农联盟，促使国民经济稳步发展。

**题型4：《九国公约》**
- 分点答案：①1921—1922年华盛顿会议签订；②表面上尊重中国主权、独立与领土完整；③**实际上打破了日本独霸中国的局面，使中国回复到几个帝国主义国家共同支配的局面**；④为美国在中国的扩张提供了方便。

**题型5：苏联模式**
- 通法：1936年新宪法宣告形成；特点——**高度集中的计划经济体制和高度集权的政治体制**；评价——短时间实现工业化，但片面发展重工业，农轻重比例失调，后来日益僵化。

### 六、易错易混

- ❌ 把一战性质说成"民族解放战争" → ✅ 一战是**帝国主义国家重新瓜分世界、争夺霸权的帝国主义战争**（虽然塞尔维亚有正义的民族解放成分，但整体性质不变）。
- ❌ 把三国同盟成员记错 → ✅ 同盟国：**德、奥匈、意**；协约国：**英、法、俄**（一战爆发后意大利倒向协约国）。
- ❌ 把二月革命和十月革命结果混了 → ✅ 二月革命（1917年3月）**推翻沙皇专制**；十月革命（1917年11月）**推翻资产阶级临时政府，建立第一个社会主义国家**。
- ❌ 把新经济政策说成"战时共产主义" → ✅ 战时共产主义是内战时期；**1921年新经济政策**才利用商品货币关系、允许私人经营。
- ❌ 把《九国公约》说成"对中国友好" → ✅ 它**使中国回复到几个帝国主义国家共同支配的局面**，是外交欺压。
- ❌ 把苏联成立时间与新经济政策混 → ✅ 1921年新经济政策；**1922年苏联成立**；1936年苏联模式形成。

### 二、核心史事（时间·人物·经过，通俗→严谨）

**1. 1929—1933年经济大危机与罗斯福新政**
- 通俗：1929年美国股市一崩，工厂关门、工人失业、牛奶倒海里，危机席卷整个资本主义世界。1933年罗斯福上台，一改此前政府"自由放任"的做法，国家直接出手干预经济：整顿金融、调节工业、调整农业、推行"以工代赈"、建社会保障。美国经济慢慢恢复，资本主义制度得到调整、巩固。
- 严谨：
  - **1929年10月下旬，美国股票价格突然暴跌**，一场空前规模的经济大危机很快席卷了整个资本主义世界。危机的特点是**持续时间长、涉及范围广、破坏性大**。
  - **1933年，罗斯福就任美国总统**，为了应付危机，他宣布实行"**新政**"，**采用国家干预经济的手段来扭转经济形势**。
  - 主要内容：整顿金融体系；加强对工业的计划指导，通过《**全国工业复兴法**》；调整农业政策；推行"**以工代赈**"；发展社会福利。
  - 影响：美国经济开始缓慢复苏，工业生产有所恢复，人民生活得到改善。**新政增强了美国政府的宏观调控能力，恢复了美国人民的信心，对资本主义世界产生了深远影响**。但新政是在维护资本主义制度前提下作出的政策调整，**它没有改变资本主义的本质，无法解决美国社会的根本矛盾**。

**2. 法西斯国家的侵略扩张**
- 通俗：危机一来，美国走了罗斯福新政的"民主改良"路子，德国、日本、意大利却走上了法西斯独裁、对外扩张的邪路：意大利1922年墨索里尼先上台；德国1933年希特勒上台，制造"国会纵火案"迫害共产党，还疯狂排犹；日本由军部控制政府。英、法对法西斯侵略搞"绥靖"，1938年《慕尼黑协定》把捷克斯洛伐克的苏台德区白白送给德国，纵容了侵略。
- 严谨：
  - **1922年，墨索里尼在意大利建立法西斯政权**。
  - **1933年，希特勒出任德国总理**，开始建立法西斯专政，世界大战的**欧洲策源地形成**。纳粹党制造"**国会纵火案**"，打击德国共产党；**残酷迫害犹太人**。
  - 1936年，受军部控制的广田弘毅内阁上台，**日本建立法西斯专政，世界大战的亚洲策源地形成**。
  - **1938年9月，英、法、德、意四国签订《慕尼黑协定》**，强行把捷克斯洛伐克的苏台德区割让给德国，这是**绥靖政策**达到顶峰的标志，它**纵容了法西斯的侵略野心**，加速了二战的爆发。

**3. 第二次世界大战**
- 通俗：1939年9月1日德国闪击波兰，英法被迫对德宣战，全面开战。1941年德国又突袭苏联，日本偷袭珍珠港把美国也拖下水，战争达到最大规模。1942年26国签《联合国家宣言》，结成世界反法西斯同盟。斯大林格勒战役是转折点；1944年6月6日盟军诺曼底登陆，从西边打回欧洲；1945年2月美英苏开雅尔塔会议安排战后秩序；5月8日德国投降；8月美国投原子弹、苏联对日宣战，9月2日日本正式签字投降，二战结束。
- 严谨：
  - **1939年9月1日，德国以"闪电战"突袭波兰**，英、法被迫对德宣战，**第二次世界大战全面爆发**。
  - **1941年6月，德国突袭苏联**，苏德战争爆发，二战规模扩大。
  - **1941年12月7日，日本偷袭美国海军基地珍珠港**，太平洋战争爆发，**第二次世界大战达到最大规模**。
  - **1942年1月，美、英、苏、中等26个国家在华盛顿签署《联合国家宣言》**，签字国保证用自己的全部力量反对法西斯，相互合作，**世界反法西斯联盟正式形成**。
  - **1942年7月—1943年2月的斯大林格勒保卫战**，苏军打败德军，它**是第二次世界大战的转折点**。
  - **1944年6月6日，美、英盟军在法国诺曼底登陆**，开辟了**欧洲第二战场**，德国陷入东西两个战场的夹击之中。
  - **1945年2月，美、英、苏三国首脑罗斯福、丘吉尔、斯大林在雅尔塔召开会议**：决定彻底消灭德国法西斯主义，战后德国由美、英、苏等国实行分区占领；决定战后成立联合国；苏联承诺在欧洲战事结束后3个月内参加对日作战。
  - **1945年5月8日，德国正式签署投降书**，欧洲战事结束。
  - 1945年8月，美国先后在日本广岛、长崎投下原子弹，苏联对日宣战，中国抗日军队发起全面反攻。**1945年9月2日，日本正式签署投降书，第二次世界大战结束**。
  - 二战是一场**世界人民的反法西斯战争**。

### 三、历史意义·阶段特征与重要结论

- **阶段特征**：1929—1933年大危机引发资本主义世界的政治分化——美国通过新政维护民主制度，德、日走上法西斯道路；第二次世界大战是世界反法西斯战争，彻底改变了世界面貌。
- 课本结论：
  - 罗斯福新政**采用国家干预经济的手段**，资本主义制度得到调整、巩固与发展，但**没有改变资本主义本质**。
  - 二战的性质是**世界人民的反法西斯战争**。
  - **《联合国家宣言》的签署标志着世界反法西斯联盟的正式形成**。
  - **斯大林格勒保卫战是第二次世界大战的转折点**。
  - 诺曼底登陆**开辟了欧洲第二战场**。
  - 二战彻底粉碎了法西斯主义和军国主义通过战争称霸世界的野心，彻底结束了列强通过争夺殖民地瓜分世界的历史，促进了世界殖民体系的瓦解，对维护世界和平、促进共同发展产生了重大而深远的影响。

### 四、因果线索与常用史观·答题模型

- 因果链：1929大危机 → 两条出路（美：新政；德意日：法西斯）→ 绥靖政策纵容侵略 → 德国扩张 → 1939全面爆发 → 1941苏德、太平洋战争 → 反法西斯同盟 → 转折（斯大林格勒）→ 反攻（诺曼底）→ 雅尔塔安排 → 法西斯投降。
- 比较模型（美、德两国应对危机的不同道路）：
  - 美国：罗斯福新政，**国家干预经济**，维护资本主义民主制度。
  - 德国：希特勒上台，建立**法西斯专政**，对外侵略扩张。
- 唯物史观：**经济危机激化矛盾，不同的应对方式导致不同走向**；世界反法西斯国家联合起来才能战胜法西斯。
- 答题模型（"二战胜利原因"题）：根本原因——**世界反法西斯联盟的建立（《联合国家宣言》），各国协同作战**。

### 五、考点与典型题型·方法

**题型1：大危机特点**
- 通法：**持续时间长、涉及范围广、破坏性大**；从**美国**开始（1929年10月股市崩溃）。

**题型2：罗斯福新政**
- 分点答案：①1933年罗斯福实行新政；**特点：国家干预经济**；②中心措施是对工业的调整，通过《全国工业复兴法》；③推行"以工代赈"；④影响：美国经济缓慢恢复，资本主义制度得到调整、巩固与发展；**但没有改变资本主义本质，无法解决根本矛盾**。

**题型3：二战进程关键节点排序**
- 通法：1939.9.1闪击波兰（全面爆发）→ 1941.6突袭苏联（规模扩大）→ 1941.12.7珍珠港（最大规模）→ 1942.1《联合国家宣言》（同盟形成）→ 1943.2斯大林格勒（转折）→ 1944.6.6诺曼底（第二战场）→ 1945.5.8德降→ 1945.9.2日降（结束）。

**题型4：《联合国家宣言》**
- 分点答案：①1942年1月，26国在华盛顿签署；②保证用全部力量反对法西斯、相互合作；③**标志着世界反法西斯联盟的正式形成**，是二战胜利的根本保证。

**题型5：雅尔塔会议**
- 分点答案：①1945年2月，美（罗斯福）、英（丘吉尔）、苏（斯大林）召开；②彻底消灭德国法西斯，战后分区占领德国；③决定战后成立**联合国**；④苏联承诺欧战结束后3个月内对日作战。

**题型6：评价绥靖政策**
- 分点答案：①1938年《慕尼黑协定》把捷克斯洛伐克苏台德区割给德国，是绥靖政策顶峰；②英法以牺牲小国利益换取自身和平，**纵容了法西斯侵略野心**，加速了二战爆发。

### 六、易错易混

- ❌ 把大危机开始时间说成1933年 → ✅ 危机**1929年从美国开始**；1933年是**罗斯福就任总统、实行新政**。
- ❌ 把罗斯福新政说成"改变了资本主义制度" → ✅ 新政是在**维护资本主义制度**前提下的政策调整，没有改变资本主义本质。
- ❌ 把二战全面爆发写成珍珠港事件 → ✅ 全面爆发是**1939年9月1日德国闪击波兰**；珍珠港事件（1941.12.7）是**达到最大规模**。
- ❌ 把转折战役写成诺曼底登陆 → ✅ 转折是**斯大林格勒保卫战（1942.7—1943.2）**；诺曼底登陆是**开辟欧洲第二战场（1944.6.6）**。
- ❌ 把二战结束时间写成1945年5月8日 → ✅ 5月8日是**德国投降、欧洲战事结束**；**9月2日日本签署投降书**才是二战正式结束。
- ❌ 把二战性质说成"帝国主义战争" → ✅ 一战是帝国主义战争；**二战是世界人民的反法西斯战争**。
- ❌ 把最早建立法西斯政权的国家当成德国 → ✅ **1922年意大利墨索里尼**最早；德国1933年、日本1936年。

### 二、核心史事（时间·人物·经过，通俗→严谨）

**1. 冷战**
- 通俗：二战一结束，美国和苏联由盟友变成对手。美国不敢直接打三战（都有原子弹），就用"除了战争以外的一切手段"对付苏联，这叫"冷战"。政治上杜鲁门主义，经济上马歇尔计划，军事上1949年拉一帮国家建北约；苏联针锋相对，1955年建华约。中间德国被分成东西两半。
- 严谨：
  - 概念：冷战是指**二战后的40多年间，以美、苏为首的两大集团之间既非战争又非和平的对峙与竞争状态**。
  - 政治：**1947年3月，杜鲁门主义的出台**，标志着**美、苏战时同盟关系正式破裂，冷战开始**。
  - 经济：美国推行**马歇尔计划**，通过援助西欧恢复经济，稳定资本主义制度，加强对西欧的控制。
  - 军事：**1949年，美、英、法等12国成立"北大西洋公约组织"（北约）**；**1955年，苏联同东欧7个社会主义国家成立"华沙条约组织"（华约）**。**两极格局由此形成**。
  - 德国分裂：1949年9月，在美、英、法占领区成立**德意志联邦共和国（西德）**；10月，在苏占区成立**德意志民主共和国（东德）**。**欧洲冷战对峙的局面基本形成**。

**2. 战后资本主义的新变化**
- 通俗：战后西欧、日本经济恢复得很快。西欧国家走到一起，先搞欧共体，1993年成立欧盟；美国90年代靠信息技术搞出"新经济"；日本1968年经济跃居资本主义世界第二。各国还陆续建了社会保障制度，号称"福利国家"。
- 严谨：
  - **欧洲联合**：20世纪50年代初，法国、联邦德国等六国组建"欧洲煤钢共同体"，以后又建立欧洲经济共同体和欧洲原子能共同体；**1967年，这三个组织合并为"欧洲共同体"**；**1993年，大部分西欧国家在欧共体基础上组成了欧洲联盟（欧盟）**，大大加快了欧洲一体化的进程。
  - 美国：20世纪90年代以后，美国出现了以**全球化和信息化**为主要特征的"**新经济**"，美国经济进一步发展。
  - 日本：1968年，日本成为**资本主义世界仅次于美国的第二经济大国**。
  - 社会保障制度：为了缓和社会矛盾，主要资本主义国家纷纷调整政策，建立起**社会保障制度**，逐步建立起包括医疗保健服务、养老、住房、失业保险和教育等在内的社会保障体系。

**3. 社会主义的发展与演变**
- 通俗：苏联模式的毛病越来越大，赫鲁晓夫、勃列日涅夫、戈尔巴乔夫改了几轮都没改好；东欧各国也照搬苏联模式，经济困难。1989年东欧各国政权纷纷更迭（东欧剧变）；1991年苏联正式解体，冷战结束，社会主义遭受重大挫折。
- 严谨：
  - 苏联的改革：**赫鲁晓夫改革**没有从根本上突破斯大林时期形成的高度集中的计划经济体制；**勃列日涅夫**改革仍未彻底突破苏联模式；**戈尔巴乔夫**改革先经济后政治，政治上取消马克思主义的指导地位，实行多党制，导致人们思想混乱、苏联解体加速。
  - **1989年，东欧政局发生剧烈动荡**，各国共产党纷纷丧失政权，社会制度随之发生根本性变化，史称"**东欧剧变**"。
  - **1991年，苏联解体**，美苏冷战结束，两极格局终结。苏联解体和东欧剧变，标志着**苏联模式的失败**，是国际社会主义运动的重大挫折，但**并不意味着社会主义运动的失败**（中国等国仍在探索中国特色社会主义道路）。

**4. 亚非拉国家的新发展**
- 通俗：二战后殖民地纷纷独立。1955年亚非国家在印尼万隆开会，周恩来提出"求同存异"；1960年非洲一年有17国独立，叫"非洲独立年"；1990年纳米比亚独立，标志非洲殖民体系彻底崩溃。古巴1959年卡斯特罗搞革命走上社会主义；巴拿马1999年从美国手里收回运河全部主权。
- 严谨：
  - **1955年，印度尼西亚的万隆会议**召开，这是第一次没有西方殖民国家参加的亚非会议。周恩来在会上提出"**求同存异**"的方针，促进了会议的圆满成功，加强了亚非国家之间的团结与合作，形成了"万隆精神"。
  - **1960年，非洲有17个国家独立，这一年被称为"非洲独立年"**。
  - **1990年，纳米比亚独立**，标志着**所有非洲国家都摆脱了殖民主义的枷锁，帝国主义在非洲的殖民体系最终崩溃**。
  - 1959年，**古巴**人民在卡斯特罗领导下推翻了美国支持的独裁政权，走上了社会主义发展道路。
  - **1999年，巴拿马从美国手中收回了巴拿马运河区的全部主权**。

### 三、历史意义·阶段特征与重要结论

- **阶段特征**：二战后形成**美苏两极格局（冷战）**；资本主义世界在恢复中出现新变化（欧洲联合、日本崛起、社会保障）；社会主义在改革中遭遇挫折（东欧剧变、苏联解体）；亚非拉民族独立运动高涨，世界殖民体系瓦解。
- 课本结论：
  - **1947年杜鲁门主义的出台，标志着冷战开始**；1955年华约成立，**两极格局形成**。
  - 欧洲联合（欧共体→欧盟）、日本崛起，**冲击了两极格局，推动世界多极化趋势**。
  - **1991年苏联解体，标志着两极格局终结、冷战结束**。
  - 万隆会议是**第一次没有西方殖民国家参加的亚非会议**。
  - **1990年纳米比亚独立，标志着帝国主义在非洲的殖民体系最终崩溃**。

### 四、因果线索与常用史观·答题模型

- 因果链：二战后美苏国家利益、意识形态对立 → 杜鲁门主义（冷战开始）→ 北约、华约对峙 → 两极格局；西欧、日本经济恢复 → 联合/崛起 → 冲击两极；苏联模式僵化 → 改革失败 → 东欧剧变、苏联解体 → 两极格局终结。
- 唯物史观：**社会主义发展道路不会一帆风顺**，苏联解体是苏联模式（僵化体制）的失败，不是社会主义本身的失败。
- 评价模型（评价冷战）：一方面两强相争避免了新的世界大战；另一方面造成世界长期分裂、局部热战不断、军备竞赛。
- 多极化趋势模型：两极格局下，**欧共体、日本、中国、不结盟运动**等多股力量崛起，推动世界由两极向多极化发展。

### 五、考点与典型题型·方法

**题型1：冷战开始与两极格局形成的标志**
- 通法：开始——**1947年杜鲁门主义**；两极格局形成——**1955年华约成立**；结束——**1991年苏联解体**。

**题型2：欧洲联合进程**
- 通法：1967年**欧共体**；**1993年欧盟**成立。

**题型3：日本经济地位**
- 通法：**1968年**，日本成为资本主义世界仅次于美国的**第二经济大国**。

**题型4：苏联解体与东欧剧变**
- 例：如何认识苏联解体？
  - 分点答案：①1991年苏联解体，标志冷战和两极格局结束；②根本原因是**苏联模式（高度集中的计划经济体制）长期僵化**，改革失败；③这是**国际社会主义运动的重大挫折**，但**不是社会主义的失败**，中国等国仍在探索符合本国国情的社会主义道路。

**题型5：万隆会议与非洲独立**
- 分点答案：①1955年万隆会议，第一次没有殖民国家参加的亚非会议，周恩来提出"**求同存异**"；②1960年"非洲独立年"（17国）；③**1990年纳米比亚独立**，标志帝国主义在非洲殖民体系最终崩溃。

**题型6：德国分裂**
- 通法：1949年西德（联邦德国）、东德（民主德国）先后成立，欧洲冷战对峙局面基本形成。

### 六、易错易混

- ❌ 把冷战开始标志说成"华约成立" → ✅ 开始标志是**1947年杜鲁门主义**；华约成立（1955）是**两极格局正式形成**的标志。
- ❌ 把欧共体和欧盟时间混了 → ✅ **1967年欧共体**；**1993年欧盟**。
- ❌ 把苏联解体说成"社会主义失败" → ✅ 是**苏联模式（僵化体制）的失败**，社会主义运动仍在探索发展。
- ❌ 把纳米比亚独立年说成1960年 → ✅ 1960年是"**非洲独立年**"；**1990年纳米比亚独立**标志非洲殖民体系最终崩溃。
- ❌ 把万隆会议说成"有殖民国家参加" → ✅ 万隆会议是**第一次没有西方殖民国家参加**的亚非会议，方针是"求同存异"。
- ❌ 把日本成为第二经济大国时间说成1990年代 → ✅ **1968年**日本成为资本主义世界第二经济大国。
- ❌ 认为冷战时期美苏真正打过第三次世界大战 → ✅ 冷战是**既非战争又非和平的对峙与竞争**，双方没有直接大规模开战。

## 第六单元 走向和平发展的世界

> 课时：第20课 联合国与世界贸易组织；第21课 冷战后的世界格局；第22课 不断发展的现代社会（课号以教材目录为准）。

### 一、本单元时空脉络（知识结构）

```
走向和平发展的世界（1991年冷战结束以来）
│
├─ 国际组织
│   ├─ 1945.10.24 联合国成立（安理会5个常任理事国）
│   └─ 1995.1.1 世界贸易组织（WTO）成立
├─ 世界格局与趋势
│   ├─ 冷战结束后：美国"一超"，欧盟、日本、中国、俄罗斯等"多强"
│   ├─ 政治趋势：多极化
│   └─ 经济趋势：全球化
├─ 科技与社会
│   └─ 计算机网络技术（信息时代）、原子能、生物工程、航天技术
└─ 全球性问题
    ├─ 生态环境（气候变暖、污染）
    ├─ 人口过快增长
    ├─ 毒品、恐怖主义、贫富分化、重大传染病
    └─ 应对：需要国际合作、构建人类命运共同体

        → 21世纪（经济全球化、政治多极化深入发展）
```

### 二、核心史事（时间·人物·经过，通俗→严谨）

**1. 联合国与世界贸易组织**
- 通俗：二战后大家怕再打世界大战，就1945年成立联合国，专门调解国际纠纷、维护世界和平；安理会有5个常任理事国（中美俄英法），对实质问题有"否决权"。经济上，为了让各国做生意更自由，1995年成立世界贸易组织（WTO），制定全球贸易规则。
- 严谨：
  - **联合国**：**1945年10月24日**，联合国正式成立，总部设在美国纽约。联合国的主要机构有联合国大会、联合国安全理事会（安理会）、联合国秘书处等。**安理会担负着维护国际和平与安全的主要责任**，由**中国、法国、俄罗斯、英国、美国5个常任理事国**和10个非常任理事国组成，**5个常任理事国拥有否决权**。
  - **世界贸易组织（WTO）**：**1995年1月1日**，世界贸易组织正式成立。其宗旨是以非歧视、开放、公平为原则，促进全球贸易和经济发展。**世界贸易组织与联合国一起，成为支撑、协调世界经济和政治的两大支柱，推动着世界的和平与发展**。

**2. 冷战后的世界格局**
- 通俗：苏联一倒，美国成了唯一超级大国，到处想当"世界警察"；但欧盟、日本、中国、俄罗斯等力量也在增长，世界格局朝"一超多强"、多极化方向走。经济上，各国你中有我、我中有你，这叫经济全球化。
- 严谨：
  - 苏联解体后，**美国成为唯一的超级大国**，但欧盟、日本、中国、俄罗斯等具备较强综合实力的国家联盟或国家也在国际和地区事务中发挥着重要作用，**世界格局朝多极化方向发展**（当前处于"一超多强"阶段）。
  - 经济趋势：**经济全球化**趋势加强，世界贸易组织成立是重要表现；各国经济相互联系、相互依存程度不断加深。

**3. 计算机网络技术与现代社会**
- 通俗：二战后第三次科技革命兴起，电子计算机是核心，后来又连成网络，人类进入"信息时代"。手机、互联网、电商、远程办公都来自这一波技术。
- 严谨：第二次世界大战后，随着电子计算机的发明和普及，**数据库和计算机网络**建立起来。20世纪90年代以来，互联网在全球迅速普及，成为现代社会重要的基础设施，**标志着人类社会开始进入"信息时代"**。计算机网络将世界各地联结成一个整体，创造了人类新的生活模式和文化观念。

**4. 全球性问题**
- 通俗：世界越来越连在一起，但麻烦也一起来了：气候变暖、环境污染、人口爆炸、毒品泛滥、恐怖主义、贫富差距、重大传染病……这些不是一个国家能搞定的，必须大家合作。
- 严谨：人类面临**日益严重的全球性问题**：生态环境恶化（气候变暖、空气污染、淡水资源短缺）、人口过快增长、毒品问题、恐怖主义、贫富分化加剧、重大传染性疾病等。这些问题**需要国际社会共同应对**，中国提出**构建人类命运共同体**，为全球治理提供了中国方案。

### 三、历史意义·阶段特征与重要结论

- **阶段特征**：冷战结束后，世界形势总体趋向缓和，**和平与发展成为时代主题**；但世界并不太平，政治多极化、经济全球化在曲折中发展，人类面临许多共同挑战。
- 课本结论：
  - **联合国是人类构建世界和平的成果，也是影响最大的国际组织**。
  - **世界贸易组织与联合国一起，成为支撑、协调世界经济和政治的两大支柱**。
  - 世界政治格局**朝多极化方向发展**；经济**全球化**趋势加强。
  - 计算机网络的普及，**标志着人类社会进入"信息时代"**。
  - 全球性问题需要**国际社会共同应对**，构建人类命运共同体是必然选择。

### 四、因果线索与常用史观·答题模型

- 因果链：二战反法西斯胜利 → 建立联合国 → 维护和平；第三次科技革命（计算机、网络）→ 经济全球化 → WTO成立；冷战结束 → 美国一超、多强崛起 → 多极化趋势；全球化加深 → 利益与风险都全球化 → 全球性问题 → 人类命运共同体。
- 唯物史观：**生产力（科技革命）推动世界联系加强**——经济全球化是生产力发展的必然结果。
- 辩证一分为二：经济全球化——既是机遇（资源配置、经济发展），也是挑战（风险跨国传递、贫富差距拉大）。
- 答题模型（"如何认识经济全球化"）：先答**是生产力发展的必然结果、是历史趋势**，再答**机遇与挑战并存**，最后答**要顺应趋势、加强国际合作、构建人类命运共同体**。

### 五、考点与典型题型·方法

**题型1：联合国与WTO**
- 通法：联合国——1945.10.24，政治支柱，5常任理事国（中美俄英法）有否决权；WTO——1995.1.1，经济支柱。

**题型2：世界格局**
- 例：冷战结束后的世界格局是？
  - 分点答案：①美国成为唯一超级大国（"一超"）；②欧盟、日本、中国、俄罗斯等多强并存；③**世界政治格局朝多极化方向发展**（暂时形成"一超多强"局面）；④经济上呈现**全球化**趋势。

**题型3：经济全球化**
- 分点答案：①表现：国际投资和国际贸易迅速增长，跨国公司影响增大，**世界贸易组织成立（1995）**是重要表现；②本质：生产力发展的必然结果；③是一柄双刃剑——既加速世界经济发展，也带来风险（贫富差距、环境污染、传染病跨国传播等）；④应对：顺应趋势，制定防范风险的有效政策，加强国际合作。

**题型4：信息时代**
- 通法：**计算机网络技术**的普及标志人类进入"信息时代"。

**题型5：全球性问题与中国方案**
- 分点答案：①问题：生态环境、人口、毒品、恐怖主义、贫富分化、重大传染病等；②不是一个国家能解决的，需要**国际合作**；③中国方案——**构建人类命运共同体**。

### 六、易错易混

- ❌ 把联合国成立时间写成1995年 → ✅ 联合国**1945年10月24日**成立；**1995年1月1日是世界贸易组织（WTO）**成立。
- ❌ 认为联合国安理会常任理事国没有否决权 → ✅ 5个常任理事国（中、法、俄、英、美）对实质问题拥有**否决权**。
- ❌ 把当今世界格局说成"已经实现多极化" → ✅ 是**朝多极化方向发展**，暂时是"一超多强"，多极化**尚未最终形成**。
- ❌ 认为经济全球化只有好处 → ✅ 是**双刃剑**，机遇与挑战并存。
- ❌ 把"信息时代"归功于蒸汽机 → ✅ "信息时代"来自**计算机网络技术**；蒸汽时代是第一次工业革命，电气时代是第二次工业革命。
- ❌ 认为全球性问题靠一个国家就能解决 → ✅ 必须**国际社会共同应对**，构建人类命运共同体。
