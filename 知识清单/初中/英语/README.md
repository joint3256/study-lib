## 话题覆盖（课标15话题，螺旋上升）

个人情况与家庭、朋友与周围的人、校园生活、日常活动与作息、兴趣与爱好、购物、饮食与健康、天气、节假日与庆祝、旅行与交通、自然与环境、动物与保护、科普常识与技术、社会与文化、情感与人际交往——在6册中循环复现、逐级加深。

## 语法项目分配（循序复现）

- 七上：be动词、名词单复数/所有格、冠词a/an、指示代词、物主代词、基数词、时间表达。
- 七下：一般现在时（实义动词三单）、现在进行时、方位介词/there be、情态动词can、祈使句、一般过去时入门。
- 八上：一般过去时（不规则）、一般将来时、比较级、must/have to、动名词、并列连词。
- 八下：过去进行时、现在完成时入门、宾语从句that/感叹句、最高级、动词不定式、被动语态入门。
- 九上：现在完成时for/since、被动语态（一般现在/过去）、状语从句（时间/条件/原因）、定语从句（who/which/that）、情态动词表推测。
- 九下：六种时态综合、宾语从句语序/时态呼应、定语从句深化、状语从句（让步/结果/目的）、中考书面表达。

## 检索提示

- 给学生讲题前：先定位"册→Module"，再按六要素快速翻看。
- 查缺补漏：优先看每 Module 的"三、语法要点"和"六、易错易混"（❌/✅成对）。
- 写作卡壳：翻"四、话题表达与写作"里的现成框架/范文。
- 词汇：每 Module 高频词给词性+释义+搭配+例句；超纲词标 *。
