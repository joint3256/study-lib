# 方法套路库 · 历史

面向线上家教的"**题型 → 方法套路**"速查库，与按知识点组织的《知识清单》（`知识清单/初中/历史/` 七上~九下共 6 册）互补：
知识清单回答"史事是什么"，本库回答"**这类历史题怎么做、第一步干什么**"。

每个方法/模型条目统一六块：**①方法/模型名 ②适用题型（识别特征） ③原理（讲清为什么） ④操作步骤 ⑤例题完整演示（题干→分点解答→答案） ⑥❌易错提醒**。
面向基础薄弱学生：先大白话讲原理，步骤可照做，材料题给简短材料。

## 二、与知识清单的分工

- 拿到一道题，先判断它考"是什么"还是"怎么做"：
  - 问史事本身（时间、人物、内容、意义）→ 去 `知识清单/初中/历史/` 对应册查。
  - 问怎么归类、怎么对比、材料题怎么组织答案、选择题怎么排除 → 来本库。
- 术语、年代、条约、会议、阶段结论一律与知识清单保持一致；遇冲突以统编教材通行表述为准并回查知识清单对应册。

## 三、合规与使用须知

- 方法主体依据《义务教育历史课程标准（2022 年版）》+ 统编教材公开目录**自行组织编写**，不复制教材全本、不收盗版"学霸笔记"扫描件、不搬运付费课程内部讲义。
- 名师讲法部分仅提炼 B站/抖音等**公开免费**内容里的"方法/思路"并用自己的话重述，来源见 [资料来源.md](资料来源.md)。
- 年代、条约、会议、改革等关键事实均可在教材与权威公开来源核对，不编造。
