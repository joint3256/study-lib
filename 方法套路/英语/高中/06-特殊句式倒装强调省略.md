# 特殊句式：倒装/强调/省略

---

## 方法一：倒装句"否定词开头+only+so/neither"法

### ① 方法名
倒装句两大类解题法

### ② 适用题型
单项选择、语法填空、短文改错

### ③ 原理（语法 form 与意义 use）

**语法形式（form）层面：**
倒装分两种：
- 部分倒装：把助动词/情态动词/be 动词提到主语前面（像变疑问句一样）
- 完全倒装：整个谓语动词提到主语前面

**部分倒装的常见触发词：**
1. 否定词放在句首：never/seldom/hardly/little/not only/not until/by no means
2. only + 状语放在句首
3. so/neither/nor 表示"也/也不"
4. 虚拟条件句省略 if

**意义（use）层面：**
倒装是为了"强调"——把否定词/only 放句首，就是为了强调这个否定/条件。

### ④ 操作步骤

1. **第一步：看到句首是否定词/only+状语 → 想到倒装**
2. **第二步：把助动词/情态动词/be 动词提前**（变成疑问句语序）
3. **第三步：注意时态和人称一致**

### ⑤ 例题完整演示

**题干：**
Never before ______ seen such a wonderful view.
A. I have  B. have I  C. I had  D. did I

**分析过程：**
- 第一步：句首 Never before 是否定短语放句首 → 部分倒装
- 第二步：把助动词 have 提前 → have I
- 第三步：现在完成时，have seen → Never before have I seen...
- 验证：我以前从未见过这么美的景色。

**答案：B**

## 方法二：强调句"It is/was...that/who..."法

### ① 方法名
强调句判断法

### ② 适用题型
单项选择、语法填空、书面表达（高级句型）

### ③ 原理（语法 form 与意义 use）

**语法形式（form）层面：**
强调句基本结构：**It is/was + 被强调部分 + that/who + 其他部分**

- 强调人：It is/was + 人 + that/who + ...
- 强调物/事/地点/时间：It is/was + 物/事 + that + ...

**判断方法：去掉 It is/was...that/who，剩下的部分仍然是一个完整的句子 → 就是强调句**

### ④ 操作步骤

1. **第一步：看到 It is/was... ______... → 想是不是强调句**
2. **第二步：去掉 It is/was 和空格词，看剩下的是不是完整句子**
3. **第三步：完整 → 就是强调句，填 that/who**
4. **第四步：强调人可以用 who，其他都用 that**

### ⑤ 例题完整演示

**题干：**
It was in the park ______ I met an old friend yesterday.
A. where  B. that  C. which  D. when

**分析过程：**
- 第一步：看到 It was... → 想强调句
- 第二步：去掉 It was 和空格 → in the park I met an old friend yesterday → 完整句子！
- 第三步：是强调句，强调地点 in the park → 用 that
- 验证：就是在公园里我昨天遇到了一个老朋友。

**答案：B**

### ⑥ ❌ 易错提醒

- **强调句不能用 when/where**——不管强调时间还是地点，都用 that
- **not...until... 的强调句**：It was not until midnight that he came back.（直到半夜他才回来）
- **倒装句不要把整个谓语提前**——部分倒装只提前助动词/情态动词/be 动词
- **so + 形容词 + that 句型中，如果 so... 放句首，主句要倒装**：So fast did he run that I couldn't catch up.
