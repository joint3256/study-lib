## 每单元固定六要素（缺一不可）

每个 `## 第N单元 单元名` 下，开头一行 `> 课时：…（课号以教材目录为准）`，再依次包含：

1. **一、本单元时空脉络（知识结构）**（年代轴 + 缩进树形，体现政权更迭与先后）
2. **二、核心史事（时间·人物·经过，通俗→严谨）**（按课组织，先大白话后严谨表述）
3. **三、历史意义·阶段特征与重要结论**（事件性质/意义/教训 + 本时期阶段特征 + 课本结论）
4. **四、因果线索与常用史观·答题模型**（背景→经过→结果→影响因果链；唯物史观；材料题模型）
5. **五、考点与典型题型·方法**（选择题/材料题：题型→通法→含分点答案示例）
6. **六、易错易混**（❌/✅ 成对：年代换算、人物张冠李戴、制度朝代错配、意义错配、史料类型）

### 教薄弱学生的使用顺序
1. 先看"**二、核心史事**"的**大白话**一句，把事情听懂；
2. 再看"**一、时空脉络**"的年代轴，把时间位置摆对；
3. 做题卡住时翻"**五、考点题型**"对号入座；
4. 交作业前扫一遍"**六、易错易混**"，避开最常见的坑。
