## 按"第一步干什么"速查

- 题干先出现年份/朝代/世纪 → 先做**纪年换算与时间定位**（01 文件模型2、08 文件模型1）。
- 出现"条约/条约内容/影响" → 先列**割地·赔款·开口·特权四要素**（02 文件模型1）。
- 出现"洋务运动/戊戌变法/辛亥革命/新文化运动"对比 → 先套**器物→制度→思想三层递进**（03 文件模型1）。
- 出现"一大/遵义会议/七大/十一届三中全会" → 先按**会议线索表**对号（04 文件模型2）。
- 出现"英国/美国/法国革命"或"俄国改革/明治维新" → 先判**性质：革命还是改革**（05 文件模型2）。
- 出现"工业革命/一战/二战/冷战/格局" → 先拉**国际格局时间轴**（06 文件模型2）。
- 是材料题 → 永远**先读设问，再划材料，后联课本，分点作答**（07 文件模型1）。
- 是选择题且纠结两个选项 → 先**排绝对词、排时空错位，再选最贴合材料的**（08 文件模型2）。
