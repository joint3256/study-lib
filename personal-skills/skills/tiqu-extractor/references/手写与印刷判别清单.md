# 手写与印刷判别清单

> 总原则：只保留卷面"印刷"内容；一切"手写"内容（文字、数字、符号、打勾、
> 草稿、手画线条与草图）一律不提取。判定拿不准的元素，标注"待人工确认"，
> 不得凭猜测保留或删除。

## 一、逐类判别

| 看到的内容 | 判定 | 处理 |
|---|---|---|
| 写在横线、括号、空格上的答案/数字/字 | 手写 | 删，空格保留为空 |
| 打勾、打叉、圈选项、画圈、分数、等级、涂改 | 手写 | 删 |
| 竖式、演算等式、划掉的过程、页边旁注、箭头批注 | 手写（草稿） | 删 |
| 在印刷图上或留白处补画的线、辅助线、小三角形、示意草图 | 手写（手绘） | 删 |
| 题干、设问、选项、分值、大题说明、表格文字 | 印刷 | 保留并转录 |
| 题目配图，含印刷的虚线、阴影、直角符号、刻度、点字母 | 印刷 | 保留并重画 |
| 手写体风格的印刷标题、卡通插图（属卷面设计的一部分） | 印刷 | 保留，勿误删 |

## 二、难分辨灰区（重点）

1. **学生在印刷图上补的铅笔线与印刷线像素重叠**：照片是扁平像素，无法分层。
   按几何逻辑判断"题目本身通常应有哪些线"，重画时只画题目本有的线；
   无法确定的线列入"待人工确认"，不要默认保留。
2. **留白处的独立小图**：与该题设问无关的（如题1旁随手画的小三角形）属涂鸦，删；
   只有当图本身是题目要求的一部分时才保留。
3. **印刷虚线 vs 手画虚线**：印刷虚线段落等长、间隔规整、与点字母/标注配套；
   手画虚线随意、常压在其他内容上、墨色与正文不一致。
4. **印刷阴影 vs 手写填充**：印刷填色均匀、边界就是图形边；手写斜线/涂黑方向杂乱。
5. **模糊、斜拍、分辨率低**：先转正，再放大、分区域逐处看，不凭整体印象判定。

## 三、判定记录（每图）

每张配图重画前，简单列出：保留的印刷元素（点、线、虚线、角、阴影、标注）、
删除的手写元素。转 PDF 核对时按此清单逐项对照，确认该删的没留下、该留的没误删。
