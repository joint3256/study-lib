# 高中化学知识清单（人教版 2019）· 板块索引

> 面向天津线上家教，用于给**基础薄弱学生**讲题、查缺补漏、快速定位知识点。
> 编写依据：《普通高中化学课程标准（2017 年版 2020 年修订）》与人教版 2019 教材目录。
> 使用方式：先定位到"册"→定位到"章"→直接翻到每章"**六、易错易混**"给学生排雷，再用"**四、模型 / 五、题型**"讲方法。

> 共 5 册、20 章。每个 `## 章` 下固定含六个 `###`（六要素），缺一不可。

## 每章固定六要素（讲题时的检索顺序）

1. **一、本章知识结构** —— 树形知识地图，先看全局。
2. **二、核心概念（通俗→严谨）** —— 基础弱学生先读"通俗"那句。
3. **三、定理、公式与结论** —— 方程式、公式、符号与单位。
4. **四、公式推导要点与常用模型** —— 守恒法、三段式、价类二维、晶胞均摊、逆合成等通法。
5. **五、考点与典型题型·方法** —— 题型→步骤→范例（含可核验解答）。
6. **六、易错易混** —— ❌/✅ 成对，给学生快速排雷（**讲题第一站**）。
