## 物理常数约定
- $g=9.8\,\text{N/kg}$，粗略计算取 $10\,\text{N/kg}$。
- 水的密度 $1.0\times10^3\,\text{kg/m}^3$；水的比热容 $4.2\times10^3\,\text{J/(kg·°C)}$。
- 标准大气压 $1.013\times10^5\,\text{Pa}$。
