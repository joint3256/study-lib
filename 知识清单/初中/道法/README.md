## 三、检索提示（怎么快速找到要讲的点）

1. **按主题找册**：
   - 讲"学习、友谊、老师父母、生命"→ 七上；
   - 讲"青春期、情绪、班集体、法律入门、未成年人保护"→ 七下；
   - 讲"社会、网络、规则道德、违法犯罪、责任、国家利益、国家安全"→ 八上；
   - 讲"宪法、权利义务、国家机构"→ 八下（待补）；
   - 讲"改革开放、创新、民主法治、文化、生态、民族复兴"→ 九上（待补）；
   - 讲"全球化、人类命运共同体、中国在世界、少年担当"→ 九下（待补）。
2. **按题型找**：每册每个单元的"五、考点与典型题型·方法"已分选择题、材料题、评析题，直接对号入座。
3. **抓关键词**：
   - "为什么类"题 → 翻该单元的"三、原理依据·意义作用"；
   - "怎么做/建议/启示类"题 → 翻"四、观点联系与做法模型"（已按国家/社会/学校/家庭/青少年分主体）；
   - "判断对错/评析类"题 → 翻"六、易错易混"，尤其警惕绝对化表述（最/唯一/彻底/只要……就）、主体错位、道德与法律混淆。
4. **辨析易混**：违法与犯罪、一般违法与犯罪、主刑与附加刑、行政处罚与刑罚、六大保护主体、情绪与情感、个人利益与国家利益——均在对应单元"易错易混"中成对列出。

## 四、核心素养主线（课标 2022）

道德与法治课程聚焦五大核心素养：**政治认同、道德修养、法治观念、健全人格、责任意识**。讲解时可对照：
- 心理品德类（七上、七下大部分）→ 健全人格、道德修养；
- 规则法律类（七下第四单元、八上第二单元、八下）→ 法治观念；
- 社会责任类（八上第三、四单元）→ 责任意识、政治认同；
- 国情国策类（九上、九下）→ 政治认同。
