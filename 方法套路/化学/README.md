# 初中 + 高中化学 · 做题套路 / 方法 / 技巧库

> 面向**基础薄弱生**，可直接用于讲题。每个方法条目固定六块：
> ① 方法名　② 适用题型/物质　③ 原理（讲清为什么）　④ 操作步骤（编号）　⑤ 一道例题完整演示（方程式配平、注明条件与↑↓，计算题给完整步骤与正确数值）　⑥ ❌ 易错提醒。
>
> 所有化学方程式均已配平并标注反应条件与沉淀/气体符号；所有计算数值均经计算器复核。

## 三、覆盖对照（与要求板块一一对应）

**初中（要求 ≥9，实际 10）**：化学用语、质量守恒与方程式计算、空气与氧气、水与溶液、碳及氧化物、燃烧与能源、金属、酸碱盐通性与复分解、物质推断与除杂分离、常见气体检验与实验装置。

**高中（要求 ≥14，实际 14）**：物质的量与 NA、离子反应、氧化还原、钠镁铝、铁铜、氯硫氮、周期律周期表、化学键与结构、化学反应与能量、速率与平衡、水溶液离子平衡、电化学、有机化学、化学实验。

## 四、使用说明
- 讲题时先带学生定位"这道题属于哪个方法"，再按"原理 → 步骤 → 例题 → 易错"走一遍。
- ⑥ 易错提醒可直接当作考前自查清单。
