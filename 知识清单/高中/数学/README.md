# 高中数学知识清单（人教A版 2019）· 使用说明

> 本目录是天津线上家教专用的**高中数学本地知识清单**，面向**基础薄弱**学生，用于讲题、查缺补漏、快速定位知识点。
> 版本：人教 A 版（2019）；依据《普通高中数学课程标准（2017 年版 2020 年修订）》。

|---|---|---|---|

合计 **18 章**。

## 二、册次定位

- **必修第一、二册**：高考共同基础（学业水平要求），也是后续内容的工具。
- **选择性必修第一、二、三册**：高考要求内容，是高三复习主干。
- 不超纲：不把大学高数、竞赛技巧当作必讲知识点；只在"拓展/选学"处点到为止。

## 三、每章六要素（固定标题，缺一不可）

1. `### 一、本章知识结构` —— 树形图 + 节次一行；
2. `### 二、核心概念（通俗→严谨）` —— 先大白话再严谨定义；
3. `### 三、定理、公式与结论` —— LaTeX 书写，符号逐一解释，注明定义域/条件；
4. `### 四、公式推导要点与常用模型` —— 推导思路链 + 常用解题模型；
5. `### 五、考点与典型题型·方法` —— 题型 → 通法 → 含解答范例；
6. `### 六、易错易混` —— `❌/✅` 成对，直击高频错误。

## 四、检索提示

- 讲题前先按知识点定位到具体章，再看"五、考点与典型题型"找对应题型。
- 学生常错处直接翻"六、易错易混"对照。
- 公式记不准翻"三、定理、公式与结论"，符号都有解释。
