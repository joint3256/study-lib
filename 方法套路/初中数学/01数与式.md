## 方法1：有理数混合运算「符号先行 + 分步定号」法

### 适用题型
- 含加、减、乘、除、乘方的多步有理数计算题（中考第17题第一问常见）。
- 题目特征：式子中同时出现正负数、括号、乘方，结果容易因符号出错。

### 原理/公式
- **先定符号，再算绝对值**：每一步运算先判断结果是正还是负，最后再把绝对值算出来。
- 符号规则：
  - 同号相加：取相同符号，绝对值相加。
  - 异号相加：取绝对值大的符号，大绝对值减小绝对值。
  - 乘除：同号得正，异号得负。
  - 乘方：负数的偶次幂为正，奇次幂为负。
- 运算顺序：**先乘方，再乘除，最后加减；有括号先算括号里的**。

### 操作步骤
1. 先观察式子中有哪些运算，按"乘方 → 乘除 → 加减"排序。
2. 逐段处理：每算一步，先写符号，再算数字。
3. 有括号的，从内到外逐层去括号。
4. 最后把所有结果按加减合并，再次确认符号。

### 例题演示
**题干**：计算 $-2^2 + (-3) \times |-4| - (-6) \div (-2)$。

**分步解答**：
1. **先算乘方**：$-2^2 = -(2^2) = -4$（注意：不是 $(-2)^2$）。
2. **算绝对值**：$|-4| = 4$。
3. **算乘法**：$(-3) \times 4 = -12$（异号得负）。
4. **算除法**：$(-6) \div (-2) = 3$（同号得正）。
5. **合并加减**：$-4 + (-12) - 3 = -4 - 12 - 3 = -19$。

**最终答案**：$\boldsymbol{-19}$

### ❌ 易错提醒
- **$-2^2 \ne (-2)^2$**：$-2^2$ 是 $-(2^2)=-4$；$(-2)^2=4$。这是最高频错误。
- 去括号时：括号前是负号，括号里每一项都要变号。
- 不要跳步！基础弱的学生跳一步就错一步，分步写最稳。

## 方法2：因式分解「一提二套三检查」法

### 适用题型
- 把一个多项式化成几个整式乘积的形式（中考必考，后续分式化简、解方程都要用）。
- 题目特征：要求"分解因式"或"因式分解到不能再分解为止"。

### 原理/公式
- **一提**：先看有没有公因式，有就先提出来。
- **二套**：提完公因式后，看剩下的部分能不能套公式：
  - 平方差公式：$a^2 - b^2 = (a+b)(a-b)$
  - 完全平方公式：$a^2 \pm 2ab + b^2 = (a \pm b)^2$
- **三检查**：检查每个括号里还能不能再分，必须分到"不能再分"为止。

### 操作步骤
1. **找公因式**：系数取最大公约数，字母取相同字母的最低次幂。
2. **提公因式**：把公因式提到括号外，括号内每一项都除以公因式。
3. **套公式**：看括号内剩几项——
   - 两项：试平方差。
   - 三项：试完全平方，或试十字相乘。
4. **检查**：每个因式都不能再分解才算完。

### 例题演示
**题干**：分解因式 $3x^3 - 12x$。

**分步解答**：
1. **提公因式**：$3x^3$ 和 $12x$ 的公因式是 $3x$。
   $$3x^3 - 12x = 3x(x^2 - 4)$$
2. **套公式**：括号里 $x^2 - 4$ 是平方差，$a=x, b=2$。
   $$x^2 - 4 = (x+2)(x-2)$$
3. **检查**：$x+2$ 和 $x-2$ 都是一次式，不能再分。

**最终答案**：$\boldsymbol{3x(x+2)(x-2)}$

### ❌ 易错提醒
- **漏提公因式**：只提字母不提系数，或只提系数不提字母。
- **分解不彻底**：比如 $x^4 - 16$ 分解成 $(x^2+4)(x^2-4)$ 就停了，$x^2-4$ 还能继续分。
- **混淆因式分解和整式乘法**：因式分解是"和→积"，整式乘法是"积→和"，方向相反。

## 方法3：十字相乘法（二次三项式因式分解）

### 适用题型
- 形如 $x^2 + px + q$ 的二次三项式分解因式。
- 题目特征：二次项系数为1，常数项是整数，能拆成两个整数相乘。
- 后续用途：解一元二次方程、二次函数找交点都能用到。

### 原理/公式
- 若能找到两个数 $a, b$，使得：
  $$a + b = p, \quad a \times b = q$$
  则：
  $$x^2 + px + q = (x + a)(x + b)$$
- **符号规律**：
  - $q > 0$（同号）：$a, b$ 同号，符号与 $p$ 相同。
  - $q < 0$（异号）：$a, b$ 异号，绝对值大的那个与 $p$ 同号。

### 操作步骤
1. 列出常数项 $q$ 的所有整数因数对。
2. 看哪一对因数的和等于一次项系数 $p$。
3. 按符号规则确定 $a, b$ 的正负。
4. 写出 $(x+a)(x+b)$，再展开验证。

### 例题演示
**题干**：分解因式 $x^2 + 5x + 6$。

**分步解答**：
1. 常数项 $q=6$，找两个数相乘得6，可能的组合：$(1,6), (2,3), (-1,-6), (-2,-3)$。
2. 看哪一组的和等于 $p=5$：$2+3=5$。
3. $q=6>0$，$p=5>0$，所以两个数都是正的：$a=2, b=3$。
4. 验证：$(x+2)(x+3) = x^2 + 3x + 2x + 6 = x^2 + 5x + 6$ ✓

**最终答案**：$\boldsymbol{(x+2)(x+3)}$

### ❌ 易错提醒
- **只拆常数项不验算和**：找到了因数对但忘了检查和对不对。
- **符号搞反**：比如 $x^2 - 5x + 6$ 应该是 $(x-2)(x-3)$，不是 $(x+2)(x+3)$。
- 二次项系数不是1时（如 $2x^2+5x+3$），需要十字交叉相乘，难度更大，基础弱的学生先掌握系数为1的情况。

## 方法4：分式化简求值「先约分后代入」法

### 适用题型
- 分式的化简、计算、先化简再求值类题目（中考第17题必考）。
- 题目特征：给出一个分式表达式，要求化简后代入某个数求值。

### 原理/公式
- 分式的基本性质：分子分母同乘（或同除以）同一个不为0的整式，分式的值不变。
- 约分：把分子分母的公因式约掉。
- 通分：把异分母分式化成同分母分式。
- **关键原则**：**先化简到最简分式，再代入数值计算**，绝对不要一上来就代数。

### 操作步骤
1. **有括号先算括号里的**：异分母先通分，合并成一个分式。
2. **除法变乘法**：除以一个分式 = 乘以它的倒数。
3. **分子分母分别因式分解**：能提公因式就提，能套公式就套。
4. **约分**：约掉分子分母的公因式，化成最简分式。
5. **最后才代入数值**：代入前确认分母不为0。

### 例题演示
**题干**：先化简，再求值：$\left(1 - \dfrac{1}{x+1}\right) \div \dfrac{x}{x^2-1}$，其中 $x=2$。

**分步解答**：
1. **算括号里的**：
   $$1 - \frac{1}{x+1} = \frac{x+1}{x+1} - \frac{1}{x+1} = \frac{x}{x+1}$$
2. **除法变乘法**：
   $$\frac{x}{x+1} \div \frac{x}{x^2-1} = \frac{x}{x+1} \times \frac{x^2-1}{x}$$
3. **因式分解**：$x^2-1 = (x+1)(x-1)$。
4. **约分**：
   $$\frac{x}{x+1} \times \frac{(x+1)(x-1)}{x} = x-1$$
5. **代入 $x=2$**：$x-1 = 2-1 = 1$。

**最终答案**：化简结果为 $\boldsymbol{x-1}$，代入后值为 $\boldsymbol{1}$。

### ❌ 易错提醒
- **直接代入不化简**：又慢又容易算错，还可能出现分母为0。
- **通分时漏乘分子**：比如 $\dfrac{1}{a} + \dfrac{1}{b} = \dfrac{a+b}{ab}$，不要写成 $\dfrac{1+1}{ab}$。
- **代入后忘记验分母**：化简后的式子虽然分母没了，但原式有意义的前提不能丢，选择题常考"x不能取哪些值"。

## 方法5：二次根式化简「被开方数因数分解」法

### 适用题型
- 二次根式的化简、计算、分母有理化类题目。
- 题目特征：根号下有数字或字母，要求化成最简二次根式。

### 原理/公式
- 最简二次根式：被开方数不含能开得尽方的因数（或因式）。
- 核心公式：$\sqrt{ab} = \sqrt{a} \cdot \sqrt{b}$（$a\ge0, b\ge0$）。
- 分母有理化：分母带根号时，分子分母同乘一个合适的根式，把根号移到分子上。

### 操作步骤
1. **把被开方数分解质因数**：找出哪些是完全平方数。
2. **把完全平方部分开出来**：$\sqrt{a^2 \cdot b} = a\sqrt{b}$（$a\ge0$）。
3. **分母有理化**：分母是 $\sqrt{a}$ 就乘 $\sqrt{a}$；分母是 $a+\sqrt{b}$ 就乘 $a-\sqrt{b}$。
4. **检查**：根号里不能再有分母，也不能再有能开出来的因数。

### 例题演示
**题干**：化简 $\sqrt{12} + \sqrt{\dfrac{1}{3}}$。

**分步解答**：
1. **化简 $\sqrt{12}$**：
   $$12 = 4 \times 3, \quad \sqrt{12} = \sqrt{4 \times 3} = \sqrt{4} \times \sqrt{3} = 2\sqrt{3}$$
2. **化简 $\sqrt{\dfrac{1}{3}}$**（分母有理化）：
   $$\sqrt{\frac{1}{3}} = \frac{\sqrt{1}}{\sqrt{3}} = \frac{1}{\sqrt{3}} = \frac{1 \times \sqrt{3}}{\sqrt{3} \times \sqrt{3}} = \frac{\sqrt{3}}{3}$$
3. **合并同类二次根式**：
   $$2\sqrt{3} + \frac{\sqrt{3}}{3} = \frac{6\sqrt{3}}{3} + \frac{\sqrt{3}}{3} = \frac{7\sqrt{3}}{3}$$

**最终答案**：$\boldsymbol{\dfrac{7\sqrt{3}}{3}}$

### ❌ 易错提醒
- **$\sqrt{a^2} = |a|$，不是 $=a$**：字母不知道正负时，结果必须带绝对值。
- **不能把根号里的加法拆开**：$\sqrt{a+b} \ne \sqrt{a} + \sqrt{b}$，这是最常见的错误。
- **分母有理化时分子也要乘**：分子分母必须同乘，不能只乘分母。
