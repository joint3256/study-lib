## 三、内容正确性核对 / 验算说明
本库所有化学方程式与计算均经独立核对，未直接照抄来源：

1. **方程式配平核对**：逐条检查两边原子种类与数目守恒，标注反应条件（Δ、高温、点燃、催化剂、通电、浓硫酸等）与沉淀 ↓、气体 ↑ 符号。重点核对了：
   - 制氧：2KMnO₄ =Δ= K₂MnO₄ + MnO₂ + O₂↑
   - 制 CO₂：CaCO₃ + 2HCl = CaCl₂ + H₂O + CO₂↑
   - 炼铁：Fe₂O₃ + 3CO =高温= 2Fe + 3CO₂
   - 铜与稀硝酸：3Cu + 8HNO₃(稀) = 3Cu(NO₃)₂ + 2NO↑ + 4H₂O（原子、电荷均守恒）
   - 电解饱和食盐水：2NaCl + 2H₂O =电解= 2NaOH + H₂↑ + Cl₂↑
   - 铝/铁转化、铝三角、电化学电极反应等。
2. **计算数值验算**（均用计算器复算，非凭记忆）：
   - Zn+H₂SO₄：6.5 g Zn → H₂ = 0.2 g
   - KMnO₄ 分解：31.6 g → O₂ = 3.2 g
   - 石灰石纯度：12.5 g 样、生成 4.4 g CO₂ → CaCO₃ 10 g、纯度 80%
   - 赤铁矿炼铁：100 t×80% Fe₂O₃ → 纯 Fe 56 t → 折含铁 96% 生铁 58.3 t
   - 配制 NaCl 溶液：50 g×6% = 3 g NaCl；稀释到 1% 需加水 250 g
   - 饱和 NaCl（S=36 g）质量分数 ≈ 26.5%
   - 标况 11.2 L O₂：n=0.5 mol、N=3.01×10²³、m=16 g
   - 配制 500 mL 0.100 mol/L NaCl：需 NaCl 2.925 g
   - 浓硫酸浓度：1000×1.84×98%/98 = 18.4 mol/L
   - Al+HCl：5.4 g Al → H₂ = 0.6 g
   - 盖斯定律：ΔH = −393.5 −(−283.0) = −110.5 kJ/mol
   - 平衡三段式 K = 0.8²/(0.6×1.8³) ≈ 0.183
   - pH：0.01 mol/L HCl → pH=2；AgCl Ksp=1.8×10⁻¹⁰ → s≈1.34×10⁻⁵ mol/L
   - 浓硫酸量取：18.4 mol/L 配 500 mL 0.184 mol/L → 量取 5.0 mL
   - 中和滴定：c(NaOH)=0.1000×20.00/25.00 = 0.08000 mol/L
