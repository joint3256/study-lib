## 方法名 → 文件 → 适用题型

1. 集合交并补——数轴/韦恩图坐标法 → 01 → 数集交并补、已知集合关系反求参数

- **基础薄弱生**：先读 ① 方法名、③ 原理、⑤ 例题，照步骤模仿；⑥ 易错提醒读两遍。
