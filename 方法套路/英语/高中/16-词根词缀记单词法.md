# 词根词缀+联想+语境记单词法

---

## 方法：单词记忆"词根拆解+联想+语境"三步法

### ① 方法名
高效记单词三步法（词根词缀法+联想记忆法+语境记忆法）

### ② 适用题型
词汇积累、阅读理解猜词、写作用词

### ③ 原理（语法 form 与意义 use）

**为什么词根词缀法有效：**
英语单词不是字母的随机组合，而是"词根+前缀+后缀"拼出来的。掌握了常见词根词缀，就能像拼乐高一样举一反三。

**构词法基本结构：**
- 前缀（prefix）：改变词义方向（不/向前/向后/向外...）
- 词根（root）：核心意思
- 后缀（suffix）：改变词性（名词/形容词/动词/副词）

**常见前缀：**

| 前缀 | 含义 | 例子 |
|------|------|------|
| un-/in-/im-/dis- | 不/否定 | unhappy, impossible, disagree |
| re- | 再/重新 | repeat, return, review |
| pre- | 前/预先 | predict, prepare, preview |
| post- | 后 | postpone, postwar |
| inter- | 之间/相互 | international, internet |
| trans- | 跨越/转换 | transport, translate, transform |
| ex- | 向外/前任 | export, ex-wife |
| sub- | 下/次级 | subway, subtitle |

**常见后缀：**

| 后缀 | 词性 | 例子 |
|------|------|------|
| -tion/-sion/-ment/-ness | 名词 | action, movement, happiness |
| -ful/-less/-ous/-able | 形容词 | careful, hopeless, famous, comfortable |
| -ly | 副词 | quickly, happily |
| -ize/-ify/-en | 动词 | realize, simplify, widen |

**常见核心词根：**

| 词根 | 含义 | 例子 |
|------|------|------|
| spect | 看 | inspect, respect, expect |
| port | 搬运/拿 | transport, import, export |
| struct | 建造 | construct, structure, destructive |
| dict | 说 | predict, dictionary, indicate |
| vis/vid | 看 | visible, video, evidence |
| duc/duct | 引导 | produce, educate, conduct |
| mit/miss | 送/发 | transmit, mission, dismiss |
| scrib/script | 写 | describe, script, prescribe |

### ④ 操作步骤

1. **第一步：拆词——把单词拆成前缀+词根+后缀**
   比如：unbelievable = un-（不）+ believe（相信）+ -able（能...的）→ 不能相信的
2. **第二步：联想——把词根意思和单词意思串起来**
   比如：spect = 看 → inspect = in（向内）+ spect（看）→ 向里面看 → 检查/视察
3. **第三步：语境——把单词放到句子里记**
   不要孤立背单词，要背一个句子，记住这个词怎么用

### ⑤ 例题演示：拆词记忆

**单词：** internationalization
**拆解：** inter-（相互/之间）+ nation（国家）+ -al（形容词后缀）+ -ize（动词后缀）+ -ation（名词后缀）
**意思：** 国际化（国家之间相互往来的过程）

**单词：** irresponsible
**拆解：** ir-（不，在r前面in-变成ir-）+ response（回应/责任）+ -ible（能...的）
**意思：** 不负责任的

### ⑥ ❌ 易错提醒
- **不要死记硬背字母**——要拆成词根词缀来记，一个词根串一串词
- **前缀的变形**：in- 在 p/b/m 前面变成 im-（impossible, imbalance）；在 r 前面变成 ir-（irregular）；在 l 前面变成 il-（illegal）
- **记单词要放到句子里**——光记中文意思没用，要知道怎么用
- **一词多义要一起记**——比如 run 有"跑/经营/运转"多个意思，都要记
- **高频词优先**——先背高考高频3500词，不要一上来就背超纲词
