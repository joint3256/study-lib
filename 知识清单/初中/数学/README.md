## 每章固定六要素（缺一不可）

1. 一、本章知识结构（树形，开头列节次）
2. 二、核心概念（通俗→严谨）
3. 三、定理、公式与结论（LaTeX，符号逐一解释、标注条件）
4. 四、公式推导要点与常用模型（数形结合、方程、函数、分类讨论等）
5. 五、考点与典型题型·方法（题型→步骤→含解答的简短范例）
6. 六、易错易混（❌/✅ 成对）

## 检索提示（给家教）

- **学生卡在某题**：先按册定位章节 → 翻"五、考点与典型题型·方法"找对应题型 → 用"六、易错易混"核对常见错误。
- **查缺补漏**：从"一、本章知识结构"树形图快速判断学生缺哪一环。
- **概念不清**：用"二、核心概念"里的通俗版先讲，再上严谨定义。
- **公式记不住**：看"三、定理、公式与结论"（符号有定义、有条件）与"四、公式推导要点"（知道从哪来）。
