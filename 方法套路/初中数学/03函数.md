## 方法13：待定系数法求函数解析式

### 适用题型
- 已知函数图象经过某些点，求函数解析式。
- 题目特征："已知一次函数过点(...)和(...)，求解析式"——一次函数、反比例函数、二次函数都能用。

### 原理/公式
- **待定系数法**：先设出函数的一般形式（里面有未知系数），再把已知点的坐标代进去，列方程（组）解出系数。
- 各函数的标准形式：
  - 一次函数：$y = kx + b$（两个未知数 $k, b$，需要两个点）
  - 反比例函数：$y = \dfrac{k}{x}$（一个未知数 $k$，只需要一个点）
  - 二次函数一般式：$y = ax^2 + bx + c$（三个未知数，需要三个点）

### 操作步骤
1. **设**：根据函数类型，设出标准形式。
2. **代**：把已知点的坐标 $(x, y)$ 分别代入，得到方程（组）。
3. **解**：解方程（组），求出未知系数。
4. **写**：把系数代回所设的式子，写出最终解析式。

### 例题演示
**题干**：已知一个一次函数的图象经过点 $(1, 3)$ 和点 $(2, 5)$，求这个一次函数的解析式。

**分步解答**：
1. **设**：设一次函数解析式为 $y = kx + b$。
2. **代入两个点**：
   - 代入 $(1, 3)$：$3 = k \times 1 + b$ → $k + b = 3$
   - 代入 $(2, 5)$：$5 = k \times 2 + b$ → $2k + b = 5$
3. **解方程组**：
   $$\begin{cases} k + b = 3 \\ 2k + b = 5 \end{cases}$$
   两式相减：$k = 2$，代回 $2 + b = 3$ → $b = 1$。
4. **写解析式**：$y = 2x + 1$。
   检验：$x=1$ 时 $y=3$ ✓，$x=2$ 时 $y=5$ ✓。

**最终答案**：$\boldsymbol{y = 2x + 1}$

### ❌ 易错提醒
- **设错形式**：反比例函数是 $y = \dfrac{k}{x}$，不是 $y = kx$。
- **点坐标代反**：横坐标代 $x$，纵坐标代 $y$，别搞反。
- **二次函数选不对形式**：已知顶点用顶点式 $y=a(x-h)^2+k$ 更简单，已知三个普通点才用一般式。

## 方法14：一次函数图象「k定方向，b定截距」法

### 适用题型
- 判断一次函数图象经过哪些象限、增减性、与坐标轴交点。
- 题目特征：给一个 $y=kx+b$，问图象不经过哪个象限，或者 $k, b$ 的正负。

### 原理/公式
- $y = kx + b$ 中：
  - **$k$ 是斜率**：决定直线从左下到右上（$k>0$，$y$ 随 $x$ 增大而增大），还是从左上到右下（$k<0$，$y$ 随 $x$ 增大而减小）。
  - **$b$ 是截距**：直线与 $y$ 轴的交点纵坐标。$b>0$ 交 $y$ 轴正半轴，$b<0$ 交负半轴，$b=0$ 过原点。
- 快速判断过象限：
  | $k$ 符号 | $b$ 符号 | 经过象限 |
  |---|---|---|
  | $k>0$ | $b>0$ | 一、二、三 |
  | $k>0$ | $b<0$ | 一、三、四 |
  | $k<0$ | $b>0$ | 一、二、四 |
  | $k<0$ | $b<0$ | 二、三、四 |

### 操作步骤
1. 从解析式中找出 $k$ 和 $b$ 的正负。
2. $k>0$ → 从左下往右上斜；$k<0$ → 从左上往右下斜。
3. $b>0$ → 和 $y$ 轴交于正半轴；$b<0$ → 交于负半轴。
4. 两条合起来，画个草图，看经过哪几个象限。

### 例题演示
**题干**：一次函数 $y = -2x + 3$ 的图象不经过哪个象限？

**分步解答**：
1. 找 $k, b$：$k = -2 < 0$，$b = 3 > 0$。
2. $k<0$ → 直线从左上往右下斜（递减）。
3. $b>0$ → 与 $y$ 轴交于正半轴 $(0, 3)$。
4. 画草图：交 $y$ 轴正半轴，向右下方走，必然经过第一、二、四象限。
5. 所以不经过**第三象限**。

**最终答案**：不经过 $\boldsymbol{第三}$ 象限。

### ❌ 易错提醒
- **$k$ 和 $b$ 的作用搞混**：$k$ 管方向（增减），$b$ 管和 $y$ 轴的交点位置，别搞反。
- **增减性说反**：$k>0$ 是 $y$ 随 $x$ 增大而增大，不是减小。
- **和 $x$ 轴交点算错**：令 $y=0$ 求 $x$，不是令 $x=0$。

## 方法15：反比例函数「k的几何意义」法

### 适用题型
- 反比例函数 $y = \dfrac{k}{x}$ 中，过图象上一点作坐标轴的垂线，求矩形或三角形面积。
- 题目特征："点 $A$ 在反比例函数图象上，过 $A$ 作 $AB \perp x$ 轴，求 $\triangle AOB$ 的面积"。

### 原理/公式
- 反比例函数 $y = \dfrac{k}{x}$ 中，$k = xy$（横纵坐标相乘）。
- **几何意义**：过图象上任意一点 $P(x, y)$，作 $x$ 轴、$y$ 轴的垂线，两条垂线与坐标轴围成的**矩形面积等于 $|k|$**。
- 由此推出：
  - 矩形面积 $S_{\text{矩形}} = |x| \cdot |y| = |xy| = |k|$
  - 连接原点和 $P$，分成的直角三角形面积 $S_{\triangle} = \dfrac{1}{2}|k|$
- $k$ 的符号：$k>0$ 图象在一、三象限；$k<0$ 在二、四象限。

### 操作步骤
1. 找到题目里给的点（或交点）在反比例函数图象上。
2. 确认是求矩形面积还是三角形面积。
3. 矩形面积直接等于 $|k|$；三角形面积等于 $\dfrac{1}{2}|k|$。
4. 如果题目给了面积反求 $k$，注意 $k$ 的正负由图象所在象限决定。

### 例题演示
**题干**：如图，点 $A$ 在反比例函数 $y = \dfrac{k}{x}$ 的图象上，过 $A$ 作 $AB \perp x$ 轴于点 $B$，若 $\triangle AOB$ 的面积为 3（$O$ 是原点），且图象在第二象限，求 $k$ 的值。

**分步解答**：
1. 识别图形：直角三角形 $AOB$，直角边是 $AB$（竖直）和 $OB$（水平）。
2. 套结论：三角形面积 $S = \dfrac{1}{2}|k|$。
3. 代入已知面积：$3 = \dfrac{1}{2}|k|$ → $|k| = 6$。
4. 定符号：图象在第二象限 → $k < 0$。
5. 所以 $k = -6$。

**最终答案**：$\boldsymbol{k = -6}$

### ❌ 易错提醒
- **面积是 $|k|$ 还是 $\dfrac{1}{2}|k|$**：矩形是 $|k|$，三角形是它的一半，别乘错。
- **忘记加绝对值**：面积一定是正数，但 $k$ 可能是负的，所以要带绝对值再定符号。
- **图象在哪个象限没看清**：第二象限的反比例函数 $k<0$，别写成正数。

## 方法16：二次函数顶点式求最值法

### 适用题型
- 求二次函数的最大值或最小值，以及对应的 $x$ 值。
- 题目特征："求二次函数的顶点坐标/最大值/最小值/对称轴"，以及实际问题（利润最大、面积最大等）。

### 原理/公式
- 二次函数的**顶点式**：
  $$y = a(x - h)^2 + k$$
  - 顶点坐标：$(h, k)$
  - 对称轴：直线 $x = h$
  - 若 $a > 0$，开口向上，顶点是**最低点**，函数有最小值 $k$。
  - 若 $a < 0$，开口向下，顶点是**最高点**，函数有最大值 $k$。
- 从一般式 $y = ax^2 + bx + c$ 化顶点式：**配方法**。
  $$h = -\frac{b}{2a}, \quad k = \frac{4ac - b^2}{4a}$$

### 操作步骤
1. 看题目给的是一般式还是顶点式。
2. 给一般式就用配方法（或对称轴公式）化成顶点式。
3. 确定开口方向：$a>0$ 有最小值，$a<0$ 有最大值。
4. 顶点纵坐标就是最值，横坐标就是取最值时的 $x$。
5. 实际问题要注意 $x$ 的取值范围（不能是负数、人数不能是小数）。

### 例题演示
**题干**：求二次函数 $y = x^2 - 4x + 3$ 的最小值，并写出此时 $x$ 的值。

**分步解答**：
1. 用配方法化顶点式：
   $$y = x^2 - 4x + 3 = (x^2 - 4x + 4) - 4 + 3 = (x - 2)^2 - 1$$
2. 找顶点：$(h, k) = (2, -1)$。
3. 看开口：$a = 1 > 0$，开口向上，有最小值。
4. 最小值就是顶点纵坐标 $k = -1$，此时 $x = 2$。

**最终答案**：当 $\boldsymbol{x=2}$ 时，函数有最小值 $\boldsymbol{-1}$。

### ❌ 易错提醒
- **配方时常数项算错**：加上4之后，要记得再减4，别只加不减。
- **最大值最小值搞反**：$a>0$ 开口向上，顶点是最低点 → 有最小值；$a<0$ 开口向下 → 有最大值。
- **实际问题不看取值范围**：比如卖东西，单价和数量都不能是负数，即使顶点在范围内也要检查是否合理。

## 方法17：二次函数与方程不等式「图象交点」法

### 适用题型
- 二次函数图象与 $x$ 轴的交点个数、一元二次方程的根的情况、根据图象写不等式解集。
- 题目特征：给抛物线图象，问"当 $x$ 取何值时 $y>0$"或"方程 $ax^2+bx+c=0$ 有几个根"。

### 原理/公式
- **二次函数与一元二次方程的关系**：
  - 抛物线 $y = ax^2 + bx + c$ 与 $x$ 轴的交点，就是方程 $ax^2 + bx + c = 0$ 的根。
  - 两个交点 → 方程有两个不相等的实根（$\Delta > 0$）。
  - 一个交点（顶点在 $x$ 轴上）→ 方程有两个相等的实根（$\Delta = 0$）。
  - 没有交点 → 方程没有实根（$\Delta < 0$）。
- **不等式解集看图象高低**：
  - $y > 0$ 的解集：图象在 $x$ 轴**上方**的部分对应的 $x$ 范围。
  - $y < 0$ 的解集：图象在 $x$ 轴**下方**的部分对应的 $x$ 范围。

### 操作步骤
1. 先找抛物线与 $x$ 轴的两个交点（即方程的两个根 $x_1, x_2$）。
2. 看开口方向：$a>0$ 开口向上，$a<0$ 开口向下。
3. 求 $y>0$（或 $y<0$）的解集：
   - 开口向上：两边 $y>0$（两根之外），中间 $y<0$（两根之间）。
   - 开口向下：中间 $y>0$（两根之间），两边 $y<0$（两根之外）。
4. 端点：交点处 $y=0$，$>0$ 或 $<0$ 不包含端点。

### 例题演示
**题干**：已知二次函数 $y = x^2 - 2x - 3$，根据图象回答：当 $x$ 取何值时，$y > 0$？

**分步解答**：
1. 求与 $x$ 轴交点（即解方程 $x^2 - 2x - 3 = 0$）：
   因式分解 $(x-3)(x+1) = 0$ → $x_1 = -1, \, x_2 = 3$。
2. 看开口：$a = 1 > 0$，开口向上。
3. 开口向上的抛物线：中间低、两边高，所以 $y>0$ 的部分在两根之外。
4. 解集：$x < -1$ 或 $x > 3$。

**最终答案**：当 $\boldsymbol{x < -1}$ 或 $\boldsymbol{x > 3}$ 时，$\boldsymbol{y > 0}$。

### ❌ 易错提醒
- **开口方向和解集方向搞反**：开口向上是"两边大于零，中间小于零"；开口向下反过来。
- **端点包不包含**：$y>0$ 不包含交点（交点处 $y=0$），所以用 $<$ 和 $>$，不用 $\le$。
- **两个根大小排错**：写解集时小根在前大根在后，别写反。
