# 被动语态：主动变被动两步法

---

## 方法：被动语态"宾语提前法"

### ① 方法名
被动语态两步转换法

### ② 适用题型
单项选择、完形填空、语法填空、短文改错

### ③ 原理（语法 form 与意义 use）

**语法形式（form）层面：**
被动语态基本结构：**be + 过去分词（done）**
- 被动的时态全部体现在 be 动词上，过去分词永远不变
- 各时态被动形式：
  - 一般现在时：am/is/are + done
  - 一般过去时：was/were + done
  - 一般将来时：will be + done
  - 现在完成时：have/has been + done
  - 情态动词：情态动词 + be + done

**意义（use）层面：**
- 主动句：主语是动作的发出者（We clean the room.）
- 被动句：主语是动作的承受者（The room is cleaned.）
- 什么时候用被动：①不知道谁做的 ②没必要说谁做的 ③强调动作承受者

**为什么考试爱考：** 中文里"被"字句用得很少，我们习惯说"作业写完了"而不说"作业被写完了"。但英语里只要主语是动作的承受者，就必须用被动语态。

### ④ 操作步骤

1. **第一步：判断主语和动词的关系**——主语是发出动作还是承受动作？
2. **主语承受动作 → 必须用被动语态（be + done）**
3. **第二步：根据时间标志词确定 be 动词的时态**
4. **第三步：检查主谓一致**——主语单数用 is/was，复数用 are/were
5. **第四步：如果需要加 by... 说明动作发出者，放在句末**

### ⑤ 例题完整演示

**题干：**
The bridge ______ two years ago. Now we can cross the river easily.
A. builds  B. built  C. was built  D. is built

**分析过程：**
- 第一步：主语 the bridge（桥）和动词 build（建造）的关系 → 桥是"被建造"的 → 被动语态
- 第二步：时间标志词 two years ago（两年前）→ 一般过去时
- 第三步：一般过去时被动 = was/were + done；主语 the bridge 单数 → was built
- 验证：桥是被建的，两年前建的 → was built，完全符合

**答案：C**

**规则套用过程：**
桥是被建的 → 被动 → be + done；two years ago → 过去时 → was + done；单数主语 → was built → 选 C

### ⑥ ❌ 易错提醒

- **不及物动词没有被动语态**：happen, take place, appear, disappear, die, arrive 这些词后面不能直接加宾语，所以没有被动。不能说 The accident was happened.
- **主动形式表被动意义**：感官动词+形容词：The book sells well.（书卖得好，不用 is sold）；The cloth feels soft.
- **be made of vs be made from**：of = 能看出原材料（桌子是木头做的）；from = 看不出原材料（纸是木头做的）
- **被动语态别忘了 be 动词**：很多学生只写过去分词，漏掉 be：The window **was broken** by Tom.（不是 The window broken by Tom.）
