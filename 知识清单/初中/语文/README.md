> 版本依据：《义务教育语文课程标准（2022 年版）》+ 统编（人教）版语文教材。
> 每册按"五个知识板块"组织（基础知识、古诗文阅读、现代文阅读、名著导读·综合性学习与口语交际、写作），每个板块下含六个固定小节（知识结构、核心知识、规律方法答题模板、常用模型识别特征、考点典型例题、易错易混）。
> 面向对象：基础薄弱初中生 + 线上家教，可直接照念、快速定位。

## 每册五大板块（固定结构）

每册文件均按以下五个 `##` 板块组织，每个板块下含六个固定 `###` 小节：

1. **板块一　基础知识**（字音字形·词语·病句·标点·文学文化常识）
2. **板块二　古诗文阅读**（文言文·古诗词曲·理解性默写；含本册必背篇目清单）
3. **板块三　现代文阅读**（按年级文体侧重：七上/七下记叙文、散文；八上事物说明文；八下事理说明文、游记；九上议论文；九下小说、戏剧）
4. **板块四　名著导读·综合性学习与口语交际**
5. **板块五　写作**（审题立意·选材结构·语言·范文框架）

每个板块下六个固定小节：
- 一、本板块知识结构（考点地图；板块二须列本册必背篇目清单）
- 二、核心知识（通俗→严谨，落到本册具体字词、文言词句、课文主旨写法）
- 三、规律·方法·答题模板（讲清为什么从这些角度答）
- 四、常用模型与识别特征（审题信号词 → 考点/模板）
- 五、考点与典型例题·示范（给分点规范作答；作文给提纲与片段）
- 六、易错易混（❌/✅ 成对）

## 检索提示

- **按知识点查**：先定位到册（如七上古诗文问题），再进"板块二"，用 `Ctrl+F` 搜篇名（如"诫子书""狼""木兰诗"）。
- **按题型查**：
  - 字音字形、成语、病句、文学常识 → 板块一。
  - 文言实词、翻译、诗词鉴赏、理解性默写 → 板块二。
  - 概括内容、赏析句子、人物形象、标题段落作用 → 板块三。
  - 名著人物情节、活动设计、劝说 → 板块四。
  - 作文审题、提纲、片段 → 板块五。
- **按易错查**：直接搜"易错易混"或搜 ❌ 标记。
- **必背篇目**：直接打开该册"板块二"第一节，有完整表格（篇名｜作者｜朝代｜体裁｜默写高频句）。
