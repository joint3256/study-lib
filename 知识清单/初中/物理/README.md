## 每章固定六要素（缺一不可）

每个 `## 第N章 章名` 下依次包含：

1. **一、本章知识结构**（树形图，开头列节次）
2. **二、核心概念（通俗→严谨）**（物理量写符号/单位/标矢量）
3. **三、定理、公式与结论**（LaTeX，符号解释、单位、适用条件）
4. **四、公式推导要点与常用模型**（控制变量法、受力分析、电路分析等）
5. **五、考点与典型题型·方法**（题型→步骤→范例）
6. **六、易错易混**（❌/✅ 成对）

## 检索提示

- **讲题前先定位章**：看到题目关键词，先到对应册对应章。
  - 力学计算 → 八上"机械运动"；八下"力""运动和力""压强""浮力""功和机械能""简单机械"。
  - 光学 → 八上"光现象""透镜及其应用"。
  - 热学 → 八上"物态变化"；九年级"内能""内能的利用"。
  - 电学 → 九年级"电流和电路""电压 电阻""欧姆定律""电功率""电与磁"。
- **薄弱学生先看二、六**：先"通俗"理解概念，再看"易错易混"避坑。
- **计算题看三、四**：先确认公式、单位、适用条件，再套模型。
- **常数速查**：
  - $g\approx 9.8\,\text{N/kg}$（粗略取 $10\,\text{N/kg}$）
  - 真空中光速 / 电磁波速 $c=3\times10^8\,\text{m/s}$
  - $15\,\text{℃}$ 空气中声速约 $340\,\text{m/s}$
  - 水的密度 $\rho_{\text{水}}=1.0\times10^3\,\text{kg/m}^3$
  - 水的比热容 $c_{\text{水}}=4.2\times10^3\,\text{J}/(\text{kg}\cdot\text{℃})$
  - 标准大气压 $p_0\approx 1.013\times10^5\,\text{Pa}\approx 760\,\text{mmHg}$
  - 家庭电路电压 $220\,\text{V}$；对人体安全电压不高于 $36\,\text{V}$；一节干电池 $1.5\,\text{V}$
