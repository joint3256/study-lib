# 高中化学 · 元素化合物（金属与非金属）

---

## 方法 H4　钠、镁、铝及其化合物（铝三角 / 过氧化钠）

### ① 方法名
**"铝三角"转化 + 两性判断法**

### ② 适用题型 / 物质
Na、Na₂O₂、Na₂CO₃/NaHCO₃ 转化；Al、Al₂O₃、Al(OH)₃ 两性；铝盐与偏铝酸盐互化及相关计算。

### ③ 原理（为什么）
- 铝及其化合物（Al、Al₂O₃、Al(OH)₃）是**两性**物质：既能与强酸反应，又能与强碱反应。
- 铝三角：Al³⁺ ⇌ Al(OH)₃ ⇌ AlO₂⁻（偏铝酸根）。
- Na₂O₂（淡黄色）与水、CO₂ 反应都放出 O₂，是强氧化剂，**不是碱性氧化物**。

### ④ 操作步骤
1. 抓住"铝三角"三个转化方向。
2. 遇到 Al(OH)₃ 沉淀溶解问题，先判断酸碱过量情况。
3. Na₂O₂ 反应注意放 O₂ 和电子转移。

### ⑤ 例题完整演示
(1) 5.4 g 铝与足量盐酸反应，生成氢气多少克？
$$\mathrm{2Al + 6HCl = 2AlCl_3 + 3H_2\uparrow}$$
| 物质 | 相对质量×系数 | 实际质量 |
|---|---|---|
| 2Al | 2×27 = 54 | 5.4 g |
| 3H₂ | 6 | x |
54/6 = 5.4/x → **x = 0.6 g**（已验算）

(2) 过氧化钠与水：2Na₂O₂ + 2H₂O = 4NaOH + O₂↑

(3) 制备 Al(OH)₃：用铝盐加**氨水**（Al³⁺ + 3NH₃·H₂O = Al(OH)₃↓ + 3NH₄⁺），不能加过量 NaOH（强碱会把 Al(OH)₃ 溶成 AlO₂⁻）。

### ⑥ ❌ 易错提醒
- Al(OH)₃ 只溶于**强酸、强碱**，不溶于弱碱（氨水）、弱酸。
- Na 保存在煤油中；Na₂O₂ 是淡黄色（不是白色），与水反应既放 O₂ 又放热。
- Na₂CO₃ 与 NaHCO₃ 鉴别：加热能分解放出 CO₂ 的是 NaHCO₃。
- Al³⁺ 与 AlO₂⁻ 双水解：Al³⁺ + 3AlO₂⁻ + 6H₂O = 4Al(OH)₃↓。

## 方法 H5　铁、铜及金属材料（铁三角）

### ① 方法名
**"铁三角"价态转化 + Fe²⁺/Fe³⁺ 检验法**

### ② 适用题型 / 物质
Fe、Fe²⁺、Fe³⁺ 相互转化；Fe²⁺/Fe³⁺ 检验；除杂；铜及其化合物、合金判断。

### ③ 原理（为什么）
- 铁三角：Fe ⇌ Fe²⁺ ⇌ Fe³⁺。Fe 遇弱氧化剂（H⁺、Cu²⁺、S）生成 Fe²⁺；遇强氧化剂（Cl₂、稀硝酸、浓硫酸）生成 Fe³⁺。
- Fe³⁺ 遇 KSCN 溶液显**血红色**（特征检验）；Fe²⁺ 检验：先加 KSCN 无现象，再加氯水后变血红。
- Fe³⁺ 易水解，配制其盐溶液要加对应酸抑制水解。

### ④ 操作步骤
1. 由目标转化方向判断需要加氧化剂还是还原剂。
2. 除杂原则：把杂质转成目标物，不引入新杂质。

### ⑤ 例题完整演示
(1) 除去 FeCl₃ 溶液中少量 FeCl₂（通适量 Cl₂）：
$$\mathrm{2FeCl_2 + Cl_2 = 2FeCl_3}$$　离子：2Fe²⁺ + Cl₂ = 2Fe³⁺ + 2Cl⁻

(2) 除去 FeCl₂ 溶液中少量 FeCl₃（加过量铁粉，过滤）：
$$\mathrm{2FeCl_3 + Fe = 3FeCl_2}$$　离子：2Fe³⁺ + Fe = 3Fe²⁺

(3) Fe(OH)₂ 白色沉淀在空气中迅速变灰绿、最终变红褐 Fe(OH)₃：
4Fe(OH)₂ + O₂ + 2H₂O = 4Fe(OH)₃

### ⑥ ❌ 易错提醒
- Fe³⁺ 溶液黄色、Fe²⁺ 溶液浅绿色，别凭颜色下结论，要用 KSCN。
- 配制 FeCl₃ 溶液要先溶于浓盐酸再加水稀释（防水解）。
- 铜绿是 Cu₂(OH)₂CO₃；CuO 黑色、无水 CuSO₄ 白色（遇水变蓝）。
- 合金是混合物，熔点一般低于成分金属、硬度高于成分金属。

## 方法 H6　氯、硫、氮及其化合物

### ① 方法名
**"酸的中心原子氧化性"判断 + 还原产物记价法**

### ② 适用题型 / 物质
Cl₂ 及漂白、浓硫酸三大特性、硝酸强氧化性、氨气与铵盐、环境保护（SO₂/NOx）。

### ③ 原理（为什么）
- Cl₂ 本身无漂白性，起漂白作用的是与水反应生成的 **HClO**（强氧化性、不可逆漂白）。
- 浓硫酸：吸水性、脱水性、（加热时）强氧化性；还原产物一般是 SO₂。
- 硝酸不论浓稀都具强氧化性：**浓硝酸还原产物为 NO₂，稀硝酸还原产物为 NO**。
- 氨气是碱性气体，铵盐受热易分解、与碱共热放出 NH₃。

### ④ 操作步骤
1. 判断酸的氧化性来自 H⁺（稀盐酸/稀硫酸的氢前金属置换）还是酸根中心原子（浓硫酸、硝酸）。
2. 由浓稀定还原产物：浓硝酸→NO₂，稀硝酸→NO，浓硫酸加热→SO₂。

### ⑤ 例题完整演示
(1) 铜与浓硫酸加热：Cu + 2H₂SO₄(浓) =Δ= CuSO₄ + SO₂↑ + 2H₂O
(2) 铜与浓硝酸：Cu + 4HNO₃(浓) = Cu(NO₃)₂ + 2NO₂↑ + 2H₂O
(3) 实验室制氨气：2NH₄Cl + Ca(OH)₂ =Δ= CaCl₂ + 2NH₃↑ + 2H₂O

### ⑥ ❌ 易错提醒
- 漂白原理不同：氯水/HClO 是氧化漂白（不可逆），SO₂ 是化合漂白（可逆，加热复原）。
- 浓硫酸不能干燥 NH₃（碱性气体）和 H₂S（还原性气体）。
- NO 遇空气立即变红棕色 NO₂；收集 NO 只能用排水法，NO₂ 用向上排空气法。
- 铵态氮肥不能与草木灰（碱性）混用，否则放出 NH₃ 降低肥效。
- 常温下浓硫酸、浓硝酸使铁、铝"钝化"（可用铁/铝容器盛装）。
