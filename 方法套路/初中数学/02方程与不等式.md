## 方法6：列方程解应用题「设→列→解→验→答」五步法

### 适用题型
- 所有需要列方程解应用题的题目（中考解答题第一题必考）。
- 题目特征：文字叙述较长，有"比……多/少""是……的几倍""一共……"等关系词。

### 原理/公式
- 方程的本质：**用两种不同方式表示同一个量**，中间画等号。
- 五步法口诀：**设未知数 → 找等量关系列方程 → 解方程 → 检验 → 写答案**。

### 操作步骤
1. **设**：问什么设什么（直接设），不好设就间接设。写清楚单位。
2. **列**：把题目里的关键句翻译成数学式子，找到"谁等于谁"。
3. **解**：按去分母、去括号、移项、合并同类项、系数化为1的顺序解。
4. **验**：代回原题看合不合理（人数不能是小数，时间不能是负数）。
5. **答**：完整写答句，带单位。

### 例题演示
**题干**：某班共有学生45人，男生比女生多3人，求男女生各多少人。

**分步解答**：
1. **设**：设女生有 $x$ 人，则男生有 $(x+3)$ 人。
2. **列**：男生人数 + 女生人数 = 全班人数
   $$x + (x+3) = 45$$
3. **解**：
   $$2x + 3 = 45$$
   $$2x = 42$$
   $$x = 21$$
   男生：$21+3=24$（人）
4. **验**：$21+24=45$ ✓，$24-21=3$ ✓。
5. **答**：女生21人，男生24人。

**最终答案**：女生 $\boldsymbol{21}$ 人，男生 $\boldsymbol{24}$ 人。

### ❌ 易错提醒
- **设未知数不带单位**："设女生为 $x$ 人"才对，不能只写"设 $x$ 是女生"。
- **列方程时两边单位不统一**：题目给了小时和分钟，要统一成一个单位。
- **忘记检验**：尤其是实际问题，解出来是负数或小数要检查是不是列错了。

## 方法7：行程问题「线段图 + 三量关系」法

### 适用题型
- 相遇问题、追及问题、航行问题（顺水逆水）。
- 题目特征：两人/两车相向而行或同向而行，问相遇时间或路程。

### 原理/公式
- 基本三量：$\text{路程} = \text{速度} \times \text{时间}$，即 $s = vt$。
- **相遇问题**：两人相向而行，相遇时两人路程之和 = 总路程。
  $$v_1 t + v_2 t = s_{\text{总}}$$
- **追及问题**：同向而行，快的追上慢的时，快者路程 - 慢者路程 = 距离差。
  $$v_{\text{快}} t - v_{\text{慢}} t = s_{\text{差}}$$
- **顺水逆水**：$v_{\text{顺}} = v_{\text{船}} + v_{\text{水}}$，$v_{\text{逆}} = v_{\text{船}} - v_{\text{水}}$。

### 操作步骤
1. **画线段图**：在图上标出起点、方向、两人位置。
2. **判断类型**：是相遇（相向）还是追及（同向）。
3. **设时间为 $t$**（通常设时间为未知数最方便）。
4. **根据"路程和/路程差"列方程**。
5. **解方程并检验**。

### 例题演示
**题干**：甲乙两地相距300千米，一辆快车从甲地开出，速度60千米/时；一辆慢车从乙地开出，速度40千米/时。两车同时出发，相向而行，几小时后相遇？

**分步解答**：
1. **画线段图**：甲——快车→　←慢车——乙，两地相距300千米。
2. **类型**：相遇问题。
3. **设**：设 $t$ 小时后相遇。
4. **列方程**：快车路程 + 慢车路程 = 总路程
   $$60t + 40t = 300$$
5. **解**：
   $$100t = 300$$
   $$t = 3$$
   检验：快车走 $60\times3=180$ 千米，慢车走 $40\times3=120$ 千米，$180+120=300$ ✓

**最终答案**：$\boldsymbol{3}$ 小时后相遇。

### ❌ 易错提醒
- **相遇和追及搞反**：相遇是"路程和=总路程"，追及是"路程差=距离差"，别混。
- **顺水逆水速度套反**：顺水快、逆水慢，$v_{\text{顺}} = v_{\text{船}} + v_{\text{水}}$，别加反了。
- **两车不是同时出发**：有先后出发时，先出发的多走了一段，要在总路程里扣掉或加上。

## 方法8：工程问题「设总工作量为1」法

### 适用题型
- 修路、放水、做零件等工程类应用题。
- 题目特征："甲单独做几天完成，乙单独做几天完成，两人合作几天完成"。

### 原理/公式
- 把**总工作量看作单位1**。
- 工作效率 = $1 \div$ 单独完成时间。
  $$\text{甲效率} = \frac{1}{a}, \quad \text{乙效率} = \frac{1}{b}$$
- 合作效率 = 各人效率之和。
- 基本关系：$\text{效率} \times \text{时间} = \text{工作量}$。

### 操作步骤
1. **设总工作量为1**。
2. **算每个人的效率**：$1 \div$ 单独完成天数。
3. **设合作时间为 $t$**（或设某个人做了几天）。
4. **列方程**：各人完成的工作量相加 = 总工作量1。
5. **解方程**。

### 例题演示
**题干**：一项工程，甲单独做10天完成，乙单独做15天完成。两人合作几天完成？

**分步解答**：
1. **设总工作量为1**。
2. **算效率**：
   - 甲效率：$\dfrac{1}{10}$
   - 乙效率：$\dfrac{1}{15}$
3. **设**：设两人合作 $x$ 天完成。
4. **列方程**：甲做的 + 乙做的 = 总工程
   $$\frac{x}{10} + \frac{x}{15} = 1$$
5. **解**：两边同乘30（最小公倍数）
   $$3x + 2x = 30$$
   $$5x = 30$$
   $$x = 6$$

**最终答案**：两人合作 $\boldsymbol{6}$ 天完成。

### ❌ 易错提醒
- **把"天"和"效率"搞混**：甲每天做 $\dfrac{1}{10}$，不是每天做10。
- **中途有人离开**：分段算——前一段甲乙一起做，后一段只剩甲，要分开列。
- **答案是分数时要写清楚**：比如 $4\dfrac{1}{2}$ 天，不要写成4.5就完事，结合题目看要不要取整。

## 方法9：配套问题「比例关系列等式」法

### 适用题型
- 生产配套问题（一个盒身配两个盒底，一张桌子配四条腿等）。
- 题目特征：车间有工人，每人每天能做A零件或B零件，问怎么安排人数才能配套。

### 原理/公式
- 核心关系：**按配套比例，使两种零件的数量刚好匹配**。
- 比如"1个盒身配2个盒底"，则：
  $$2 \times \text{盒身数量} = \text{盒底数量}$$
  （盒底的总数是盒身的2倍，才刚好配套）

### 操作步骤
1. **设**：设安排 $x$ 人做A零件，剩下的人做B零件。
2. **算数量**：人数 × 每人每天产量 = 每天生产的零件数。
3. **找配套比例**：看题目说"几个A配几个B"。
4. **列等式**：把比例关系翻译成方程。
5. **解方程，写答案**。

### 例题演示
**题干**：某车间有22名工人，每人每天可以生产1200个盒身或2000个盒底。一个盒身需要配两个盒底，为了使每天生产的盒身和盒底刚好配套，应安排多少人生产盒身，多少人生产盒底？

**分步解答**：
1. **设**：设安排 $x$ 人生产盒身，则 $(22-x)$ 人生产盒底。
2. **算每天产量**：
   - 盒身：$1200x$ 个
   - 盒底：$2000(22-x)$ 个
3. **配套关系**：1个盒身配2个盒底 → 盒底总数 = 2 × 盒身总数
4. **列方程**：
   $$2000(22-x) = 2 \times 1200x$$
5. **解**：
   $$44000 - 2000x = 2400x$$
   $$44000 = 4400x$$
   $$x = 10$$
   生产盒底人数：$22-10=12$（人）
   检验：盒身 $1200\times10=12000$，盒底 $2000\times12=24000$，$24000 = 2\times12000$ ✓

**最终答案**：安排 $\boldsymbol{10}$ 人生产盒身，$\boldsymbol{12}$ 人生产盒底。

### ❌ 易错提醒
- **比例写反**："1个盒身配2个盒底"是盒底 = 2 × 盒身，不是盒身 = 2 × 盒底。
- **人数算错**：总人数减出来的人别漏乘每人产量。
- **配套关系看反**：题目说"1桌4椅"，就是椅子 = 4 × 桌子数量。

## 方法10：利润问题「三价两率」法

### 适用题型
- 打折销售、利润率、成本售价类应用题。
- 题目特征："进价多少，标价多少，打几折出售，利润率是多少"。

### 原理/公式
- **三价**：
  - 进价（成本）：$\text{成本价} = c$
  - 标价（原价）：$\text{标价} = m$
  - 实际售价：$\text{售价} = m \times \dfrac{\text{折扣}}{10}$（打8折就是乘0.8）
- **两率**：
  - 利润 = 售价 - 进价
  - 利润率 = $\dfrac{\text{利润}}{\text{进价}} \times 100\%$
- 核心等式：$\text{售价} = \text{进价} \times (1 + \text{利润率})$

### 操作步骤
1. **找出题目里的三个价**：成本、标价、实际售价分别是多少（哪个已知哪个未知）。
2. **确定折扣**：打几折就是原价 × 零点几。
3. **套公式**：利润 = 售价 - 成本；利润率 = 利润 ÷ 成本。
4. **列方程**：求什么就设什么，用上面的等式列。
5. **解方程**。

### 例题演示
**题干**：一件商品进价为200元，按标价打8折出售后，仍可获利40元，求这件商品的标价是多少元？

**分步解答**：
1. **已知**：成本 = 200元，打8折，利润 = 40元。
2. **设**：设标价为 $x$ 元。
3. **实际售价**：打8折 → $0.8x$ 元。
4. **列方程**：利润 = 售价 - 进价
   $$0.8x - 200 = 40$$
5. **解**：
   $$0.8x = 240$$
   $$x = 300$$
   检验：售价 $300\times0.8=240$，利润 $240-200=40$ ✓

**最终答案**：这件商品的标价是 $\boldsymbol{300}$ 元。

### ❌ 易错提醒
- **打折的基数搞错**：打几折是在**标价**基础上乘，不是在进价上乘。
- **利润率的分母是成本不是售价**：利润率 = 利润 ÷ 成本，不是 ÷ 售价。
- **"打几折"和"便宜了几折"搞混**：打8折 = 按原价的80%卖 = 便宜了20%。

## 方法11：二元一次方程组「消元」法

### 适用题型
- 解二元一次方程组，以及用方程组解应用题（含两个未知数的题）。
- 题目特征：有两个未知数，两个方程。

### 原理/公式
- 核心思想：**消元**——把两个未知数变成一个，化成一元一次方程来解。
- **代入消元法**：从一个方程里解出 $y = \text{含}x\text{的式子}$，代入另一个方程。
- **加减消元法**：把两个方程中某个未知数的系数化成相同（或相反），然后相减（或相加）消掉这个未知数。

### 操作步骤（代入消元）
1. 从系数简单的那个方程出发，把一个未知数用另一个表示出来。
2. 代入另一个方程，变成一元一次方程。
3. 解出第一个未知数。
4. 代回原来的式子，求出第二个未知数。
5. 写解：$\begin{cases} x = \dots \\ y = \dots \end{cases}$

### 例题演示
**题干**：解方程组 $\begin{cases} y = 2x - 3 \\ 3x + 2y = 8 \end{cases}$

**分步解答**：
1. **第一个方程已经解出 $y$**：$y = 2x - 3$。
2. **代入第二个方程**：
   $$3x + 2(2x - 3) = 8$$
3. **解一元一次方程**：
   $$3x + 4x - 6 = 8$$
   $$7x = 14$$
   $$x = 2$$
4. **求 $y$**：把 $x=2$ 代回 $y = 2x - 3$
   $$y = 2\times2 - 3 = 1$$
5. **写解**：$\begin{cases} x = 2 \\ y = 1 \end{cases}$
   检验：$3\times2 + 2\times1 = 6+2 = 8$ ✓

**最终答案**：$\boldsymbol{\begin{cases} x = 2 \\ y = 1 \end{cases}}$

### ❌ 易错提醒
- **代入时漏乘括号**：把 $y=2x-3$ 代入 $3x+2y=8$，要写成 $3x+2(2x-3)=8$，别写成 $3x+2\times2x-3=8$。
- **加减消元时符号错**：两式相减时，每一项都要变号，别只减第一项。
- **解完不写大括号**：二元一次方程组的解要用大括号括起来，两个未知数对应好。

## 方法12：一元一次不等式（组）解集「数轴定界」法

### 适用题型
- 解一元一次不等式组，并在数轴上表示解集。
- 题目特征：有两个不等式，求公共部分；或求整数解。

### 原理/公式
- 解不等式和解方程步骤几乎一样：去分母、去括号、移项、合并同类项、系数化为1。
- **唯一区别**：不等式两边同乘（或除以）同一个**负数**时，**不等号方向要改变**！
- 解集口诀：
  - 同大取大（$x>a, x>b$，$a>b$ → 解集 $x>a$）
  - 同小取小（$x<a, x<b$，$a<b$ → 解集 $x<b$）
  - 大小小大中间找（$x>a, x<b$，$a<b$ → 解集 $a<x<b$）
  - 大大小小找不到（$x>a, x<b$，$a>b$ → 无解）

### 操作步骤
1. **分别解每个不等式**，得到各自的解集。
2. **画数轴**，把两个解集都画出来。
3. **找公共部分**：重叠的区域就是不等式组的解集。
4. **求整数解**：在解集范围内数整数，注意端点要不要取到。

### 例题演示
**题干**：解不等式组 $\begin{cases} 2x - 1 > 3 \\ 3x + 2 \le 11 \end{cases}$，并写出整数解。

**分步解答**：
1. **解第一个不等式**：
   $$2x - 1 > 3$$
   $$2x > 4$$
   $$x > 2$$
2. **解第二个不等式**：
   $$3x + 2 \le 11$$
   $$3x \le 9$$
   $$x \le 3$$
3. **数轴找公共部分**：$x>2$ 且 $x\le3$ → 公共部分是 $2 < x \le 3$。
4. **找整数解**：在 $2<x\le3$ 范围内的整数只有 $x=3$。

**最终答案**：不等式组的解集是 $\boldsymbol{2 < x \le 3}$，整数解为 $\boldsymbol{x=3}$。

### ❌ 易错提醒
- **系数化为1时忘记变号**：两边除以负数，不等号方向必须反过来！比如 $-2x > 4$ → $x < -2$，不是 $x > -2$。
- **端点空心实心搞反**：$>$ 或 $<$ 用空心圈（不包含），$\ge$ 或 $\le$ 用实心点（包含）。
- **求整数解时漏数或多数**：解集是 $2<x\le3$，整数解只有3，2不算（因为是严格大于）。

## 方法35：一元二次方程根的判别式与韦达定理「先判根，再用和积」法

### 适用题型
- 已知一元二次方程 $ax^2+bx+c=0$（$a\ne0$），判断根的个数、求待定系数范围；不解方程求两根之和、两根之积，或求含两根的代数式的值。
- 题目特征：出现"有两个不相等/相等的实数根""无实数根""$x_1+x_2$""$x_1x_2$""两根互为相反数/倒数"。

### 原理/公式
- **根的判别式**：$\Delta = b^2 - 4ac$（$a$、$b$、$c$ 须是一般式里带符号的系数）。
  - $\Delta > 0$ → 两个不相等的实数根。
  - $\Delta = 0$ → 两个相等的实数根。
  - $\Delta < 0$ → 没有实数根。
- **韦达定理（根与系数的关系）**：当方程确有实根（$\Delta\ge0$）时，
  $$x_1+x_2 = -\frac{b}{a}, \qquad x_1 x_2 = \frac{c}{a}$$
- 常见代数式用和与积凑：$x_1^2+x_2^2=(x_1+x_2)^2-2x_1x_2$；$\dfrac{1}{x_1}+\dfrac{1}{x_2}=\dfrac{x_1+x_2}{x_1x_2}$。

### 操作步骤
1. **化一般式**：把方程整理成 $ax^2+bx+c=0$，带符号读出 $a$、$b$、$c$。
2. **先算 $\Delta=b^2-4ac$**：求待定系数范围时，按"两不等→$\Delta>0$、两相等→$\Delta=0$、无实根→$\Delta<0$"列不等式求解。
3. **再用韦达**：求 $x_1+x_2$、$x_1x_2$ 直接套公式，不必解方程。
4. **凑代数式**：遇到 $x_1^2+x_2^2$、$\dfrac{1}{x_1}+\dfrac{1}{x_2}$ 等，先用和与积的恒等式变形，再代入。
5. **回代检验**：求出的待定系数要代回 $\Delta$，确认仍满足根的条件。

### 例题演示
**题干**：已知关于 $x$ 的方程 $x^2-4x+k-1=0$ 有两个不相等的实数根。(1) 求 $k$ 的取值范围；(2) 若两根为 $x_1,x_2$，且 $x_1^2+x_2^2=10$，求 $k$。

**分步解答**：
1. 一般式：$a=1$，$b=-4$，$c=k-1$。
2. **(1) 判别式**：有两不等实根 → $\Delta>0$
   $$\Delta=(-4)^2-4\cdot1\cdot(k-1)=16-4k+4=20-4k>0$$
   解得 $k<5$。
3. **(2) 韦达定理**：$x_1+x_2=-\frac{-4}{1}=4$，$x_1x_2=\frac{k-1}{1}=k-1$。
4. 凑 $x_1^2+x_2^2$：
   $$x_1^2+x_2^2=(x_1+x_2)^2-2x_1x_2=4^2-2(k-1)=16-2k+2=18-2k$$
   令 $18-2k=10$，得 $2k=8$，$k=4$。
5. **检验**：$k=4<5$，此时 $\Delta=20-16=4>0$ ✓，确有两个不等实根。

**最终答案**：(1) $\boldsymbol{k<5}$；(2) $\boldsymbol{k=4}$。

### ❌ 易错提醒
- **用韦达前不验 $\Delta$**：若 $\Delta<0$ 根本没有实根，$x_1+x_2$、$x_1x_2$ 公式毫无意义。一定先判根、再用韦达。
- **和的符号错**：$x_1+x_2=-\dfrac{b}{a}$ 前面有负号，别写成 $\dfrac{b}{a}$。
- **没化一般式就套公式**：必须先写成 $ax^2+bx+c=0$，$a$、$b$、$c$ 带符号读，常数项移项别漏。
