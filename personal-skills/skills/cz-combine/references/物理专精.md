## 一、本科定位与思维纹理

物理这一科，本质是**用公式和图像描述身边的现象**。它既不像数学那样纯推导，也不像化学那样记方程式，而是「先观察现象→猜一个规律→做实验验证→用公式算→用图像看趋势」。初中物理的核心是**定性理解加定量计算**：先把概念讲明白（力是什么、电流是什么），再套公式算数，最后要写清单位和方向。

中考怎么考：
- **选择/填空/作图题**：考概念辨析、单位换算、光路图、力的示意图、电路图。靠的是「概念清、方向对、图规范」。
- **实验探究题**：考控制变量法、数据表格、图像分析、误差分析。常见实验：测密度、测平均速度、探究凸透镜成像、探究杠杆平衡、伏安法测电阻、测小灯泡电功率。靠的是「会读数、会控制变量、会写结论（在……一定时，……与……成……）」。
- **计算题**：力学（速度、密度、压强、浮力、功功率机械效率、杠杆滑轮）、电学（欧姆定律、电功电功率、电热）、热学（比热容、热量）。靠的是「已知→求→公式→代入→带单位→答」六步走。
- **科普/阅读题**：给一段新材料（磁悬浮、光伏发电、深海潜水器），问其中用到的物理知识。靠的是「从材料里抓关键词，挂到课本已学模型上」。

这一科「怎么想」：
1. **见到题先判板块**：是力、热、光、电、声、能量中的哪一块？不同板块思维完全不同。
2. **力学先画受力图**：一重二弹三摩擦，每个力找施力物体；画完再列平衡方程。
3. **电学先判串并联**：去表法（电流表当导线、电压表当开路），再标三要素（I、U、R），最后套欧姆定律。
4. **实验题先想控制变量**：研究谁跟谁的关系，就保持其他量不变、只变研究的那个量。
5. **计算题必须带单位、写公式**：不能只写代数；结果要对数量级有感觉（人对地面压强约 $10^4\,\text{Pa}$、家庭灯泡电阻约几百欧）。

和别的理科区别：化学记物质反应和现象，物理记公式和方向；数学不讲究单位和实际物理意义，物理每个公式都有适用条件（如 $p=\rho gh$ 只对静止液体和均匀柱体、欧姆定律只适用于纯电阻）。

## 二、科目识别与版本册次

### 2.1 如何判定本科（题型/材料/关键词特征）
- 题干出现**单位（N、Pa、J、W、A、V、Ω、℃、Hz）、物理量符号（F、G、m、V、ρ、p、I、U、R、P、Q）、实验装置图（斜面、杠杆、滑轮组、电路图、凸透镜、温度计）** → 物理。
- 出现**生活现象（刹车前倾、船浮在水面、筷子在水中弯折、冬天窗户内侧结冰花、用吸管喝饮料）** → 物理。
- 出现**公式变形计算、图像（s-t 图、v-t 图、U-I 图、m-V 图）、数据表格** → 物理。
- 注意区分：同样出现「实验」，化学实验看物质变化（气泡、沉淀、颜色），物理实验看物理量变化（读数、长度、温度、电流）；同样出现「材料题」，历史答过去的事，物理答「这个现象用到了哪个物理规律」。

## 五、快解 / 速判（草稿快解板块用）

每条写清原理、适用、操作、局限。

1. **串并联速判（去表法）**
   - 原理：电流表内阻极小相当于导线，电压表内阻极大相当于开路。
   - 适用：所有含电表的电路图。
   - 操作：把电流表换成导线、电压表擦掉，看用电器是依次连成一串（串联）还是两端分别连在一起（并联）。
   - 局限：含滑动变阻器时要判清它接的是哪两个接线柱（「一上一下」）。

2. **浮沉速判（比密度）**
   - 原理：浸没物体，ρ物<ρ液上浮、=悬浮、>下沉。
   - 适用：判断木块、铁块、鸡蛋在水/盐水中状态。
   - 操作：直接比 ρ物 与 ρ液；漂浮悬浮时 F浮=G，不用阿基米德。
   - 局限：空心物体（轮船）要按平均密度比，不能用外壳材料密度。

3. **凸透镜成像档位速查**
   - 原理：一倍焦距分虚实、二倍焦距分大小。
   - 适用：给 u 和 f 判断像的性质。
   - 操作：u>2f 照相机；f<u<2f 投影仪；u<f 放大镜；u=2f 等大；u=f 不成像。
   - 局限：「物近像远像变大」只对实像；u<f 时物体靠近透镜，虚像反而变小。

4. **受力图秒画口诀「一重二弹三摩擦」**
   - 原理：按固定顺序找力，避免漏力或添力。
   - 适用：所有要列平衡方程的力学题。
   - 操作：先画重力（竖直向下）→ 找每个接触点画弹力（垂直接触面/沿绳）→ 判摩擦（与相对运动趋势相反）。
   - 局限：每个力必须能找到施力物体，找不到就是臆想的力，删掉。

5. **量级估算（检查计算结果）**
   - 原理：对常见物理量数量级有感觉，能快速发现单位错误。
   - 适用：所有计算题结果自检。
   - 操作：人对地面压强约 $10^4\,\text{Pa}$；家用电灯电阻约几百欧；一节 5 号电池 1.5 V；水的比热容是常见物质里最大的。
   - 局限：只用于发现明显错误，不能代替计算。

6. **选择题排绝对词**
   - 原理：物理题中「一定、总是、全部、只要……就」往往错。
   - 适用：概念辨析选择题。
   - 操作：见到绝对词优先怀疑；如「物体受到浮力就一定上浮」「导体电阻与电压成正比」都是错的。
   - 局限：课本上确实有绝对结论的（如「串联电路电流处处相等」）不能乱排。

7. **g 取值速判**
   - 原理：题目给 g=10 就用 10；没给通常取 9.8，但中考计算题若答案要整数，往往默认 10。
   - 适用：所有力学计算题。
   - 操作：读题第一遍先圈 g 的取值；草稿和正式解答保持一致。
   - 局限：题目明确说 g=9.8 时不能图省事用 10。

## 六、高频易错 / 易混清单

| 错例 | 正确做法 |
|---|---|
| 压力当成重力到处用 | 只有水平面上、无其他竖直外力时 F=G；斜面、压墙、上提/下压时压力不等于重力 |
| 面积单位不换算（cm² 直接代） | $1\,\text{cm}^2=10^{-4}\,\text{m}^2$，p=F/S 前必须换成 m² |
| 走路时还用双脚面积 | 走路一脚着地，S 减半、p 翻倍 |
| 液体压强用物体密度 | p=ρgh 中 ρ 是**液体**密度，不是物体密度 |
| 深度 h 从容器底算起 | h 是从**液面**到该点的竖直距离 |
| 阿基米德用物体密度 | F浮=ρ液gV排，ρ液 是液体密度 |
| 部分浸入还用 V物 | V排 只是液面下那部分体积 |
| 漂浮时还代 V物 | 漂浮时直接 F浮=G，V排<V物 |
| 上浮过程认为浮力变大 | 露出水面前 V排 不变浮力不变；露出后 V排 减小浮力才减小到等于 G |
| 密度计测不同液体浮力不同 | 密度计任何液体中都漂浮，浮力总等于自重，只是浸入深度不同 |
| 推而未动用 f=μN | 推而未动是静摩擦，由平衡条件求；μN 是滑动摩擦 |
| 摩擦力方向与运动方向相反 | 是与**相对运动/趋势**相反；传送带带动物体时摩擦力可向前 |
| 二力平衡与相互作用力混淆 | 二力平衡作用在**同一物体**；相互作用力作用在**两个物体** |
| 匀速上升拉力大于重力 | 只要匀速，拉力都等于重力，与运动方向无关 |
| 由 R=U/I 说电阻与电压成正比 | R 是导体本身性质，R=U/I 只是计算式，与 U、I 无关 |
| 并联总电阻等于两电阻之和 | 并联是 1/R=1/R₁+1/R₂，越并越小 |
| 串联电路电阻大的电流小 | 串联电流处处相等，电阻大的两端电压大 |
| 变阻器电阻变大，它分得电压变小 | 串联中变阻器电阻变大，总电流变小，定值电阻电压变小，变阻器电压反而变大 |
| 伏安法测电阻只测一次 | 要多次测量求平均值减小误差 |
| 连接电路开关闭合、滑片置最小阻值 | 开关应断开、滑片置最大阻值处保护电路 |
| 入射角当成与镜面夹角 | 入射角是与**法线**的夹角；镜面夹角 = 90° - 入射角 |
| 法线画成实线 | 法线是辅助线，必须虚线 |
| 认为漫反射不遵守反射定律 | 每一条光线都遵守反射定律 |
| 近视用凸透镜矫正 | 近视像成在视网膜前，用**凹透镜**；远视用凸透镜 |
| 把惯性当成力画出来 | 惯性是属性，不是力，不能画「惯性力」 |
| 物态变化方向搞反 | 熔化吸热、凝固放热；汽化吸热、液化放热；升华吸热、凝华放热 |

## 七、名师大白话讲法 / 口诀 / 比喻

讲法总原则：从生活场景切入，先讲「为什么」，再讲「是什么」，最后才套公式。讲法话术文件见 `$LIB/方法套路/讲法话术.md`（第 341 行起「第二部分：物理」），下面是初中可直接照念的浓缩版。

1. **讲「力是物体对物体的作用」**：你拍桌子，手也疼——因为手对桌子施力的同时，桌子也对手施力。力不能脱离物体存在，找不出施力物体的力就是瞎想的。

2. **讲「惯性」**：公交车急刹车，人会往前倾。人的脚跟着车停下了，人的上半身由于惯性还要保持原来向前的运动状态，所以往前倒。惯性不是力，是物体本身的属性，质量越大惯性越大。

3. **讲「压强」**：书包带为什么要做宽？菜刀为什么要磨薄？压力一样时，受力面积越大压强越小，背起来不勒肩；受力面积越小压强越大，切菜才快。

4. **讲「液体压强深度」**：潜水员为什么下潜越深越要穿抗压服？因为水越深压强越大，就像你在水里，上面压的水越多，肩膀越沉。

5. **讲「浮力」**：把空矿泉水瓶按进水里，手会感到一股向上顶的力，这就是浮力。物体浸在水里，上下表面受到的水压不一样大，下面压强大、上面压强小，合力向上就是浮力。

6. **讲「串并联」**：串联就像糖葫芦，一颗坏了整串都不亮；并联就像教室里的灯，一盏坏了其他还亮。串联电流一路走到底处处相等；并联各支路电压都等于电源电压。

7. **讲「欧姆定律」**：电压就像水压，电阻就像水管粗细，电流就像水流。水压越大水流越大，水管越细水流越小——这就是 I=U/R。

8. **讲「凸透镜成像」**：照相机离物体远，成缩小倒立实像；投影仪离物体近（在一倍到二倍焦距之间），成放大倒立实像；放大镜离物体更近（一倍焦距以内），成正立放大虚像。记住「一焦分虚实、二焦分大小」。

9. **讲「反射」**：入射角和反射角都是跟法线的夹角，不是跟镜面的夹角。法线就是过入射点垂直镜面那条虚线，先把这条线画出来，角度就不会算错。

10. **讲「控制变量法」**：研究电流跟电压关系时，要保持电阻不变；研究电流跟电阻关系时，要保持电压不变。就像研究「学习时间对成绩的影响」，得保持「学习方法」不变，否则说不清是谁的功劳。

口诀汇总：
- 受力分析：一重二弹三摩擦，每个力找施力物。
- 浮沉：漂浮悬浮浮力等重力，沉底才用阿基米德。
- 凸透镜：一焦分虚实，二焦分大小；实像倒立异侧，虚像正立同侧。
- 折射：空气里那个角总是大的。
- 电路计算：一画（判串并联）二标（I、U、R 已知问号）三算（套欧姆定律联立）。

### 7.1 网上名师招牌套路（精选·已甄别·只收本库没有的）

以下套路均来自抖音、B 站、小红书、知乎及学而思/猿辅导/学科网等平台的**公开**讲法，只提炼方法论思想并按初中课标口径改写，不搬运付费课程、不整段复制原视频台词。已与本文件第一节概念、第四节模型、第五节快解、本节原有口诀逐条比对，**高度重合的不重复收录**（见本节末"未收录说明"）。流传数十年的公共口诀不归属真人；给得出公开链接的才标来源。

1. **节点法（标号法）画等效电路图**
   - 来源：学而思 1 对 1 公开资料《初中物理电学之串并联电路的简化》（http://m.jiajiaoban.com/sz/e/20150116/54b8d5cace625.shtml ）称"节点跨接法"；抖音多位初中物理博主公开讲法反复使用（如 https://www.iesdouyin.com/share/video/7438988747389127986 ）。
   - 怎么操作：①先用去表法把电流表换成导线、电压表擦掉（本文件第五节第 1 条）；②用字母 a、b、c 给每个节点标号——**纯导线直接连在一起的点标同一个字母**，每经过一个用电器（电阻/灯泡）就换一个字母；③把同一个字母的点捏合成一个点，按"a—用电器—b"的关系重新画成横平竖直的规范电路，串并联一眼可判。
   - 原理（为什么）：导线电阻极小可忽略，导线上任意两点电势相等，本来就该看成同一个点；原图绕来绕去只是走线方式不同，把等势点合并后电路的连接关系不会变。
   - 适用：接线扭曲、一时看不出串并联的复杂电路图（去表法处理不了的那种）。局限：滑动变阻器必须先看清接的是哪两个接线柱（"一上一下"），不能直接当定值电阻；含电压表时只能先擦掉判结构，判完再把它放回被测用电器两端。

2. **多物体受力：先整体、后隔离**
   - 来源：抖音初中物理公开讲法（多位老师反复使用，如 https://www.iesdouyin.com/share/video/7626712888769638373 、https://www.iesdouyin.com/share/video/7687070255819040241 ）；"状态相同先整体、接触面上再隔离"为公开通用表述，不归属某一位老师。
   - 怎么操作：①看叠放/连接的几个物体运动状态是否一致（一起静止，或一起匀速直线运动）；②状态一致时先把它们**看成一个整体**，只画外部对整体的力（整体重力、地面支持力、外部拉力/推力、地面摩擦），不画它们之间的相互作用力，先把地面摩擦、外部支持力求出来；③再**隔离**其中一个物体，补画它与相邻物体间的压力、静摩擦（用二力平衡反推）。
   - 原理（为什么）：整体内部物体之间的作用力是一对相互作用力，大小相等方向相反，对整体而言合力为零，画出来也会抵消，不如不画；一旦要求"AB 之间的摩擦力/压力"这种内力，整体法求不出，必须隔离。
   - 适用：叠放、连接体的平衡态力学题（求地面摩擦、墙面支持力、两物体间摩擦）。局限：只对**平衡态**（静止/匀速）成立；绝不能引入 F=ma（那是高中方法，见 7.2 第 3 条）。

3. **液面升降 Δh = ΔV排 / S容**
   - 来源：抖音初中物理公开讲法（如 https://www.iesdouyin.com/share/video/7504630974160964904 ）；学科网/原创力文档等公开资料称"漂浮体液面变化模型"。
   - 怎么操作：①判物体最终状态——漂浮/悬浮时直接 F浮=G，沉底时用阿基米德；②算浮力变化量 ΔF浮（增减物体、增减外力、冰熔化前后）；③由 ΔF浮=ρ液gΔV排 反算 ΔV排；④柱形容器中液面高度变化 Δh=ΔV排/S容（S容为容器底面积）；⑤再由 Δp=ρ液gΔh 算液体对容器底压强变化。
   - 原理（为什么）：物体多排开多少液体，这部分液体就会被挤到容器里让液面上升；柱形容器中体积增量等于底面积乘高度增量，所以 ΔV排 与 Δh 成正比。
   - 适用：柱形容器中漂浮物增减、船球模型、冰熔化、剪断绳等液面升降题。局限：只对**柱形容器**成立（非柱形容器不能直接 ΔV排/S容）；漂浮物体始终漂浮时 ΔF浮=ΔG 才成立，一旦物体由漂浮变为沉底，要分两段算 V排，不能套一条公式。

4. **多次测量目的二分（测量型 vs 探究型）**
   - 来源：猿辅导等机构抖音公开讲法（https://www.iesdouyin.com/share/video/7569938858662497577 ）；北京教育考试院公开文章《紧扣变量逻辑关系 解决实验探究问题》（https://www.bjeea.cn/uploads/soft/241016/1799%E6%9C%9F6%E7%89%88.pdf ）。
   - 怎么操作：题目问"为什么多次测量"时按实验类型分两种答——**测量型**实验（伏安法测电阻、测密度、测平均速度）答"多次测量取平均值，减小误差"；**探究型**实验（探究电流与电压关系、探究杠杆平衡条件、探究影响浮力大小的因素）答"多次实验寻找普遍规律，避免偶然性"。
   - 原理（为什么）：测量型实验每次读数有随机误差，平均一下误差相互抵消；探究型实验只测一组数据可能是巧合，多测几组才能看出规律是不是普遍成立。两种题目的"多次"目的完全不同，答反了就丢分。
   - 适用：所有中考实验探究题"评估/反思"类设问。局限：结论句"在……一定时，……与……成……"的写法本文件第一节已述，此处不重复；结论范围不能超出题目给的数据区间。

5. **电路故障两步判：先看电流表定短/断，再看电压表定位置**
   - 来源：抖音公开讲法（多位博主反复使用，如 https://www.iesdouyin.com/share/video/7550494981031595305 、https://www.iesdouyin.com/share/video/7572832611664497929 ）；学科网公开资料（https://www.zxxk.com/soft/53275771.html ）。
   - 怎么操作：①**先看电流表**——电流表有示数，说明电路是通的（故障是某处**短路**）；电流表无示数，说明电路断了（故障是某处**断路**）；②**再看电压表**——电压表有示数且接近电源电压，说明电压表两个接线柱到电源两极是通的，断路点就在电压表**两接线柱之间**的被测部分；电压表无示数，说明电压表到电源两极之间**某一处断了**（断路点在被测部分之外）；③短路情形下，被短路的用电器不工作、与它并联的电压表无示数（测的是一根导线的电压）。
   - 原理（为什么）：断路=电流走不通，电流表必无示数；短路=电流走导线绕过用电器，回路仍通所以电流表有示数。电压表能测出接近电源电压，说明它"看到"了电源两极，反过来说明断点不在它到电源的路径上。
   - 适用：串联电路中一个用电器短路/断路的经典故障题。局限：只对**一表测一用电器**的串联电路成立；并联电路支路故障、电压表直接测电源电压的情形，套口诀会误判，必须按电流实际路径重画分析。

### 7.2 已剔除的「大招/秒杀」及原因

1. 摒弃 **纯口诀/黑话秒杀版**（如电路故障"两表一致对外、两表不同内斗、电流有短无断"，以及"立断""内断外短""外短内断"等不解释原理的暗号）
   - 剔除原因：**只记结论不讲原理、玄学黑话**。口诀只在"电压表并联在某一个用电器两端、电路为纯串联"时才成立；一旦换成电压表测电源电压、并联支路、或开关同时控制多个用电器，直接背口诀必然判错。这类说法把推理链压缩到只有博主自己能解码的字数，换一个电路图的画法就对不上号，也和教材上"断路/短路/短路处两端电压为零"的规范表述冲突。本文件保留的是 7.1 第 5 条"先看电流表、再看电压表"的**推理链**，不是这句黑话本身。

2. 摒弃 **"漂浮切割比值法：ρ物/ρ液=V排/V物，切完直接套"**
   - 剔除原因：**适用极窄，换条件就错**。这个比例只在"均匀柱体竖直漂浮、切去上面一部分后剩余部分仍能漂浮"时成立；切完若物体由漂浮变为悬浮/沉底、或物体不是柱体、或被切的是斜着的一块，比例全部失效。中考题常故意在这些地方挖坑，只背比值不画受力图必错。

3. 摒弃 **"高中整体法隔离法：用 F=ma 求叠加体加速度"**
   - 剔除原因：**超纲**。初中物理只处理平衡态（a=0），整体法在这里只能用来列"合力为零"的平衡方程；一引入 F=ma、用 f=μN 求加速运动物体，就越过了初中课标，中考解答中写出来不得分，还会把孩子搞糊涂。
