## 方法30：平均数/中位数/众数「看分布选代表」法

### 适用题型
- 给一组数据，求平均数、中位数、众数；
- 给实际问题，问用哪个统计量代表一般水平更合适。
- 题目特征："某班5名同学身高……求中位数/众数/平均身高"。

### 原理/公式
- **平均数**：所有数据加起来，除以个数。
  $$\bar{x} = \frac{x_1 + x_2 + \dots + x_n}{n}$$
  特点：用到了所有数据，但容易受极端值影响。
- **中位数**：把数据从小到大排列，正中间的那个数（偶数个时是中间两个的平均数）。
  特点：不受极端值影响。
- **众数**：出现次数最多的数。
  特点：可能不止一个，也可能没有。
- **选用原则**：
  - 数据比较均匀、没有极端值 → 用平均数。
  - 有特别大或特别小的极端值 → 用中位数。
  - 问"最受欢迎""最常出现" → 用众数。

### 操作步骤
1. **求平均数**：全部加起来 ÷ 个数。
2. **求中位数**：先排序 → 找中间位置 → 取中间那个（或中间两个的平均）。
3. **求众数**：数每个数出现几次 → 找次数最多的。
4. **选代表**：看数据有没有极端值，选合适的统计量。

### 例题演示
**题干**：某小组7名同学的数学成绩（分）为：85，90，88，85，92，90，90。求这组数据的平均数、中位数和众数。

**分步解答**：
1. **平均数**：
   $$\bar{x} = \frac{85 + 90 + 88 + 85 + 92 + 90 + 90}{7} = \frac{620}{7} \approx 88.6$$
2. **中位数**：先从小到大排序：85，85，88，90，90，90，92。
   共7个数，第4个是中位数 → 90。
3. **众数**：数次数：
   - 85 出现2次
   - 88 出现1次
   - 90 出现3次
   - 92 出现1次
   出现最多的是90 → 众数是90。

**最终答案**：平均数约为 $\boldsymbol{88.6}$ 分，中位数是 $\boldsymbol{90}$ 分，众数是 $\boldsymbol{90}$ 分。

### ❌ 易错提醒
- **求中位数不排序**：直接找中间那个数是错的，必须先从小到大排好。
- **偶数个数据的中位数算错**：比如4个数，中位数是第2个和第3个的平均数，不是随便一个。
- **众数可能有多个**：如果两个数出现次数并列最多，那两个都是众数。

## 方法31：概率求法「列表法 / 树状图法」

### 适用题型
- 两步或两步以上的随机事件，求概率。
- 题目特征："先后抛两枚硬币""同时摸两个球""经过两个路口遇红灯概率"。

### 原理/公式
- 概率 = 所求事件出现的结果数 ÷ 所有等可能结果总数。
  $$P(A) = \frac{\text{事件}A\text{包含的结果数}}{\text{所有等可能结果总数}}$$
- **列表法**：适合两步试验（两个因素），用表格列出所有可能。
- **树状图法**：适合两步及以上，一层层画分支。

### 操作步骤
1. **判断几步试验**：
   - 两步 → 列表法或树状图都行。
   - 三步及以上 → 树状图法更清楚。
2. **画列表/树状图**：把所有可能结果都列出来，不重不漏。
3. **数总数**：一共有多少种等可能结果。
4. **数目标事件**：符合题目要求的有几种。
5. **算概率**：目标数 ÷ 总数。

### 例题演示
**题干**：同时抛两枚均匀硬币，求两枚都正面朝上的概率。

**分步解答**：
1. 两步试验：第一枚、第二枚。
2. 列表法：

   | 第一枚\第二枚 | 正 | 反 |
   |---|---|---|
   | 正 | (正,正) | (正,反) |
   | 反 | (反,正) | (反,反) |

3. 所有等可能结果共4种。
4. "两枚都正面朝上"只有1种：(正,正)。
5. 概率：
   $$P = \frac{1}{4}$$

**最终答案**：两枚都正面朝上的概率为 $\boldsymbol{\dfrac{1}{4}}$。

### ❌ 易错提醒
- **结果数漏算或多算**：列举的时候要按顺序来，别跳着写，容易漏。
- **"放回"和"不放回"搞混**：摸球题里，放回和不放回结果总数不一样，看清楚题目。
- **概率约分**：结果能约分的要约成最简分数。

## 方法32：选填快解 · 特殊值法

### 适用题型
- 选择题、填空题中，题目给了一般条件，但答案是确定的。
- 题目特征："如果 $a < 0 < b$，下列哪个一定成立……"——用具体的数代进去试，又快又准。

### 原理/公式
- 既然题目说"对所有满足条件的数都成立"，那我们就**挑一个最简单的特殊值**代进去验证，排除不对的选项。
- 挑值原则：
  - 好算（整数、小数字）。
  - 符合题目条件（别选不符合条件的数）。
  - 有代表性（比如 $a$ 是负数，就选 $a=-1$；别选 $a=-1000$ 这种太偏的）。

### 操作步骤
1. 看题目给了什么条件范围（比如 $x>0$，$0<a<1$）。
2. 挑一个最简单的特殊值，代进每个选项算。
3. 哪个选项算出来不对，就排除哪个。
4. 如果只剩一个选项了，直接选。
5. 如果剩两个以上，再换一个特殊值再试一次。

### 例题演示
**题干**：若 $0 < a < 1$，则 $a$，$\dfrac{1}{a}$，$a^2$ 的大小关系是（  ）。
A. $a < \dfrac{1}{a} < a^2$
B. $a^2 < a < \dfrac{1}{a}$
C. $\dfrac{1}{a} < a < a^2$
D. $a < a^2 < \dfrac{1}{a}$

**分步解答**：
1. 条件：$0 < a < 1$。挑最简单的：$a = \dfrac{1}{2}$。
2. 算三个值：
   - $a = \dfrac{1}{2}$
   - $\dfrac{1}{a} = 2$
   - $a^2 = \left(\dfrac{1}{2}\right)^2 = \dfrac{1}{4}$
3. 排序：$\dfrac{1}{4} < \dfrac{1}{2} < 2$，即 $a^2 < a < \dfrac{1}{a}$。
4. 对应选项 B。

**最终答案**：$\boldsymbol{B}$

### ❌ 易错提醒
- **选的值不符合条件**：题目说 $a<0$，你选了 $a=1$，那算出来肯定不对。
- **一个特殊值就定所有**：如果代一个值排除了两个选项，剩下两个都有可能，要再换一个值再试。
- **特殊值法只用于选填**：大题不能用特殊值法，必须写一般推导过程。

## 方法33：选填快解 · 排除法

### 适用题型
- 选择题中，能明显看出某些选项不对的。
- 题目特征：四个选项里，有明显荒谬的、和条件矛盾的，可以先排除。

### 原理/公式
- 选择题的答案是四选一，**排除掉三个错的，剩下那个就是对的**。
- 排除的依据：
  - 符号不对（结果应该是正的，选项里有负的）。
  - 大小不对（比如算出来应该比5大，选项里有比5小的）。
  - 单位不对、明显不合理。

### 操作步骤
1. 先大概判断答案的范围（正负、大小量级）。
2. 扫一遍选项，明显不对的直接划掉。
3. 排除完之后，剩下1~2个选项，再仔细算。
4. 特殊值法和排除法可以配合着用。

### 例题演示
**题干**：计算 $(-2)^3$ 的结果是（  ）。
A. $-6$
B. $6$
C. $-8$
D. $8$

**分步解答**：
1. 先判断符号：负数的奇次幂是负的，排除 B（6）和 D（8）。
2. 剩下 A（-6）和 C（-8）。
3. $(-2)^3 = (-2)\times(-2)\times(-2) = -8$，选 C。

**最终答案**：$\boldsymbol{C}$

### ❌ 易错提醒
- **排除的时候想当然**：排除一定要有依据（符号、大小、明显矛盾），不能凭感觉。
- **排除法和特殊值法配合用更高效**：先排除明显错的，再代特殊值验证剩下的。
- **填空题不能用排除法**：填空没有选项，必须自己算出准确答案。

## 方法34：选填快解 · 数形结合法

### 适用题型
- 函数题、不等式题、几何题，画个图就能看出答案。
- 题目特征：给函数解析式，问图象过哪些象限；或者给不等式组，问解集。

### 原理/公式
- **代数问题翻译成图形**：
  - 函数 → 画图象草图。
  - 不等式 → 画数轴。
  - 几何边长 → 画示意图。
- 画图不需要精确，只要方向、位置、大致比例对就行，目的是"看出"答案。

### 操作步骤
1. 把题目里的条件转换成图形：函数画坐标系，不等式画数轴。
2. 草图不用尺规，大概画个样子。
3. 从图上直接读出答案：经过哪几个象限、解集是哪段、哪条边长。
4. 对照选项选出答案。

### 例题演示
**题干**：一次函数 $y = 2x - 3$ 的图象不经过（  ）。
A. 第一象限
B. 第二象限
C. 第三象限
D. 第四象限

**分步解答**：
1. $k = 2 > 0$ → 直线从左下往右上斜。
2. $b = -3 < 0$ → 与 $y$ 轴交于负半轴 $(0, -3)$。
3. 画草图：交 $y$ 轴负半轴，向右上方斜，必然经过一、三、四象限。
4. 不经过第二象限，选 B。

**最终答案**：$\boldsymbol{B}$

### ❌ 易错提醒
- **图画得太潦草**：草图也要标清楚关键信息（截距正负、开口方向），不然看了也白看。
- **只画图不算数**：数形结合是"图帮你找方向，计算帮你定准确值"，不能只靠猜图。
- **坐标系画错方向**：$x$ 轴向右为正，$y$ 轴向上为正，别画反。
