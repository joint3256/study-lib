# 高中化学 · 化学实验

---

## 方法 H14　化学实验（制备 / 分离提纯 / 检验 / 定量实验与误差）

### ① 方法名
**"目的选方法 + c=n/V 误差归因"实验综合法**

### ② 适用题型 / 物质
常见气体制备综合题；分离提纯方法选择；离子/物质检验；一定物质的量浓度溶液配制与中和滴定的误差分析。

### ③ 原理（为什么）
- 分离方法依据混合物各成分物理性质差异：固液不溶用过滤；溶液中得溶质用蒸发；沸点不同用蒸馏；溶质在互不相溶溶剂中分配不同用萃取分液。
- 一定物质的量浓度溶液配制：c = n/V，误差分析归结为操作使 n 偏大/偏小，还是 V 偏大/偏小。
- 中和滴定原理：c(待)·V(待) = c(标)·V(标)（一元酸碱按 1:1 计）。

### ④ 操作步骤
- 配制：计算 → 称量（天平）→ 溶解（烧杯、玻璃棒）→ 冷却 → 转移（容量瓶）→ 洗涤 → 定容（胶头滴管）→ 摇匀。
- 误差：由 c = n/V，看操作影响 n 还是 V。
- 滴定：查漏→润洗装液→滴定→读数→计算 c(待)=c(标)V(标)/V(待)。

### ⑤ 例题完整演示
(1) 用 18.4 mol/L 浓硫酸配制 500 mL 0.184 mol/L 稀硫酸，需量取浓硫酸多少毫升？
- c₁V₁ = c₂V₂：18.4 × V₁ = 0.184 × 0.500
- V₁ = 0.005 L = **5.0 mL**（已验算）

(2) 用 0.1000 mol/L 盐酸滴定 25.00 mL 未知浓度 NaOH 溶液，消耗盐酸 20.00 mL，求 c(NaOH)。
- c(待) = c(标)V(标)/V(待) = 0.1000 × 20.00 / 25.00 = **0.08000 mol/L**（已验算）

(3) 分离方法选择：KNO₃（多）中混 NaCl → 降温结晶；NaCl（多）中混 KNO₃ → 蒸发结晶；乙醇和水 → 蒸馏；碘水提取碘 → 萃取分液。

### ⑥ ❌ 易错提醒
- 容量瓶不能用来溶解、稀释或长期存放溶液；定容时视线与凹液面最低处相平。
- 误差：定容时**俯视** → 加水偏少、V 偏小 → c 偏大；**仰视** → V 偏大 → c 偏小。
- 烧杯和玻璃棒要洗涤 2~3 次并将洗涤液一并转入容量瓶。
- 滴定管（装标准液）要用待装液润洗；**锥形瓶不能润洗**（否则标准液偏多）。
- 蒸馏时温度计水银球在蒸馏烧瓶支管口处；萃取分液时下层液体从下口放出、上层从上口倒出。
- 浓硫酸稀释："酸入水"，沿烧杯壁缓缓倒入并不断搅拌，不能水入酸。
