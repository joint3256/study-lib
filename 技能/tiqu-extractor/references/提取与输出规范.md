# 提取与输出规范

## 一、预处理
- 横拍、倒置、侧躺的照片逐张转正；按页码/题目顺序排好。
- 必要时把一页裁成题块、放大后再读，避免漏字、看错符号。

## 二、文字转录
- 逐题转录：题号、题干、全部选项、每一小问、分值；一个字、一个符号都不缺。
- 符号用规范写法：三角形 △、角 ∠、全等 ≅、相似 ∽、约等 ≈、不等 ≠、度 °、
  平行 ∥、垂直 ⊥、大于等于 ≥、小于等于 ≤、上标 x²/x³、根号 √、圆周率 π、乘 ·。
- 待填空位用全角空格"（　）"或下划线原样保留，不填任何手写答案。
- 易混字符看清：0 与 O、1 与 l、6 与 b、5 与 S、上标与普通数字。

## 三、图形重画（目标：尽量与原图一样）
- 用 `assets/fig_helpers.py`（newax/seg/poly/lab/rmark/ang/tick/save）。
  例：
  ```python
  import sys; sys.path.insert(0, "<skill>/assets")
  from fig_helpers import *
  set_outdir("/abs/work/figs")
  fig, ax = newax((-0.5, 5), (-0.5, 3))
  poly(ax, [(0,0),(2,1.8),(4,0)])
  rmark(ax, (0,0), (4,0), (2,1.8))   # 若该角为直角
  lab(ax,(0,0),"A",0,-0.3)
  save(fig, "q01.png")
  ```
- "尽量一样"指：点的左右/上下相对位置、线段连接关系、角度大小观感、边长比例、
  交点落在哪条边，都与原图一致；画布必须等比例（set_aspect("equal")）。
- 印刷的虚线、阴影、直角符号、角弧、等号刻度、点字母全部画全；
  题目印刷的辅助线要保留，学生后加的手绘辅助线不画。
- 多个并列判断图（如"下面四个图"）可排成 2×2 以保证每个子图清晰，
  但每个子图内部的比例与形态不得改变。
- 函数图象：画坐标轴、箭头、刻度与标签，按关键点（截距、顶点、交点）定形，曲线趋势准确。
- 配图命名 qNN.png（NN 为题号，如 q02.png），统一存到工作目录的 `figs/`。

## 四、组装与转换
1. 按 `scripts/make_clean_doc.py` 的 JSON 结构写 `extract.json`（题目块、选项、配图路径与宽度）。
2. 运行：`python3 make_clean_doc.py extract.json`，得到干净 Word。
   图片宽度按版面：常规图约 12cm；横长图 15–16cm；复杂图适当加宽以看清细节。
3. 运行：`python3 doc_to_outputs.py <word>`，得到 PDF 与每页干净页面 PNG
   （每次新建 `<文档名>-<随机后缀>/`，PDF 与 `pages/` 均在其中；具体路径见脚本输出，保留旧成果）。

## 五、文件命名
- Word/PDF：`<试卷名>_原题提取（干净无手写）.docx/.pdf`。
- 干净页面图片：由本次新目录中的 `pages/page-N.png` 导出，即"干净页面导出的图片"。
