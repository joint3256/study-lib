## 一、本科定位与思维纹理

历史这一科，本质是**时空轴上的因果链**。任何一道题都能拆成四样东西：**时间、地点、人物、事件**，再加上一条「为什么发生（背景/原因）→ 发生了什么（内容/措施）→ 造成什么结果（影响/意义）」的因果线。和数学物理最大的不同是：历史不推导公式，而是**先把事件钉到时间轴上，再按因果线分点作答**。

中考怎么考：
- **选择题**：给一个时间、一个关键词、一段材料，让你判断属于哪件事、哪个朝代、哪个结论。靠的是「时间定位＋排除法」。
- **材料解析题**：给一段或几段文字、表格、地图，问原因、措施、影响、评价、变化趋势、比较异同。靠的是「答案从材料里找一部分、回课本补一部分，再分点写」。
- 高频设问动词：**背景/原因（要分根本原因、直接原因）、内容/措施、意义/影响、评价（一分为二）、变化/趋势、比较异同**。

这一科「怎么想」：
1. 任何事件先问三句话——它发生在**哪一年/哪个朝代**？它是**因为什么**发生的？它**改变了什么**？
2. 做材料题**先读设问、再读材料**，带着问题去找采分点，不要一上来就啃大段材料。
3. 答案一定要**①②③分点**，几分写几点；多用历史术语，不整句照抄材料，也不写成一大段。
4. 评价类题目**必须一分为二**：先说积极/进步作用，再说局限/消极面，最后给历史地位。

和别的文科区别：道法答「观点＋材料＋做法」，历史答「材料信息＋课本结论＋因果分点」；历史特别强调**时间不能错、朝代不能错、人物事件不能张冠李戴**。

## 二、科目识别与版本册次

### 2.1 如何判定本科（题型/材料/关键词特征）
- 题干或材料出现**年份、朝代、年号（贞观、开元、民国）、人名（商鞅、汉武帝、孙中山、瓦特）、条约名（南京/马关/辛丑）、事件名（鸦片战争、洋务运动、辛亥革命、工业革命）** → 历史。
- 出现**历史地图（张骞出使西域路线、北伐战争形势、通商口岸分布）、年代尺、数据变化图表、老照片/漫画** → 历史。
- 设问是「原因、措施、影响、评价、变化趋势、比较异同」且材料讲的是**过去发生的事** → 历史。
- 注意区分：同样出现「政策/措施」，道法答「国家/政府/公民怎么做」，历史答「哪个朝代/哪国、颁布了什么、造成什么结果」。

## 四、核心模型 / 答题模板库（题型 → 识别信号 → 模板步骤 → 结论范式）

完整例题见本地「方法套路/历史/初中/」对应文件，本节是索引与浓缩。

### 4.1 朝代时序与制度演变（中国古代史）
- **朝代歌排队法**（详见 `01_中国古代史_朝代时序与制度演变.md`）：识别信号＝「事件排序、发生在哪个朝代、朝代更替」。步骤＝默唱朝代歌拉空轴 → 把事件钉到朝代站 → 跨朝代从早到晚排。结论范式：夏—商—西周—东周（春秋·战国）—秦—西汉—东汉—三国—两晋—南北朝—隋—唐—五代—北宋/南宋—元—明—清。
- **公元/世纪/年代/民国换算法**（同文件模型 2）：识别信号＝「哪一世纪、民国几年、相距多少年」。公式＝世纪＝年份前两位＋1（1840→19 世纪）；民国＝公元−1911（1912 为民国元年）；跨公元前后相距＝两数绝对值相加再−1（无公元 0 年）。
- **地方行政制度演变**（同文件模型 3）：分封制（西周，世袭）→ 郡县制（秦，皇帝任免、不世袭）→ 行省制（元，中央派官，省制开端）。问趋势答「地方权力不断削弱、中央集权不断加强」。
- **君主专制强化线索**（同文件模型 4）：秦设丞相 → 隋唐三省六部（相权一分为三）→ 明废丞相（朱元璋）→ 清军机处（雍正，顶峰）。口诀「秦设相，唐分相，明废相，清军机处到顶」。
- **选官制度演变**（同文件模型 5）：世卿世禄（血缘）→ 军功爵（战国商鞅）→ 察举制（汉）→ 九品中正制（魏晋，看门第）→ 科举制（隋创立、隋炀帝设进士科）→ 八股取士（明清僵化）。
- **经济重心南移三阶段**（同文件模型 6）：魏晋南北朝开始开发 → 唐中期（安史之乱后）开始南移 → 南宋最后完成（「国家根本，仰给东南」）。核心原因＝北人南迁带去劳动力与技术。
- **民族交融主线**（同文件模型 7）：北魏孝文帝改革（迁都洛阳、说汉语、穿汉服、改汉姓、通婚姻）→ 唐文成公主入藏 → 元回族形成 → 清巩固统一多民族国家。

### 4.2 列强侵略与不平等条约（中国近代史）
- **条约四要素对比法**（详见 `02_中国近代史_列强侵略与不平等条约.md`）：识别信号＝「某条约内容、条约对比」。把每条条约拆成**割地、赔款、开口通商、特权/其他**四格：
  - 《南京条约》1842：割**香港岛**、赔 2100 万银元、广厦福宁上五口、协定关税。
  - 《马关条约》1895：割**台湾全岛及澎湖**、赔 2 亿两、沙市重庆苏州杭州四口、**允许开设工厂**（商品输出转资本输出）。
  - 《辛丑条约》1901：赔 4.5 亿两、清政府保证严禁人民反帝、划东交民巷使馆界、拆炮台许驻军。
- **半殖民地化三级台阶**（同文件模型 2）：鸦片战争（《南京条约》）**开始**沦为 → 第二次鸦片战争**进一步加深**（俄国割地最多）→ 甲午战争（《马关条约》）**大大加深** → 八国联军（《辛丑条约》）**完全沦为**。口诀「开始南京，加深二鸦，大大加深马关，完全沦为辛丑」。
- **侵华战争因果链**（同文件模型 3）：背景（工业革命后列强要打开中国市场）→ 借口/爆发 → 条约 → 影响。根本原因＝列强资本主义发展要市场；直接借口如虎门销烟。

### 4.3 近代化探索与救亡图存（中国近代史）
- **器物→制度→思想三层递进**（详见 `03_中国近代史_近代化探索与救亡图存.md`）：洋务运动（地主阶级洋务派，学技术，自强求富，近代化开端）→ 戊戌变法（资产阶级维新派，学君主立宪，改良）→ 辛亥革命（资产阶级革命派，学民主共和，推翻帝制但未改变社会性质）→ 新文化运动（民主与科学，思想解放）。
- **救亡图存四栏答题法**（同文件模型 2）：主张—代表—结果—启示；启示扣失败原因反推（只学技术不变制度救不了中国；资产阶级方案在半殖民地半封建中国走不通）。

### 4.4 中共党史与新民主主义革命
- **革命六站时间轴**（详见 `04_中共党史与新民主主义革命.md`）：1921 中共一大（建党）→ 1924—1927 第一次国共合作与北伐 → 1927 南昌起义、秋收起义、井冈山（农村包围城市）→ 1934—1936 长征 → 1931—1945 抗日战争 → 1946—1949 解放战争 → 1949 建国。
- **重要会议一站一结论**（同文件模型 2）：中共一大 1921（建党，面貌焕然一新）；遵义会议 1935（生死攸关转折点、确立毛泽东领导地位）；中共七大 1945（确立毛泽东思想为指导思想）；十一届三中全会 1978（改革开放，建国以来伟大转折）。
- **抗战框架**（同文件模型 3）：1931 九一八＝局部抗战起点；1936 西安事变和平解决＝抗日民族统一战线初步形成；1937 七七事变＝全民族抗战开始；1945.8.15 日本投降。意义＝近代以来反抗外敌入侵**第一次取得完全胜利**的民族解放战争、世界反法西斯战争重要组成。

### 4.5 世界史·资产阶级革命与改革
- **英美法革命对照表**（详见 `05_世界史_资产阶级革命与改革.md`）：英国 1640 议会重新召开（开始）、1689《权利法案》→ 君主立宪；美国 1775 来克星顿、1776.7.4《独立宣言》（宣告美国诞生）、1787 宪法（三权分立）→ 联邦共和国（既是民族解放战争又是资产阶级革命）；法国 1789.7.14 攻占巴士底狱、《人权宣言》→ 摧毁君主统治。
- **革命 vs 改革判别**（同文件模型 2）：自下而上打出来＝革命（英、美、美国内战）；自上而下改出来＝改革（俄国 1861 年改革、日本明治维新）。俄日都走上资本主义但保留大量封建残余；美国内战是**第二次资产阶级革命**（维护统一、废除奴隶制）。

### 4.6 世界史·工业革命、大战与国际格局
- **两次工业革命对比**（详见 `06_世界史_工业革命·世界大战与国际格局.md`）：第一次（18 世纪 60 年代起，英国，瓦特改良蒸汽机，蒸汽时代，火车汽船，靠工匠经验）；第二次（19 世纪六七十年代起，美德领先，电力广泛应用，电气时代，汽车飞机内燃机，科学与技术紧密结合）。
- **国际格局三段轴**（同文件模型 2）：一战后凡尔赛—华盛顿体系 → 二战后美苏两极格局（1947 杜鲁门主义＝冷战开始；1991 苏联解体＝两极结束）→ 当今多极化趋势＋经济全球化。
- **一战二战框架**（同文件模型 3）：一战 1914—1918（萨拉热窝事件，帝国主义战争，1917 十月革命）；二战 1939—1945（德国突袭波兰全面爆发，世界反法西斯战争，斯大林格勒战役是转折点）。

### 4.7 材料题通用答题模板（全库通法）
详见 `07_历史材料题通用答题模板.md`，三大模型：
- **五步作答法**：看设问 → 定时空 → 划材料 → 联课本 → 分点作答。
- **六类设问句式**：原因/背景（根本＋具体＋直接）、内容/措施（按政治经济军事文化分层）、意义/影响（积极＋局限＋地位）、评价/启示（一分为二＋从教训反推）、变化/趋势（由……到……、不断……）、比较异同（先同后异）。
- **史料实证判别**：第一手史料（当时实物、档案、出土文物、当事人记载）价值高于第二手（后世史书、教科书、小说影视剧）；孤证不立、多方互证。

## 五、快解 / 速判（草稿快解，仅思路、不写卷面）

详见 `08_历史选择题快解法.md`，每条写清原理/适用/操作/局限。

1. **时间定位法**：原理＝历史最大线索是时间，时间对不上、选项再漂亮也不选。操作＝圈题干时间（含年号/世纪/民国）→ 翻译成朝代/阶段 → 选项事件时间不符直接排除。局限＝课本原文特例要凭史实，不能机械套。
2. **关键词＋三排除法**：排**绝对词**（彻底、完全、全部、唯一、根除、始终、所有——除非课本原文明确这么说）；排**时空错位**（朝代/地点对不上）；排**张冠李戴**（把 A 事件的内容安到 B 事件，如把《马关条约》开厂安到《南京条约》）。剩两个纠结时，选**最贴合题干材料**的，而不是最熟的。
3. **地图/图表/漫画快解**：先读图名、图例、坐标轴、表头、图中文字标注，再由标注锁朝代/事件；不看图名不凭印象选。
4. **组合选择题排除法**：先找最有把握的一个小序号——它肯定错，凡含它的选项全排除；它肯定对，凡不含它的全排除；缩到一个后再验证。
5. **材料题踩点口诀**：「先读设问再读材料；几分写几点；答案＝材料提炼＋课本结论；不整句照抄、不写一大团；原因别漏根本，影响别漏局限，启示扣失败原因。」
6. **分值定点数**：4 分题写 2 点、6 分题写 3 点、8 分题写 4 点；多写不扣分、少写不得分。

## 六、高频易错 / 易混清单（错例 → 正确做法）

- **年代换算**：错把 1840 年当成 18 世纪 → 前两位 18＋1＝19 世纪；错把民国元年当 1911 → 元年是 1912，固定加减 1911；跨公元前/公元后直接相减 → 应两数绝对值相加再减 1。
- **条约张冠李戴**：错把《南京条约》割地写成「割香港」→ 是割**香港岛**；错把「开设工厂」安到《南京条约》→ 是**《马关条约》**；错把五口通商记成沙市重庆 → 广厦福宁上是《南京条约》，四口是《马关条约》。
- **社会性质台阶配错**：错说鸦片战争后完全沦为 → 鸦片战争是**开始**，「完全沦为」是《辛丑条约》后；错把「大大加深」安到《南京条约》→ 是《马关条约》。
- **侵华战争顺序**：错排 → 鸦片战争(1840)→第二次鸦片战争(1856)→甲午(1894)→八国联军(1900)；错把虎门销烟当鸦片战争根本原因 → 它是直接借口，根本原因是英国要打开市场。
- **运动性质判错**：错说洋务运动是资产阶级改革 → 它是**地主阶级洋务派自救运动**；错说戊戌变法是革命 → 是**资产阶级改良**；错说辛亥革命完成反帝反封建 → 它推翻帝制但**没改变半殖民地半封建社会性质**。
- **会议结论配错**：错把「确立毛泽东思想为指导思想」安到遵义会议 → 那是**中共七大**；遵义是确立毛泽东的领导地位、生死攸关转折点。
- **抗战起点配错**：错把九一八当全民族抗战开始 → 九一八 1931 是**局部抗战起点**，全民族抗战开始是 1937 七七事变。
- **革命 vs 改革**：错说俄国 1861 改革是自下而上 → 是沙皇**自上而下**；错把明治维新说成学中国 → 是学欧美（大化改新才学唐朝）；错说美国内战是改革 → 是**第二次资产阶级革命**。
- **工业革命归错**：错把电灯汽车归到第一次工业革命 → 属第二次；错说第一次工业革命科学与技术紧密结合 → 那是第二次特点。
- **国际格局配错**：错把苏联解体当冷战开始 → 苏联解体是**两极结束**，冷战开始是 1947 杜鲁门主义；错把凡尔赛—华盛顿体系说成二战后 → 是一战后。
- **君主专制 vs 中央集权**：错把两者混为一谈 → 一个是皇权 vs 相权（君臣），一个是中央 vs 地方；错说废丞相是雍正 → 废丞相是明太祖朱元璋，雍正设军机处。
- **绝对化表述**：选项出现「彻底、完全、唯一、根除」几乎都错（课本原话除外，如「完全沦为半殖民地」是《辛丑条约》的定论）。
- **商鞅变法误区**：错因商鞅被处死就说变法失败 → 商鞅虽死、新法继续推行，变法是成功的，为秦统一奠定基础。

## 七、名师大白话讲法 / 口诀 / 比喻（可照念，详见 `讲法话术_历史.md`）

- **时空轴记忆**：把朝代做成一条「地铁线」，每站贴一个锚点事件。先背通行朝代歌，再在轴上钉秦统一（前 221）、隋统一（589）、唐（618）、北宋（960）、元统一（1279）、明（1368）、清。做题第一步先问「它在地铁线哪一站」，站错队就排除。
- **朝代歌**：夏商与西周，东周分两段；春秋和战国，一统秦两汉；三分魏蜀吴，二晋前后延；南北朝并立，隋唐五代传；宋元明清后，皇朝至此完。
- **条约钩子口诀**：《南京条约》「割香港岛、五口通商、协定关税」；《马关条约》「割台湾、赔 2 亿、开工厂」；《辛丑条约》「赔 4.5 亿、不许反帝、洋人的朝廷」。
- **半殖民地化台阶口诀**：「开始南京，加深二鸦，大大加深马关，完全沦为辛丑。」
- **君主专制线索口诀**：「秦设相，唐分相，明废相，清军机处到顶。」
- **生活化比喻**：分封制像爸爸把家产分给几个儿子、儿子大了不听爹的；郡县制像公司分店经理由总部任命、随时撤换——所以越到后来中央越集权。科举制像以前当官看你爹是谁（世袭），现在全天下一起考试凭分数上，相当于从「内定」变「统考」。洋务运动像清朝病人只换西药、不换病根（制度），所以吃了药还是没好。半殖民地像家里来了强盗，抢你东西、还逼你签字答应，你还得自己过日子但说了不算。
- **材料题开口三步**：「咱们先别看这段长材料，先看它问啥。」「问啥就回材料里找啥——把时间、人名、政策划出来。」「答的时候①②③分开写，几分大概写几点，别整段抄材料。」
- **高频坑反复念**：不整句照抄材料；不写一大团要分点；原因别漏根本原因、影响别漏消极/局限；启示别写「要好好学习」，要扣着失败原因说。

### 7.1 网上名师招牌套路（精选·已甄别·仅收录现有库未覆盖者）

> 甄别说明：本节只放**现有 4.7/5/6/7 节没有成体系讲过、且对基础薄弱学生确有增量**的方法。凡与本文件已有内容（五步作答、三排除、一分为二、由 A 到 B、朝代歌/条约钩子/半殖民地台阶/君主专制线索/材料题开口三步）重合者，一律不重复收录，清单见本节末。署名只写可核实的平台与链接，不替任何老师编话；无稳定主页者标「平台公开讲法/通用方法」。

- **套路一：审设问指令词——答案来源三判**
  - 来源：光明网·文摘报《中考历史解题思路与答题技巧》（2026-09-12，https://epaper.gmw.cn/wzb/html/content/202609/12/content_25020.html ）明确区分「根据材料／结合所学／根据材料并结合所学」三种指令；学科网 2027 广东汕头中考一轮复习资料同此口径；抖音历史老师公开口播同法。属平台公开讲法，不署个人姓名。
  - 怎么操作：拿到材料先别看正文，先把设问读一遍，圈出指令词——
    - 「**根据材料**（指出/概括）……」→ 答案就在材料里，把关键词划出来、用自己的话概括即可，不用硬搬课本；
    - 「**结合所学**（回答/分析）……」→ 材料只是引子，答案主要回课本对应结论；
    - 「**根据材料并结合所学**……」→ 两边都要，材料信息＋课本结论各占一半。
    然后再带着问题回材料里划时间、人物、政策、转折词（但、然而、虽然）。
  - 原理（为什么）：设问指令直接限定答案出处。先读材料容易被一长串无关信息带偏；先看指令等于先知道「要从哪里找、找多少」，再回去划，命中率高。
  - 适用：所有材料解析题，尤其给两三段长材料的大题。
  - 局限/坑：不能因此跳读材料全文；「结合所学」时课本结论必须回准到统编某册某单元，不能凭印象；「根据材料」题若材料没说全，仍需按分值补课本结论，不是死扣材料一句。

- **套路二：原因/背景题「政经文外」四角度清单＋根本原因往经济上追**
  - 来源：学科网《统编版初中历史 2026 年中考万能答题模板》（https://www.zxxk.com/soft/57018708.html ）给出政治/经济/思想/外部分层；重庆中小学智慧教育平台公开讲义「历史背景＝（国内＋国际）（经济＋政治＋文化）」（https://basic.cq.smartedu.cn/ ）；抖音「历史简答题万能模板」公开口播同法。属平台公开讲法。
  - 怎么操作：问「原因/背景/条件」时，按四个角度想，再扣材料关键词挑两三个写——
    - **政治**：制度、政策、阶级矛盾、政局稳定/动荡、战争；
    - **经济**：生产力、生产关系、经济政策、贸易/市场；
    - **思想文化**：思想解放、科技进步、教育发展；
    - **外部**：国际环境、外国影响、外来压力。
    「根本原因」默认往**经济基础/生产力/生产关系**上追（例：鸦片战争根本原因是工业革命后英国要打开市场，虎门销烟只是直接借口）。
  - 原理：历史事件是多重因素叠加，缺一个角度就漏一个采分点；根本原因是最深层、最稳定的那个，按「经济基础决定上层建筑」通常落在经济/生产力上。
  - 适用：「分析……的原因/背景/条件」类大题（中国史、世界史通用）。
  - 局限/坑：四角度不能全堆上，要扣材料关键词选相关两三个，否则空话不采分；「根本原因」也不是一律套经济——要按统编课本定论走（例：辛亥革命根本原因落民族资本主义发展＋民族资产阶级壮大；西安事变直接原因是民族危机上升）。

- **套路三：比较异同题「分维度对答」**
  - 来源：抖音「同异解题法」公开口播（https://www.iesdouyin.com/share/video/7690540211286353147 ）；易教网《中考历史比较题》（https://www.eduease.com/zixun_info-id-140047.htm ）。属平台公开讲法。
  - 怎么操作：先从下面挑题干涉及的维度——**背景/目的、主体（领导阶级）、内容/措施、性质、结果、影响**；再按维度一对一地写：先答相同点（「二者都……」），后答不同点（「前者……后者……」）。不要东一句西一句。
  - 原理：比较题采分点是「同＋异」成对出现，缺一半丢一半；按维度对答能保证不漏点、不重复。
  - 适用：「比较……和……的异同」「指出……与……的不同」类（如洋务运动 vs 戊戌变法、英美法资产阶级革命、两次工业革命）。
  - 局限/坑：维度要选题干实际涉及的，别硬凑无关维度；相同点和不同点都要写，不能只写不同。

### 7.2 已剔除的「大招/秒杀」及原因

以下几条在抖音/小红书被包装成「秒杀/蒙题大法」，经甄别不采用，且**不得进入规范解答，连草稿快解也不提倡**：

- 摒弃 **「两个选项说法相近就都排除」「选项在题干只字未提就直接排除」**（见抖音「玄学蒙题」，https://www.iesdouyin.com/share/video/7484188544014011648 ）。属「只记结论不讲原理／玄学口诀」——凭感觉操作，换一道题就失效；且「题干没提就排」与材料题「结合所学」要求直接冲突（课本结论本来就不写在材料里），照做会把正确的课本答案排掉。
- 摒弃 **「初中历史不用背、开卷也能满分、选择题不用死记」类营销话术**（抖音多条引流视频）。属「与课标教材冲突／只给结论不讲原理」——2022 年版课标明确要求掌握基本史事、年代、人物、事件；不背史实、只靠技巧，材料题和年代定位题直接无从下手。
- 摒弃 **「万能模板无脑套所有考点」（政治经济思想军事外交……一整页全堆上去）**（见豆丁网/学科网部分付费模板）。属「适用极窄／答非所问」——真正的采分点是扣材料关键词选相关两三个角度，全堆上去反而空洞、不得分，还浪费卷面时间。
