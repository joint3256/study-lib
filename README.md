# 中学学习资料库（初高中 数学 / 物理 / 化学 / 英语 · 全国通用）

这是一套**本地、可离线检索、便于跨设备同步**的中学学习资料库，服务于线上家教备课、给基础薄弱学生讲题、查缺补漏、快速定位知识点。
**只收录初中与高中的数学、物理、化学、英语四科**，其余学科不收录。

- 地区/版本：知识清单以天津现行版本为骨架、按知识点组织、**对全国通用**；另建有《全国版本映射》对接全国主流教材版本（见下）。
- 内容形态：全部为 **Markdown / CSV / JSON 纯文本小文件**，不含大体积 PDF / 图片 / 音频，便于放进私有 Git 仓库或网盘文件夹跨设备同步。
- 最近更新：2026-10-10（新增 全国版本映射、方法套路库）。

## 三·补二、方法套路库（题型 → 怎么做）

`方法套路/` 是可直接拿去讲题的速查库，共 **188 个方法/模型**：初中数学 34、高中数学 37（含 4 个"快解·超纲"）、物理 54（含 2 超纲）、化学 24、英语 39。每个方法六块齐全：方法名 / 适用题型 / 原理（讲清为什么）/ 操作步骤 / 例题完整演示（结果均验算）/ ❌易错提醒。

`方法套路/讲法话术*.md` 把 B站/抖音/小红书/公众号公开免费内容里名师的解题套路与"大白话"讲法提炼成话术（口诀、比喻、问答引导、高频坑）；只提炼公开免费内容、未搬运付费课程，获取不到的已在"未能获取清单"如实说明。

## 四、怎么快速找东西（推荐路径）

1. **想看某册教材原文** → `同步清单/教材同步清单.md` → 找学段/学科/册次 → 点"官方在线链接"。
2. **想讲某个知识点 / 找公式 / 找题型** → 进 `知识清单/<学段>/<学科>/`，打开对应"册"文件，按"章 → 六要素"定位；
   - 不知道在哪一册：先看该学科目录下的 `README.md`（板块索引）。
3. **想知道某类题怎么做、第一步干什么** → 进 `方法套路/`（先看其 `README.md`），按学科与题型找方法；想要"大白话"讲法/口诀/比喻 → `方法套路/讲法话术*.md`。
4. **学生用的是其他版本教材** → 进 `同步清单/全国版本映射/`，用该版本章节映射找到对应通用知识点，再回到知识清单/方法套路。
5. **全文检索**：在资料库根目录用任意编辑器/命令行做关键词搜索（如搜"二次函数""欧姆定律""非谓语动词"），即可定位到具体章。
6. **想确认范围是否超纲** → 对照 `课标/_课标说明.md` 中对应课程标准。

## 五、跨设备同步（本地要有、多设备可用）

资料库是纯文本、体积小，两种常用方式：
- **私有 Git 仓库（推荐，带版本历史）**：在 GitHub / Gitee 建一个**私有仓库**，把本目录纳入版本管理，各设备 `clone/pull/push` 即可。
- **网盘同步文件夹**：把本目录放进网盘（坚果云、OneDrive 等）的同步目录，多设备自动同步。

> 仓库的创建与访问令牌（Token）由使用者自行办理；本资料库本身不内置任何账号或密钥。更新内容时，先遵循 `知识清单/_编写规范与模板.md`，保持六要素格式一致。

## 六、维护与边界

- 新增/修改知识点：先读 `知识清单/_编写规范与模板.md`，沿用统一标题与深度；每处事实、公式、方程式须可核验，宁可标注"以教材目录为准"也不臆造章号或结论。
- 每个学科板块的 `资料来源.md` 记录课标、教材版本与实际参考的开源资源（含协议）；全库内容依据课标与教材目录自行编写，未复制受版权保护的教材或教辅正文。
- 明确不做：不收录初高中数理化英以外学科；不存放全本教材/盗版教辅；不生成 Word/PPT。
