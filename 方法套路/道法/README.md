# 方法套路库 · 道德与法治（道法）

面向线上家教的"**题型 → 方法套路**"速查库，与按知识点组织的《知识清单》（`知识清单/初中/道法/` 七上~九下共 6 册）互补：
知识清单回答"**观点是什么**"，本库回答"**这类道法题怎么做、第一步干什么**"。

每个方法/模型条目统一六块：**①方法/模型名 ②适用题型（识别特征） ③原理（讲清为什么） ④操作步骤 ⑤例题完整演示（题干→分点解答→答案） ⑥❌易错提醒**。
面向基础薄弱学生：先大白话讲原理，步骤可照做；材料题给简短材料，答案分点、可直接誊写。

## 二、与知识清单的分工

- 拿到一道道法题，先判断它考"是什么"还是"怎么做"：
  - 问观点本身（某制度/某权利/某原则是什么、为什么这么规定）→ 去 `知识清单/初中/道法/` 对应册查。
  - 问材料怎么对应观点、选择题怎么排、大题分几点、主体是谁 → 来本库。
- 制度名称、国家机关职权、法条、刑罚种类等关键表述一律与知识清单及现行宪法、法律保持一致；遇冲突以统编教材通行表述为准并回查知识清单对应册。

## 三、合规与使用须知

- 方法主体依据《义务教育道德与法治课程标准（2022 年版）》+ 统编（部编）教材公开目录 + 现行宪法与法律、党的公开文件**自行组织编写**，不复制教材全本、不收盗版"学霸笔记"扫描件、不搬运付费课程内部讲义。
- 名师讲法部分仅提炼 B站/抖音/公众号等**公开免费**内容里的"方法/思路"并用自己的话重述，来源见 [资料来源.md](资料来源.md)；公开渠道确实获取不到的在讲法话术文档末尾"未能获取清单"如实列出。
- 观点、制度、国家机构、法条均与统编教材和现行法律一致、可核对，不编造。
