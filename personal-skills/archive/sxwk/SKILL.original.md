# 数学网课指令（数学试卷 → 网课讲解 Word）

## 输入与产出
- 输入：1 份教材 Word（知识点来源）＋ N 张题目照片（含手写，可能横拍/倒置）。
- 产出：1 份 Word（**不做 PPT**），网课风格；面向约 50/100、基础弱、不爱思考的孩子，循序渐进、不超纲，让孩子听懂、一目了然、提升兴趣。

## 1. 提取
- 先把横拍、倒置的照片逐张转正，建立干净工作区。
- 逐题提取【原题原文 ＋ 原图】，**彻底剔除一切手写**：孩子写的答案、画歪的辅助线、打勾、分数等一律不要。

## 2. 每题固定结构（严格按此顺序）
1. **题目原文 ＋ 规范图**。
2. **网课互动**：橙色＝老师提问，绿色＝孩子短答，灰色＝“答不上就提示”；只在关键处问，每题 2~4 问，不每句都问；多鼓励、提自信。
3. **知识点（蓝色，逐条）**：从教材里找，写清定义 / 原理 / 公式。
4. **易错点（黄色，逐条）**。
5. **举一反三（绿色）**：同知识点、同难度、不一样的新题，给答案 ＋ 详细过程。
6. **一句鼓励**。

## 3. 图片
- 几何图按原图规范重画（干净、无手写），比例 / 点位 / 标注与原图一致。
- 辅助线、延长线及延长线上的点都画全，用不同颜色标出（延长线用虚线 ＋ 点），或在图旁另附一张标注图；每图配图注。

## 4. 套（组）末总结
- 每一套 / 组题结束加一个知识点总结：逐条列知识点 ＋ 标注用到本组哪几道题 ＋ 对照教材章节。

## 5. 交付前自检
- 先跑 Word 结构审计（audit，退出码为 0）。
- 再转 PDF 逐页视觉核对：图无手写、辅助线 / 延长线齐全、答案正确、套末总结对应题号。
- 全部无误后用 present_files 一次性交付完整 .docx；不发半成品，不在未做完时提前交付。
