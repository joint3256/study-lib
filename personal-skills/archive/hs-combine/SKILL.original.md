# hs-combine · 高中数学综合讲解（彩色 Word ＋ 可照念口播，无问答）

## 一、定位与产出
- 输入：N 张高中数学题目照片（含手写，可能横拍/倒置）＋可选教材文件。
- 产出：1 份 Word（**不做 PPT**）。融合 gaoshu1 的先补旧知识/原理讲透 与 hs-talk 的口播讲法，**删掉师生一问一答**，全部改成可直接朗读的陈述讲解。文档既能存档发家长，也能照着面对面讲课。
- 面向基础薄弱、一听就会一做就废的高中生，大白话、不跳步、多鼓励。
- **规范解答（第4块）只用高中课内、高考认可的方法**；大学/超纲方法只能出现在第5块草稿快解并明确标注阅卷风险。

## 二、自动检索知识库（做题前先查，路径见 references/知识库检索.md）
按以下顺序取材，知识点优先用课本/知识清单原文，不凭空编：
1. `学习资料库/知识清单/高中数学/`：必修第一册、必修第二册、选择性必修第一/二/三册，按册取结构化知识点。
2. `学习资料库/方法套路/高中数学/01~08.md`：按题型取模型、步骤、快解（集合逻辑不等式／函数／三角解三角形／数列／向量立体几何／解析几何／导数／概率统计与选填快解）。
3. `学习资料库/方法套路/讲法话术.md`：取名师大白话讲法、口诀、比喻。
4. 教材原文：`学习资料库/教材/高中/数学·人教A版/`，或用户当条消息附的教材 docx（用 python-docx 读取相关章节）。
5. `学习资料库/课标/`：需要权威依据时查高中数学课程标准。
- 引用课本内容要标注「来源：人教A版 必修/选必 X 第 X 章」；库里确实没有才自己总结，并标注「资料无原文，模型总结」。

## 三、每道题固定结构（8 块，整行底色块，不是只改字色）
| # | 板块（Word 里用此文字标题） | 整行底色 / 字色 | 内容要求 |
|---|---|---|---|
| 1 | 【题目】 | F4F7FB / 222222 | 原题原文＋规范图/表，保留全部选项、空格；彻底剔除手写（答案、勾、分数、画歪辅助线）。 |
| 2 | 【知识点】 | DEEBF7 / 1F4E79 | 本题用到的课本定义、定理、公式，写原理；标注教材来源。涉及旧知识孩子可能不会，先用一两句＋小例子补会（递归补缺）。 |
| 3 | 【解题思路】 | E2EFDA / 375623 | 名师视角还原思考顺序：拿到题先看什么、为什么想到这个模型/定理；立体几何点明建系方法、解析几何点明设线方式。大白话、可照念。 |
| 4 | 【规范解答】 | 白底 / 222222 | 高考标准书写，①②③一句一步，每步写依据（定理/公式名），不跳步；立体几何建系、解析几何设而不求等按高考得分点写全。 |
| 5 | 【草稿快解】 | FCE4D6 / C55A11 | 提速法（特值/端点代入、特殊化、结论秒杀、对称/极限分析等），写清①原理②适用③操作④局限；**首行标注「仅草稿演算，禁止直接写卷面」**；含大学/超纲方法时额外标注「超纲、有阅卷风险」。 |
| 6 | 【易错点】 | FFF2CC / BF8F00 | 最易错/易混处＋错例＋正确做法（如端点开闭、多解、分类遗漏、符号方向）。 |
| 7 | 【答案】 | FDECEA / C00000 加粗 | 最终答案，红色加粗、浅红整行底。 |
| 8 | 【举一反三】 | E4DFEC / 5B3A8C | 同知识点、同难度、不一样的新题，给答案＋详解；优先取教材/知识清单里的同源习题。 |

- 每块文字都写成**能直接念出口**的口语陈述句，不出现“老师问/学生答”。
- 题与题之间可加一句鼓励（陈述式，不用 emoji）。
- 验算/逻辑闭环并入相关板块：把答案代回原题真算一遍，确认等号、边界条件、分类是否完整。

## 四、几何图规范
- 按原图规范重画（干净、无手写），比例/点位/标注与原图一致；立体几何按建系结果配图、辅助线画全；解析几何图形坐标准确；每图配图注。
- 可用颜色高亮关键边、角、法向量、交点，帮孩子一眼看出结构。

## 五、格式与讲法硬规则
- 字体：中文宋体、标题黑体、英文/数字/公式 Times New Roman；正文约 11.5pt、大题标题约 13.5pt。
- 整行底色块（非仅字色），色值按第三节；正文近黑 222222、提示灰 595959、表头深蓝底白字。
- **不用 emoji**；做 Word 不做 PPT；图片比例与原图一致。
- 关键数值/结果必须用 calculator 或 sympy 现算验证，不心算；答案与每步中间值一致。
- 解答题必须写全过程，不能只写特值/秒杀结论；特值能排除、能验证，但通常不能单独证明，需配规范推导。

## 六、套末总结
每套/每组题结束加：知识点总结表（知识点｜用到的题号｜教材册别章节）、必背公式/定理/结论清单、本套模型与快解清单、集中易错提醒。

## 七、自检与交付
1. 先跑 Word 结构审计（audit，退出码 0）。
2. 再转 PDF 逐页视觉核对：图无手写、辅助线/建系齐全、答案正确且与中间值一致、端点开闭/多解/分类已查、整行色块、无问答与 emoji、举一反三与套末总结对应题号。
3. 全部无误后用 present_files **一次性交付完整 .docx**；不发半成品、不提前交付。
