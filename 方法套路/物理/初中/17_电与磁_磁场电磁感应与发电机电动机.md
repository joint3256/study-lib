# 初中物理方法套路库 · 电与磁（磁场、电磁感应与发电机电动机）

---

## 模型 1：磁场、磁感线与奥斯特实验

### ① 方法/模型名
"磁体外部 N→S"磁感线 + 安培定则判 N 极

### ② 适用题型
题干出现"磁感线方向、小磁针指向、通电螺线管 N/S 极、电流方向与磁极关系、电磁铁磁性强弱、奥斯特实验"。

### ③ 原理/公式
- 磁体周围存在磁场，磁场方向规定为小磁针静止时 N 极所指方向。
- 磁感线：磁体外部从 N 极出发回到 S 极；磁感线越密磁场越强。
- 奥斯特实验：通电导线周围存在磁场（电流的磁效应），说明电可以生磁。
- 安培定则（右手螺旋定则）：右手握住螺线管，四指指向电流方向，大拇指所指那端就是 N 极。
- 电磁铁磁性强弱：电流越大、线圈匝数越多，磁性越强；插入铁芯磁性大大增强。

### ④ 操作步骤
1. 已知电流方向 → 用安培定则判 N 极。
2. 已知 N 极 → 反推电流方向。
3. 小磁针 N 极指向 = 该点磁场方向 = 磁感线切线方向。
4. 电磁铁磁性强弱判断：看电流大小、匝数多少、有无铁芯。

### ⑤ 例题完整演示
**题干**：通电螺线管中电流从左端流入、右端流出，判断螺线管 N 极在哪端。

- 右手握住螺线管，四指沿电流方向（左端流入→正面向上→右面向下→右端流出）。
- 大拇指指向右端 → 右端是 N 极。
- **答案：右端是 N 极。**

### ⑥ 易错提醒
- ❌ 磁感线是真实存在的——磁感线是假想曲线，用来描述磁场，实际不存在。
- ❌ 小磁针 S 极指向磁场方向——小磁针 N 极指向才是磁场方向。
- ❌ 安培定则用左手——必须用右手。
- ❌ 电磁铁磁性与匝数无关——匝数越多磁性越强。

## 模型 2：电磁感应与发电机（机械能→电能）

### ① 方法/模型名
"闭合电路+部分导体+切割磁感线"三条件判感应电流

### ② 适用题型
题干出现"导体在磁场中运动、电流表指针偏转、发电机原理、电磁感应现象、产生感应电流条件、感应电流方向与什么有关"。

### ③ 原理/公式
- 电磁感应：闭合电路的一部分导体在磁场中做**切割磁感线运动**时，导体中产生感应电流。这是法拉第发现的。
- 产生感应电流三条件：(1) 电路闭合；(2) 一部分导体（不是整个电路都在磁场中）；(3) 做切割磁感线运动。
- 能量转化：机械能 → 电能。
- 感应电流方向：与导体运动方向和磁场方向有关。只改变其中一个，电流方向改变；同时改变两个，电流方向不变。
- 发电机原理：电磁感应。发电机线圈在磁场中转动，切割磁感线产生交变电流（交流电）。

### ④ 操作步骤
1. 看电路是否闭合（有电流表/用电器形成回路）。
2. 看导体是否在磁场中做切割磁感线运动（导体运动方向与磁感线方向不平行）。
3. 两条件都满足 → 产生感应电流 → 电流表偏转。
4. 判断方向：分别看磁场方向和导体运动方向是否改变。

### ⑤ 例题完整演示
**题干**：U 形磁铁中悬挂一根导体棒，导体棒与电流表组成闭合回路。以下哪种情况电流表指针偏转？A. 导体棒静止；B. 导体棒沿磁感线方向上下运动；C. 导体棒垂直磁感线左右运动；D. 导体棒沿磁感线方向前后运动。

- A：静止不切割 → 无电流。
- B：沿磁感线方向运动不切割 → 无电流。
- C：垂直磁感线运动 = 切割 → 有感应电流，指针偏转。
- D：沿磁感线方向不切割 → 无电流。
- **答案：C。**

### ⑥ 易错提醒
- ❌ 只要导体在磁场中运动就产生感应电流——必须做切割磁感线运动，且电路闭合。
- ❌ 整个电路都在磁场中运动也产生感应电流——必须是"一部分导体"切割，整个电路平动时磁通量不变，无感应电流。
- ❌ 发电机是电能→机械能——发电机是机械能→电能（电磁感应）；电动机才是电能→机械能。
- ❌ 同时改变磁场方向和导体运动方向，电流方向改变——同时改变两个因素，电流方向不变。

## 模型 3：电动机（电能→机械能）与圆盘发电机模型

### ① 方法/模型名
"通电导体在磁场中受力"判电动机 vs "电磁感应"判发电机

### ② 适用题型
题干出现"通电导体在磁场中运动、电动机原理、扬声器原理、圆盘发电机、铜盘转动产生电流、换向器"。

### ③ 原理/公式
- 磁场对通电导体的作用：通电导体在磁场中受到力的作用。能量转化：电能 → 机械能。这是电动机原理。
- 导体受力方向：与电流方向和磁场方向有关。只改变其中一个，受力方向改变；同时改变两个，受力方向不变。
- 电动机：利用通电线圈在磁场中受力转动的原理。有电源供电。
- 发电机：利用电磁感应原理。无外部电源，靠线圈转动产生电流。
- 圆盘发电机模型：铜盘可看作沿半径方向排列的大量导体棒。铜盘在垂直盘面的磁场中转动时，每根半径方向导体棒都在切割磁感线，圆心与边缘之间产生感应电动势。从轴和边缘各引出一个电极，就可以对外供电。铜盘持续转动时，半径方向导体棒不断切割，感应电流方向不变（不像往复运动那样周期性变化）。

### ④ 操作步骤
1. 判断是电动机还是发电机：看题干有没有外部电源供电。
   - 有电源 → 通电导体受力 → 电动机（电能→机械能）。
   - 无电源，靠运动产生电流 → 电磁感应 → 发电机（机械能→电能）。
2. 圆盘发电机：把铜盘拆解为无数根沿半径方向的导体棒，每根棒切割磁感线，圆心与边缘之间有电压。
3. 感应电流方向/受力方向判断：分别看磁场方向和电流方向（电动机）/导体运动方向（发电机）是否改变。

### ⑤ 例题完整演示
**题干**：水平铜盘安装在竖直转动轴上，磁场垂直盘面由左向右。铜盘顺时针匀速转动（从左往右看），铜盘边缘和轴各接一个电极组成回路。判断回路中是否有感应电流，方向是否周期性变化。

- 铜盘可看作沿半径方向的大量导体棒并排。
- 铜盘转动时，每根半径方向导体棒都在垂直切割磁感线 → 产生感应电流。
- 铜盘持续顺时针转动，每根导体棒的运动方向相对磁场方向不变（只是位置轮换）→ 感应电流方向不变。
- **答案：回路中有感应电流，方向不周期性变化（直流）。**

### ⑥ 易错提醒
- ❌ 电动机和发电机原理混淆——电动机有电源，是通电受力；发电机无电源，是电磁感应生电。
- ❌ 圆盘发电机电流方向周期性变化——铜盘持续转动，半径方向导体棒不断切割，方向不变，输出直流电。
- ❌ 扬声器是电磁感应——扬声器工作时音频电流通过线圈，线圈在磁场中受力振动纸盆发声，是电动机原理（电能→机械能→声能）。
- ❌ 动圈式话筒是电动机原理——话筒说话时声音使线圈在磁场中振动切割磁感线产生电流，是发电机原理（声能→机械能→电能）。
