# 方法套路库 · 总索引

面向线上家教的"**题型 → 方法套路**"速查库，与按知识点组织的《知识清单》互补：知识清单回答"这块知识是什么"，本库回答"这类题怎么做、第一步干什么"。所有方法条目统一含六块：**方法名 / 适用题型 / 原理（讲清为什么）/ 操作步骤 / 例题完整演示 / ❌易错提醒**。

> 面向基础薄弱学生：先大白话讲原理，再给可照做的步骤，例题数字简单、结果均经验算。
> 高中用到大学或课标外结论的快解法，一律标注"**快解·超纲**"并同时给课标内正统解法与阅卷风险。

## 三、合规与使用须知

- 方法库主体为依据课标与教材体系**自行组织编写**；引用的开源仓库（含许可证）见各板块 `资料来源.md`，仅采纳 MIT / Apache / CC0 / CC-BY 等宽松协议或许可证可确认者。
- 名师部分只提炼其**公开免费**内容里的"方法/思路"并用自己的话讲清原理；**未下载、搬运其付费课程或内部讲义**，未整段复制独家内容。
- 本库不含任何盗版商业教辅、付费"学霸笔记"扫描件，不含 PDF/音视频/图片等二进制文件。
- 公式用 LaTeX；例题结果均经工具验算，但用于正式教学前仍建议对照学生所用版本教材核对术语与符号。
