## 每个 Unit 的六要素（固定标题，缺一不可）

1. `### 一、模块地图与话题主线` —— 板块构成 + 话题/功能意念。
2. `### 二、核心词汇与短语` —— 高频词（词性+释义+搭配+例句），超纲标 `*`。
3. `### 三、语法要点` —— 结构(form)+用法(use)+例句+易错。
4. `### 四、话题表达与写作` —— 功能句/语块/范文或框架；选必含概要写作与读后续写方法。
5. `### 五、常考题型与解题方法` —— 听力/阅读/七选五/完形/语法填空/应用文/读后续写，题型→步骤→示例。
6. `### 六、易错易混` —— ❌/✅ 成对。

## 语法学习路线（给家教的讲解顺序建议）

```
必修一：句子成分 + 五种基本句型 + 六大时态起步
  ↓
必修二：时态进阶（过去进行/完成）+ 被动语态 + 情态动词
  ↓
必修三：三大从句起步（定语从句 + 名词性从句）
  ↓
选必一：从句深化（非限制性/表语/同位语/状语从句）
  ↓
选必二：非谓语（to do / doing）+ 虚拟语气
  ↓
选必三：分词作定语状语 + 特殊句式（倒装/强调/省略）
  ↓
选必四：主谓一致 + it/there be + 构词法（高考冲刺）
```

## 写作能力进阶

- **必修**：应用文（书信/通知/报道/演讲稿）+ 记叙文，重格式与功能句。
- **选必**：增加**概要写作（summary，三步法：找主题句→合并删例→连接成 30 词）**与**读后续写（continuation，两段式：第一段推情节、第二段升主题；情绪曲线 + 衔接语块）**。

## 检索提示

- 查某个语法点：直接在文件内搜关键词，如"定语从句""虚拟语气""非谓语""倒装"。
- 查某个话题写作：搜"功能句""写作框架""读后续写"。
- 基础薄弱学生：按"先通俗后严谨"顺序，先看每单元"模块地图"建立全局，再攻"语法要点"和"易错易混"。
