##### 【方法】二次函数三式互化与图像定位法

- **适用题型**：二次函数图像判断、对称轴/顶点/交点快速定位、不等式与二次函数结合题。
- **原理（为什么）**：二次函数有三种"长相"——一般式、顶点式、交点式。不同形式暴露不同信息：一般式能看出开口方向和y轴截距；顶点式直接读出顶点坐标和对称轴；交点式直接读出与x轴的两个交点。就像拼拼图，每块拼图（每种形式）都有自己的特征面，你得知道哪块拼图该翻哪面。
- **操作步骤**：
  1. 看题目给的是哪种形式，先读出它能直接给的信息；
  2. 如果需要的信息它给不了，就转成另一种形式；
  3. 一般式→顶点式：配方（提a、配平方、整理常数项）；
  4. 一般式→交点式：求根公式解出两个根x₁、x₂，写成a(x-x₁)(x-x₂)；
  5. 三种形式都能读出开口方向（看a的正负）。
- **例题演示**：
  已知 f(x) = x² - 4x + 3，求顶点坐标、对称轴、与x轴交点。
  - 第一步：配方。f(x) = (x² - 4x + 4) - 4 + 3 = (x-2)² - 1
  - 第二步：顶点式读出顶点 (2, -1)，对称轴 x = 2
  - 第三步：求根。x² - 4x + 3 = 0 → (x-1)(x-3) = 0 → x₁=1, x₂=3
  - 与x轴交点：(1, 0) 和 (3, 0)
  - 开口向上（a=1>0）
- **易错提醒**：
  - 配方时常数项算错——提a之后，括号里加多少就要在括号外减多少乘a；
  - 顶点式的顶点坐标符号反了——(x-h)²+k 的顶点是 (h, k)，h前面是减号；
  - 忽略判别式Δ<0时没有实根，不能写成交点式。
- **口诀/比喻**："二次项系数是抛物线的脾气——正的向上翘，负的向下趴。"
- **高频坑**：题目给一般式让判断对称轴，很多学生直接背 -b/2a 算错符号；用顶点式一眼就能看出来。

##### 【方法】充分条件与必要条件的"推导方向"判断法

- **适用题型**：命题关系判断（充分/必要/充要）、逻辑用语选择题。
- **原理（为什么）**：条件推得结论 = 充分性成立；结论推得条件 = 必要性成立。就像"中国人→亚洲人"，中国人能推出是亚洲人（充分成立），但亚洲人推不出是中国人（必要不成立）。
- **操作步骤**：
  1. 先分清谁是条件p，谁是结论q；
  2. 判断 p⇒q 是否成立（充分性）；
  3. 判断 q⇒p 是否成立（必要性）；
  4. 两个都成立 = 充要；只有p⇒q = 充分不必要；只有q⇒p = 必要不充分；都不成立 = 既不充分也不必要。
- **例题演示**：
  "x>2" 是 "x²>4" 的什么条件？
  - p: x>2，q: x²>4
  - p⇒q：x>2 → x²>4 ✓（充分成立）
  - q⇒p：x²>4 → x>2？不对，x=-3也满足x²>4但不满足x>2（必要性不成立）
  - 结论：充分不必要条件
- **易错提醒**：
  - 搞反谁推谁——"A是B的什么条件"里，A是条件，B是结论，方向是A→B；
  - 忽略负数情况——平方大不代表原数大。
- **生活化比喻**："有身份证就能进考场（充分），但进考场的人不一定都带了身份证（必要不成立）。"

##### 【方法】"缺谁找谁"——正弦定理快速切入法

- **适用题型**：解三角形中已知边和角混合条件，求某条边或某个角。
- **原理（为什么）**：正弦定理 a/sinA = b/sinB = c/sinC 本质是"边和它对面的角"的比值固定。题目里给了几条边、几个角，你要求的那个量如果不在已知的"边-对角"配对里，就必须通过已知的配对搭桥过去。所以"缺谁找谁"的意思是：要求谁，就去找谁所在的那组比例里，另外三个量知不知道两个。
- **操作步骤**：
  1. 先把题目里已知的边和角全部标在三角形图上；
  2. 看要求的边（或角）对面是哪个角（或边）；
  3. 找一组已知的"边+对角"作为基准比值；
  4. 列比例式：未知边 / sin(对角) = 已知边 / sin(已知对角)；
  5. 解出未知量。
- **例题演示**：
  在△ABC中，已知 B=60°，C=45°，b=√6，求c。
  - 第一步：已知 b=√6 对应角B=60°（这是一组完整配对）
  - 第二步：要求c，c对应角C=45°
  - 第三步：列比例 c/sinC = b/sinB
  - 第四步：c / sin45° = √6 / sin60°
  - sin45°=√2/2，sin60°=√3/2
  - c = √6 × (√2/2) / (√3/2) = √6 × √2 / √3 = √12/√3 = √4 = 2
  - 答案：c = 2
- **易错提醒**：
  - 找错对应关系——边a对应角A，边b对应角B，别张冠李戴；
  - 用正弦定理求角时注意可能有两解（SSA情况），要判断是否合理；
  - 题目给的是cos值时，先转成sin值再代。
- **口诀**："缺谁找谁，谁不在就找谁。题里有b和c，缺a就找a。"
- **高频坑**：看到题目条件多就慌，其实只要先把已知的"边-对角"配对圈出来，思路立刻就清晰了。

##### 【方法】命题人教学法（逆向拆题法）

- **适用题型**：所有中档题、压轴题的思路切入。
- **原理（为什么）**：学生刷题慢、换个题型就不会，是因为一直在"做题人视角"——见招拆招。出题人视角则反过来：这道题想考哪个考点？条件是怎么埋的？学生会在哪一步自己绕进去？阅卷人怎么给分？同一个出题思路会变出哪些题型？站在这个角度看，题目就不是千变万化的了，而是"同一个考点换了件衣服"。
- **操作步骤**（三步破题法）：
  1. **定位考点**：这道题到底在考哪个知识点？（从答案反推：标准答案用到了什么公式、什么定理？）
  2. **匹配模型**：这个考点我学过哪类题型？有没有对应的解题模板？
  3. **规范书写**：按阅卷标准写步骤，踩分点一个都不能少。
- **例题演示**：
  已知函数 f(x) = x³ - 3x + 1，求在点 (2, 3) 处的切线方程。
  - 第一步（定位考点）：考的是"导数的几何意义——切线斜率=导数值"
  - 第二步（匹配模型）：切线方程三步走——求导→代切点横坐标得斜率→点斜式写方程
  - 第三步（规范书写）：
    - f'(x) = 3x² - 3
    - f'(2) = 3×4 - 3 = 9（斜率k=9）
    - y - 3 = 9(x - 2)
    - 整理：y = 9x - 15
- **易错提醒**：
  - 切点不在曲线上的情况（"过某点的切线"≠"在某点处的切线"）——要先设切点再列方程；
  - 导数算错（特别是复合函数求导漏层）；
  - 大题不写定义域。
- **话术**："知识点是课本告诉你是什么，考点是出题人告诉你会怎么考。80分和110分的差距，就是前者记住了知识点，后者能在题目里识别考点。"
- **高频坑**：改错题只抄正确答案，不改思路——下次换个角度出又懵了。

##### 【方法】整体换元法（三角函数求参数范围）

- **适用题型**：y = Asin(ωx + φ) 型函数的单调性、对称轴、最值问题。
- **原理（为什么）**：复杂的复合三角函数看起来参数很多很吓人，但只要设 t = ωx + φ，它就变回了最简单的 y = Asin t。原来的所有性质（单调性、对称轴、最值）都是关于t的，你只需要把x的范围翻译成t的范围，然后在t的世界里用最基础的正弦函数性质解题就行。
- **操作步骤**：
  1. 设 t = ωx + φ；
  2. 根据x的范围算出t的范围；
  3. 在 y = Asin t 的基础正弦函数上找答案；
  4. 把t换回x，得到最终结果。
- **例题演示**：
  求 f(x) = sin(2x + π/6) 在 x∈[0, π/2] 上的值域。
  - 第一步：设 t = 2x + π/6
  - 第二步：x∈[0, π/2] → 2x∈[0, π] → t∈[π/6, 7π/6]
  - 第三步：y = sin t 在 t∈[π/6, 7π/6] 上的值域
    - t=π/2时取最大值1
    - t=7π/6时取最小值 sin(7π/6) = -1/2
  - 第四步：值域为 [-1/2, 1]
- **易错提醒**：
  - 换元后t的范围算错（特别是系数和符号）；
  - 忘记看A的正负——如果A是负的，最值要反过来。
- **话术**："设个t，把复杂函数变回最简单的正弦函数，难题一下就降级了。"

##### 【方法】圆上切线"留一带一"法

- **适用题型**：过圆 x² + y² = r² 上一点 P(x₀, y₀) 求切线方程。
- **原理（为什么）**：圆的切线方程其实有一个很巧妙的规律。圆方程 x² + y² = r² 里，x² = x·x，y² = y·y。过圆上一点 (x₀, y₀) 的切线方程就是：把其中一个x换成x₀，把其中一个y换成y₀。也就是 xx₀ + yy₀ = r²。为什么？因为切线垂直于过切点的半径，半径斜率是 y₀/x₀，所以切线斜率是 -x₀/y₀，用点斜式推出来就是这个结果。这个方法对圆心不在原点的圆（如 (x-a)²+(y-b)²=r²）也类似：(x-a)(x₀-a)+(y-b)(y₀-b)=r²。
- **操作步骤**：
  1. 确认给定点在圆上（代入圆方程成立）；
  2. 圆方程里每个平方项拆成两个相同变量相乘；
  3. 每个变量"留一个、带一个"——留原式里的x和y，带切点坐标x₀和y₀；
  4. 写出切线方程。
- **例题演示**：
  求过圆 x² + y² = 25 上一点 (3, 4) 的切线方程。
  - 第一步：验证 3² + 4² = 9+16 = 25 ✓ 在圆上
  - 第二步：x²→x·x，y²→y·y
  - 第三步：留x带x₀=3，留y带y₀=4 → 3x + 4y = 25
  - 验证：圆心(0,0)到直线3x+4y-25=0的距离 = |-25|/5 = 5 = r ✓
- **易错提醒**：
  - 点不在圆上（在圆外）时不能直接用这个公式，要先设切点；
  - 圆心不在原点时要写成 (x-a)(x₀-a)+(y-b)(y₀-b)=r²，不能直接套xx₀+yy₀=r²；
  - 直线方程最后要整理成一般式或斜截式。
- **口诀**："留一代一，平方拆开，一个留原式，一个带切点。"
- **高频坑**：大题里不能直接写"由留一带一得……"，还是要按点斜式完整推导，这个方法用来快速验算或选填提速。

##### 【方法】试根法分解三次多项式

- **适用题型**：三次及以上多项式因式分解，特别是导数题中需要因式分解求零点。
- **原理（为什么）**：对于整系数三次多项式 ax³+bx²+cx+d，如果有有理根 p/q（p是常数项的因数，q是首项系数的因数），那就能分解出一个一次因式 (qx-p)。核心思想是"降次转化"——把不会的三次问题，转化成熟悉的二次问题。
- **操作步骤**：
  1. 写出常数项d的所有因数和首项系数a的所有因数；
  2. 组合成 p/q 的可能值，逐个代入试；
  3. 试出一个根x=r后，说明有因式 (x-r)；
  4. 用多项式除法或待定系数法分解出二次因式；
  5. 二次多项式继续分解。
- **例题演示**：
  分解 f(x) = x³ - 3x + 2
  - 第一步：常数项2的因数：±1, ±2
  - 第二步：试 x=1：1-3+2=0 ✓ 根是x=1
  - 第三步：有因式 (x-1)
  - 第四步：待定系数：x³-3x+2 = (x-1)(x²+ax+b)
    - 展开：x³ + ax² + bx - x² - ax - b = x³ + (a-1)x² + (b-a)x - b
    - 对比系数：a-1=0 → a=1；-b=2 → b=-2
  - 第五步：x² + x - 2 = (x+2)(x-1)
  - 最终结果：f(x) = (x-1)²(x+2)
- **易错提醒**：
  - 试根的时候正负号都要试，别只试正数；
  - 试出来的根可能是重根；
  - 待定系数法对比系数时要仔细，特别是常数项的符号。
- **话术**："把三次降成二次，把一个不会的新东西转化成会的简单的已知的东西——这就是转化思想。"

##### 【风格】"记核心、练模型"学习法

- **公式地图→题型地图**：高中数学400多个常考题型，靠背公式记不完，要把每个题型和对应的方法绑定。
- **模型化补形法**：看到题目中的线索，锁定特殊模型（如全等三角形、相似三角形、特殊角度），把未知量转化为模型中已知的量，跳过复杂证明。
- **反命题思维**：站在命题人角度想"这道题到底想考什么核心考点，设置了哪些陷阱来迷惑我"。
- **计算可视化**：从代数和几何两个维度理解不等式和函数图像，让分类讨论有据可依。

**讲法定位**：计算基本法为特色，圆锥曲线从基础到压轴系统讲解。适合中档学生突破计算关。

---

##### 【方法】圆锥曲线大题五步法（标准联立流程）

- **适用题型**：椭圆/双曲线与直线相交，求弦长、面积、中点、斜率等常规大题。
- **原理（为什么）**：高考圆锥曲线大题80%以上都是同一个套路——设直线、联立方程、用韦达定理。不管题目问的是什么，只要是直线和曲线相交的问题，核心都是"联立之后用韦达定理表示出x₁+x₂和x₁x₂"。题目问的其他东西（弦长、面积、中点）都只是在这个基础上再翻译一下。
- **操作步骤**：
  1. **设直线**：根据条件设直线方程（注意斜率不存在的情况要单独讨论）；
  2. **联立**：把直线方程代入曲线方程，整理成关于x（或y）的一元二次方程；
  3. **写Δ**：判别式大于零才有两个交点，先写Δ>0；
  4. **韦达定理**：写出 x₁+x₂ 和 x₁x₂；
  5. **找关系列式子**：把题目要求的目标（弦长/面积/中点/斜率）用 x₁+x₂ 和 x₁x₂ 表示出来，代入求解。
- **例题演示**：
  已知椭圆 x²/4 + y² = 1，直线 y = x + 1 与椭圆交于A、B两点，求弦长|AB|。
  - 第一步：设直线 y = x + 1（斜率存在）
  - 第二步：联立。代入椭圆：x²/4 + (x+1)² = 1
    - x²/4 + x² + 2x + 1 = 1
    - (5/4)x² + 2x = 0
    - 5x² + 8x = 0
  - 第三步：Δ = 64 - 0 = 64 > 0 ✓ 两个交点
  - 第四步：韦达定理。x₁+x₂ = -8/5，x₁x₂ = 0
  - 第五步：弦长公式 |AB| = √(1+k²) · |x₁-x₂|
    - |x₁-x₂| = √[(x₁+x₂)² - 4x₁x₂] = √[(64/25) - 0] = 8/5
    - k=1，√(1+1) = √2
    - |AB| = √2 × 8/5 = 8√2/5
- **易错提醒**：
  - 忘记讨论斜率不存在的情况（直线垂直x轴时不能设y=kx+b）；
  - 联立后整理方程出错（特别是两边乘分母的时候）；
  - 韦达定理的符号——ax²+bx+c=0中，x₁+x₂ = -b/a，负号别丢；
  - 弦长公式里的 √(1+k²) 别忘乘；
  - 大题里一定要写"由Δ>0，直线与椭圆有两个交点"这句话，不然会扣分。
- **话术**："高考一定会以基本方法为主，不需要整那些奇奇怪怪的方法，把基本的联立方法学好就足够了。"
- **高频坑**：很多学生圆锥曲线做不出来，不是思路不会，是联立之后计算算错。所以阿不老师专门讲"计算基本法"——怎么算得又快又准。

---

##### 【方法】圆锥曲线三步法（构图-翻译-计算）

- **构图**：设点、设线、找出关系。关键判断：到底是设点还是设线？题目给的条件更偏向点的坐标关系就设点，偏向直线斜率截距就设线。
- **翻译**：几何图形和代数计算之间互相转化。比如"OA⊥OB"翻译成 x₁x₂ + y₁y₂ = 0；"中点在某条线上"翻译成中点坐标满足直线方程。
- **计算**：通过计算得出结果。
- **理念**："不要一上来就想秒杀大招，高考考的就是通法。"

##### 【方法】正交分解法（受力分析标准流程）

- **适用题型**：多个力作用下的静态平衡问题、牛顿第二定律问题。
- **原理（为什么）**：一个力可以分解成任意两个方向的分力。我们选择互相垂直的x轴和y轴来分解，这样每个方向上的力就可以直接加减（因为垂直方向互不影响）。不管有几个力，拆进坐标轴之后都变成了简单的代数运算，不用死磕平行四边形定则。
- **操作步骤**（黄夫人总结的四步）：
  1. **建系**：选研究对象，建立直角坐标系（x轴沿运动方向或主力方向，y轴垂直）；
  2. **找夹角**：确定各个力与坐标轴的夹角；
  3. **分解力**：把不在坐标轴上的力分解到x轴和y轴上；
  4. **列方程**：沿x轴和y轴分别列平衡方程（或牛顿第二定律方程）。
- **例题演示**：
  一个质量m=2kg的物体放在倾角θ=37°的斜面上匀速下滑，求摩擦力和支持力。（g=10m/s²，sin37°=0.6，cos37°=0.8）
  - 第一步：建系。x轴沿斜面向下，y轴垂直斜面向上。
  - 第二步：受力分析：重力mg（竖直向下）、支持力N（垂直斜面向上，沿y轴）、摩擦力f（沿斜面向上，沿x轴负方向）。
  - 第三步：分解重力。
    - x方向分量：mg·sinθ = 2×10×0.6 = 12N
    - y方向分量：mg·cosθ = 2×10×0.8 = 16N
  - 第四步：列方程。匀速下滑=平衡状态，合力为零。
    - x方向：mg·sinθ - f = 0 → f = 12N
    - y方向：N - mg·cosθ = 0 → N = 16N
  - 答案：摩擦力12N沿斜面向上，支持力16N垂直斜面向上。
- **易错提醒**：
  - 坐标系方向选错——尽量让更多的力落在坐标轴上，减少分解的数量；
  - 分解时三角函数用错——角度是斜面倾角时，沿斜面的分量是mg·sinθ，垂直的是mg·cosθ；
  - 忘记判断运动状态——匀速=平衡（合力为零），加速=牛顿第二定律（合力=ma）。
- **口诀**："第一步建系，第二步找夹角，第三步分解力，第四步列方程。"
- **高频坑**：动态平衡问题（物体缓慢移动）不适合用正交分解硬算，应该用矢量三角形法。

---

##### 【方法】矢量三角形法（三力动态平衡）

- **适用题型**：物体受三个力平衡，其中一个力大小方向都不变（通常是重力），一个力方向不变，第三个力方向变化。
- **原理（为什么）**：三个力平衡意味着三个力矢量首尾相接构成一个封闭三角形。当其中一个力慢慢变化时，这个三角形的形状也跟着变。你把三角形画出来，看边长和角度怎么变，就能判断力的大小怎么变。
- **操作步骤**：
  1. 受力分析，确认是三个力平衡；
  2. 先画大小方向都不变的那个力（通常是重力mg，竖直向下）；
  3. 再画方向不变的那个力（比如绳子始终竖直）；
  4. 第三个力把三角形补封闭；
  5. 看物体移动过程中这个三角形怎么变形，对应判断力怎么变。
- **适用场景对比**：
  - 正交分解法：力多（3个以上）、静态平衡、角度是特殊角 → 用正交分解
  - 矢量三角形法：三个力、动态平衡、一个力方向不变 → 用矢量三角形
- **话术**："受力分析一共两个方法——正交分解法和矢量三角形。静态多力用正交分解，三力动态平衡用矢量三角形。"

##### 【方法】力学整体隔离法（口诀版）

- **口诀原文**："力学问题方法多，整体隔离和假设；整体只需看外力，求解内力隔离做；状态相同用整体，否则隔离用得多；即使状态不相同，整体牛二也可做；假设某力有或无，根据计算来定夺；极限法抓临界态，程序法按顺序做；正交分解选坐标，轴上矢量尽量多。"
- **适用题型**：连接体问题、多物体系统的受力分析和运动分析。
- **原理（为什么）**：两个物体粘在一起运动（加速度相同）时，可以把它们看成一个整体，这样它们之间的相互作用力（内力）就不用考虑了，因为内力等大反向互相抵消。求外力的时候用整体法特别快。但如果要求的是两个物体之间的力（内力），就必须把其中一个单独拿出来分析（隔离法）。
- **操作步骤**：
  1. **先判断**：两个物体加速度是否相同？相同→可以用整体法；不同→必须隔离。
  2. **求外力/加速度**：对整体列牛顿第二定律（只算外力，不算内力）。
  3. **求内力**：隔离其中受力较少的那个物体，列牛顿第二定律。
- **例题演示**：
  光滑水平面上，质量m₁=1kg和m₂=2kg的两个物块紧挨在一起，用F=6N的水平力推m₁，求两物块之间的弹力。
  - 第一步：判断加速度相同（紧挨一起运动），可以用整体法。
  - 第二步：整体列牛二。F = (m₁+m₂)·a → 6 = 3·a → a = 2m/s²
  - 第三步：求内力（两物块之间的弹力N）。隔离m₂（因为m₂只受N，受力少好算）。
  - 对m₂列牛二：N = m₂·a = 2×2 = 4N
  - 答案：两物块之间弹力为4N。
- **易错提醒**：
  - 整体法里内力不能算进去——很多学生把两物体之间的力也加到整体的合力里；
  - 加速度不同时不能强行整体法——比如斜面上下滑的物体和斜面本身加速度就不一样；
  - 求内力时隔离哪个物体有讲究——选受力少的那个，方程更简单。
- **高频坑**：摩擦力存在的连接体问题，要先判断是静摩擦还是动摩擦，再决定能不能整体。

---

##### 【方法】受力分析七力清单（口诀版）

- **口诀原文**："分析受力要仔细，定量计算七种力；重力有无看提示，根据状态定弹力；先有弹力后摩擦，相对运动是依据；万有引力在万物，电场力存在定无疑；洛仑兹力安培力，二者实质是统一；相互垂直力最大，平行无力要切记。"
- **七种力的检查顺序**：
  1. 重力（一定有，除非题目说忽略）
  2. 弹力（接触且有形变才有）
  3. 摩擦力（有弹力且有相对运动/趋势才有）
  4. 万有引力（天体运动）
  5. 电场力（有电场就有）
  6. 安培力（通电导线在磁场中）
  7. 洛仑兹力（运动电荷在磁场中）
- **关键提醒**：
  - 先有弹力才有摩擦力——没有挤压就没有摩擦；
  - 洛仑兹力方向始终垂直于速度方向，不做功；
  - 安培力和洛仑兹力本质上是一回事（一个是宏观导线，一个是微观电荷）。

- **错题记录方法**：不抄题，重点记错因、对应模型和解题思路，定期复盘。

##### 【方法】CSM三步解题法

- **适用题型**：所有高中物理综合题，特别是文字长、条件多、读不懂题的题目。
- **原理（为什么）**：学生做不出物理题，往往不是不会算，是读题之后脑子里没有物理画面。题目写的是一大段文字，你得先把它"翻译"成物理情景——谁在什么地方、受什么力、怎么动的。然后再从这个情景里识别出对应的模型，调用模型的解题套路。就像拼积木：不管题目看起来多复杂，拆开之后都是那几块积木（模型）在不同位置的组合。
- **操作步骤**：
  1. **C（Comprehend/阅读题干）**：逐句读题，提取关键信息——研究对象是谁？已知量有哪些？求什么？
  2. **S（Situation/建立情景）**：在脑子里（或草稿纸上）画出物理图景：物体长什么样、怎么放的、怎么动的、受什么力。把冰冷的文字变成动态画面。
  3. **M（Model/识别模型）**：这个情景对应哪个经典模型？传送带模型？板块模型？平抛模型？圆周运动模型？识别出模型后，直接调用该模型的标准解题流程。
- **例题演示**：
  题目："一个物体轻放在匀速运行的传送带上，经过一段时间后与传送带共速，求物体在传送带上留下的痕迹长度。"
  - 第一步（C）：研究对象=物体；已知=初速度为0、传送带速度v、动摩擦因数μ；求=痕迹长度。
  - 第二步（S）：物体刚放上去时速度为0，传送带在动，所以物体相对于传送带向后滑，摩擦力向前，物体加速。等物体速度加到和传送带一样快时，两者没有相对滑动了，痕迹就不再变长。
  - 第三步（M）：这是"传送带模型"——刚放上去的加速阶段。
    - 物体加速度 a = μg（摩擦力提供）
    - 加速到v的时间 t = v/a = v/(μg)
    - 这段时间内物体的位移 x₁ = (1/2)at² = v²/(2μg)
    - 传送带的位移 x₂ = vt = v²/(μg)
    - 痕迹长度 = 相对位移 = x₂ - x₁ = v²/(2μg)
- **易错提醒**：
  - C环节漏条件——题目里每个数字都有用，没用的话可能是你漏了；
  - S环节画面感不强——特别是多过程问题（先加速后减速、先上升后下落），要画v-t图辅助；
  - M环节模型认错——传送带的"倾斜传送带"和"水平传送带"解法不一样，斜面的角度要考虑进去。
- **比喻**："受力分析就像给物体穿衣服——重力是内衣（一定穿），弹力是外套（有接触才穿），摩擦力是鞋子（走路才有）。一件一件穿，别漏也别多穿。"
- **话术**："见题有思路，解题有模型。模型背后必有规律，看破题目复杂的文字和情景，拆解出背后不变的模型。"

#### 11. 夏梦迪（高中物理名师，体系化教学）

**讲法定位**：体系化极强，被称为T0级老师。从根本上解决"画不出图、没思路"的问题。49道母题破解变式题。

##### 【方法】刷题四步法

- **适用场景**：所有物理刷题阶段，帮学生搞清楚"刷了很多题但没效果"的问题。
- **四个层次（从低到高）**：
  1. **见过**：这个题型我做过，知道大概长什么样；
  2. **想明白过**：不仅做过，还搞清楚了思路是什么、为什么这么做；
  3. **能算对**：思路有了，计算也能跟上，结果算不错；
  4. **快**：又对又快，考试时间够用。
- **原理（为什么）**：很多学生刷题只停留在第一层"见过"，做了就忘，下次遇到还是不会。真正有效的刷题是一层一层往上走：先见个面→再想明白→再算对→最后练速度。跳层是不行的——你连思路都没想明白，刷再多题也只是机械重复。
- **操作建议**：
  - 第一遍：按知识点做题，不追求速度，追求"想明白"；
  - 第二遍：同类题集中做，追求"能算对"；
  - 第三遍：限时做套卷，追求"快"。
- **话术**："刷题到底应该怎么追求？第一个追求是见过，第二个追求是想明白过，第三个追求是能算对，第四个追求是快。"

##### 【方法】连接体模型——整体隔离法标准推导

- **适用题型**：两个或多个物体连接在一起（绳子、弹簧、靠在一起），求加速度、内力、外力。
- **原理（为什么）**：当两个物体相对静止（加速度相同）时，它们之间的内力大小相等方向相反，对整体来说合力为零，所以可以把它们当成一个物体来分析。这就是整体法的依据。但要求内力（比如绳子拉力、接触面弹力）时，内力在整体法里被抵消了，求不出来，所以必须隔离一个物体单独分析。
- **操作步骤（赵玉峰强调要自己能推导）**：
  1. 先判断：各物体加速度是否相同？相同→整体法可用；
  2. **整体法求加速度**：对整体列牛顿第二定律，外力之和 = 总质量 × 加速度；
  3. **隔离法求内力**：选受力较少的物体隔离，列牛顿第二定律；
  4. 联立求解。
- **例题演示**（光滑地面连接体）：
  质量m=1kg和M=2kg的物块用轻绳连接，放在光滑水平面上，用F=3N的力拉M，求绳子拉力T。
  - 第一步：加速度相同，可以用整体法。
  - 第二步：整体列牛二。F = (m+M)·a → 3 = 3·a → a = 1m/s²
  - 第三步：隔离m（m只受绳子拉力T，受力少）。对m列牛二：T = m·a = 1×1 = 1N
  - 答案：绳子拉力T=1N。
  - 拓展：如果地面不光滑（动摩擦因数μ=0.1）呢？
    - 整体：F - μ(m+M)g = (m+M)a → 3 - 0.1×3×10 = 3a → 0 = 3a → a=0（不动了）
    - 这种情况要先判断动不动。
- **易错提醒**：
  - 有摩擦力时要先判断物体动没动——静摩擦和动摩擦算法完全不同；
  - 滑轮连接的问题，两个物体加速度大小相等但方向不同，要注意方向；
  - 绳子张紧才有拉力，松弛时拉力为零。
- **话术**："先把模型的基本核心思路掌握，基本的推导过程自己能推导出来。推导的过程实际上就是在夯实基础的过程。"

##### 【风格】"邪修技巧"系列——快速判断法

- **"缓慢"=平衡**：题目里看到"缓慢"两个字，就说明系统时刻处于平衡状态（速度趋近于零，加速度为零），直接按平衡问题做。
- **竖小平大**：竖直方向的力变化和水平方向的力变化规律（动态平衡中常用的快速判断口诀）。
- **v-t图像降维法**：传送带问题、追及相遇问题，画v-t图像直接看面积和斜率，比列方程快得多。
- **核心理念**：技巧是辅助，基础推导才是根本。"邪修技巧"用来选填提速，大题还是要老老实实写步骤。
