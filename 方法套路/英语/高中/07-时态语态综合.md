# 时态语态综合：时间轴+主被动判定法

---

## 方法：时态语态"时间轴定位+主被动判断"综合法

### ① 方法名
高中时态语态综合判定法

### ② 适用题型
单项选择、完形填空、语法填空、短文改错

### ③ 原理（语法 form 与意义 use）

**语法形式（form）层面：**
高中阶段需要掌握的时态共16种，核心8种：

| 时态 | 主动形式 | 被动形式 |
|------|---------|---------|
| 一般现在时 | do/does | am/is/are done |
| 一般过去时 | did | was/were done |
| 一般将来时 | will do | will be done |
| 现在进行时 | am/is/are doing | am/is/are being done |
| 过去进行时 | was/were doing | was/were being done |
| 现在完成时 | have/has done | have/has been done |
| 过去完成时 | had done | had been done |
| 过去将来时 | would do | would be done |

**意义（use）层面：**
判断两步走：
1. **时间定位**：动作发生在"现在/过去/将来/过去的将来"哪个时间点/段？
2. **体貌判断**：动作是"一般（经常/事实）/进行（正在）/完成（已完成影响现在）"？
3. **主被动判断**：主语是发出动作还是承受动作？

### ④ 操作步骤

1. **第一步：找时间状语/时间线索**——确定时间锚点（现在/过去/将来）
2. **第二步：判断动作体貌**
   - 经常性/习惯性 → 一般体
   - 正在进行 → 进行体
   - 已完成、对现在有影响 → 完成体
3. **第三步：判断主被动**——主语和动词的关系
4. **第四步：主谓一致检查**——主语单复数决定 be 动词/助动词形式

### ⑤ 例题完整演示

**题干：**
By the end of last year, another new gymnasium ______ in Beijing.
A. had been completed  B. was completed  C. has been completed  D. would be completed

**分析过程：**
- 第一步：时间标志词 By the end of last year（到去年年底为止）→ 过去的过去
- 第二步："by + 过去时间" → 过去完成时
- 第三步：gymnasium（体育馆）是"被建成"的 → 被动语态
- 第四步：过去完成时被动 = had been done
- 验证：到去年年底为止，又一座新体育馆在北京建成了。

**答案：A**

**规则套用过程：**
by + 过去时间 → 过去完成时；体育馆被建 → 被动 → had been completed → 选 A

### ⑥ ❌ 易错提醒

- **by + 将来时间 → 将来完成时**：By the end of next year, we will have finished the project.
- **过去完成时必须有"过去的过去"参照点**——不能单独用，必须有一个过去时间做参照
- **被动语态别忘了 be 动词**：The project was completed last month.（不是 The project completed...）
- **瞬间动词没有进行时和完成时的持续用法**：join/die/buy/borrow/arrive 不能和 for/since 连用
  - 误：He has joined the army for 3 years.
  - 正：He has been in the army for 3 years. / He joined the army 3 years ago.
